## 回归扫查（全部是我自己操作出来的帧）

- **两个首屏**：参加者首屏 lead 是唯一主角（42px Cormorant 时间 + 宋体局名 + 红粉笔倒计时 + 靛蓝织带 CTA），其余行是白标 / 时间 / 局名 / 副文 / 入口，层级清楚；局主首屏 lead 是「审核申请」裁片（`homes/stills.png`、`coverage/j-home`、`h-home`）。

- **打印**：吊牌从右侧布边下分三次抽出，有停顿，再系线打结；挂牌中提示「挂牌中 · 吊牌从布边下抽出，一停一抽」，行动区没有可点按钮；落定后票面清晰（`ticket/print-zoom.png`）。成局后出票：阅读约定滚到底 → 确认入局 → 「撕开，联系局主」+ 挂牌（`scrub-confirm/f13–f31`）。
- **撕票**：拉 14px 释放回弹（`ticket/drag-zoom.png` 第一行）；拉过阈值后先写入（「线绷紧了 · 正在记录」），线断、线头回弹，吊牌带旋转落进存根袋，最后联系白标展开（`tear/release.png`）。
- **0.5× 取消燃烧**：订单簿裁片从角上起火，焦边推进，灰线轮廓 + 作废章，成员 void；返回落到「历史 · 已取消」（`cancel/`、`cancel-return-rec/`）。
- **散场 + 出席**：记为散场 → 出席 tab；逐人记录、更正、轨迹；计数「出席 3/4」「1 人出席未记录」；返回后局主列表变成「已散场 · 1 人出席待记录」（`end-attend/`）。
- **草稿撤销**：删除 → 行收起 → 空态 + 撤销条 → 撤销 → 回原槽；摘要内删除同样；10s 后自动提交（`drafts/f27`）。
- **空态 + 长标题**：七种空态是完整构图（`coverage/b-empty`、`b-empty-h`、`b-drafts` 等），只有一场 / 只有草稿 / 待处理较多 / 当前较多都正常；长标题两行省略，折叠顶栏单行省略。
- **失败 → 重试**：发出邀请失败在来样布片内写「本机保存失败，请重试 [重试]」，重试成功；撕票失败时吊牌回弹，写「未能保存，请重新撕下副券」，重试后落袋；读取失败；记为散场失败在弹层内显示 + 重试（`fail-retry/`）。

## 其他观察（不计入缺陷）
