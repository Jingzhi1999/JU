## 通过的项目（有证据）

- **第一眼与层级**：lead 裁片是唯一主角（42px Cormorant 时间 + 24px 宋体粉线蓝局名 + 红粉笔倒计时 + 基线针脚 + 靛蓝织带 CTA）；其余行只有白标 / 时间 / 局名 / 副文 / 「动词 ›」，时间、地点、状态、行动不在同一层级（coverage/j-home、h-home）。
- **一套系统、两种角色**：参加 / 发起共用裁片、白标、粉笔组头、布边底栏；票件是吊牌、名单是针脚 + 记号表、管理是订单簿账本、弹层是翻起的布角，形态与职责不同；与其余九套在构图、字体、组件、材质、过渡、核心动作六维都不同。
- **详情 / 管理与首页同等质量**：详情 = 同一张裁片沿折线翻开；订单簿头部仍是裁片，账本标签页 + 区块；sticky 顶栏滚过 96px 后局名单行省略升入栏内（collapse/f02、f04、f07）。
- **出票**：吊牌从右侧布边下三次抽出、两次停顿，再系线打结，挂牌期间行动区占位不可点，落定在粉线叉下（ticket/f01–f15，confirm/f09–f17）。
- **撕票**：拖拽跟手；拉 14px 释放回弹（ticket/f16–f21）；过阈值后写入先于落袋（「线绷紧了 · 正在记录」f32），线头回弹 + 纤维（f34），吊牌带旋转落进存根袋、仍可读（f35–f41），联系白标从吊牌下翻出（f45），列表变「已撕 · 吊牌归你」。
- **燃烧**：同一张吊牌 / 裁片从角点起火，焦边推进、灰烬随火线出现、灰线轮廓紧跟焦边浮出，烧完是带两道焦痕的轮廓，版面不再移动（exit-burn/f20–f42，resched-decline/f12–f36，cancel/f24–f44 共 21 帧，history/f03–f12）；已取消的首次打开烧一次，再开静态（history/f19）。
- **结果与返回**：撤回 / 退出 / 拒绝改期 / 接受改期 / 审核 / 改时间 / 散场 / 取消都有原位结果；返回时如果换了分区，会先切过去再落到原行（withdraw/f20、exit-burn/f46、resched-decline/f42、resched-accept/f30、ticket/f58、cancel/f48）。
- **计数**：发出邀请后待审 2→1、预留 1→2、空 2→1、多一针，组头「已处理 1」；谢绝后「已谢绝 · 对方会看到「这次没留住」」，申请 √（approve-reject/f08–f24）；改时间后「改期答复 已答复 0/4」、头部「4 人未答复新时间」、局卡条 20:15（resched-sheet/f16–f24）；出席「出席 3/4 · 1 人出席未记录」+ 更正轨迹「更正 出席 → 未出席」（end-attend/f26）；拒绝改期后席位 4/5、「你已离开 · 席位已释放」（resched-decline/f39）。
- **失败与重试**：全部失败都显示在发生的地方，文案按清单写；重试成功（fail-retry/f06、f16、f29、f35、f38、f41）。
- **空态 / 边界**：七种空态 + 读取失败「读不出 · 本机记录暂时读不出来 · 重新读取」；只有草稿时显示「草稿还在 / 接着改草稿」；长标题在列表里 2 行省略，在详情 / 订单簿里 3 行，折叠顶栏单行省略（variants、collapse/f07）。
- **语义**：没有信用分；八种没成行各写各的状态词与副文（hist1/hist2 = coverage/j-d-*）；候补里的他人显示 `L**`；局主微信只在撕票后可见；`gathering` 没有退出；未出席写「待核实 · 不自动处罚 · 可更正」；主动退出写「占同一账户每年 4 次机会之一（只陈述，不评分）」。
- **面板**：索引 50/50、1× / 0.5×、关键帧滑杆双向可拖（scrub/f05–f11）、释放后续跑、重播会复原整张吊牌再烧（f19–f26）、暂停、重置、变体、下一次保存失败都能用；减少动态下所有动作直接到结果态（rm）。
- **快速连点**：stress 全部 17 帧无吞层、无半开层、无假失败；连点只写入一次；燃烧中返回再打开，显示的是烧完的状态。草稿撤销条 10s 后自动提交（探针：9.8s 仍在，10.6s 已提交）。

## 缺陷

### Major

**M1 · 列表票件行：小吊牌压在行内入口文字上** — 局名只有一行的票件行（待撕票 / 待联系 / 待赴约），右侧的小吊牌图标盖住了「撕开票根 ›」的「根」字和「联系局主 ›」的「主」字。默认首屏就能看到。证据：`homes/f02`（放大：吊牌压在「根」上）、`confirm/f22`（11:30、09:00、15:00 三行）、`ticket/f58–f60`、`coverage/j-home.png` 底部一行。
修法：给小吊牌一个固定的右栏，行内入口 `padding-right ≥ 34px` 并 `white-space:nowrap`；或者把吊牌放在入口上方的固定 y 位置，不随局名行数变化。

**M2 · 历史 · 散场行：出席白标叠在状态白标上** — `.c05-att`（absolute，right 22 / top 46）叠在 `.c05-lab.kept「已散场」`上。探针：状态白标 left 512 / w 60，出席白标 left 524 / w 48。结果是：出席 / 未出席行左边多出一组针脚；局主还没记录的行，「等章」虚线标是透明底，下面的「已散场」透出来，读起来像「鄢散场」。证据：`coverage/j-history-many.png`（第 3 行 读书会 · 《秋园》；第 1 行 周五爵士小酒馆）、`fail-retry/f39`、`coverage/j-history.png`。
修法：一个角只放一枚白标。散场行要么只留出席白标，状态文字按 §0「文字四角色」写在文字栏；要么把出席白标移到自己的位置（状态白标下方或行动列）。`.c05-att.none` 改用不透明布底。

**M3 · 返回历史行时，飞行物件透字或换材质** — (a) 局主取消后返回：飞回去的是无底色的灰线轮廓，约 620ms 的飞行里下面模糊列表的字透过来，两层字叠在一起（`cancel/f47`：「德州扑克新手桌 / 已取消 · 不能撤销… / 查看完整局卡」压在「已散场 1 · 13:00 看展搭子」上）。(b) 参加者退出 / 拒绝改期后返回：飞的是不透明的漂白布裁片，落进未成行组的轮廓行时一帧换成灰线轮廓（`exit-burn/f45→f46`、`resched-decline/f41→f42`）。这两处都在最重要的三个流程收尾，违反“前—中—后同一物件、同一材质”。
修法：作废行的飞行物件用轮廓材质，但垫一层不透明台面色底（cloth3 ≈ .95）；或者飞行中把漂白布逐渐褪成轮廓，落点时材质已经一致。

### Minor

- **m1 · 落点交接闪一下** — 覆盖层约 670ms 卸载后，目标行才从 opacity 0 用约 250ms 淡入。探针：671–696ms 为 0，719ms 0.10，926ms 0.95。所以不透明的裁片消失后，会先看到一张半透明的行（`land-1x/f03→f04`、`land-slow/f05–f08`）。另外飞回去的头部高 116px、没有需求行，目标行高 128px，形状在落点处跳一下。修法：去掉 `.landing` 的 0→1 淡入，同一帧交接；飞行头部渲染与行相同的内容和高度。
- **m2 · 改时间弹层收起时换成了新数据** — 提交成功后，收起中的弹层显示「原定 ~~周四 12.24 · 20:15~~ → 周四 12.24 · 20:15」+ 红字「新时间和原时间一样…」+ 禁用的按钮（`resched-sheet/f15–f16`）。修法：提交时把弹层内容存一份快照，phase 'out' 期间渲染快照；成功后不再显示校验文字。
- **m3 · 中文断行** — 长标题订单簿头部「第一次开门请多包 / 涵 · 来的人都有一杯」把一个词拆开（`variants/f20`，360 宽 `width/f06`）；账本日期「SAT 12.19 / · 20:30」换行（`variants/f21`）；360 宽列表「…21:30 · 旧牌不 / 能用」孤字（`width/f00`）。修法：按「 · 」分词放进不断行 span（`word-break:keep-all`），账本日期和「旧牌不能用」加 `nowrap`。
- **m4 · 改期的新时间重复出现** — 详情里 21:30 出现了三次：头部副行「改为 周五 12.18 · 21:30」、需求行、新吊牌上（`coverage/j-d-reschedule.png`）。列表行的时间列写旧的 20:30 却没有删除线，下面又写「改为 新」（`homes/f00`）。G10 要求新时间只出现一次、旧时间只在一处带删除线。修法：详情头部只写「局主改了时间」，新时间只留在新吊牌上；列表时间列的 20:30 加删除线。
- **m5 · 毛刺像一个符号** — 拉线到 p>.75 时，线中段出现一个类似星号的小记号（`ticket/f28–f33`，放大图），不像断点处的纤维；真正的纤维要等断开后才出现（f34）。修法：亮股从结处逐渐变细；断点处画 3–5 根张开的短纤维，长度随 p 增加。
- **m6 · 焦边是一个整圆在扩大** — 焦边几乎是正圆弧，从一个角推进（`exit-burn/f24–f34`、`cancel/f28–f40`），看起来更像纸而不像起毛的布边。修法：2–3 个错位的圆或噪声位移，加大毛边尺度，边缘加纤维须。
- **m7 · 360 宽：吊牌右侧被布边盖住** — 「跑完喝咖啡」「集合 08:50 门口」和票号被裁掉（`width/f01`），builder 已自报。修法：吊牌几何随容器宽度缩放，或在 <380px 时减少布边的覆盖。
- **m8 · 没成局的成员写了「票根作废」** — 德州扑克（未成局 2/6）取消后，成员 Ivy 写「票根作废 · 取消前已确认」（`cancel/f36–f46`）。这局从来没出过票，按 G8，撕票 / 票根的说法只在出票后出现。修法：未成局时写「取消前已确认 · 未出票」。

## 其他观察（不计入缺陷）

- 默认数据「待处理较多」下徽标是参加 4 / 发起 3，来自 core 数据（`JU.derive`），不是本方案的问题；E 表写的 6 / 5 需要主负责人对齐。
- 「退出候补」加了一个二次确认层（用的是 core 的 `JU.COPY.leaveQueue`），没有惩罚性文字。
- 新发出的预留显示「剩 06:00:00」（清单示例是 05:59:59），属于静态时钟。
- 吊牌在存根袋里被袋口遮住下半部分，这是有意的“收进袋里”，可读性不受影响。
