## Major
1. **出票时纸看不见：前大半段只有一片和页面同色的空白，最后才「显影」。** `.c09-blank`（页面底色 `--page`，盖住整张票包括黑边）的 `clip-path: inset(X% 0 0 0)` 从上往下收，但票是从出纸口**下沿先出来**的，所以露在外面的永远是被 blank 盖住的部分，墨迹揭到的部分还在出纸口里。探针（0.5×）：t=3.24s 票 `translateY −115px`（露出 85px），blank `inset(38.8%)` 覆盖票 y 77→200，正好盖住全部露出部分；直到 t≈5.4s 才开始看到字。截图：print f12–f26 出纸口下是一块没有边框、没有字的浅色区域，f27–f29 字才从出纸口往下长出来，f30 落定；confirm f06–f10 同样（确认入局即成局后出票）。§6 要求「物件从明确的出口逐步露出、露出—停顿—再露出」——节奏写在 keyframes 里，但纸本身看不见，读起来是「空白 → 突然一张票」。**修复**：blank 改成从**下往上**收（`inset(0 0 X% 0)`），或者干脆把墨迹揭示绑在出纸口线上（blank 的上沿 = 出纸口位置，跟纸走），并且 blank 不盖黑边与票框（只盖内容层），让走纸时能看到纸边和票框。
2. **退出 / 拒绝改期 / 撤回的写入失败：确认层直接关掉，失败提示落在首屏外，而且排版塌成一列竖字。** 面板「下一次保存失败」→ 确认退出：确认层关闭，票不动，屏幕上没有任何反馈；alert 实际渲染在详情底部（探针 alert top=1345，手机下沿 940）。滚到那里看，`.c09-acts .c09-btn{width:100%}` 把 alert 里的「重试」也撑成整宽，文字 span 被挤到一个字宽，「本机保存失败，请重试」变成竖排，重试按钮压在字上（fail-leave f03 放大、f13；fail-retry f20–f25 失败后画面毫无变化）。拒绝改期同样（fail-leave f07–f13）。D 表要求：退出写入失败「停在确认层」，拒绝失败「层内 `保存失败，尚未退出…`」。**修复**：失败时不关确认层，把 alert 放在确认层按钮上方（与申请行同一套 `.c09-ialert`）；把规则改成 `.c09-acts > .c09-btn{width:100%}`，别命中 alert 里的按钮。
3. **快速连点「发出邀请」/「谢绝」出现假错误。** 同一行连点三次「发出邀请」：结果行「已发出邀请 · 等对方确认」出来了，但同时冒出粉色「这份申请已经处理过。重试」（stress f07–f08）；「谢绝」同样（探针 alerts=["这份申请已经处理过。重试"]）。点「重试」没有意义。第 1 轮 #7 只修了草稿删除，这一类没有统一处理。**修复**：行进入处理中就禁用两颗按钮、同一申请 id 只发一次写入；engine 回「已经处理过」时静默忽略，不当成可重试的失败。
4. **弹层关闭定时器没清：快速「关闭 → 再打开」后，刚打开的弹层自己消失。** `closeSheet()` 用 `after(340)` 卸载弹层，`openSheet()` 不取消它。操作「去不了了 → 继续赴约 → 去不了了」（间隔 50ms）：重新打开的「退出这局？」滑进来一半，340ms 时连同遮罩被直接切掉，没有收起动画（sheet-vanish f01–f04；探针 view.sheet='exit' 到 331ms，395ms 时 sheet=null）。局卡弹层同样：查看局卡 → 关闭 → 查看局卡，最后没有弹层（stress f10–f11）。这是简报点名的「快速连点后半开 / 卡住的层」。**修复**：`openSheet` 时取消挂起的卸载定时器（保存 `this._sheetT` 并清掉），或在卸载回调里检查 `sheetPhase === 'out'` 再卸。
5. **拒绝改期后的结果自相矛盾：说「席位已释放」，名单却还写「阿禾（你）已确认 · 5/5」。** resched-decline f35–f38：残片下方「已退出 · 拒绝改期 · 席位已释放」，再往下名单 5/5，自己仍是「已确认」贴纸（探针 seats `阿禾:ok(you)`，stage=`declined`）。退出（exit f38）就正确变成「名单 3/4」且没有自己。G9 计数口径与 C8「拒绝：席位变空位」都要求一致。根因是共享 engine 的 `declineReschedule` 没改成员状态，但画面是 C09 的。**修复**：C09 在 `declined` 时从名单剔除自己并把席位显示为空位（或请主负责人在 engine 里补 `you(it).status='declined'`，十套一起受益）。

## Minor
1. **撕起 / 贴回的过渡还有重叠与重影。** 打开 f01：覆盖层裁切下沿正好切过下一行列表的局名，「名单 2/3」和被切了一半的「周四 Livehouse」字形叠在同一行（detail-half f01 放大）。关闭 f15：贴纸复制层半透明淡入时盖在详情上，「周六早午餐 · 只聊不卷」「11:30」「已预留」各出现两份，一实一虚（detail-half f15 放大）。关闭时详情的黑色吸顶页头会在列表中间漂一帧（detail-half f14、resched-accept f25、reschedule f18）。**修复**：裁切下沿对齐行与行之间的缝；关闭时复制层先不透明再落（或详情内容在复制层开始落时先淡出 120ms）；关闭阶段把 `.c09-dh` 一起裁进去或先隐藏。
2. **取消落定时管理页头一帧跳 72px。** 烧完换成焦边空白页时，页头高 242→170、下面的页签与成员区一帧上移 72px（探针 chips top 438→366，两次 20ms 采样之间；cancel f36→f37）。**修复**：焦边页与燃烧页同高落定，或给高度 / 下方内容一个 260ms 收拢。
3. **取消后的管理页：作废成员还在倒计时，局卡条消失。** Leon「取消前已预留 · 剩 05:02:00」（cancel f37、coverage `h-m-cancelled` 同类），预留已随取消结束，不该再有剩余时间。局卡条（缩略 + `查看局卡`）在取消后整个不见了，C1 要求它始终在、C12 应能打开灰掉的局卡。**修复**：void 成员去掉 `剩 …`；焦边页里保留抽色的局卡缩略与「查看局卡 ›」。
4. **预留到期详情副文写成了「条 00:00:00」。** 「预留到期未确认 · 位置已补给他人 · 条 00:00:00」（coverage `j-d-expired`）——把清单里「展开：条 `00:00:00`」（指进度条显示 00:00:00）照抄成了文案。**修复**：画一条空的胶带进度条 + `00:00:00`，副文去掉「条」。
5. **历史较多没有月份标题。** `ds_many_history` 要求跨月出月份标题；C09 散场组 12.12 / 11.22 / 11.14 跨两个月，只有「散场 3」「未成行 8」两个组头（探针；scroll-many f06–f08）。**修复**：散场组内按月插一条影印小条「12 月 / 11 月」。
6. **身份切换时选中的本子比内容晚换。** 点「我发起的」后，旧本内容淡出的那几帧里，页头仍是「我参加的」选中（home f05），换本完成才翻过去。F03 要求语义当帧切换。**修复**：点击当帧切选中态，内容再做换本。
7. **撤回申请没有物件动作。** 确认后结果块直接出现（「已撤回申请」），没有清单 D 表 `p_exit` 撤回里的信封 / 回执一类过程（withdraw f05–f13），和退出、拒绝改期的燃烧相比是唯一一个没有「过程」的结束动作。**修复**：用一张便签贴纸被撕下、折起盖住局卡缩略即可，同材质、300–400ms。
8. **管理页的「贴纸纸」只是名字。** 方向卡写「管理 = 一张贴纸纸，审核 = 撕下贴纸贴到人名旁」；实际是两颗按钮 + 结果贴纸拍上去（approve f08、f22）。主负责人第 1 轮也指出十套申请审核结构雷同。**修复**：「发出邀请」做成页侧一排可撕的荧光贴纸，点 / 拖时贴纸从贴纸纸上揭起、飞到人名旁落定，按钮只做键盘 / 读屏兜底。
9. **toast 压在名单行上，「已加微信」还多了一条清单里没有的 toast。** 「已记录加微信 · 按最终时间赴约」与「已接受改期 · 按新票根的时间见」都落在名单上，盖住「小面」「Momo」那一行（tear f41–f44、resched-accept f30）。改期接受的 toast 是清单规定的，但「已加微信」成功按 C 节 / G12 不该出 toast（便签里已经换成「已加微信 · 等这次见面」）。**修复**：去掉「已加微信」的 toast；其余 toast 的落点抬到底栏之上、名单之外的空白，或在联系便签下方原位出现。
