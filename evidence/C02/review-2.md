## Major

### 1. 票面层 / 联系层返回列表时叠印

**现象**

- 从票面或联系层返回列表时，联系条、卡、读卡器不参与翻出，一直完全不透明，直到卸载那一帧。
- 与此同时，列表与底栏已经开始显现。
- 结果是两层可读文字叠在一起。

**证据**

- `resched-accept/f39`（1×）：「局主 老杨 laoyang.ju 复制 / 已加微信 · 等这次见面。」整条压在底栏「找局 开局 我的局 设置」上。
- `contact-back/f04–f06`（0.5×）：
  - 牌头行飞回时从卡与读卡器上滑过。
  - f05 卡仍完整、联系条仍可读。
  - f06 联系条「局主 蛋挞 dantat.coffee 复制」停在已落位的行上方，底栏在它下面半透明显现。

**与规格不符**：spec/motion/C02.md M4 的「严格分段返回」只对成员视图成立。

**修法**

- 把 `.c02-gate`、`.c02-contact`、改期旧票、作废结果牌都纳入 `.c02-drow`（或单独给它们 `c02-dout`），让它们与牌面行一起 rotateX 加透明退场。
- 列表 `unblank` 一律等票面层透明度到 0 之后再开始。

### 2. 返回落点行落在固定底栏下面

**现象**

- 返回时用 `scrollIntoView({block:'nearest'})`，没有扣掉 92px 的钢轨底栏。
- 换组后的落点行，以及索引进入后的落点行，都有一半被底栏盖住。
- 被盖住的正好是 1.4s 琥珀落点标记所在的行。

**证据**

- 自然流程：`resched-accept/f40–f45`。接受改期后这局移到「就快见面」，「21:30 周四 Livehouse 待赴约」的日期行与状态行在底栏下面。
- 索引进入：`land-nav/f02`（h-m-members → 返回，「19:30 自然酒小试 · 六款」）、`land-nav/f04`（j-d-going → 返回）。
- 实测数据：行 bottom 912 > 底栏 top 862。

**修法**：落点滚动改为「行底 ≤ 滚动区可视底 − 底栏高 − 12px」（scroll-margin-bottom 或手算），并且先滚、再飞回。

### 3. 列表局名单行截断（主负责人第一轮「高」，未处理）

**现象**

- 默认数据里，列表行和详情牌头的局名都被单行省略：
  - `coverage/j-home.png`：「周四 Livehouse · 散场后…」
  - `coverage/j-d-going.png` 牌头、`land-nav/f04`：「外百老汇小剧场 · 一起…」
  - `b-long.png`：局名被截到只剩一半。
- 与此同时，地点副信息反而没有省略号，直接在字中间截断：`b-long.png` 第 2 行「…KNICKERBOCKER 大道与 TROUTM」。

**与规格不符**：state-inventory E `ds_long` 要求「局名 ≤2 行省略；只有地点可省略」。现在正好反过来。

**修法**

- 行内局名改为两行（行高随之 +18px），状态翻片放到时间格同一行右侧或第二行末，翻片只承担时间与状态。
- 副信息行 `text-overflow: ellipsis`，只省略地点。

### 4. 作废残骸读起来像一块棕色污渍（主负责人第一轮「中」，未处理）

**现象**

- 过热的焦痕是一个从卡底中点长出的正半圆。
- 边缘是毛茸茸的棕色，内部再嵌 5 颗像珍珠的灰白玻璃珠。
- 落定后盖住卡面下半，读起来像泥 / 毛皮 / 污渍，不像受热的塑料。

**证据**

- `resched-decline/f35`（放大）、`exit/f24–f35`、`cancel/f26–f36`、`coverage/h-m-cancelled.png`。
- 方向卡写的「磁条处焦黑、磁条断裂」看不到：磁条在槽内。
- 裂纹 `.c02-crack` 在任何帧里都没有可辨识的断口。

**修法**

- 焦痕沿磁条 / 槽口方向横向扩散：用椭圆或带状 mask，比如 `ellipse 160×40` 先沿底边走、再向上舔。
- 颜色改为塑料焦化：黑褐中心 → 琥珀褐 → 发黄熔边，少用暖棕绒毛；起泡改成半透明鼓包，加高光与暗边，不要实心灰珠。
- 残骸态把卡推出槽口 15–20%，露出断开、翘起的磁条。
- 裂纹加宽到能看见。

### 5. 草稿摘要与草稿行丢了左边距，文字贴着屏幕边

**现象**

- 「草稿摘要」弹层里，局名 / 日期 / 地点 / 席位 / 完成度 / 改于 这些标签的 left = 0，贴着机身边缘。
- 弹层底部的「继续编辑 › · 不在本范围演示」被机身圆角裁掉。
- 列表草稿行的「继续编辑 › · 不在本范围演示」在 x=2，而同一行的局名在 x=16。

**证据**

- `coverage/h-draft.png`、`coverage/h-drafts-many.png`、`drafts/f01–f17`。
- 实测：`.c02-draft .dl` 标签 left 0，`.c02-inert` left 2。

**原因**：`concepts/src/C02.dc.html:564` 的 `.c02-draft{padding:4px 0 0}` 覆盖了 `.c02-sbody{padding:0 18px 12px}` 的左右内边距；草稿行的 `.c02-dracts` 本身没有左内边距（`:129` 只有 `padding-left:2px`）。

**修法**：
- 把 `:564` 改为 `padding:4px 18px 12px`。
- `.c02-dracts` 改为 `padding-left:16px`，与行文字对齐。
