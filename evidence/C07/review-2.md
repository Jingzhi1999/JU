## Major

### M1 草稿删除没有"原位收起"，撤销时格子从网格左上角飞出、压在别的草稿上
- **证据**：`draft-undo2/` f03→f04：「冬至火锅」整格在一帧内消失，留一个空槽，下面的「雨天读书局」再用 520ms 上移（f04–f07）。撤销 f12–f13：一个缩小的「冬至火锅」幽灵格出现在网格左上角、叠在「未命名的局」上，再斜着长大飞回原槽。构建者自己的 `evidence/C07/draft-undo/` f02→f03、f09 是同一现象。
- **探针**：删除后 +275ms，该格 rect 从 `top 494 · 358×144` 跳到 `top 300 · 2×2`（网格原点）再淡出；撤销时从 `44×18 @ y326` 用约 470ms 长到 `358×144 @ y494`。
- **根因**：`C07.pack()` 给 off 格的 left/top/width/height 都是 0，而 `.c07-tile.off` 的 transition 只列了 opacity / transform / visibility，于是几何量瞬间归零；回来时 `.landed` 的几何过渡又从 0 起步。
- **为什么是 major**：M10「草稿删除、相邻内容让位、撤销恢复」与 H 组合规则「行原位收起 / 展开 260ms → 原槽位展开」都没有成立；被删的物件没有过程，撤销的物件起点错误且遮挡邻格。
- **怎么修**：off 格保留最后一个槽位的矩形（不要归零），在原位做 260ms 收起（height→0 或 `clip-path: inset(0 0 100% 0)` + opacity）；撤销时先把格放回原槽、从 scaleY(0) / inset 展开，邻格同步让位。

### M2 格子重排的落点：收回的详情落进一张显示"写入前状态"的冻结格，两层文字重叠，状态回退约 200ms
- **证据**：
  - `confirm-reflow/` f27–f29（1×）、`confirm-reflow-half/` f05–f08（0.5×）：确认入局后详情已经是「待撕票 11:30 · 撕开，联系局主」并打印了票；返回时它收进一张写着「已预留 04:21:00 · 预留到期前阅读约定并确认 · 阅读并确认」的格子，f06 两层同时可见（11:30 的白色残影压在 04:21:00 下、「Brooklyn · 威廉斯堡」重复两遍），然后才重排成 2×1。
  - `resched-accept/` f30（放大）：接受新时间后收回的格仍是「待确认新时间 · 原定 20:30 · 改为 21:30 · 答复新时间 ›」，上面压着白色大字「21:30 / 周四 Livehouse · 散场后吃宵夜」。
- **为什么是 major**：这是方案的核心动作 ①。§0 要求"同一物件在运动前后身份连续"、"不得留下残影、重叠"；客户在 0.5× 下会清楚看到"刚确认完又变回待确认"。
- **怎么修**：冻结的应当是布局（位置 / 尺寸），不是内容。冻结格用写入后的行数据（新 chip、新时间、新 CTA）按旧尺寸渲染；或者让落地那一帧的格面就是 hero 本身，再由同一节点 FLIP 到新槽。交叉淡化只用在两边相同的文字上。

### M3 中文标题与票面信息的断行：单字孤行、拆开《》书名、把"局主"拆成两行
- **证据（全是默认数据、一级画面）**：
  - 详情 hero 24px：「周四 Livehouse · 散场后吃宵 / 夜」（`resched-accept/` f31、coverage `j-d-reschedule`）；「外百老汇小剧场 · 一起看《海 / 鸥》」（`exit/` f04、coverage `j-d-going`），同一个拆开的《海鸥》也出现在首页宽格（`home/` f04）。
  - 通行证标题：「手冲咖啡品鉴 · 三款豆 / 子」（`detail-open-back/` f03）、「公园慢跑 3K · 跑完喝 / 咖啡」（`print-tear/` f12）。
  - 1×1 格：「法拉盛早茶 · 周日十 / 点」「周末速写 · 画人不画 / 景」（`home/` f04 放大）。
  - 票面 meta：「威廉斯堡 · 集合 19:20 门口 · 局 / 主 你」（`end-attend/` f04、coverage `h-m-members`、`h-m-reschedule`）。
  - 正文：取消操作盘「成员不计主动退 / 出。」（`cancel-half/` f01）。
- **为什么是 major**：客户验收单明确写"中文排版本身要好看"；局名是每一层的主角，最大的 24px 标题上留单字、拆书名号，第一眼就能看到。
- **怎么修**：局名按「 · 」切段，每段 `white-space:nowrap`（只在分隔符处换行），整体加 `text-wrap: pretty`（或 balance）；《…》视为不可拆单元；票面 meta 中「局主 {名}」「集合 HH:MM 门口」各自 nowrap；正文段落加 `text-wrap: pretty` 避免两字孤行。
