## 2. 仍未解决（全部 minor）

- **O1 · 改期详情里新时间仍出现两次**：`coverage/j-d-reschedule`。页头行副本印「21:30 改为 周五 12.18」，新版票又印「21:30」。旧时间已经只剩旧票上的删除线一处，但 G10 要求新时间只出现一次。
  - 修法：详情页头的行副本只保留局名和「改为」小字，或者改印「新时间见下方新版票」。新时间只留在新票上。
- **O2 · 草稿删除失败条的按钮折成竖排**：`fail-retry2` f07、`fail-retry` f19。底部 `.c01-err` 里「取消 / 重试」被挤成「取 / 消」「重 / 试」。fix-r1 只修了单内和便签内的红框。
  - 修法：`.c01-err .c01-btn{white-space:nowrap;flex:0 0 auto}`，文字区 `min-width:0`。
- **O3 · 关闭途中再点同一行会闪一下**：`reopen3` f02–f06。顺序是：详情整页 → 空白纸 → 行副本重新飞入 → 正文再印一遍。
  - 修法：在 `out` 阶段内再点同一行，直接反向回到 `in`，不要从 `start` 重来。
- **O4 · 撕票落定后，名单先上跳再被推下**：`tear-land1x` f06→f07→f10，「N」头像的 y 是 681 → 596 → 753。`tear` f27→f28→f31 也一样。副券落槽后，提示行和副券高度先被移除，名单上跳约 85px；约 100ms 后联系层插入，名单又下推约 157px。票本身没动，但同一块内容一上一下，读作跳动。
  - 修法：让联系层直接接替副券和提示行让出的高度，可以先占位再印墨；或者在联系层出现前保持副券区的高度。
- **O5 · 改时间成功后，退出中的便签闪出红字**：`resched-submit` f07–f08（1×）和 f27–f31（0.5×）。写入成功后，活动时间已经等于新时间，便签按「同时间」重新计算，退出途中印出「新时间和原时间一样，换一个日期或时间才能确认。」。这是成功之后出现的假错误提示。
  - 修法：提交后冻结便签内容，或者在 `slip.out` 阶段不渲染 `same` 提示。
- **O6 · 返回落点换形时的身份跳变**：`exit-burn` f36–f38、`cancel` f39–f45。飞回的行副本是「当前」列表的样式：两行局名，或者普通印刷行。它落在历史里换了形态的行上：单行局名，或者焦条。两者靠 140ms 淡入淡出交接，局名折行在交接那一刻跳了一下。
  - 修法：关闭前把副本换成目标行的样式，或者让副本在途中完成换形。
