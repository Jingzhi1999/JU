## 成立的部分（有证据）

- **第一眼与系统**：目录页的红页码 + 眉注 + 宋体局名 + 引导点行动条，是十套里唯一的浅色编辑版式。跨页的图版现在以中文局名为主（34px），英文缩成 13px 眉注（coverage/j-d-*）。编辑部（管理）和跨页用的是同一套纸、红、线规则（coverage/h-m-*）。和另外九套并排看，构图、字体、材质、过渡都不一样（C01–C10 joined-home 并排）。
- **翻页（M4 / M1）**：绕书脊的 3D 翻页，红书签先出现，叶背透印，下页有扫动阴影。返回时翻回，原条目落红书签（turn-open-back f01–f09、f14–f22）。翻页中途按「目录」会从当前角度倒放（f30–f35），连点只响应一次（fast-clicks f00–f05）。
- **印制（§6）**：数据写入的同一帧就进入「待印制」套准框，CTA 灰、副券不可拖。走纸是“露出 → 停 → 再露出”三段，然后自上而下上墨、套红，完成后 CTA 才变黑（confirm-print f06–f17）。第 1 轮的“先闪出印好的票”已经不存在。
- **撕券（§6）**：拖动跟手，撕口从上沿和左沿同时向内推进，已撕段有白 / 灰纤维带，副券绕内角抬起并投影（tear-full f02–f12）。松手后先向左荡出、压平，再直落进夹页口，被前片挡住下半，同一个元素留在袋里；联系层等落定后才升起（f13–f24）。未过阈值会回弹，失败时复位并出「再撕一次」（tear-rebound f04–f12、f17–f25）。
- **燃烧（§6）**：退出（C 型）、拒绝改期（B 型：副券卷起 + 沿右边、下边推进）、取消（S 型局卡条）都是在同一张票上起火：火线 → 焦褐带 → 缺口扩大 → 留下不规则的残片（带票面字迹）→ 结果字淡入，纸灰在 mask 外的兄弟层飘落。夹页里的副券不会被烧（exit-burn f08–f20，resched-decline f12–f24，host-cancel f11–f33）。关键帧拖动 5→95→50→5% 往返结果一致，释放后续跑，重播会在完整票面上重烧（scrub2 f04–f36）。
- **管理**：审核结果在原位换成红笔「采用 / 退稿」行。待审 2→1→0，预留 1→2，空位 2→1，座位格新增斜纹格，头部状态变成「2 人已预留 · 等确认」，返回后行落在「招募中」组（host-approve f08、f15、f22、f26）。改时间同时间禁用并给注，提交后出 toast 和改期答复（host-resched）。散场后出席三段全不选中，新鲜记录才盖章，更正会留轨迹「更正 出席 → 未出席」，计数与头部同步（host-end-attend f06–f29）。
- **结果与回路**：撤回 / 放弃预留 / 退出候补 / 主动退出 / 拒绝改期 / 局主取消，状态词和副文各不相同，返回都落在往期对应的封面上（resched-decline f29，withdraw-release，exit-burn f25–f27）。草稿删除后行原位收起，撤销后回到原槽位，删空后显示正确的空态（card-drafts f13–f33）。
- **失败 / 面板**：失败都出现在动作发生处，重试都能成功（fail-retry）。面板的索引、0.5×、暂停、关键帧、重播、重置、变体、下一次保存失败都可用（panel、scrub2）。
- **语义**：全 50 状态文本扫描，没有评分、等级、处罚类字样。参加者视图里没有申请人邮箱、留言、成员微信、自报加微信、离开记录；候补他人显示 `L**`。八种“没去成”各写各的。

## 问题（按严重度）

### Major

1. **减少动态下，打开 / 返回会闪出半张渲染或叠字的帧**（§0 不得重叠 / 残影；§2「.rm 下必须直接呈现结果态」）
   - 证据：`rm-ghost/f21` 打开「周六早午餐」时，目录的局名、倒计时、底栏叠在跨页的图版和元信息上。`rm/f02` 打开「公园慢跑」时同样叠字。`rm-ghost2/f30` 打开「外百老汇」时两页文字完全叠在一起。`rm-ghost2/f05、f12、f19、f33` 返回目录时，所有宋体局名、lead 倒计时、底栏图标缺失一帧，只剩页码和小字。连续 5 次打开 / 返回，每次都至少出现一帧。1× 下同一组操作是干净的（turn-ends 全部帧）。
   - 原因（探针）：`.rm` 下 `c03-turn` 只是把时长压到 1ms，叶子仍然走 `turning → hidden` 和 `preserve-3d` 的 0→−180° 过程。class 已经是 `hidden`，计算出的 visibility 还要再过约 30ms 才变成 hidden，这期间叶子页的背景已经不画了，文字层却还在。
   - 建议：`.rm` 下完全不走 3D。打开时在挂载跨页的同一次 render 里直接给叶子 `hidden`（不加 `turning`），返回时直接以 rotateY(0) 显示叶子（不加 `returning`）。或者加 `.rm .c03-leaf.turning,.rm .c03-leaf.returning{animation:none!important}`，并在同一帧切换 visibility。

2. **从编辑部底部点「取消这局」（自然路径）后，焦痕残块留在局名下的时间地点行上**（§0 动画后不得留下残影 / 重叠；§6 落定结果要和动作结果一致）
   - 证据：`cancel-natural/f17、f19`（滚回顶部，等了 3 秒）：「已取消 · 周一 12.28 · 20:00 · Queens · 阿斯托利亚」后半被一块实心黑色矩形盖住；`host-cancel/f33`（0.5×，同样的路径）是一条褐色模糊带横穿「20:00 · Queens · 阿斯托利亚」。只要滚动 5px 就消失（`cancel-natural/f18`）。从索引直接打开取消层再确认（`cancel-1x/f16–f17`）和静态的已取消页（`cancelled-static/f02`）都干净。另外，自然路径下燃烧时局卡条有一半压在吸顶的局名下面，起火的那几帧日期行被页眉羽化盖住（`cancel-natural/f08–f10`）。
   - 原因：局卡条的 `c03-scorch` / `c03-rough` 滤镜区域是 userSpaceOnUse，从条上方 −80px 开始；燃烧时条在吸顶页眉下面滚动，烧完回到 scrollTop 0 时，这块滤镜区域的残留合成层画到了条外面。
   - 建议：给 `.c03-bsvg` 外面包一层 `overflow:hidden; contain:paint`（或 `clip-path:inset(0)`），把滤镜区域收到条内（y ≥ 0）。`burnt` 落定后，用静态残片替换正在动的 `c03-sc` / `c03-emb` 层。起火前先把局卡条滚到吸顶页眉下方完全露出的位置（`scrollTop = strip.offsetTop − 页眉高 − 12`）。

3. **刊名、分区标签和多个文字按钮的字体被 `.app button{font:inherit}` 覆盖：刊名不是规格写的宋体 900，而是 Noto Sans SC 400**（第一眼 / 中文排版 / 一致）
   - 证据（计算样式探针，在 j-home、h-m-review、j-d-ended、h-m-attendance 上查）：`.c03-issue.on`（「参加刊 / 发起刊」刊名）= Noto Sans SC 400 40px，规格是 Noto Serif SC 900；未选中的刊 = Sans 400 **14px**，规格是 Serif 900 21px；`.c03-tab`（本期 / 往期 / 存稿）= Sans 400 14px，规格是 Serif 700 15px；`.c03-back-btn`、`.c03-link`、`.c03-rh`、`.c03-fliphint`、`.c03-ttlb` 同样掉回 Sans 400 14px。`document.fonts.check('900 … Noto Serif SC')` = false，字体链接里请求了 900 却从来没用到。画面上（coverage/j-home、h-home）首屏最大的字「参加刊」是细的黑体，和下面宋体 700 的 lead 局名不是同一个声音；另一刊的切换入口缩成一个 14px 灰字，身份切换的入口变弱。
   - 原因：`.app button` 的特异度是 (0,1,1)，高于 `.c03-issue` / `.c03-tab` 等单类选择器 (0,1,0)。
   - 建议：改成 `:where(.app) button{font:inherit}`，或把相关规则写成 `.app .c03-issue` 等。改完复看刊头：刊名 Serif 900 40px 与 lead 局名 31px / 700 的主次关系、发起刊 21px 灰的入口。

### Minor

4. 目录滚动收起停在 scrollTop≈40 时，淡出的大刊名「参加刊 / 17」和淡入的小标题「参加刊 · 本期」都只有约 10% 不透明度，上下错开、部分叠在一起，读起来是一帧发灰的重影（`long/f22`，裁切放大后可见）。第 1 轮的同位 50% 叠字已经修好，这里是残余。建议刊名透明度在 p≈0.4 前就归零（`1 − 2.5p`），小标题从 p≥0.5 才开始出现。
5. 返回目录时没有恢复原来的滚动位置：打开前目录 scrollTop = 0，源行「公园慢跑」完全可见；返回后 scrollTop = 298（探针）。翻回来的那一页已经是滚过的构图，和翻走的那一页不是同一张（`turn-open-back/f00` 对比 f18–f26）。规格（F01）是“恢复滚动，换了组才滚进视口”。建议只在源行不在可视区时才 scrollIntoView。
6. 长标题在跨页里找不到完整局名：图版两行加「····」截断，票面同样截断，跑头也截断（`long/f03、f06`）。编辑部收起后的吸顶标题折成两行，不是规格要求的单行省略（`long/f16`）。建议跨页正文（元信息行上方或参加约定前）给一次完整局名；编辑部吸顶标题在 `tight` 时 `-webkit-line-clamp:1`。
7. 身份翻刊落地之后，刊名还要再做 300ms 的字号过渡（大小互换，徽标跳位），等于翻页结束后又来一个动作（`role-switch-1x/f04–f05、f22–f23`）。建议新刊在翻页开始时就以终态字号渲染在下面，或者把字号过渡并进翻页的同一时段。
8. 退出燃烧进行中按「目录」：回到的是「本期」原来的滚动位置，没有落点书签，也没有跟着这局去往期（`fast-clicks/f43–f50`）。正常点「查看退出结果」是会落在往期封面的（exit-burn f25）。建议中途返回时走同一套落点逻辑。
9. 结果页的「查看退出结果」实际只是合上跨页回到目录，人已经在结果页上了，按钮文字却承诺“去看结果”；撤回申请的结果页也写「查看退出结果」（`withdraw-release/f08`，`exit-burn/f25`）。建议改为「回到目录 · 往期」或「收起」；撤回写「撤回」。
10. 已取消局卡条的残片（S 型）只剩右上角一小块褐色，带「、联系关闭」的半截字，封面缩略和日期都被烧光，读起来更像一块污渍，不像局卡的残片（`cancel-1x/f13–f17`，`coverage/h-m-cancelled`）。存档票根背面的「有 JU，就开局」，「有」字被镜像的撕口切掉一半（`history/f12–f13`）。参加者跨页图版右下的状态标，在待审核 / 候补中 / 待全员确认时写「席位已预留」，容易读成“我的位置已预留”（`coverage/j-d-pending、j-d-waitlist`；清单 A 里 pending 写的是 `仍可报名`）。

## 判定

blocker 0 · major 3 · minor 10 → **通过**（通过条件：0 blocker 且 major ≤ 3）。建议先修 3（一行 CSS，但会改变首屏刊头的观感，改后要复看），再修 1、2（都是渲染闪帧 / 残块，修法明确），minor 4–6 最影响观感。第 1 轮认可的翻页、印制、撕券、三种燃烧、红笔审核、出席章，修的时候不要简化。
