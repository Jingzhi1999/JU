## 成立的部分（有证据）

- 构图与材料：目录页（红页码 + 眉注 + 宋体局名 + 引导边注）→ 跨页 → 编辑部是一个系统；书脊暗部、叠页纸边、哑光纸、校对红一致；往期是等尺寸封面格，焦边空框也占一格（coverage/j-history-many, h-history）。
- 翻页：绕书脊的 3D 翻页，红书签先出现，下页扫动阴影，叶背透印；返回翻回并落在原条目，红书签停留 2s（home-turn f01–f04、f15–f27；turn-scrub）。
- 审核：按钮原位换成红笔结果行（采用 / 退稿划线），待审 −1、预留 +1、空位 −1、座位格新增斜纹格、头部状态重算、列表行同步（manage-approve f05–f10、f19）。
- 改时间：日期为空 / 同时间均禁用并有注，提交后 toast「已改时间 · 等 4 位成员答复」、头部改期中、改期答复 0/4、成员行「未答复新时间」（manage-resched f01–f15）。
- 出席：三段全不选中起步，新鲜记录出红章，静态不重放，更正留轨迹「更正 出席 → 未出席」，计数 1/4…4/4、头部「N 人出席未记录」递减，往期「1/4 人到场」（manage-end-attend）。
- 结果与回路：撤回 / 放弃预留 / 退出候补 / 主动退出 / 拒绝改期 / 已取消各自不同的状态词与副文，返回都落到往期对应封面（withdraw-release、waitlist-leave、exit-burn、resched-decline 末帧）。
- 空态：七种都是完整版式（标题 + 短墨线 + 说明 + 惰性或真按钮 + 「本页留白」）（coverage/b-empty, b-drafts, drafts f18–f19）。
- 面板：索引、0.5×、暂停、关键帧（翻页 / 印制 / 落券 / 燃烧均可拖，燃烧 5→50→5% 往返确定）、释放后续跑、重播在同一张票上重烧、重置、变体、下一次保存失败均可用；减少动态直接给结果态且可读（rm-and-scrub f01–f11）。
- 连点：连点打开只响应一次、翻页中返回被忽略、确认层连点不叠层，没有卡住的半开层（fast-clicks）。
- 语义：没有信用分；八种没去成各写各的；候补他人显示 `L**`；参加者只见局主微信；申请人微信成局前不显示。

## 问题（按严重度）

### Major

1. **出票前先闪出已印好的票，且“撕开票根”先可点再变灰**（M8 打印，§6）
   - 证据：`read-confirm-print/f06–f07`：确认入局后票页已经是印好的整张票（带「票根」红章），CTA「撕开票根」为黑色可点；`f08` 票面变成空白卡片、CTA 变灰，然后才开始走纸印制。索引跳转同样：`print-tear-contact/f02` 整张已印票，`f03` 消失成空白再送纸。
   - 原因：`afterOpen` / `confirmNow` 调 `startPrint(id,key,120–260)`，延迟期间 `tk.phase` 仍是 idle、`printed[key]` 未写，票按完成态渲染。
   - 建议：未印过的版本在 `printing` 之前就渲染为“未出纸”态（叶在书脊外、CTA 禁用、副券不可拖），把 `phase:'pending'` 在 setState 同一帧写入；或去掉延迟直接进入 `printing`。

2. **燃烧把整张票吃光后留一段空白，再换上一个画出来的焦框**（M8 作废，§6「同一物件 / 剩余形态」）
   - 证据：`exit-burn/f10–f13` 票页位置完全空白（只有几粒灰点），`f14` 突然出现粗糙矩形描边 + 两道曲线 +「票根作废」；`manage-cancel/f18–f21` 局卡条位置空白，`f22` 焦框弹出；拖帧 `burn-scrub2/f06`（50%）已空白。退出 / 取消 / 拒绝改期 / 首次打开已取消全部如此。孔是共享 `fx-hole` 的正圆 + 橙色描边圈，没有焦黄带、卷边或残片，读起来更像圆形擦除而不是纸被烧。
   - 建议：`--fx-reach` 不要覆盖整张（留下不规则残片），在洞缘后面加一圈焦褐渐变带；`burnt` 的焦框改成同一张票的残留（保留未烧到的票角 + 焦边 + 文字残迹），与燃烧末帧重合淡入而不是在空白后出现；起火点按方向卡放在页角。

3. **撕下的副券落过了夹页，盖在成员名单上，再被换成夹页里的小标签；落点还被同时升起的联系层挡住**（M8 撕票归宿、「同一时刻一个主要动作」）
   - 证据：`stub-fall/f08–f09`（落券关键帧 90% / 100%）副券停在「成员 6/6」下面「你（阿禾）」那一行上，比「夹页 · 存根」低约 100px；`f10` 副券消失，夹页口出现「副券 · 已撕」小标签，联系层同时盖住下半屏。`resched-accept/f21` 同样：副券在成员行上方、联系层已经升起。
   - 原因：`c03-fall` 100% 是 `translate(-14px,246px)`，而副券原位已在票面 y 144–236，夹页紧贴票底；联系层在 300ms 打开，落券 760ms。
   - 建议：按夹页实际位置计算落点（约 +110px），在落点做“插入夹页”遮挡（夹页前片盖住券的下半），落定后同一个元素缩成存根；联系层等落券结束（≥760ms）再升起。

4. **拒绝改期时，没撕过的新票突然变成“已撕”，旧版票同时消失**（M7 / M8，语义 G8）
   - 证据：`resched-decline/f06–f08`：确认退出后新票（JU-008v2）右上标签由「时间已改」变成「已撕」，右下副券区直接变成已撕的露底 + 纤维边，区块注「副券已撕 · 存根在夹页」；上方「旧版」票不再显示。之后才开始燃烧（起火点正好在已经缺掉的副券区）。
   - 原因：`ticketVals` 在 stage 变成 `declined` 后用旧票的 `ticket.torn` 判断新票。
   - 建议：`declined` 的作废票按“新票未撕”渲染（副券仍在、标签「新票作废」），旧票保留到烧完再一起归档；区块注改为「新票作废 · 未撕」。

5. **滚动收起页眉时两行文字叠在一起，停在半途就一直是重影**（M3，§0「不得残影 / 重叠」）
   - 证据：`scroll-many/f02`（scrollTop 45）：页眉「我的局 · 十二月刊」与渐入的「参加刊 · 本期」各约 50% 透明度叠在同一位置；`f03`（80）刊名「参加刊」与「17」从页眉下面滑过被硬切；`f12`（编辑部 30）右上页码「076」与渐入的局名小标题重叠，同时大标题仍是 30px，屏上出现两个局名。`long-title/f08` 标题字形被吸顶页眉横切。
   - 建议：眉注与小标题分两个时段（先 0–28px 淡出眉注，再 28–56px 淡入小标题），页码在小标题出现前让位；页眉下沿加 12–16px 纸色羽化遮罩；编辑部大标题按规格 30→18px 连续缩小而不是另起一个小标题。

6. **跨页页首仍由超大英文意大利体当主角**（第一眼 / 中文排版，主负责人第一轮已列为“高”，未修）
   - 证据：`coverage/j-d-invited.png`、`j-d-reschedule.png`、`j-d-ended.png` 等全部跨页：顶部 272px 色块里只有 54px 的「SLOW BRUNCH / LATE SHOW / JAZZ SET」，中文局名在色块下方 27px；完整局卡 `coverage/h-m-card.png` 同样以「BAR TRIAL」为主。
   - 建议：图版里放中文局名（宋体 32–36px、两行内）+ 局卡信息（statusLabel、caption），英文降为眉注或页码旁 11–14px 小字；图版高度降到 ~200px，让日期时间行进入首屏上半。

7. **列表状态行与跨页元信息的中文断行、色点对齐不过关**（中文排版）
   - 证据：`coverage/j-home.png` 008 行「局主改了时间，答复前旧票不 / 能用」，红点垂直居中在两行之间而不是跟首行；`resched-accept/f32` 008 / 020 行「按最终时 / 间赴约」；`coverage/j-many.png` 036 行副文折成三行、最后一行只剩一个「认」；跨页三栏元信息「Brooklyn · 威廉 / 斯堡」「布什 / 维克」「中 / 央公园」「西 / 村」（j-d-invited、j-d-reschedule、j-d-tear）；长标题跨页「周四 Livehouse · 散 / 场后一起吃宵夜 · 不 / 喝酒也欢迎来坐坐」（long-title/f06）。
   - 建议：状态行改成两行结构（第 1 行 色点 + 标签 + 右侧动作，第 2 行副文，`text-wrap:pretty` / 词组 `nowrap`），色点 `align-self:flex-start` 对齐首行；地点按「区 · 街区」两段各自 nowrap，必要时只截断街区；居中标题按「 · 」分段断行。

   - 建议：`e.status === 'cancelled'`（以及成员状态非 invited）时不渲染 `leftText`。

## 判定

blocker 0 · major 8 · minor 10 → **不通过**（通过条件：0 blocker 且 major ≤ 3）。优先修 1–4（三个核心物件动作的连续性），再修 5–7（重影、页首英文、断行），8 是一行逻辑。
