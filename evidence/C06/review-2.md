- 审核：结果原位替换按钮 + 「已邀请」印章 + 座位格 / 计数 / 头部 status / 分页签「申请 2→1→已处理」同帧变化，返回后行从「待你处理」落到「招募中」、徽标 2→1（`approve/`）。

- 散场 / 出席：索引卡滑走露出拍立得，三段选择、印章、更正留痕（`end-att/`）；草稿删除邻居同步让位、撤销回原槽、失败→重试（`drafts/` `fail-retry/` f35–f43）；减少动态全部直接呈现结果态（`rm/`）；面板：索引 50/50、0.5×、关键帧、释放、重播、重置、变体、下一次保存失败都可用（`scrub/` `coverage/`）。
- 语义：无信用分 / 评分字样；八种「没去成」标题与副文各不相同；参加者只见他人名字与 `L**`，只在撕票后见局主微信；拒绝改期后计数正确重算。

## Minor（12）
1. **管理页头部重复**：夹板上的索引卡与下面纸张头部重复局名、时间、座位格、计数（`coverage/h-m-review.png` `h-m-members.png` 等），前 470px 是两份同样的信息，申请 / 成员内容从 y≈530 才开始。建议纸张头部只留 status + meta + 进度行，局名交给夹板上的卡；或滚动时把卡缩成一条。
2. **管理 / 详情滚动没有折叠过程**：纸张滑进固定物件下面，遮挡边缘留下被切一半的文字条（`review-2/over-scroll/` f03「自然酒小试」半行、f05「已散场 · 24 小时内…」半行）。遮挡边加羽化，物件随滚动缩小（F02 的 88px 收起）。
3. **旧时间出现两处**：参加者改期详情里旧票删除线 20:30 + 新票「原定 周五 12.18 · 20:30」；局主改期答复页头部删除线 + 改期答复区对照行（`coverage/j-d-reschedule.png` `h-m-replies.png`），违背 G10。
4. **多余的成功 toast**：审核通过 / 谢绝、撕票、已加微信、记为散场、全员出票都弹 toast（`approve/` f04–f10、`tear/` f31–f40、`end-att/`），而 G12 / C 只允许删除草稿、复制、改时间（及改期接受）。结果已原位呈现，去掉这些 toast。
5. **失败文案与位置不按清单**：撕票失败显示通用「本机保存失败，请重试」于纸张底边，而不是副券处的「未能保存，请重新撕下副券」；退出写入失败时确认层被关闭、红条落在纸上，清单要求「停在确认层」+「无法保存退出，请重试」（`fail-retry/` f04–f08、f24–f28）。
6. **历史展开缺项且构图雷同**：散场拍立得没有「点一下 · 看背面」翻面；预留到期没有 `00:00:00` 条；八种未成行详情都是同一张纸、下半约 45% 空白，且对没参加过的结局（到期 / 放弃 / 未通过）也写「散场后遇到问题…」（`coverage/j-d-ended.png` `j-d-expired.png` `j-d-released.png` `j-d-rejected.png`）。
7. **索引卡横线不对齐基线**：蓝色横线穿过「通过即发出 6 小时预留」字身、压到「20:30」顶部（`coverage/h-home.png`、`h-m-review.png`、`b-long-h.png`）。把行高与横线间距对齐（如 26px 网格）。
8. **撤回时便签折进杯垫的中间帧**：压扁的便签文字与杯垫文字叠成双影（`review-2/withdraw/` f12）。折叠时先把便签文字淡出。
9. **离场残影**：退出处理中按返回，历史列表上方有一帧飘着那张票（`stress-exit-back/` f02、`stress/` f17）；首次打开已取消后放下，带灰的烟灰缸从列表页脚上滑出（`history/` f44–f45）。
10. **辅助文案拥挤 / 重复**：撕票提示「按住副券向下撕 · 没撕够会弹回」11px 居中挤在票与左对齐标题之间（`coverage/j-d-tear.png`）；待审核详情「等局主审核 · 不占名额」出现 3 次；已确认待成局写「此阶段没有「去不了了」」读起来像开发备注（`coverage/j-d-pending.png` `j-d-gathering.png`）。
11. **拿起物件与纸张之间露出压暗桌面的字**：票下沿与纸张上沿之间可见红色「已预留 剩 04:21:00」残字（`review-2/print/` f22–f30、`coverage/j-d-tear.png`）。让纸张上沿压住物件下沿，或该缝隙压暗到不可读。
12. **360 宽偏挤**：物件固定 340px，左右只剩 ≤10px，详情里副券右缘被裁（`review-2/w360/` f01–f07；把 `.app` 设为 360px 的近似验证，非真机）。物件宽改为 `min(340px, 100% - 32px)`。
