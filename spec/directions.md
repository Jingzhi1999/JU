# 「我的局」十套方向卡 · 差异矩阵

每套先回答六件事：① 构图与信息组织 ② 字体与比例 ③ 组件构造 ④ 材质与光影 ⑤ 空间过渡 ⑥ 三个核心动作。任意两套至少在四个维度上有可见、可操作的区别。共享：同一份演示数据与业务引擎（`src/core/ju-data.js`）、同一评审面板。

## C01 票据卷 Receipt Roll

1. **构图与信息组织**：整屏是一条 ~340px 宽的热敏纸带，从顶部出纸口打印出来。纸带按「要你回应 / 就快见面 / 还在等」分段，每段之间一条齿孔虚线。第一眼看纸带顶部的粗体局名与大号时间；第二眼看每条下方的一行状态（点阵字）。身份切换 = 两卷纸（参加 / 发起），切换时当前卷收回、另一卷走出。
2. **字体与比例**：局名 Noto Sans SC 500 20px；时间 DM Mono 28px（纸带上最大的字）；地点 14px；状态 12px 点阵感（DM Mono + letter-spacing）。纸宽固定，长标题自动折行，不缩小。
3. **组件构造**：局条 = 纸带上的一段打印（无边框，只有墨与齿孔）；票 = 纸带上有加粗边框的一截，可沿齿孔撕；名单 = 打印的表格（点线对齐）；弹层 = 另一小截纸从纸带侧面「贴」上去（便签）；按钮 = 打印的反白方块。
4. **材质与光影**：热敏纸 #f3efe6 带轻微横向纸纹，墨色 #1a1a1a 略有打印不均（filter: url(#fx-ink)）；出纸口有阴影与滚轴高光；撕下的纸有真实卷曲。
5. **空间过渡**：进入详情 = 纸带继续走纸，详情内容在该条下方被「打印」出来（上方内容不动，下方让位）；返回 = 纸带回卷。管理界面 = 局主的「工单」，同样是打印。
6. **核心动作**：① 出票：纸带走纸打印一张加粗边框的票（分三段走纸，有停顿）；② 撕票：从齿孔右端按住拖，渐进断裂，副券卷曲落下成「存根」堆在底部；③ 取消：局主确认后，纸带从该条起火，焦卷推进，剩余纸灰落入底栏，历史区出现一张焦边条目。

## C02 站牌 Departure Board

1. **构图**：深色机械板，每局一行翻牌：左列 HH:MM（大），中列局名，右列状态牌（黄 / 白 / 红字）。顶部是两块身份牌「参加 / 发起」，切换时整板翻一遍。第一眼：时间列和黄牌状态；第二眼：局名。
2. **字体**：Unbounded 700（数字）+ Noto Sans SC 700（局名，翻牌内）；状态 Archivo Narrow 大写 + 中文。翻牌格字号统一 18px，行高固定 44px。
3. **组件**：翻牌行 = 一串分格翻片，每格可翻；票 = 磁条卡（圆角、磁条、打孔）；名单 = 侧板上的座位灯（亮 = 已确认，闪 = 预留，灭 = 空）；弹层 = 从板下方升起的操作面板（金属拨杆与按钮）。
4. **材质**：板面 #121417 带细噪点，翻片 #1d2024 有上下两半的受光差，字是喷漆白 / 黄；卡片是磨砂塑料。
5. **空间过渡**：行被点选后其他行翻成空白，该行向下「展开」成多行牌面显示详情；返回时牌面翻回列表。管理 = 侧面拉出的操作盘。
6. **核心动作**：① 状态翻牌：审核通过 / 改期 / 取消时，相应格一格格翻（带机械节奏与声感的抖动）；② 过闸撕票：把卡插入读卡槽，卡被吞入一半、读卡灯亮、吐出已撕（打孔）卡；③ 作废：取消后卡片在读卡槽里过热，磁条处焦黑、塑料起泡，最后牌面翻成「取消」。

## C03 刊 Editorial Spread

1. **构图**：一本杂志。首屏是目录页：左上眉注「我的局 · 12 月」，大号局名纵列成目录条目，右侧页码。身份 = 两期（参加刊 / 发起刊）。第一眼：最大的那条目录（lead）；第二眼：页码与一行小字状态。
2. **字体**：Noto Serif SC 700（局名 26–34px）+ Noto Sans SC（正文 14px）+ Instrument Serif（页码、英文眉注）。严格的 4 列网格、字行对齐。
3. **组件**：目录条目 = 标题 + 引导点 + 页码；详情 = 跨页（左页图版：局卡；右页文字：时间地点成员）；票 = 页角的撕角券；名单 = 版面里的人物小传列表；弹层 = 夹在页间的纸条（校对条）。
4. **材质**：哑光铜版纸 #f7f5f0，墨 #111，一个红（校对红 #c8102e）；页面有书脊阴影与纸厚的边；翻页时有真实的折弯与背面透印。
5. **空间过渡**：从目录条目翻到对应跨页（3D 翻页，折线在书脊）；返回 = 翻回目录并落在原条目。管理 = 「编辑部」页面：申请是来稿，审核 = 红笔批注。
6. **核心动作**：① 翻页展开：目录条目被点时该行变成书签，页面从右向左翻开到跨页；② 撕券：从页角虚线撕下券（纸角翻起、撕裂、券飘落到页底「夹页」里）；③ 烧页：取消时跨页从一点烧穿，焦洞扩大、灰屑飘落，剩下焦边的页框留在目录里（历史 · 已取消）。

## C04 夜玻璃 Night Glass

1. **构图**：深蓝黑夜色背景（静止，不循环），局是一块块层叠的毛玻璃板，按纵深排列：最近最清楚（要你回应），远的缩小并失焦。身份切换 = 两叠玻璃左右平移。第一眼：最前的玻璃板上的局名和倒计时；第二眼：后面的模糊板。
2. **字体**：Sora 600（数字、倒计时）+ Noto Sans SC 500（局名 22px）；中文用较大字距；状态用小号大写拉丁 + 中文并置。
3. **组件**：玻璃板（边缘高光、内部折射的背景色）；票 = 全息通行证（倾斜时光带扫过）；名单 = 玻璃板内的头像珠串；弹层 = 从底部升起的一块更厚的玻璃（更强的模糊）。
4. **材质**：backdrop-filter 模糊 + 边缘 1px 高光 + 内阴影；背景是几片静止的色彩光斑（不循环动画）。
5. **空间过渡**：点选的玻璃板向前抬起并放大到全屏，其余板后退并更模糊（景深）；返回 = 反向。管理 = 一块宽玻璃上的「控制台」胶囊。
6. **核心动作**：① 景深展开：板前移时其他板退后、模糊、变暗，有真实的视差；② 通行证撕票：通行证的副券部分是一层薄玻璃，拖动时裂开（裂纹沿齿孔），分离后碎片化消失；③ 玻璃作废：取消时通行证从一点起裂纹，裂纹扩散、碎片一块块坠落，剩下空框和裂缝，列表里的板变成暗色薄片归档。

## C05 缝线 Muslin & Seams

1. **构图**：白坯布工作台，局是摊开的裁片（不规则但克制的轮廓：直角 + 一处斜边），每片上有粉线划的局名与时间；状态是白布标（四针白线缝在角上）。身份 = 两张台（参加 / 发起）。第一眼：粉线写的局名；第二眼：布标上的小字。
2. **字体**：Noto Serif SC 300/500（局名 24px，疏朗）+ Cormorant（数字、英文）+ 手写粉线用 Zhi Mang Xing（仅标注）。留白比例大，但信息完整。
3. **组件**：裁片 = 米白布块（有布纹和轻微起伏的投影）；票 = 吊牌（硬卡纸 + 棉线 + 金属扣眼）；名单 = 粉笔画的记号表；弹层 = 一块翻起来的布角下面的内容。
4. **材质**：坯布纹理（feTurbulence 极细）、粉线（白色半透明笔触）、缝线（虚线 + 针脚阴影）、吊牌卡纸与棉线。只有一束光，从左上。
5. **空间过渡**：裁片沿折线翻开（3D 折），露出里面的内容；返回 = 折回。管理 = 「裁缝的订单簿」。
6. **核心动作**：① 翻开裁片：从点按点起折线，布料有重量地翻开并落平；② 剪线撕票：吊牌靠棉线栓在裁片上，拖动把线拉紧、绷断（线断口回弹），吊牌落到「存根袋」；③ 布面烧焦：取消时从一角烧起，布边起毛、焦黑、最后剩一圈灰线轮廓归档到历史。

## C06 桌面 Desk Objects

1. **构图**：俯视一张桌面（深色木或毛毡），局是摊在上面的物件：票根、拍立得、便签、纸杯垫，物件之间有真实重叠与阴影；最急的在最上面且摆正，其他微微旋转。身份 = 桌面左右两半（或推开一叠换另一叠）。第一眼：摆正的那张；第二眼：下面露出一角的。
2. **字体**：Noto Sans SC 700（局名，手写标签感用 Ma Shan Zheng 只做批注）+ Space Mono（时间）。
3. **组件**：物件各有形态：票根（齿孔）、拍立得（白边 + 影像区）、便签（纸胶带贴着）、杯垫（圆形）；名单 = 一张名片堆；弹层 = 一张从桌边推进来的纸。
4. **材质**：桌面纹理、每个物件有厚度边与接触阴影；纸胶带半透明。
5. **空间过渡**：点物件 = 把它拿起来（阴影变大、摆正、放大到屏幕中央），其他物件退到桌面并变暗；放下 = 回到原位。管理 = 一块夹板（clipboard）。
6. **核心动作**：① 拿起 / 放下：带旋转校正与阴影变化的 FLIP；② 撕票：双指感：按住票根一角拖，沿齿孔撕开，副券落在桌面上留着（真实的「桌面上多了一片纸」）；③ 烟灰缸：取消时票根被丢进桌角烟灰缸，从角起燃，焦边推进，烧到最后只剩一撮灰和一片未燃尽的角，归档。

## C07 格盘 Bento Grid

1. **构图**：方格仪表盘（浅灰底），每局一格，格子尺寸由任务权重决定：要你回应 = 2×2，就快见面 = 2×1，还在等 = 1×1；局主的待处理格最大并有数字。身份 = 两块盘横向滑动。第一眼：最大的格子里的局名与倒计时；第二眼：小格。
2. **字体**：Noto Sans SC 600（局名）+ DM Mono（数字、计数）；格内文字按格大小变级。
3. **组件**：格子（圆角 18px，纯色或双色）；票 = 通行证格（二维码 + 条）；名单 = 头像格阵；弹层 = 一个格子膨胀到底部的「操作盘」。
4. **材质**：平面但有层：格子有 1px 边与极浅的底影；颜色按分区（要你回应 = 暖橙、就快见面 = 青绿、还在等 = 灰蓝）。
5. **空间过渡**：格子 FLIP 膨胀到整盘并在内部分成子格（详情、成员、动作），其他格缩入边缘成导航条；返回 = 收回原格。管理 = 子格盘。
6. **核心动作**：① 格子重排：状态变化后格子尺寸改变，所有格子 FLIP 到新位置；② 像素撕票：通行证格的副券一列像素格被「刮」下来（拖动），格子一块块脱落；③ 像素作废：取消时通行证从一角开始逐块脱落、落下、变灰，剩下的格子碎片合成历史里的一个灰格。

## C08 时间尺 Timeline Ruler

1. **构图**：一把竖直时间尺占左侧 56px（日期刻度 + 当前线），局是尺右侧的块：块的高度 = 时长，块的 y = 时间；今天的块更亮；状态用块的描边与填充区分（虚线 = 待审核，实线 = 已预留，填充 = 已确认，票状 = 已出票）。身份 = 两条尺并排切换。第一眼：当前线附近最近的块；第二眼：更远的块。
2. **字体**：Archivo Narrow（刻度数字）+ Noto Sans SC 500（局名 18px）；时间用尺上的刻度读，不重复写。
3. **组件**：时间块；票 = 块变成打孔的票（尺上的「打卡」）；名单 = 块内的座位格；弹层 = 块向右拉出的抽屉。
4. **材质**：扁平但有尺的物理感（刻度压印、当前线是红色细线）；块有极轻的投影。
5. **空间过渡**：点块 = 块横向展开占满右侧并向下伸展成详情，尺上的其他块缩成小标记；返回 = 收回。管理 = 块内展开的多层抽屉。
6. **核心动作**：① 改期滑动：接受新时间时，块沿尺滑到新位置，旧位置留一个淡影，新票在新位置打印；② 打卡撕票：块的右端有副券，向右拖出撕开；③ 尺上作废：取消时块从中间焦化（像烧过的尺子），残留一道焦痕刻在尺上，块本身滑入历史尺。

## C09 影印贴纸 Zine & Stickers

1. **构图**：一本 A5 zine，每页一局（可上下翻页，也可缩略为页阵）；页面是高反差影印质感，局名是大号黑体贴在页上，状态是荧光贴纸（撕得起来）。身份 = 两本 zine。第一眼：荧光贴纸与大字；第二眼：页脚手写时间地点。
2. **字体**：ZCOOL QingKe HuangYou（局名 36px）+ Noto Sans SC（正文）+ Liu Jian Mao Cao（手写批注）；荧光粉 #ff4fa3 / 荧光黄 #f1ff3b 贴纸。
3. **组件**：页面、贴纸（有白边与微微翘起的角）、订书钉 DIY 票、纸胶带；弹层 = 一张贴上去的便签贴纸。
4. **材质**：影印黑有颗粒与不均（fx-grain），贴纸有光泽，纸胶带半透明。
5. **空间过渡**：贴纸被撕起露出下一层（详情页）；返回 = 贴回去。管理 = 一张贴纸纸（sticker sheet），审核 = 撕下贴纸贴到人名旁。
6. **核心动作**：① 撕贴纸：从角起拖，贴纸翻起露出背胶与下面内容；② 剪票：票上印着剪刀线，拖动沿线剪开（锯齿），副券掉进页脚口袋；③ 影印烧：取消时页面被打火机从一角烧，影印纸发黑卷边，最后剩一页焦边空白，贴纸烧成一个黑点归档。

## C10 胶片 Film Strip

1. **构图**：暗房：横向滚动的 35mm 底片条（齿孔、帧号），每帧一局；帧的曝光程度 = 状态（待审核 = 几乎透明、已预留 = 淡、已确认 = 显影、已出票 = 满格），当前帧在灯箱光下最亮。身份 = 两卷胶片。第一眼：灯箱里的那一帧（局名、时间）；第二眼：旁边的暗帧。
2. **字体**：Noto Sans SC 500（局名 20px）+ Space Mono（帧号、时间）；红蜡笔批注用 Long Cang。
3. **组件**：帧、底片条、放大镜；票 = 一张相纸（显影出来）；名单 = 接触印样的小格；弹层 = 暗房的红灯面板。
4. **材质**：底片的橙棕基底、齿孔透光、灯箱白光、相纸的厚边；红灯模式下的色偏。
5. **空间过渡**：帧被点选后从灯箱放大成相纸（像显影：先空白再逐渐显出）；返回 = 相纸缩回帧。管理 = 灯箱 + 红蜡笔（审核 = 圈选）。
6. **核心动作**：① 显影出票：相纸从显影盘里升起，影像从无到有逐渐显出（打印的替代形式）；② 剪底片：撕票 = 用裁刀沿帧边剪下副券帧（拖动裁刀）；③ 胶片熔穿：取消时帧受热，从中心起泡、熔穿、边缘卷曲，最后帧框变黑归档。
