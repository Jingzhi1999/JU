### 0.1 评审结论三段（A/B/C）——逐条可核对
- A 结构与可用性
  - [ ] 一个「我的局」下两个独立功能：我参加的 / 我发起的，各自的分组、分区、空态、滚动记忆与返回上下文。
  - [ ] 身份常在：滚到任何深度，功能分段条与分区行都在；评审镜像里也看得到。
  - [ ] 入口稳定：当前 / 草稿 / 历史在 0、1、很多条时都在同一位置。
  - [ ] H1 按任务进入（审核时申请在前），头部不再透字，处理结果原位出现。
  - [ ] 危险操作用危险色；弹层带活动身份与旧→新对照；草稿删除可撤销。
- B 视觉质感（简）
  - [ ] 一条文字轴 + 一个主角：首项是全屏唯一抬起的纸托（5% 纸纹），按钮宽 = 文字栏；其余为从文字轴起细线分隔的扫读行。
  - [ ] 摘要物件与详情同源：JuCardV2 真渲染、V27 票根、08 票墙卡；物件只承担识别，信息由文字承担。
  - [ ] 文字角色收敛：局名 17/19px、Archivo 日期「SAT 12.19 · 20:30」、街区地点、13px 状态。
  - [ ] 一套材质：静置接触影 / 唯一抬起的纸托 / 凹槽托盘；光从上方；选中块是托盘里的白色纸片；不用模糊和玻璃。
  - [ ] 0 / 1 / 多、长中文、中英混排都有设计好的状态；320 短屏按高度重新分配。
- C 动效语言
  - [ ] 物件不跳：同一张卡直线飞进详情（380ms）、从详情（含 06g）飞回原位或新位置（360ms）；进入途中返回从当前位置原路飞回。
  - [ ] 切换功能时，选中语义当帧切换，选中块与两窗格同一变量同步移动。
  - [ ] 状态用 V27 的语言落定：座位盖章、日期重印、卡面抽色与余烬。
  - [ ] 结果出现在动作发生的地方；撤销在删除之前；历史不重放盖章。
  - [ ] 每个场景都有减少动态替代与打断处理（中途返回、连点、离开再进）。

## 1. 信息架构（评审断言的产品结构）

### 1.1 两个功能 × 分区 × 分组

| 功能 | 分段条文案 | 徽标数 = | 分区（固定顺序，0 条也渲染） | 当前分区分组（按顺序） | 组头排序口径（脚本核对） |
|---|---|---|---|---|---|
| 我参加的 | 「我参加的」+ 数字 | 要你回应 的条数（E01：badge=3=firstGroup） | 当前 / 历史 | 要你回应 → 就快见面 → 还在等 | 按截止先后 / 已成局 · 按日期 / 等局主或其他成员 |
| 我发起的 | 「我发起的」+ 数字 | 待你处理 的条数（E01：badge=2） | 当前 / 草稿 / 历史 | 待你处理 → 改期中 → 招募中 → 已成局 | 审核与出席 / 等成员逐人答复 / 还没成局 / 按日期 |

- 组头格式：标签 + 计数 + 排序口径，如「要你回应 3 · 按截止先后」；计数 = 组内可达行数，只写一次；空组不渲染（脚本 `.filter(g=>g[2].length)`）。
- 徽标为 0 时不显示数字；分区入口计数紧跟标签（E17：「历史 4」「草稿 2」「草稿 1」「历史 9」「历史 3」）。
- 分组命名只用两个维度：任务（要你回应 / 待你处理）与生命周期（就快见面 · 还在等 / 招募中 · 改期中 · 已成局 · 散场 · 未成行）。
- 局主「待你处理」行内带真实阶段标签（E22：「周五小酒馆试营业|招募中」「看展搭子 · 现代馆|已散场」；改期中组：「阳台烧烤 · 自带肉|改期中」）。已散场但未记出席的局只在 待你处理 与 历史 出现，不挂在进行中。
- 参加行：物件在左、文字在右；发起行：文字在左、物件在右（靠任务与空间关系区分，不用两套配色）。

## 8. 限制与未完成（评审原文 10 条）

1. 原型环境：台账与存储为本地模拟；「已发出邀请」等结果是原型状态，不代表真实通知送达；服务端权限未验证。
2. 性能：只在无头 Chromium + SwiftShader 测量。整页重渲染（flushSync，30 次）中位数：产品视图 v2.1 30.1ms → V3 33.4ms；评审画布 40.6ms → 44.5ms（p90 42.7 / 54.5ms）。真机未测，不作 60fps 结论；动效时长取自原则区间，需真机复测。
3. 功能切换「中途反向」：本环境第一段过渡在第二次点击前已走完，只录到完整返回；连点一致性由 E01 / E13 验证。列表→详情中途返回已单独验证（原路飞回、无残留）。

### 10.3 计数规则
| 计数 | 规则 |

| 分段条徽标 | 参加 = 要你回应 条数；发起 = 待你处理 条数；0 不显示 |

| 分区入口计数 | 紧跟标签（历史 4 / 草稿 1），0 时仍渲染入口 |
| 座位 | 「已确认 a/b（含你）」+ 口径句「b 个座位（含你）· 已确认 a · 预留 r」；「还有 n 个空位等人」；座位条 segs = 容量 |

| 倒计时 | 6 小时「HH:MM:SS」+ 进度条（E03：05:59:58 ≈1.0，00:59:28 ≈0.165） |
| 撤销 | 10 秒（原则 8s / 5–10s） |

### 10.4 格式与导航
- 日期：「SAT 12.19 · 20:30」（Archivo，星期 月.日 · 24h）；列表行「SAT 12.19 · 20:30 · 东村」；详情 long「Manhattan · 东村」；草稿「日期未定」；弹层写「纽约时间」；不随 locale 变。
- 底部导航「找局 / 开局 / 我的局 / 设置」不变；返回键 aria「返回上一页」；返回上下文：返回我的局（含 role / filter / y / landed）、返回找局；详情入口：参加 → s05 / s06 / s06g / s11 / s12，发起 → h01，历史 → 08 / 12。
- 评审镜像：m01 锁定「我参加的 3」、m02 锁定「我发起的 2」，分区「当前」。
