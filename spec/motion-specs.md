## 2. 三个核心动作

### ① 走纸打印（出票）
- **触发**：进入票面（从列表点「撕开票根」等 ticket 物件行）、改期答复界面打开（新版票）、全员确认成局（`engine.confirmReservation` 返回 `formed:true`）；评审面板「重播」重印同一张票。
- **运动对象**：票（`.c01-tkwrap > .c01-pr`，高 250px 的一截纸）。纸带上方内容不动，下方内容被推下（让位）。
- **起点 / 终点**：高度 0（印头处）→ 250px 落定在该行之下；票面文字随纸露出，不缩放、不移动。
- **分段**（总 2200ms × k）：0–24% 走纸到 34%，24–34% 停顿，34–60% 走到 72%，60–70% 停顿，70–96% 走完，96–100% 停稳。关键帧 `c01-feed3`，`linear` 分段；每段像步进电机的匀速推进。
- **变换中心**：顶边（高度动画，`overflow:hidden`）。
- **遮罩 / 阴影**：印头处 10px 向下的暗渐变（`.c01-pr.printing::after`），打印完消失；打印中副券 `pointer-events:none`，提示文「出票中 · 打印完成前不能撕」。
- **中断 / 重播**：`.scrub` 下 `animation-play-state:paused` + `animation-delay:-frame×dur×k`；`.rm` 下直接高度 = 终值；重播由 `beforeReplay('print')` 把票置回 idle 再打印。
- 同族快版：进入详情 / 工单正文用 `c01-feed2`（900ms，一次停顿），切换标签页 700ms。

### ② 沿孔撕票
- **触发**：在副券右端按下（`onPointerDown` + `setPointerCapture`），向左 / 向下拖；`p = clamp((−dx·1.0 + dy·1.15)/175)`。
- **运动对象**：同一张票渲染两份（keep / stub），各自 `clip-path` 由 `c01TearClip`（从右向左：`x ≥ (1−p)·w` 为已撕）生成；已撕段 = 纤维轮廓，未撕段 = 直线齿孔。
- **过程**：拖动中副券以左上角为轴 `rotate(p·12deg) translateY(p·4px)`，撕口张开 `p·6px`；亮纤维带 + 软阴影只画在已撕段；p < 0.55 释放 → 220ms ease-out 回弹到 0。
- **落点**：p ≥ 0.55 释放 → 先 `engine.tearTicket`（或改期新票 `engine.acceptReschedule`；失败则回弹并出现重试条），成功后副券 `off`：820ms `cubic-bezier(.45,.02,.75,.5)`，`rotate 12→−26deg`、`rotateX 0→70deg`（卷曲）、`scale .68`、`translateY(--drop)` 到底栏存根槽（drop 由副券实际位置测得），进入槽后在存根堆里出现一片新存根（420ms 弹入）并计数「存根 N」。
- **留下的部分**：主票高度 250→184px，底边换成锯齿 `clip-path`，对应「已撕票待联系」；300ms 后联系层（局主微信 + 复制 + 已加微信）以墨迹揭示方式打印。
- **变换中心**：副券 `transform-origin: 0 0`（仍附着的左端）。
- **中断 / 重播**：拖动中切换数据会重置；`.scrub` 控制落下关键帧；重播：`beforeReplay('tear')` 恢复未撕、移除最后一片存根，再次落下。

### ③ 焦卷作废（取消 / 退出 / 拒绝改期）
- **触发**：局主「取消这局」便签 → 确认取消 → 700ms「取消中…」→ `engine.cancel` 成功 → 工单上的活动条起火；参加者「去不了了」/「新时间去不了」确认 → 票起火；`j-d-cancelled` 直接显示残片。
- **运动对象**：同一张票 / 活动条（`.c01-burn` 容器 + 内嵌 SVG mask）。起火点：工单活动条在局卡缩略图下沿 (60,70)，票在右下 (250,120)。
- **过程**（2600ms 票 / 2800ms 条，`cubic-bezier(.35,.05,.5,1)`）：mask 中 `circle.c01-hole` 半径 0 → `--reach`（经 `#fx-rough-strong` 置换成毛边），同半径的 16px 深棕炭圈与 5px 橙色余烬线（带 4px 辉光，80% 后淡出）贴着洞沿推进；10 粒纸灰从起火点落向底栏（1500ms ease-in，各自 0–1100ms 延迟、±46px 横漂、旋转），落到槽后底栏出现灰堆。
- **剩余形态**：烧尽后容器折叠为 0 高，原位出现焦炭残片 `.c01-char`（深棕、上下锯齿 clip-path、灰字：时间 · 局名 · 「已取消 · 票根作废 · 联系已关闭」），600ms 落定。
- **结果一致**：工单头状态「已取消」、进度隐藏、成员行「取消前已确认 / 取消前已预留」、安排只剩「再开一局」（本范围内不可点）；返回列表落在 历史 › 已取消 的焦边条目上（高亮 1.6s）。参加者侧：票残片 + 结果块（已退出这局 / 未接受新时间），返回落在 未成行。
- **遮罩 / 阴影**：mask 作用在整张票上，炭圈与余烬在 SVG 内（`overflow:hidden` 裁到票框）；纸灰在遮罩之外的兄弟层。
- **中断 / 重播**：`.scrub` 暂停洞、炭圈、余烬、纸灰四组关键帧并按 `--frame` 定位；`.rm` 直接呈现残片；重播 `beforeReplay('burn')` 复原票 / 活动条再烧。

## 3. 其余动效族（简述）
- 共享元素展开：点行 → `JU.fx.rectIn` 取矩形 → 第二层纸上的同一条从原位（`--dy`）420ms `cubic-bezier(.2,.8,.2,1)` 滑到返回行之下，底层纸带墨色退到 18%，第二层纸底色 320ms 变实；返回反向，原行在落点高亮。
- 身份切换：纸带 430ms 收回出纸口（`translateY(-780px)`），换卷，再 520ms 走出；拨杆同步 380ms。
- 分区切换：正文快速重印 420ms。
- 便签：右侧滑入 380ms `cubic-bezier(.2,.9,.3,1.05)`，落定 −1.2°，背景压暗 45%。
- 回执小条（toast）：从底栏槽升起 420ms，2.6s 后退回。
- 印章（出席记录）：560ms 从 1.9 倍落下带 −20°→−9° 回正。
- 草稿删除：行 360ms 收起（高度实测 `--rh`）→ 撤销条 10s 墨线倒计时 → 撤销 420ms 回到原位。
- 处理中：按钮右侧三点步进；失败：底部红边纸条（重试 / 取消）。

### 材质规则（玻璃）
- 基础玻璃 `.g`：`backdrop-filter: blur(14px) saturate(1.35)`，表面 160° 线性渐变 α.11→.045→.075，`inset 0 1px 0 rgba(255,255,255,.34)`（顶边高光）+ `inset 0 0 0 1px α.10`（1px 边）+ `inset 0 -16px 26px -20px rgba(0,0,0,.5)`（底部内阴影 = 厚度）+ `0 20px 44px -24px rgba(0,0,0,.75)`（落影）；`::before` 顶部 40% 的反光。

- 暗玻璃 `.g.dark` / 书脊 `.spine`：几乎不透光的深色薄片，1px 边 α.05–.08，只有顶边 α.08–.12 的微光；pack 色 4px 边条。

## 2. 三个核心动作

### ① 景深展开（局卡 → 详情 → 返回）
| 项 | 说明 |
|---|---|
| 触发 | 点任意玻璃板（整板是按钮）；`JU.fx.rectIn` 取该板矩形 `from` |
| 运动对象 | 详情层 `.pane`（厚玻璃）+ 内层 `.pane-in`；背景 `.home` |
| 起点 → 终点 | `.pane` 的 `clip-path: inset(top right bottom left round 18px)` = 板矩形 → `inset(0 round 0)`；`.pane-in` `translateY(from.y − 44px)` → 0（标题从板的位置出发）；`.home` scale 1 → .93，blur 0 → 10px，brightness 1 → .5 |
| 分段 | 0–20ms 置起始态并强制样式刷新（`flush`）；20–480ms 三者同时过渡；返回 400ms 反向，再 40ms 卸载并高亮落点 1.4s（`c04-land` 边光收敛） |
| 曲线 | `cubic-bezier(.2,.8,.2,1)`；返回同曲线 400ms |
| 变换中心 | `.home` 50% 40%；clip 以板矩形为准（无非等比缩放，文字不变形） |
| 遮罩 | clip-path inset（圆角 18→0）；`.pane-bg` 上溢 260px 避免平移露底 |
| 阴影变化 | 背景整体变暗 50% + 失焦；详情顶边 1px 高光常驻 |
| 中断 / 重播 | 展开中按返回 → 立即进入 out；返回时若源板已换分组（终态）先切到历史分区再量矩形（`unscale` 还原 .93 缩放）；面板「重播」= `open-card`：先卸载详情再从同一板重新展开；跳转索引用 `noanim` 直接呈现 |

### ② 裂开撕票（副券 = 薄玻璃）
| 项 | 说明 |
|---|---|
| 触发 | 在副券（`.piece.stubp`，齿孔以下 72px）按住向下拖，`setPointerCapture`；`p = (dy + .25·dx) / 120` |
| 运动对象 | 副券薄玻璃（translate 0→18px、rotate 0→−2.4°，origin 左上）；裂纹 SVG（齿孔折线 + 3 条支裂 + 4 条竖向碎片界线）；主票底边 clip |

| 阈值 / 回弹 | 松手 p ≥ .55 → `JU.engine.tearTicket`（或改期页 `acceptReschedule`）；否则 `spring` 回位 420ms `cubic-bezier(.2,1.25,.3,1)`，裂纹随 p 收回 |
| 碎裂分离 | 副券换成 7 块碎片（同一 DOM 模板、clip-path 多边形，上沿沿齿孔折线）：`c04-shard` 720ms `cubic-bezier(.4,0,.75,.4)`（重物下落），每块 delay i×85ms（从左到右），位移 (dx≈±14, dy 120–210px) + 旋转 ±22°，55% 后透明；820ms 后进入 `torn`：主票底边保留折线断口 + 光带，联系层 460ms 弹簧升起，CTA「已加微信」 |

| 遮罩 | 主票 / 副券 / 碎片均为 `clip-path: polygon` |

### ③ 碎裂作废（取消这局 / 主动退出 / 拒绝改期）
| 项 | 说明 |
|---|---|
| 触发 | 弹层「确认取消 / 确认退出」→ 引擎成功 → 弹层收起（460ms）→ 作废序列 |
| 运动对象 | 同一张通行证（局主侧为「局主副本」，从局卡条下方 380ms 升起）：裂纹 SVG（9 条从起裂点 (68%,40%) 到边缘的射线 + 内环折线）、18 块径向碎片（内三角 + 外梯形，确定性随机 seed 17）、空框 `.frame` |
| 分段 | 0–900ms 裂纹沿路径依次画出（`c04-crack` dashoffset len→0，`cubic-bezier(.3,.1,.6,1)`）；900ms 起碎片按离起裂点距离逐块坠落，每块 delay 900 + i×85ms，单块 720ms 重物曲线（dx = 离心 .45 倍 + 抖动，dy 150–280px，rot ≈ 离心角）；1900–2500ms 裂纹淡到 α.35；3200ms 落定 `void`：碎片移除，留下 1px 边空框 + 深色底 + 残留裂纹 + 「已取消 · 票根作废 / VOID」；随后端态构图 520ms 弹簧落定（标题 / 受影响人数 / 事实表） |

### 出票（全息成像，§6 打印对应）
触发：进入「待撕票」/「改期待答复」详情（或确认入局即成局）。出口 = 票上方 2px 发光射线 `.emit`。`c04-print` 2200ms 线性：0–6% 票从 −16px 下落显形；6–28% 成像线 `--c04-rv` 0→30%（票头）；28–36% 停顿；36–64% → 72%（时间与信息）；64–72% 停顿；72–100% → 112%（齿孔与副券，齿孔 / 标记在 72–80% 淡入）。成像线上有 34px 青白光带 `.sweep`（screen）跟随；成像中副券不可拖、显示「正在出票」。`.scrub` 定帧；`.rm` 去遮罩直接显示。

### 其它动效族（简述）
入场 / 落点 `c04-enter`、`c04-land`；角色切换 = 两叠玻璃 520ms 平移 + 滑块弹簧；弹层升起 480ms + 背景 blur 6px；联系层 / 撤销条 460ms 弹簧升起；事实变化 `c04-settle`（标题、进度、申请结果行、珠串 `c04-beadin`）；出席章 `c04-mark`（1.8→.96→1 + 去模糊）；草稿删除 = 行 max-height 380ms 折叠 → 撤销条 10s 琥珀计时 → 撤销后 `c04-enter` 回位；处理中 = 按钮光带扫过 `c04-busy` + 失败后底部红玻璃条（重试 / 取消）；提示条 `c04-toast` 2.6s。
