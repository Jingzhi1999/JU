## 2. 三个核心动作

### ① 走纸打印（出票）
- **触发**：进入票面（从列表点「撕开票根」等 ticket 物件行）、改期答复界面打开（新版票）、全员确认成局（`engine.confirmReservation` 返回 `formed:true`）；评审面板「重播」重印同一张票。
- **运动对象**：票（`.c01-tkwrap > .c01-pr`，高 250px 的一截纸）。纸带上方内容不动，下方内容被推下（让位）。
- **起点 / 终点**：高度 0（印头处）→ 250px 落定在该行之下；票面文字随纸露出，不缩放、不移动。
- **分段**（总 2200ms × k）：0–24% 走纸到 34%，24–34% 停顿，34–60% 走到 72%，60–70% 停顿，70–96% 走完，96–100% 停稳。关键帧 `c01-feed3`，`linear` 分段；每段像步进电机的匀速推进。
- **变换中心**：顶边（高度动画，`overflow:hidden`）。
- **遮罩 / 阴影**：印头处 10px 向下的暗渐变（`.c01-pr.printing::after`），打印完消失；打印中副券 `pointer-events:none`，提示文「出票中 · 打印完成前不能撕」。
- **中断 / 重播**：`.scrub` 下 `animation-play-state:paused` + `animation-delay:-frame×dur×k`；`.rm` 下直接高度 = 终值；重播由 `beforeReplay('print')` 把票置回 idle 再打印。
- 同族快版：进入详情 / 工单正文用 `c01-feed2`（900ms，一次停顿），切换标签页 700ms。

### ② 沿孔撕票
- **触发**：在副券右端按下（`onPointerDown` + `setPointerCapture`），向左 / 向下拖；`p = clamp((−dx·1.0 + dy·1.15)/175)`。
- **运动对象**：同一张票渲染两份（keep / stub），各自 `clip-path` 由 `c01TearClip`（从右向左：`x ≥ (1−p)·w` 为已撕）生成；已撕段 = 纤维轮廓，未撕段 = 直线齿孔。
- **过程**：拖动中副券以左上角为轴 `rotate(p·12deg) translateY(p·4px)`，撕口张开 `p·6px`；亮纤维带 + 软阴影只画在已撕段；p < 0.55 释放 → 220ms ease-out 回弹到 0。
- **落点**：p ≥ 0.55 释放 → 先 `engine.tearTicket`（或改期新票 `engine.acceptReschedule`；失败则回弹并出现重试条），成功后副券 `off`：820ms `cubic-bezier(.45,.02,.75,.5)`，`rotate 12→−26deg`、`rotateX 0→70deg`（卷曲）、`scale .68`、`translateY(--drop)` 到底栏存根槽（drop 由副券实际位置测得），进入槽后在存根堆里出现一片新存根（420ms 弹入）并计数「存根 N」。
- **留下的部分**：主票高度 250→184px，底边换成锯齿 `clip-path`，对应「已撕票待联系」；300ms 后联系层（局主微信 + 复制 + 已加微信）以墨迹揭示方式打印。
- **变换中心**：副券 `transform-origin: 0 0`（仍附着的左端）。
- **中断 / 重播**：拖动中切换数据会重置；`.scrub` 控制落下关键帧；重播：`beforeReplay('tear')` 恢复未撕、移除最后一片存根，再次落下。

### ③ 焦卷作废（取消 / 退出 / 拒绝改期）
- **触发**：局主「取消这局」便签 → 确认取消 → 700ms「取消中…」→ `engine.cancel` 成功 → 工单上的活动条起火；参加者「去不了了」/「新时间去不了」确认 → 票起火；`j-d-cancelled` 直接显示残片。
- **运动对象**：同一张票 / 活动条（`.c01-burn` 容器 + 内嵌 SVG mask）。起火点：工单活动条在局卡缩略图下沿 (60,70)，票在右下 (250,120)。
- **过程**（2600ms 票 / 2800ms 条，`cubic-bezier(.35,.05,.5,1)`）：mask 中 `circle.c01-hole` 半径 0 → `--reach`（经 `#fx-rough-strong` 置换成毛边），同半径的 16px 深棕炭圈与 5px 橙色余烬线（带 4px 辉光，80% 后淡出）贴着洞沿推进；10 粒纸灰从起火点落向底栏（1500ms ease-in，各自 0–1100ms 延迟、±46px 横漂、旋转），落到槽后底栏出现灰堆。
- **剩余形态**：烧尽后容器折叠为 0 高，原位出现焦炭残片 `.c01-char`（深棕、上下锯齿 clip-path、灰字：时间 · 局名 · 「已取消 · 票根作废 · 联系已关闭」），600ms 落定。
- **结果一致**：工单头状态「已取消」、进度隐藏、成员行「取消前已确认 / 取消前已预留」、安排只剩「再开一局」（本范围内不可点）；返回列表落在 历史 › 已取消 的焦边条目上（高亮 1.6s）。参加者侧：票残片 + 结果块（已退出这局 / 未接受新时间），返回落在 未成行。
- **遮罩 / 阴影**：mask 作用在整张票上，炭圈与余烬在 SVG 内（`overflow:hidden` 裁到票框）；纸灰在遮罩之外的兄弟层。
- **中断 / 重播**：`.scrub` 暂停洞、炭圈、余烬、纸灰四组关键帧并按 `--frame` 定位；`.rm` 直接呈现残片；重播 `beforeReplay('burn')` 复原票 / 活动条再烧。

## 3. 其余动效族（简述）
- 共享元素展开：点行 → `JU.fx.rectIn` 取矩形 → 第二层纸上的同一条从原位（`--dy`）420ms `cubic-bezier(.2,.8,.2,1)` 滑到返回行之下，底层纸带墨色退到 18%，第二层纸底色 320ms 变实；返回反向，原行在落点高亮。
- 身份切换：纸带 430ms 收回出纸口（`translateY(-780px)`），换卷，再 520ms 走出；拨杆同步 380ms。
- 分区切换：正文快速重印 420ms。
- 便签：右侧滑入 380ms `cubic-bezier(.2,.9,.3,1.05)`，落定 −1.2°，背景压暗 45%。
- 回执小条（toast）：从底栏槽升起 420ms，2.6s 后退回。
- 印章（出席记录）：560ms 从 1.9 倍落下带 −20°→−9° 回正。
- 草稿删除：行 360ms 收起（高度实测 `--rh`）→ 撤销条 10s 墨线倒计时 → 撤销 420ms 回到原位。
- 处理中：按钮右侧三点步进；失败：底部红边纸条（重试 / 取消）。

## 2. 三个核心动作

### ① 状态翻牌（M5 / M7 / M1 / M2 的落定方式）
- **触发**：任何翻牌键下的文字改变（`cells(key, text)` 在渲染时比较上一次文字）：审核通过 / 谢绝后管理盘头部状态「2 份申请待审 → 1 份申请待审」、出席记录「未记录 → 出席」、取消后「已取消」、参加者侧「待撕票 → 待联系 → 待赴约」、牌头标题「局主改了时间 → 新时间已确认」、列表行状态与时间（改期接受后时间格翻到新时间）。身份 / 分区切换用整板翻（见下）。
- **运动对象**：每格四层（`.c02-fh.top` 新面上半、`.c02-fh.bot` 旧面下半静止；`.fa` 旧面上半、`.fb` 新面下半旋转）。文字本身不位移，只有翻片在翻（REF33 的「只有边在走」）。
- **分段**（每格）：fa `rotateX(0→-90deg)` 170ms `cubic-bezier(.55,0,.9,.6)` 轴在格底；fb `rotateX(90→0deg)` 210ms `cubic-bezier(.2,.8,.3,1)` 轴在格顶，延迟 160ms；落定「咔」`translateY(1.5px)` 140ms 在 +340ms；格间错峰 55ms × 格序号（`--i`）。变换中心：fa `50% 100%`，fb `50% 0`；每格 `perspective:260px`；`backface-visibility:hidden`。
- **结束**：flip 类在 `60ms × 字数 + 620ms` 后移除（`forceUpdate`），各层回到静止（旧面 = 新面），文字清晰无残影（实际观察：`evidence/C02/manage/`、`end-att/` 中翻到一半与翻完的帧）。
- **整板翻（身份 / 分区）**：身份牌先 150ms 滑动并按覆盖像素反色（`.c02-plfg` `clip-path: inset(0 50% 0 0) ↔ inset(0 0 0 50%)`，REF15），同时所有行 `rotateX(0→-90deg)` 220ms（机械曲线，错峰 `min(i,9)×22ms`）→ 300ms 后换身份、滚动归零 → 行 `rotateX(90→0)` 320ms `cubic-bezier(.2,.8,.3,1)` 同样错峰；分区切换同构（240ms 换）。`perspective:1000px` 在 `.c02-list`。
- **中断 / 重播**：翻牌过程中切换数据只会让新文字再翻一次；`board` 忙时忽略再次切换；评审「重播」在 `beforeReplay('flap')` 里把最近翻过的键恢复成旧文字再翻一次；`.rm` 下 1ms 直接换面。

### ② 过闸撕票（M8 撕票 + 出票）
- **出票（打印的站牌版）**：触发 = 本版票第一次打开（`tear` 行的票面、改期新票、确认入局后 `formed`）。卡从读卡槽上方的出卡区**向上**分段露出：`c02-issue` 2200ms linear，`translateY 104%→70%`（0–18%）停（18–26%）`→30%`（26–48%）停（48–56%）`→-2%`（56–80%）`→1%`（88%）`→0`（100%）；印刷用 `--c02-ink`（`@property` 注册）驱动的自下而上 mask（`linear-gradient(0deg, #000 ink, transparent ink+10%)`）紧跟卡的上沿露出字迹；读卡灯琥珀、显示屏「出票中 · ISSUING」；出票中卡 `pointer-events:none`，提示「打印完成前不能插卡」。`.scrub` 下 `animation-play-state:paused` + `animation-delay:-frame×dur×k`；`.rm` 1ms。已出过的版本记在 `tk.printed`，再进不重印。实际观察：`evidence/C02/print/sheet.png`、`confirm-flow/`。
- **过闸（撕票）触发**：在 `.c02-gatecard`（ready 态，`cursor:grab`）按下并**向下**拖（`setPointerCapture`）；`p = clamp(dy / 150)`；卡 `translateY(p × 58%)` 跟手（无过渡）；显示屏「插入中 · NN%」，提示「再推一点 / 松手 · 读卡」。
- **释放**：`p < 0.55` → `spring` 240ms `cubic-bezier(.2,1.1,.3,1)` 回弹到 0；`p ≥ 0.55` → **先写入** `engine.tearTicket`（改期新票 = `engine.acceptReschedule`），失败则回弹 + 红灯故障条「…请重新插卡」+ 重试（重试直接再吞卡），成功才进入序列。
- **序列**（`gateSeq`，均用 `this.after`）：0ms 吞卡 `motor` 260ms 机械曲线到 58%（显示 FEEDING）→ 300ms 读卡（琥珀灯 READING，「请勿拔卡」）→ 1020ms 打孔：读卡器 `c02-shake` 120ms 下沉 2px，卡加 `punched`（真孔 mask），碎屑窗内圆片 `rest`：`translateY(-20px)→0 rotate(20deg)` 300ms `cubic-bezier(.4,0,.6,1.4)`（分离部分有重量地落入槽内 = 残留物）→ 1700ms 吐卡 `eject` 460ms `cubic-bezier(.3,0,.2,1)` 回到 0 → 2200ms 落定：绿灯「已过闸 · PASSED」，联系条 `translateY(14px)→0` + 透明度 300ms `cubic-bezier(.2,.9,.3,1)`（局主 · 微信号 · 复制 · 已加微信）。留下的卡 = 右下带孔的同一张卡，对应「已撕票待联系」；列表行状态翻成「待联系」。
- **变换中心**：卡 `transform-origin: 50% 100%`（槽口一侧）。遮罩：打孔 mask 作用在整张卡面；碎屑在读卡器槽内（卡面之外）。
- **中断 / 重播**：拖动中换数据集会重置；`beforeReplay('gate')` 把卡放回 ready、清空碎屑、收起联系条，再跑一次序列（不重复写入）。实际观察：`evidence/C02/tear/sheet.png`（17 帧）、`resched-accept/`、`punch-close/`。

### ③ 过热作废（M8 作废 / 燃烧）

## 2. 三个核心动作

### ① 翻页展开（目录条目 → 跨页；M4，也用于身份切换 M1）
- 触发：点目录条目 / 封面 / lead CTA；身份切换点刊名。
- 运动对象：整张目录页（`.c03-leaf`，含底栏），绕书脊（`transform-origin: 0 50%`，`perspective: 2000px` 在 `.app`）向左翻 0 → −180°。跨页在翻页开始时已完整排在下面（z 3，叶 z 6）。
- 阶段：0–140ms 该条目右缘出现红色书签（`.c03-mark`，180ms ease 滑入）；0–900ms `c03-turn`（`cubic-bezier(.45,.05,.3,1)`）；叶右缘 26px 页边渐变 `c03-edge` 在 30–60% 时间内 0→1→0；下页上的扫动阴影 `c03-shade`（左起 38% 墨色渐变，`scaleX 1 → .5 → .06`，20–55% 时间最深）；900ms 后叶 `visibility:hidden`（保留滚动位置），跨页可操作。
- 返回：`c03-turn-back` 820ms（`cubic-bezier(.4,0,.2,1)`）−180 → 0，阴影反播；返回前若条目换了分区先切分区并 `scrollIntoView` 原条目，落地后该行红书签保持 2s（`landed`）。
- 身份切换：两页同时渲染（旧刊作叶 620ms 快翻，新刊在下），翻完后恢复该刊的分区与滚动记忆。
- 减少动态：1ms；中断：翻页中不响应二次点击（`view.phase === 'turn'` 时 `closeOver` / `openOver` 直接返回）；重播：`beforeReplay('turn')` 回到目录再翻。
- 证据：`evidence/C03/card-detail-back/sheet.png`（0.5×）。

### ② 撕角券（票页右下副券；M8 撕票，也是改期接受）
- 触发：按住副券（`.c03-side.stub`，`data-act="tear"`，setPointerCapture）向左上拖；键盘 Enter / 空格直接撕。
- 几何：票面 334×236，副券 132×92（内角 (202,144)），上、左两条齿孔。两份票面：keep（页面）与 stub（券）各由 `c03Clips(p)` 给出互补多边形；撕口沿上边从右向内、沿左边从下向内同时推进，撕过的段用 `JU.fx.tearProfile` 的纤维偏移（上 22 段 ±3.4px，左 16 段 ±3.4px），未撕段保持直线齿孔；两条纤维带（白 / 灰）只画在已撕段上。
- 进度：`p = clamp((−dx + −dy·0.7) / 150)`。stub 变换 `translate(−12p, −9p) rotate3d(.57,−.82,0, −44p°)`（绕内角、垂直于对角线的轴抬起，`perspective:700px`），阴影 `14p 18p (22p+4) rgba(20,10,0,.18+.22p)`；抬起即显示页下（`.c03-under`：`--paper2` + 内阴影）。
- 释放：p ≥ 0.55 → `engine.tearTicket`（改期则 `acceptReschedule`）80ms 处理后 stub 加 `off`：`c03-fall` 760ms `cubic-bezier(.5,0,.85,.4)`，从当前姿态（`--c03-pose`）落到页底夹页（55%：`translate(−18px,150px) rotate(−14deg)`；100%：`translate(−14px,246px) rotate(−19deg) scale(.98)`），落定后由夹页里的「副券 · 已撕 JU-NNN」存根接续（同一物件归宿）；页面保留撕口与露出的下页。300ms 后联系层校对条升起；改期接受再 toast「已接受改期」。p < 0.55 → 360ms `cubic-bezier(.34,1.5,.64,1)` 回弹。写入失败 → 副券复位 + 行内「未能保存，请重新撕下副券 · 重试」。
- `.scrub` 支持落券关键帧；减少动态直接分离；重播恢复未撕态并关闭联系层。
- 证据：`evidence/C03/tear/sheet.png`，`evidence/C03/reschedule-reply/sheet.png`。

### ③ 烧页（取消 / 退出 / 拒绝改期；M8 作废）
- 触发：局主「确认取消」后（对象 = 编辑部的局卡条 334×96）；参加者「确认退出」后（票页 334×236，起火点 (86,160)）；拒绝改期（新票页，起火点右下角 (318,226)，卷边炭化变体 B）；`cancelled` 的历史首次打开烧一次，之后静态（`burned[id]`）。
- 阶段：写入先于动效 → 360ms 后 `.fx-burn.burning`：SVG mask 的 `.fx-hole` 从起火点 r 0 → `--fx-reach`（票 470 / 局卡条 380）2600ms `cubic-bezier(.3,.05,.55,1)`，`feTurbulence` 毛边；`.fx-ember` 14px 火线沿孔缘推进、85% 后淡出；兄弟层 `.c03-ashes` 12–14 片纸灰从起火点附近一次性落下（1400ms，延迟 0–900ms，位移 ±48 / 110–150px）。2600ms 后 `burnt`：票面隐藏，同位置留下焦边页框（粗糙描边矩形 + 两道焦痕）与结果字「票根作废 · 主动退出 · 联系关闭」/「新票作废」/「已取消 · 归入往期」。
- 落点：局主侧头部状态「已取消」、进度行隐藏、成员行 void、安排区只剩惰性「再开一局」，返回目录后落在往期 · 已取消的焦边封面；参加者侧 CTA 变「查看退出结果 / 查看取消结果」→ 返回落在未成行的焦边封面。
- `.scrub` 用共享规则定格任意帧；暂停可停在半途；减少动态直接出现焦框；重播（`beforeReplay('burn')`）恢复完整票面再烧。
- 证据：`evidence/C03/cancel/`、`burn-void/`、`reschedule-reply/`（后半）。

### 出票（全息成像，§6 打印对应）

### 材质规则
- 台面 = 坯布：3px 经纬重复渐变（横 `rgba(255,255,255,.28)` / 纵 `rgba(70,58,36,.08)`）+ 整屏一层 `feTurbulence baseFrequency .9` 极细纤维噪点（alpha ≤ .11，`.c05-grain`）。只有一束光，从左上：所有投影偏右下（裁片 `drop-shadow(1px 2px 0) + (5px 9px 9px)`，lead `9px 15px 14px`）。
- 裁片 = 漂白布块：矩形 + 右上 26px 斜切角（`clip-path` 多边形；阴影用 `filter: drop-shadow` 跟随切角）；lead 与详情裁片叠 26px 粉笔格（REF68 的「变形刻度」，静止时作为裁缝台面的格线）；左边一个三角牙口（裁缝对位记号）；表面 160° 高光渐变。
- 四针白标（`.c05-lab`）：白底 + 四角各一针 5px 对角线（四个 `linear-gradient` 背景，四角定位）；状态只换文字颜色：红粉笔 = 要你回应，蓝 = 等待，绿 = 就快见面，灰 + 布色底 = 未成行。

- 吊牌：232×176 硬卡纸，左上 14px 切角，18px 金属扣眼；棉线两层（暗底 + 亮面 2.6/1.4 虚线 = 捻线）。存根袋：裁片底部 68px 一条略深的布袋，上沿白边 + 内阴影 + 针脚线。右侧 26px「翻起的布边」（`.c05-edge`）带投影，吊牌从它底下抽出。

- 弹层 = 翻起的布角：底部整块裁片上滑，顶部 18px 折边渐变 + 针脚线；背景压暗 `rgba(50,40,25,.4)`。
- 未成行 / 已取消 / 草稿：只画粉笔 / 灰线轮廓（无填充、虚线描边、切角仍在），已取消再在切角处留一小块焦痕；文字换 `--ash` / `--ink3`。
- 圆角：几乎没有（按钮 2–3px）；边线 1–1.5px；噪点只在台面一层，文字永远在纯色裁片上。

## 2. 三个核心动作（REF 对应见 §3）

### ① 翻开裁片（局卡 → 详情，M4；同一机制用于管理与草稿）
- 触发：点裁片任意处（`.c05-hit`）或 lead 的织带 CTA。运动对象：覆盖层 `.c05-over.c05-full`（clip-path 从行矩形到全屏）+ 内层 `.c05-sheetwrap`（translateY 从 `行.y − 58` 到 0）+ 裁片下半片 `.c05-flap`（`perspective(1400px) rotateX(72deg) → 0`，变换中心 50% 0 = 折线）。
- 起点：`JU.fx.rectIn(行, .app)`；`phase:'start'` 渲染后 `void getBoundingClientRect()` 刷新样式再切 `'in'`。
- 分段：0–460ms clip-path + 位移（`cubic-bezier(.2,.8,.2,1)`）；150ms 延迟后 560ms 翻片落平（`cubic-bezier(.3,1.18,.32,1)`：越过 0 约 −3° 再回到 0 = 布料落平后回摆一次，REF37）；翻片上方的折痕阴影渐变（`rgba(40,30,20,.38) → 0`）同步淡出；900ms 后进入 `'flat'`：移除 clip-path / transform / 阴影层，文字重新以恒等变换栅格化（无模糊残留）。背景：头部、台面、底栏加 `.back`（`blur(2px) brightness(.9)`，420ms），不缩放，保证返回时测量矩形准确。
- 返回：`scrollTop=0` → 若行换了分区先切分区 → `scrollIntoView` → 翻片 300ms 折回（`cubic-bezier(.5,0,.8,.4)`）→ 120ms 后 clip-path / 位移 460ms 收回行矩形 → 620ms 卸载；原行 1.7s 粉笔蓝高光（`.landed`）。找不到原行 → 收回到打开时的矩形。
- 中断 / 重播：`after()` 全部随面板暂停；`beforeReplay('open')` 回到列表再播；`.rm` 下 1ms 直接到位。
- 证据：`evidence/C05/card-detail-back/sheet.png`（0.5×，23 帧：f01–f03 可见裁片一边升到顶一边翻开，f12–f15 折回收进原行）。

### ② 剪线撕票（吊牌断线，M8；`tear` 首次打开先走「挂牌」= 出票）
- 挂牌（出票）：`phase idle → printing`：`.c05-tagwrap` keyframes `c05-tagin` 2000ms linear：`translateX(130% → 84%（18–30% 停）→ 38%（50–62% 停）→ −1.5% → .8% → 0)` = 三次抽出、两次停顿，吊牌从右侧布边底下露出（布边 z 5 在上，投影压在卡纸上）；2000ms → `tying`：棉线 `stroke-dashoffset 400 → 0` 520ms（`cubic-bezier(.4,.1,.5,1)`），480ms 后线结 `scale(0 → 1)` 260ms（`cubic-bezier(.2,1.4,.3,1)`）；2700ms → `ready`（出现「↓ 拉」粉笔字与去不了了）。挂牌中吊牌不可拖、无操作按钮。`.scrub` 下 `c05-tagin` 以 `--frame` 定格。
- 断线（撕票）：`onPointerDown`（setPointerCapture）→ `onPointerMove` 把 `dy` 映射到 `p = dy / 36`（clamp 0–1）：吊牌 `translateY(p·36)`、投影抬高（`.lifted`）、棉线二次贝塞尔的垂度 `24·(1−p)` → 0、线宽 2.6 → 1.5（绷紧）。释放 `p ≥ .55`：先写入 `engine.tearTicket`（160ms 处理，吊牌保持绷紧的「hold」），成功 → `motion('tear')`：线在结处断开——裁片一侧线头 `.c05-stub` 以结为轴 `rotate(−58° → 16° → −7° → 0)` 560ms（`cubic-bezier(.2,1.2,.3,1)`）回弹，末端 3 根线纤维；吊牌一侧残线 `.c05-remsvg` 挂在扣眼下摆动 `30° → −14° → 6° → 0` 900ms；吊牌 `c05-tagdrop` 700ms（`cubic-bezier(.45,.05,.5,.95)`）`translateY(36 → 67 / rotate −3.4° → 50 / 1.6° → 56 / 0)` 落进存根袋（袋口 z 4 盖住卡纸下 34px）。740ms → `torn`；1020ms → 联系白标 420ms 上浮出现。`p < .55` 释放：`transform` 420ms `cubic-bezier(.2,1.3,.3,1)` 回弹，线重新松垂。写入失败：吊牌弹回 + 底部红线失败条「没保存上 · 本机保存失败，请重试」，重试成功后继续断线。
- 结束态：粉线叉上留一截线头（`线头留在裁片上`），吊牌在存根袋里仍可读（标题 / 时间 / 集合 / 地点），列表小吊牌的线变成断头。
- 改期接受 = 同一动作作用于新版吊牌（`data-act="accept"` → `engine.acceptReschedule`），落袋后旧吊牌盖「作废」。
- 证据：`evidence/C05/print/sheet.png`（挂牌 12 帧）、`evidence/C05/tear/sheet.png`（0.5×，拖 6 帧 + 断线落袋 8 帧 + 复制 / 已加微信）、`evidence/C05/reschedule-reply/sheet.png`、`evidence/C05/confirm-flow/sheet.png`（阅读约定 → 确认 → 成局 → 挂牌）、`evidence/C05/rm-scrub/sheet.png`（关键帧 30% / 60%）。

### ③ 布面烧焦（取消 / 退出 / 拒绝改期 / 已取消首次打开，M8 + M11）
- 对象：同一张吊牌（参加者）或管理页的裁片头（局主取消），`.fx-burn` + SVG mask（`id="c05-hole-{uid}"`，`maskUnits=userSpaceOnUse`，洞用 `fx-rough-strong` 打毛）。起火点：吊牌右下角（222,168），裁片右上切角（338,12）。
- 分段：`--fx-dur` 吊牌 2600ms / 裁片 3000ms，`cubic-bezier(.3,.05,.55,1)`：洞半径 `0 → 5% → reach（330 / 430px）`；洞缘同步三圈描边（都被 mask 裁掉内侧一半，只剩外沿）：`c05-glow` 3px 琥珀 `#f0b060`（火线）→ `c05-char` 12 / 16px 焦黑 `#2b1c14` → `c05-scorch` 32 / 40px 棕 `#8a5e38` α.6（焦黄晕）→ `c05-fuzz` 3px 灰棕 `1.5 2.5` 虚线 + 毛边滤镜（布边起毛）；最后 15% 火线淡出。灰烬：12–14 粒 `fx-ash` 从起火角散落（`JU.fx.scatter`，1400ms，位于 mask 之外的兄弟层）。

## 2. 三个核心动作

### ① 拿起 / 放下（M4，所有 `p_detail` / `p_ticket` / `p_history` / H1 进入与返回）
- **触发**：点物件（`[data-rid]`）；`openOver()` 用 `JU.fx.rectIn` 取 bbox，按中心 + `offsetHeight` + 行内 `--rot` 反推未旋转矩形 `from{x,y,h,rot}`。
- **运动对象**：同一物件（`.c06-held`，复用列表的物件模型与标记）；原位留下虚线「灰尘轮廓」（`.c06-obj.src::before`，REF92 被拎起的投影）。
- **起点 / 终点**：`translate(from.x, from.y) rotate(from.rot)` → `translate(25px, 80px) rotate(0)`；阴影 `0 7px 12px -7px` → `0 30px 50px -18px rgba(0,0,0,.85)`。
- **分段**：phase `start` 渲染 → 读一次布局（`getBoundingClientRect`）→ 20ms 后 `in`；物件 430ms `cubic-bezier(.2,.8,.2,1)`；桌面同时 `brightness(.58) blur(1.6px)` 380ms + 遮罩 `rgba(8,16,12,.42)` 360ms；纸张（`.c06-sheetwrap`）从 `translateY(106%)` 推进 440ms 同曲线、延迟 80ms；返回标签带 240ms 淡入（延迟 200ms）。
- **放下**：`closeOver()` 先 `locate()`（物件已换分区则先切分区并 `scrollIntoView(center)`），重新测矩形 → phase `out`（430ms 回到原位、纸张 360ms 退回、遮罩褪去）→ 450ms 后卸载；落点 `landed` 光晕 1500ms。源行找不到（`gone`）→ 160ms 淡出。
- **变换中心**：物件中心（与列表旋转一致）。
- **中断 / 重播**：开启中可直接放下（从当前变换反向）；连点被 phase 判定拦截；`.rm` 下过渡 1ms；重播 `beforeReplay('lift')` 回到列表再拿起。

### ② 桌上撕票（M8，`tear` 首次打开、改期接受）
- **触发**：按住副券（`.c06-tside.stub`，只在 `clip-path` 多边形内响应，`setPointerCapture`），向下 / 向右拖：`p = clamp((dx·0.9 + dy·1.1) / 170)`。
- **运动对象**：同一张票渲染两份（keep / stub），`c06ClipV()` 以 x=252 竖向齿孔、从**上**往下撕（`y ≤ p·180` 为已撕，纤维轮廓；未撕段仍是直线齿孔）；副券以左下附着点为轴 `transform-origin:252px 180px`，`rotate(p·10deg) translate(p·6px, p·2px)`，撕口张开 `p·5px`，已撕段画 1.6px 亮纤维带。
- **释放**：p < 0.55 → 240ms `cubic-bezier(.2,.8,.3,1.1)` 回弹到 0；p ≥ 0.55 → 先 `engine.tearTicket`（改期新票 `engine.acceptReschedule`，120ms 处理）→ 成功后 `off`：780ms `cubic-bezier(.35,0,.75,.35)` 落到 `translate(-6px, 560px) rotate(-26deg)`（改期新票 330px）→ `rest`：副券留在右下角桌面上，带自己的接触阴影（真实的「桌上多了一片纸」）；主票右缘换成锯齿（`C06_TORN_KEEP`）；1000ms 后局主名片从纸张上方滑入（460ms，`translateY(-70px)→0`）+ 回执 toast。
- **失败**：写入返回 error → 副券回弹、底部红边纸条「本机保存失败，请重试」+ 重试。
- **变换中心**：副券附着端（252,180）。
- **中断 / 重播**：拖动中换数据会重置；`.rm` 直接分离；重播 `beforeReplay('tear')` 复原副券与 p=0。评审脚本可用 `[data-act=accept]`（改期）直接触发 `commitTear('fresh')`。

### ③ 烟灰缸（M8 作废 / 燃烧：主动退出、拒绝改期、局主取消、`cancelled` 首次打开）
- **触发**：确认层「确认退出 / 确认取消」→ 处理中（460ms / 取消 700ms）→ engine 成功 → `motion('burn')`。
- **运动对象**：同一张票（`.c06-tkw`）或同一张索引卡（`.c06-cardburn`）；烟灰缸（SVG 玻璃碟）从左边推进 `left:-200px → -14px` 420ms。
- **起点 / 终点**：票从它在纸张上的位置 → 碟中：`translate(-114px, 714 - (top + 90))px rotate(-14deg) scale(.56)` 620ms `cubic-bezier(.4,0,.6,1)`。
- **燃烧（660ms 后开始，2600ms）**：`.fx-burn.burning` 遮罩里的圆洞从左下角 (44,150) `r 0 → 430px`（`fx-hole`，`cubic-bezier(.3,.05,.55,1)`，`#fx-rough-strong` 毛边）；14px 余烬环同半径推进、85% 后淡出；9 粒纸灰在**兄弟层** `.c06-ashes`（`fx-ash` 1400ms ease-in，延迟 0–1100ms，横漂 ±50px、下落 70–110px）落进碟里。
- **剩余形态（660 + 2650ms）**：票面 `burnt` 隐去；碟里出现灰堆（两枚 `#fx-rough` 椭圆）+ 一片未燃尽的角（`.c06-charbit`，500ms 淡入）；纸张上落下结果块（标签带 + 标题 + 副文，420ms settle）。
- **结果一致**：参加者标题换为 `detailTitle`，联系层关闭；返回列表落在 历史 › 未成行 的杯垫上（杯垫右侧露出同一片残角）；局主：夹板头部「已取消 · 不能撤销」+ 残角、成员 void、安排只剩惰性「再开一局」，列表 → 历史 · 已取消 杯垫。
- **中断 / 重播**：`.scrub` 暂停洞、余烬、纸灰并按 `--frame` 定位（`evidence/C06/rm-half-scrub/`）；`.rm` 直接呈现灰烬结果；重播 `beforeReplay('burn')` 复原票 / 卡并清空碟。

## 2. 三个核心动作

### ① 格子重排（状态变化后格子改尺寸，所有格 FLIP 到新位置）
- **触发**：任何经 `JU.engine` 的写入改变了分组 / lead / 分区（确认入局成局、审核通过、撕票、散场、删除草稿）；在展开层内写入时盘面先冻结（`state.frozen` 指向写入前的数据），返回收回原格后再释放 → 重排在视线内发生。
- **运动对象**：全部 `.c07-tile`（绝对定位，由 `C07.pack()` 计算 left/top/width/height）与组头 `.c07-head`。DOM 顺序固定（按 `data.joined` / `data.hosted` / 草稿初始顺序），位置只由布局结果决定，所以同一张格在运动前后是同一节点。
- **起点 / 终点**：旧 left/top/width/height → 新值；离开本分区的格 `off`（透明度 0 + scale .92 + 240ms 后 visibility hidden）；进入的格反向。
- **分段**：位置与尺寸 520ms `cubic-bezier(.2,.8,.2,1)`；格内布局因尺寸级别变化（L↔W↔S）切换模板时内容 320ms 淡入；盘高 520ms 同曲线；落点格外圈 2px 分区色描边 1.9s（`landed`）。
- **变换中心**：各格左上角（left/top），不用 scale 拉伸文字。
- **遮罩 / 阴影**：无遮罩；lead 格底唇与投影随类名切换（300ms）。
- **中断 / 重播**：期间再点击直接进入新格；`.rm` 1ms 直达；`.swap`（分区 / 身份切换）关闭过渡，改为按 `--i` 错峰 45ms 的 `c07-tile-in`（位移 14px + 3px 模糊 + 透明，REF16 的错峰替换）；重播 `beforeReplay('reflow')` 把 `frozen` 复位为写入前数据再释放。
- 证据：`evidence/C07/confirm-formed-print/`（brunch 确认 → 成局出票 → 返回 → brunch 从 2×2 缩成 2×1、livehouse 升为 lead）、`draft-undo/`（删除让位 / 撤销回位）、`switch-scroll/`。

### ② 刮落撕票（通行证副券像素列被拖动刮下）
- **触发**：在 `.c07-stub`（右侧 3×14 像素列）按下（`setPointerCapture`）向下 / 向左拖，`p = clamp((dy·1.0 + max(0,−dx)·0.8)/150)`；键盘 / 评审用 `data-act="tear"`（改期新票 `data-act="accept"`）按钮走同一路径（自动 p=1，380ms 后提交）。打印中、旧票、已撕、作废时不可刮。
- **运动对象**：42 粒 `.c07-sc`（8px 像素，每粒带确定性抖动 `--jx/--jy/--jr` 与落下延迟 `--d = 行×26ms + 0–40ms`）。
- **过程**：行序 `row/14 < p` 的粒子加 `det`：`translate(dx·.55 + jx, dy·.55 + jy) rotate(jr)`，110ms 跟手；提示文「再刮一点」→ p ≥ .55「松手就撕下」；未过阈值释放 → 260ms `cubic-bezier(.2,.8,.2,1)` 回到格位。
- **落点**：过阈值释放 → 先写入（`engine.tearTicket` / `acceptReschedule`，220ms 处理）→ 成功后 `.falling`：每粒 `c07-sc-fall` 900ms `cubic-bezier(.5,0,.9,.6)`，从跟手位置落到 `translate(jx·3−20px, 270px) rotate(jr·6)` 并淡出，按 `--d` 错峰（总 ≈1.0–1.1s）；1000ms 后副券位变成点线「存根槽」（`slot`）+ 底部 3 粒残留像素，标签 `STUB · 已撕`；1280ms 后联系层子格（局主 · 微信 · 复制 · 已加微信）错峰进场；改期新票刮下后旧票子格卸载，新票标题改为「通行证」，toast「已接受改期 · 按新票根的时间见」。
- **失败**：写入失败 → 粒子 260ms 回位 + 票下方红条「未能保存，请重新刮下副券（本机保存失败，请重试）」+ 重试（重试 = 自动再刮一次）。
- **变换中心**：每粒自身中心；落下在票框之外可见（`.c07-void` 不裁切）。
- **遮罩 / 阴影**：无遮罩；副券区 4% 墨色渐变暗示可刮；已撕后只剩虚线槽。
- **中断 / 重播**：`.scrub` 暂停落下关键帧并按 `--frame` 定位（1100ms 轴）；`.rm` 直接呈现已撕；重播 `beforeReplay('tear')` 复原未撕、收起联系层后再刮。
- 证据：`evidence/C07/tear/`（真实拖拽：detach → 阈值提示 → 落下 → 存根槽 → 联系层）、`resched-accept/`、`fail-retry/`、`replay/`。

### ③ 像素作废（取消 / 退出 / 拒绝改期：通行证从一角逐块脱落、变灰，合成历史里的灰格）
- **触发**：局主「取消这局」操作盘确认 → 460ms 处理 → `engine.cancel` 成功 → 操作盘收起 120ms 后局卡·通行证开始脱落；参加者「去不了了」确认 → `engine.exitEvent`（`effect.burn`）→ 主票脱落；「新时间去不了」→ `engine.declineReschedule` → 新票脱落。脱落期间 hero 保持写入前的状态（`view.hold`），残留落定时才翻为灰色终态。
- **运动对象**：同一张 `.c07-pass`，被 12×8 的 SVG `<mask>`（`id="c07-vm-{uid}"`，96 个 `rect.vc`）遮罩；兄弟层 `.c07-vf` 96 粒等尺寸像素碎片（颜色按格位取：二维码区墨 / 白交错、副券列墨、其余白 + 少量灰）。
- **过程**（总 ≈3.2s）：起火点右上角；每格延迟 `d = (距角距离/最大距离)^1.05 × 1900ms + 0–140ms`。到时刻该 mask 格 `opacity 1→0`（1ms steps，票面出现缺口），同一时刻兄弟碎片出现并 `c07-vf-fall` 1200ms `cubic-bezier(.45,0,.9,.55)`：先 18% 上抬 6px，再落到 `translate(±40px, 230–300px) rotate(±160°)`，`grayscale 0→1`、淡出 —— 缺口沿对角线推进、碎片一路变灰。
- **剩余形态**：3200ms 后 `dropped`：票面 `visibility:hidden`，原位 420ms 落定一个灰格 `.c07-ghost`（虚线边、3×3 灰像素、右下 2 粒残留像素），文字「票根作废 · 局主取消 / 主动退出 / 新票作废 · 拒绝改期」+ 后果句；参加者侧随即出现结果子格（已退出这局 / 未接受新时间 / 回到格盘）。
- **结果一致**：局主 hero「已取消」、进度格隐藏、成员行「取消前已确认 / 取消前已预留」、安排区只剩「再开一局」（本范围内不可点）；返回列表时落在 历史 › 已取消 的灰色 1×1 格；参加者历史的 `cancelled / exited / declined` 首次打开直接显示灰格（不重放）。
- **变换中心**：碎片各自中心；mask 坐标 = 票面像素坐标（`maskUnits=userSpaceOnUse`，覆盖 400×260 以容纳更高的票面）。
- **遮罩 / 阴影**：mask 只作用在 `.c07-pass`；碎片在 `.c07-void` 的兄弟层，不被裁切；灰格无投影（已失效的物件不离开盘面）。
- **中断 / 重播**：`.scrub` 同时暂停 mask 格与碎片两组关键帧（`animation-delay: d·k − frame·3200ms·k`）；`.rm` 直接灰格；重播 `beforeReplay('void')` 复原票面后再脱落。
- 证据：`evidence/C07/cancel/`、`void-exit/`、`resched-decline/`、`scrub/`、`half-rm/`、`replay/`。

## 2. 三个核心动作

### ① 改期滑动（M7）—— `acceptReschedule()` / `.c08-slide`
- **触发**：改期答复面板里点「接受新时间」（`data-act="accept"`）；评审面板「重播」走 `beforeReplay('slide')` 把块放回旧位。
- **运动对象**：面板里的局部尺段（46px 尺 + 刻度，比例：时差 ≥4h 0.6px/min、≥2h 0.9px/min、否则 1.6px/min）上的**同一个块** `.c08-sblk`（高 118px）。打开时块停在旧时间刻度，新时间处是红色虚线占位「新时间 · 21:30 · 等你答复」；上方对照卡「原定 ~~周五 12.18 · 20:30~~ → 改为 周五 12.18 · 21:30 [晚 1 小时]」。
- **分段**：0ms 写入（`engine.acceptReschedule`，处理中 300ms）→ 块 `top` 旧 → 新，640ms `cubic-bezier(.3,.7,.2,1)`，运动中投影加深（`moving`），红色占位 300ms 淡出，旧位 200ms 后 400ms 淡入虚线淡影「~~20:30~~ 原定 · 旧票不再使用」→ 700ms 时块面换成票纸并开始**打印**（见 ②的打印段，1800ms）→ 打印完 240ms 后副券自动打卡脱落（820ms）→ 落定 300ms 后联系层淡入、存根槽 +1 → 1200ms 后 toast「已接受改期 · 按新票根的时间见」。全程约 5.2s × k。
- **变换中心 / 遮罩**：块用 `top` 过渡（相对局部尺），票面打印用 `--c08-ink` 驱动的 `mask: linear-gradient(#000 ink, transparent ink+5%)`；印头 `.c08-phd` 7px 深灰条随 `top: var(--c08-ink)` 同步下行。
- **落点一致**：hero 状态 → 待赴约 / 新时间已确认；列表行回到就快见面（已撕票块）；旧位淡影只在面板里保留，列表以票块位置（新时间刻度）表达。
- **中断 / 重播**：`.scrub` 对打印与脱落关键帧按 `--frame` 定位；`.rm` 下块直接到位、票直接印好、联系层直接出现；重播先 `beforeReplay('slide')` 复位到旧位。
- **观察值**：`evidence/C08/resched-accept/`（16 帧，400ms 间隔）：f03 块已在新位 + 淡影，f04–f07 印头四段走纸，f08–f10 副券脱落与打卡，f11+ 联系层与 toast。拒绝改期走 ③（`decline-burn/`）。

### ② 打卡撕票（M8）—— `tearDown/tearMove/tearUp/dropStub()` / `.c08-tkw`
- **触发**：票面右端 84px 副券 `onPointerDown`（`setPointerCapture`，阻止选择），向右拖：`p = clamp((dx·1 + dy·.35)/110)`；拖动中副券 `translate(30p px, 6p px) rotate(9p deg)`，撕口张开 8p px；释放 p < 0.55 → 220ms `cubic-bezier(.2,.9,.3,1.3)` 回弹。
- **运动对象**：同一张票渲染两份（`c08-tk-keep` / `stub`），各自 `clip-path` 由 `JU.fx.tearClipV({w:302,h:156,x:218,profile,progress:p})` 生成；撕裂从顶端沿打孔线向下推进，已撕段是纤维轮廓、未撕段是直线孔。
- **落点**：p ≥ 0.55 释放 → 先写入（`engine.tearTicket`，失败则回弹 + 红边重试条）→ 副券 `off`：820ms `cubic-bezier(.45,.02,.7,.5)`，`translate(34,-4) rotate(4°)` 30% 后 `translate(120,170) rotate(26°)` 淡出（有重量地甩出去落下）→ 票面右沿换成锯齿、左上出现 16px **打卡孔**（360ms 弹入）+ 纸屑 chad 700ms 落下 → 存根槽 `.c08-stubtray` 出现一片新存根（420ms 弹入，计数「已撕 N」）→ 300ms 后联系层（局主 · 微信 · 复制 · 已加微信）420ms 落定并滚入视口。
- **变换中心**：副券 `transform-origin: 0 100%`（仍附着的左下角）。
- **打印（出票）**：`tear` 首次打开 520ms 后或成局后 420ms 后：票纸先以空白票面出现，`.printing` 1800ms 线性关键帧 `--c08-ink: 0→26%（停）→62%（停）→100%→108%`，印头同步下行并在 90% 后淡出；打印中副券 `pointer-events:none`，提示「出票中 · 打印完成前不能撕」。
- **中断 / 重播**：`.scrub` 作用于打印、脱落、打卡；`.rm` 直接呈现已撕态；重播 `beforeReplay('tear')` 用 `forceStub` 复原副券再落下，`beforeReplay('print')` 复位 `printed`。
- **观察值**：`evidence/C08/tear/`（15 帧）：f01–f07 拖动中撕口推进与副券偏转，f08–f10 甩出，f11+ 锯齿边 + 打卡孔 + 联系层；`print/`（9 帧）：四段走纸；`fail-retry/`：写入失败时副券回弹 + 重试条，重试成功。

### ③ 尺上作废（M8 作废 / M9 归档）—— `burnTicket()` / `cancelEvent()` / `.c08-burn` `.c08-scar` `.c08-histrule`
- **触发**：参加者「去不了了 → 确认退出」（`exitEvent`，burn）、「新时间去不了 → 确认退出」（`declineReschedule`）、局主取消（`h-m-cancel` → 确认取消）、`cancelled` 票根首次打开（600–760ms 后自动烧一次，之后静态灰烬）。写入先于动效；写入失败停在抽屉内重试条。
- **运动对象**：同一张票（302×156）或管理页的局卡条（302×84），容器 `.fx-burn.c08-burn` + 内嵌 SVG mask。起火点在**中间**（`cx=151`），`--fx-reach` 196 / 176（≈ 半对角线 + 毛边余量，保证 2.6s 内洞缓慢吃完整张）。
- **过程**（2600ms，`cubic-bezier(.3,.05,.55,1)`）：mask 圆 `r: 0 → 5% → reach`（`#fx-rough-strong` 置换成毛边）+ 同半径 12px 焦炭圈 + 7px 橙色余烬线（4px 辉光，85% 后淡出）贴洞沿外推；10 粒纸灰（`JU.fx.scatter(10)`，各自 0–900ms 延迟）从票面落向下方 1400ms；票面文字随洞消失（mask 作用在整张票上，文字不糊）。→ 2600ms：票容器 `burnt`（折叠）→ **焦痕** `.c08-scar` 16px 焦炭条在票的位置 600ms 从 `scaleY(.2)` 立起（下方烟渍）→ 3250ms：焦痕 760ms `cubic-bezier(.4,0,.2,1)` 沿尺下滑 38px 落进下方的**历史尺** `.c08-histrule`（一段带刻度的尺条，虚线空槽变为实心焦痕槽）→ 4050ms：结果构图（标题「已退出这局 / 未接受新时间 / 局主取消了」+ 事实副文 + 回到列表）。
- **结果一致**：参加者返回时落在历史 › 未成行，该行就是尺上的一道焦痕（标题 / 状态 / 副文两行）；局主取消后头部「已取消」、进度隐藏、局卡条不再回来（历史尺里的焦痕代替它，「票根作废 · 联系已关闭」+ 查看局卡）、成员 void、安排区只剩「再开一局」（惰性）；返回落在历史 › 已取消。
- **遮罩 / 阴影**：mask 作用整张票，炭圈与余烬在 SVG 内（`overflow:hidden` 裁到票框）；纸灰在遮罩外的兄弟层 `.c08-ashes`。
- **中断 / 重播**：`.scrub` 暂停洞、炭圈、余烬、纸灰、焦痕立起并按 `--frame` 定位；`.rm` 直接呈现焦痕已入槽 + 结果；重播 `beforeReplay('burn')` 用 `forceTicket` 复原票 / 局卡条再烧。
- **观察值**：`evidence/C08/exit-burn/`（15 帧，480ms）：f04 小洞、f05 中洞 + 炭圈、f06 大洞 + 余烬、f07 烧尽 + 纸灰、f10 焦痕立起、f11 滑入历史尺、f12 结果、f14 列表落点；`cancel/`（局主取消 → 历史尺 → 票根作废构图 → 历史 › 已取消）；`decline-burn/`、`history/`（`cancelled` 首次打开）；`rm-half/`（减少动态直达结果；0.5× 与关键帧滑杆）。

## 2. 核心动效 ①：撕贴纸 → 露出下一层（局卡 → 详情，M4）

## 2. 三个核心动作

### ① 显影出票（打印的替代形式）
- **触发**：进入 `tear` / `reschedule` 票面（首次打开，`openDetail` 后 520ms）、全员确认成局（`engine.confirmReservation` 返回 `formed:true`，确认层收起后 320ms）；评审面板「重播」（`beforeReplay('develop')` 把相纸放回盘底再显影）。
- **运动对象**：`.tk`（相纸 + 相连副券底片段为一组，同一物件）；上方的「镊子」`.tongs` 只在显影中出现。
- **起点 / 终点**：`translateY(100% + 44px)`（整组沉在显影盘液面之下，液面带 `z-index:3` 挡在前面）→ `translateY(0)` 落定在盘上方。
- **分段**（`c10-rise`，总 2600ms × k，linear 分段）：0–14% 升到 62%（露边）；14–26% 停顿；26–48% 升到 28%（半张）；48–60% 停顿；60–84% 升到 0（整张）；84–100% 停稳。—— REF42 的「露边 → 半张 → 整张」三停顿。
- **影像显出**：影像层 `.pimg` 在显影中加 SVG 亮度遮罩 `#c10-dev-tk`（黑底 + 三个白色圆 `circle.dh`，经 `#fx-rough-strong` 置换成斑块），三圆 `r: 0 → 300px`，各 1700ms，延迟 0 / 420 / 760ms；显影完成后去掉遮罩，文字始终不缩放、不模糊。相纸湿润高光 `.print::after` 在完成后 1200ms 淡出（`fx.wet`）。
- **变换中心**：组底边（`transform-origin: 50% 100%`）。
- **遮挡 / 阴影**：显影盘 `overflow:hidden` + 液面带在前；显影中 `.busyveil` 挡掉票上的指针事件，副券不可剪。
- **中断 / 重播**：`.scrub` 下 `c10-rise` 与 `c10-devhole` 均 `animation-play-state:paused` + `animation-delay: -frame × 2600ms × k`；`.rm` 下直接呈现已显影的相纸；`after(2600)` 落定 `printed`。
- **证据**：`evidence/C10/print/`、`confirm-flow/`（成局后显影）、`rm-half-scrub/`（关键帧 30% / 60%）。

### ② 剪底片（撕票）
- **触发**：在相纸下缘相连的副券底片段 `.negwrap` 上按下（`onPointerDown` + `setPointerCapture`），沿帧边向右推裁刀；`p = clamp((x − x0) / (w × 0.8))`。接受改期同样剪新票副券；「接受新时间」按钮是等价入口。
- **运动对象**：副券底片段渲染两份：`.negs.a`（刀左侧、已剪断部分，`clip-path: inset(0 (1−p)·100% 0 0)`，随 p 下沉 5px、转 −1.6°）与 `.negs.b`（刀右侧、仍相连部分）；裁刀 `.blade`（2px 亮刃 + 木柄）跟随 p 平移；切口 = 刀后方的 2px 亮线 `.cut` + 6px 切痕阴影。
- **过程**：拖动中提示「继续向右推裁刀」→ p ≥ .55「松手即剪断」；p < .55 释放 → 240ms `cubic-bezier(.2,1.05,.3,1)` 回弹到 0（`spring`）。
- **落点**：p ≥ .55 释放 → 先写入（`engine.tearTicket` / `engine.acceptReschedule`，失败则回弹 + 红灯重试条），成功后 p=1、`.negwrap.off`：副券段 760ms `cubic-bezier(.45,.02,.75,.5)` `translate(−22px,118px) rotate(−18°) rotateX(72°) scale(.86)` 卷曲落向下方的底片袋（显影盘此时 `overflow:visible`、液面降到后层），盘体同时收短 68px；760ms 后底片袋里弹入一片存根（`c10-stubin` 460ms）并计数「存根 1」，300ms 后红灯联系层滑入（`c10-slidein` 420ms）。
- **留下的部分**：相纸页脚红蜡笔改为「8 小时内联系局主」，状态行「有效 · 已剪副券」，对应 `contact`。
- **变换中心**：已剪段左上角（`transform-origin: 0 0`）。
- **中断 / 重播**：`.scrub` 暂停 `c10-drop`；重播 `beforeReplay('cut')` 以 `fx.replayStub` 把副券段放回原处，再播剪断落袋。
- **证据**：`evidence/C10/tear/`、`resched-reply/`（新票副券）、`fail-retry/`（剪断失败回弹 → 重试）。

### ③ 胶片熔穿（取消 / 退出 / 拒绝改期的作废）
- **触发**：局主「取消这局」红灯层 → 确认取消 → 420ms「取消中…」→ `engine.cancel` 成功 → 红灯层收起（期间 `hold`，灯箱帧保持完整）→ 灯箱上的帧受热；参加者「去不了了」→ 确认 → 票面（相纸 + 副券）受热；`cancelled` 行首次点开烧一次，之后静态残片。
- **运动对象**：同一张帧 / 票（`.hero.melt` / `.tk.melt`），SVG mask 作用在整个物件上；灯箱光 `.lbglow` 在它后面，不被遮罩。热源在物件中心（`cx,cy = W/2,H/2`）。
- **过程**（总 3000ms × k，`c10-melt` 分段 linear）：0–24% **起泡**：洞只到 reach×.035，七粒气泡 `.bub`（径 6–14px，球面高光）按 0–760ms 延迟依次鼓起（`c10-bub` 6% 处 scale 1.15 回落）；24–58% **熔穿**：洞半径推进到 .6 reach，洞沿由内到外是 4px 琥珀热线 `.mg`、18px 黑色熔融环 `.mr`、30px 棕色热晕 `.mo`（三环同心、半径同步、均经 `#fx-rough-strong` 置换成毛边，环的内半被洞吃掉只剩外缘）；58–100% 洞推到 reach（灯箱帧 222px / 票 262px ≈ 对角线一半，正好吃尽）；52% 起 **卷曲**：面 `perspective(600px) rotateX(−9°) rotateY(5°) translateY(5px)` 并压暗到 .5。灯箱帧熔穿时透出灯箱白光，票面熔穿时透出显影盘的暗色。
- **剩余形态**：2550ms（灯箱）/ 2700ms（票）后换成残片 `.rsd`（600ms `c10-settle` 落定）：黑帧框 + 不规则圆角的洞（灯箱侧 `#d8c7a4` 透光带内暗角；票面侧 `#1c130c`）+ 三粒熔珠 + 左上角说明（「局主取消 · 票根作废」/ 「已退出 · 票根作废」+ 原定时间）+ 角标 `VOID · 已熔穿`。
- **结果一致**：局主侧头部 `已取消`、进度行隐藏、成员行「取消前已确认 / 取消前已预留」、联系关闭、安排区只剩惰性「再开一局」；返回列表落在 历史 › 已取消 的黑帧（带洞）并高亮 1.4s。参加者侧：残片 + 结果块（已退出这局 / 未接受新时间 / 局主取消了 + 中性事实句），返回落在 未成行。
- **中断 / 重播**：`.scrub` 暂停洞、三环、面、气泡五组关键帧并按 `--frame` 定位；`.rm` 直接呈现残片；重播 `beforeReplay('melt')`（`fx.restore` / `cstage:'restore'`）把物件复原再烧。
- **证据**：`evidence/C10/cancel/`（灯箱帧）、`exit-melt/`（票面）、`rm-half-scrub/`（0.5× + 关键帧 30% / 65%）。
