读法：每套方案的代理只读自己那一节。每行给出 **REF id · 案例名（创作者）· 类别/状态 · 借鉴的原则 · 落点**。「借鉴的原则」是从台账 observation 里提炼的一条可操作规则（不是 translation 的照抄）；「落点」指向方向卡六个维度里的具体位置（构图 / 字体 / 组件 / 材质 / 过渡 / 三个核心动作）与 `state-inventory.md §H` 的动效族。每节末尾一行「不复制」划清边界。

映射规则（已核对）：每套 8 条；每套至少跨 3 个类别（ui / motion / editorial / designer / award）；动效相关行优先用 `已看动效` 的案例；同一案例最多出现在 3 套里（实际最多 2 套）；80 个映射位用了 66 个不同案例，任意两套共用的案例不超过 2 个。未进入映射的 28 个案例仍留在台账里备查（多为与具体方案构造关系较弱的活动页 / 商品页静态案例）。

## C01 票据卷 Receipt Roll

方向卡要点：~340px 热敏纸带从顶部出纸口打印；时间是纸带上最大的字（DM Mono 28px）；票 = 纸带上加粗边框的一截，沿齿孔撕；走纸打印分三段停顿；取消 = 从起火点焦卷。

## 跨方案共同原则（十套都要守）

1. **中文三级比例，只有一个最大字。** 局名 : 时间 : 发起人 ≈ 1.7 : 1.2 : 1（REF68、REF76、REF85），或编号 / 期号小字 : 局名 = 1 : 2（REF48、REF62、REF66）。C01 允许时间比局名大，但同一屏只能有一个最大字；不靠大号英文撑场，中文局名本身要排得好看。
2. **身份连续。** 展开、弹层、换态都是同一对象在动：卡片连续放大到详情（REF27）、按钮长成确认卡（REF28、REF19）、新状态作为复制叠在原件上由裁切边揭出（REF33）；中途不换素材、不出现空白矩形。
3. **背景退让先到位。** 弹层或详情出现时后方缩小 / 压暗 / 失焦，且失焦先于弹层（REF17、REF29、REF30、REF27）；返回走反向回到原位（`F01`）。
4. **材质诚实。** 厚度靠遮挡、边缘与背面表达——出纸槽压住纸顶边（REF44、REF42）、翻页中缝的立起页边（REF39）、背面的半透明薄片（REF38）；纹理靠重复小单元平铺成面（REF69）；只在「离开表面」的物件上加投影（REF92）。不用渐变 + 投影堆层冒充厚度。
5. **滞后与回弹。** 受牵引的材料先动受力点、再传到边缘，静止前回摆一次（REF37、REF41）；撕口按单元逐个断开而非直线裁切（REF41、REF85）；未过阈值释放要回弹。
6. **状态原位换值，其余不重排。** 状态标在原位弹出 / 翻面（REF36、REF33），计数原地跳字（REF08）；只给当前状态上色，其余保持中性（REF12）。
7. **反馈一次性，背景静止。** 纸屑、色圆、火花只出现一次并在 1.5s 内结束（REF47、REF40、REF46）；活体感只允许极慢漂移且主体不动（REF34）；背景不做循环渐变与漂浮粒子（REF86 的静态页、契约 §0）。
8. **进场二选一：错峰或整体渐显。** 逐槽 60–80ms 错峰（REF16、REF08、REF35）或整体 35% → 100% 淡入（REF81）；不整屏同闪，也不逐格弹跳。
9. **角色靠一个小标记。** 主办用皇冠 / 胶囊 / 唯一偏置元素（REF01、REF03、REF06、REF68），成员用同一单元重复（REF69、REF82），不给主办另一种形状；未确认 / 匿名成员用遮罩或素面占位（REF71、REF73、REF77）。
10. **中文排版规范。** 标题与正文靠字体族分层（宋 / 黑，REF56）；中英混排英文前后半角空格、「」《》、破折号「——」（REF55、REF62）；中英局名用全角间隔号「・」连接（REF64）；双语标签中文在上、1.2 倍（REF52）；编号、页码、时间等元信息贴角小字、位置固定（REF66、REF82、REF60）。
