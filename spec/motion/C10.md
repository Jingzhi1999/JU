## 2. 三个核心动作

### ① 显影出票（打印的替代形式）
- **触发**：进入 `tear` / `reschedule` 票面（首次打开，`openDetail` 后 520ms）、全员确认成局（`engine.confirmReservation` 返回 `formed:true`，确认层收起后先把 `.pbody` 平滑滚到顶（若不在顶部，等 520ms），再起显影——显影盘与底片都在视口内）；评审面板「重播」（`beforeReplay('develop')` 把相纸放回盘底再显影）。
- **运动对象**：`.tk`（相纸 + 相连副券底片段为一组，同一物件）；上方的「镊子」`.tongs` 只在显影中出现。
- **起点 / 终点**：`translateY(100% + 44px)`（整组沉在显影盘液面之下，液面带 `z-index:3` 挡在前面）→ `translateY(0)` 落定在盘上方。
- **分段**（`c10-rise`，总 2600ms × k，linear 分段）：0–14% 升到 62%（露边）；14–26% 停顿；26–48% 升到 28%（半张）；48–60% 停顿；60–84% 升到 0（整张）；84–100% 停稳。—— REF42 的「露边 → 半张 → 整张」三停顿。
- **影像显出**：影像层 `.pimg` 在显影中加 SVG 亮度遮罩 `#c10-dev-tk`（黑底 + 三个白色圆 `circle.dh`，经 `#fx-rough-strong` 置换成斑块），三圆 `r: 0 → 300px`，各 1700ms，延迟 0 / 420 / 760ms；显影完成后去掉遮罩，文字始终不缩放、不模糊。相纸湿润高光 `.print::after` 在完成后 1200ms 淡出（`fx.wet`）。
- **变换中心**：组底边（`transform-origin: 50% 100%`）。
- **遮挡 / 阴影**：显影盘 `overflow:hidden` + 液面带在前；显影中 `.busyveil` 挡掉票上的指针事件，副券不可剪。
- **中断 / 重播**：`.scrub` 下 `c10-rise` 与 `c10-devhole` 均 `animation-play-state:paused` + `animation-delay: -frame × 2600ms × k`；`.rm` 下直接呈现已显影的相纸；`after(2600)` 落定 `printed`。
- **证据**：`evidence/C10/print/`、`confirm-flow/`（成局后显影）、`rm-half-scrub/`（关键帧 30% / 60%）。

### ② 剪底片（撕票）
- **触发**：在相纸下缘相连的副券底片段 `.negwrap` 上按下（`onPointerDown` + `setPointerCapture`），沿帧边向右推裁刀；`p = clamp((x − x0) / (w × 0.8))`。接受改期同样剪新票副券；「接受新时间」按钮是等价入口。
- **运动对象**：副券底片段渲染两份：`.negs.a`（刀左侧、已剪断部分，`clip-path: inset(0 (1−p)·100% 0 0)`，随 p 下沉 5px、转 −1.6°）与 `.negs.b`（刀右侧、仍相连部分）；裁刀 `.blade`（2px 亮刃 + 木柄）跟随 p 平移；切口 = 刀后方的 2px 亮线 `.cut` + 6px 切痕阴影。
- **过程**：拖动中提示「继续向右推裁刀」→ p ≥ .55「松手即剪断」；p < .55 释放 → 240ms `cubic-bezier(.2,1.05,.3,1)` 回弹到 0（`spring`）。
- **落点**：p ≥ .55 释放 → 先写入（`engine.tearTicket` / `engine.acceptReschedule`，失败则回弹 + 红灯重试条），成功后 p=1、`.negwrap.off`：副券段 760ms `cubic-bezier(.45,.02,.75,.5)` `translate(−22px,118px) rotate(−18°) rotateX(72°) scale(.86)` 卷曲落向下方的底片袋（显影盘此时 `overflow:visible`、液面降到后层），盘体同时收短 68px；760ms 后底片袋里弹入一片存根（`c10-stubin` 460ms）并计数「存根 1」，红灯联系层滑入（`c10-slidein` 420ms）；1240ms 时若联系层下缘超出视口，`.pbody` 平滑下滚到能看全它。接受改期剪断后 toast「已接受改期 · 按新票根的时间见」。
- **留下的部分**：相纸页脚红蜡笔改为「8 小时内联系局主」，状态行「有效 · 已剪副券」，对应 `contact`。
- **变换中心**：已剪段左上角（`transform-origin: 0 0`）。
- **中断 / 重播**：`.scrub` 暂停 `c10-drop`；重播 `beforeReplay('cut')` 以 `fx.replayStub` 把副券段放回原处，再播剪断落袋。
- **证据**：`evidence/C10/tear/`、`resched-reply/`（新票副券）、`fail-retry/`（剪断失败回弹 → 重试）。

### ③ 胶片熔穿（取消 / 退出 / 拒绝改期的作废）
- **触发**：局主「取消这局」红灯层 → 确认取消 → 420ms「取消中…」→ `engine.cancel` 成功 → 红灯层收起 → 灯箱上的帧受热；参加者「去不了了」→ 确认 → 票面（相纸 + 副券）受热；`cancelled` 行首次点开（`fx.hold` 保持完整，560ms 后）烧一次，之后静态残片。开烧前若 `.pbody` 不在顶部，先平滑滚到顶（物件在视口内）。
- **运动对象**：同一张帧 / 票（`.hero.melt` / `.tk.melt`），SVG mask 作用在整个物件上；灯箱光 `.lbglow` 在它后面、不被遮罩，开烧即 900ms 过渡到暖暗琥珀（`.lbwrap.burnt`）。
- **几何**（物件自身 px 坐标）：管理页帧 358×234，热源 (236,158)，洞终点 r=98；票 338×304(+68)，热源 (228,166)，r=100；参加者的底片（票面上方的紧凑帧 358×116）热源 (274,72)、r=30；历史格（帧面 240×170）热源 (162,124)、r=62（= 帧面宽 × .675 / 高 × .729 / 宽 × .258，360 宽下按实测格尺寸换算）。偏心到右下：局名前几个字、时间、左上与右上角保留；洞 + 焦环合计约吃掉物件的 45–55%，不吃尽。
- **同一个洞（列表 ↔ 飞行 ↔ 详情）**：主体帧的 mask 圆与四层焦环的 `cx / cy / r / stroke-width` 由 CSS 变量给出（`--ix/--iy/--ir/--irs` 详情尺寸，`--ox/--oy/--or/--ors` 源格尺寸），`start / out` 两态切到源格几何、520ms `--pease` 过渡；熔珠 `left / top / size` 同步过渡。返回时帧面换上历史格的外衣：灯箱光淡出（不再从右向左擦掉）、帧面底 `#050302`、洞后的灯箱光换成暗房台面，所以落地的那一帧与历史格逐像素同形；再次打开时洞从格的尺寸长回详情尺寸、灯箱暖光 900ms 亮起。参加者退出 / 拒绝改期时，底片与相纸一起受热（同一段 3000ms 关键帧，底片不卷曲）；首次打开「局主取消」时底片已带着列表上那个洞（静态），只有相纸烧一次。
- **过程**（总 3000ms × k，`c10-melt` 分段 linear）：0–24% **起泡**：洞只到 r×.05，七粒气泡 `.bub`（6–14px，球面高光）按 0–760ms 延迟鼓起，其中四粒落在终点洞沿外侧；24–58% **熔穿**：洞推进到 .68r，洞沿由内到外是 4px 琥珀热线 `.mg`、18px 黑色熔融环 `.mr`、30px 棕色热晕 `.mo`、64px 淡焦痕 `.ms`（同心、同步、同一 `#c10-rough` 噪声置换，内半被洞吃掉只剩外缘）；58–100% 推到 r，热线在 86–100% 熄灭；50–78% **卷曲**：面 `perspective(700px) rotateX(−6°) rotateY(3°)` 压暗到 .74，78–100% 冷却回平（`transform:none`，停在 `brightness(.84) saturate(.74)`，文字不带变换、不糊）。
- **剩余形态**：3000ms 时 `burning → melted`（静态类，取值与关键帧 100% 完全相同，无跳变）：同一物件、同一洞形，焦环冻结成边缘，四粒熔珠变暗留在洞沿；洞里淡入 `.vtag`（700ms）：`VOID · 已熔穿` + 「局主已取消 · 票根作废 / 联系已关闭」（局主）或 `局主取消 · 票根作废` / `已退出 · 票根作废` / `未接受新时间 · 票根作废`（参加者）。未剪的副券段一起留下，写「已作废 · 不能再剪」、不可拖。
- **结果顺序**：确认取消写入成功后，头部生命周期标、状态行、进度行与分区徽标仍显示取消前的事实（取消前的数据快照 `_pre`），到熔穿 58%（1740ms × k，「熔穿」段结束）时才落定为 `已取消`（`ttlsettle` 420ms），进度行 420ms 收起而不是瞬间消失。
- **结果一致**：局主侧头部 `已取消`、状态行「已取消 · 不能撤销，票根作废、联系关闭」（不重复前缀）、进度行隐藏、成员行「取消前已确认 / 取消前已预留 · 预留作废」（不显示倒计时）、联系关闭、安排区只剩惰性「再开一局」；返回列表落在 历史 › 已取消 的黑帧（右下带焦洞）并高亮 1.4s。参加者侧：烧过的相纸 + 结果块（已退出这局 / 未接受新时间 / 局主取消了 + 中性事实句），返回落在 未成行；再次打开是同一张烧过的相纸（静态）。
- **中断 / 重播**：`.scrub` 暂停洞、四环、面、气泡关键帧并按 `--frame` 定位；`.rm` 直接呈现终态；重播 `beforeReplay('melt')`（`fx.restore` / `cstage:'restore'`）把物件复原再烧。
- **证据**：`evidence/C10/cancel/`（灯箱帧，0.5×）、`exit-melt/`（票面，0.5×）、`resched-reply/`（拒绝改期）、`history-note/`（首开烧一次、再开静态）、`rm-half-scrub/`（关键帧 8 / 30 / 65 / 92%、重播、减少动态）。

## 3. 其余动效族（简述）
- **M1 身份切换**：两卷胶片（`.rolls` 200% 宽轨道）480ms `cubic-bezier(.2,.8,.2,1)` 横移，离开的卷淡到 0；拨片指示 420ms 弹性滑动。
- **M2 分区切换**：`c10-expose` 420ms —— 暗房灯先灭（28% 处亮度 0）再把新一张接触印样显出。
- **M3 滚动折叠**：纵向滚过 36px → `.home.col`：标题 28→18px、眉注与日期胶囊 300ms 收起，身份拨片与分区行常驻，分区行下沿 16px 羽化遮罩；底片条横向滚动时灯箱光只照当前对齐的帧（`onScroll` → `lit` 索引，420ms 扫光 + 墨色反相），每条底轨的「n/N」计数同步更新（`pos[分组]`，切分区 / 身份时归零）。
