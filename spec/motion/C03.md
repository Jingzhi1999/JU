### 材质规则
- 整屏是一本书的右页：左 34px 书脊暗部渐变（`.c03-gutter`），右 6px / 底 5px 是叠页的纸边线（`.c03-stack`）。纸面只有极淡的 45° 重复细纹（`rgba(0,0,0,.016)` / 3px），不用噪点滤镜，文字永远清晰。
- 厚度靠遮挡与边缘表达：翻页时的 26px 页边渐变（REF39）、翻页在下页上投下的扫动阴影、撕角时的页下露出（`--paper2` + 内阴影）与纸纤维边（白 1.6px + 灰 1.6px 两条锯齿带）。投影只出现在离开纸面的物件（抬起的副券、校对条、飘落的券）。
- 票页 = 装订插页（更白的卡纸 `#fbfaf6`，1px 浅边，底部 1px 落影）；副券是右下角 132×92 的撕角券，上、左两边为虚线齿孔，内角一个红色折角记号。
- 弹层 = 夹在页间的校对条（`#fffdf7`，左侧 1px 红边线、顶部 1px 纸边、上方投影），从页底滑入；背后跨页 `scale(.985)` + `saturate(.85)` + 42% 墨色压暗。
- 吸顶页眉下沿有 14px 纸色羽化（`::after`，只在收起后出现），滑到页眉下的刊头 / 图版不被硬切。
- 圆角：几乎没有（按钮 2px，封面格 1px）；圆形只用于头像、章与色点。边线 1px；组头与表头用 1px 墨线，行间 1px `--rule2`。

## 2. 三个核心动作

### ① 翻页展开（目录条目 → 跨页；M4，也用于身份切换 M1）
- 触发：点目录条目 / 封面 / lead 行动条；身份切换点刊名。
- 运动对象：整张目录页（`.c03-leaf`，含底栏），绕书脊（`transform-origin: 0 50%`，`perspective: 2000px` 在 `.app`）向左翻 0 → −180°。跨页在翻页开始时已完整排在下面（z 3，叶 z 6）。
- 阶段（900ms，动画 `linear` + 分段关键帧，让叶子大部分时间可见）：0–16% 0→−15°（`cubic-bezier(.45,0,.9,.7)` 从静止起步）；16–55% −15→−60°（线性）；55–74% −60→−80°（线性，叶子收窄成书脊边的一条，仍可见）；74–100% −80→−180°（`cubic-bezier(.3,0,.9,.5)` 快速翻过 90° 到书脊后）。0–180ms 该条目右缘红色书签（`.c03-mark`）滑入；叶右缘 26px 页边渐变 `c03-edge` 25–76% 出现（60% 最深）、84% 消失；下页扫动阴影 `c03-shade`（左起 38% 墨色渐变）18–74% 最深，`scaleX 1 → .5 → .22 → .04`；900ms 后叶 `visibility:hidden`（保留滚动位置），跨页可操作。
- 返回：`c03-turn-back` 820ms：0–24% −180→−92°（`cubic-bezier(.1,.4,.5,1)`），24–100% −92→0°（`cubic-bezier(.3,.3,.25,1)`），约 3/4 时间叶子可见；阴影反播；条目若换了分区先切分区并 `scrollIntoView`，落地后该行红书签保持 2s（`landed`）。
- 中断：翻页中按「目录」= **从当前角度倒放**：同一套关键帧的副本 `c03-turn-r` / `c03-shade-r` / `c03-edge-r` 反向播放，`animation-delay = −(1 − frac)·900ms·k`（frac 由开始时间算出，用副本是为了让浏览器新建动画而不是沿用旧的开始时间），frac·900ms 后回到目录并落书签；暂停 / 关键帧拖动 / 减少动态时忽略。翻页中的二次打开仍被忽略。
- 身份切换：两页同时渲染（旧刊作叶，同一关键帧 620ms 快翻，新刊在下），翻完后恢复该刊的分区与滚动记忆。
- 减少动态：1ms；重播：`beforeReplay('turn')` 回到目录再翻。
- 证据：`evidence/C03/card-detail-back/sheet.png`（0.5×，含翻页中倒放）。

### ② 印制 + 撕角券（票页右下副券；M8 打印 / 撕票，也是改期接受）
- 印制前态：未印的票版本从数据写入的**同一帧**起渲染为「未出纸」：叶子停在书脊外（`translateX(−106%)`、墨 0%、红版 0），落点处是 1px 虚线套准框（斜细纹 + 书脊侧 4px 暗口），写「票页 · 待印制」，印制中写「印制中」；CTA 灰、副券不可拖、键盘撕不可用，提示「票页印制中 · 请稍候」。确认入局成局 / 索引跳到票根面 / 重播都先进入这一态，不会先闪出印好的票或可点的「撕开票根」。与票无关的索引面（如待撕票的详情）在打开的同一次渲染里就记为已印。
- 印制 2400ms：送纸 0–50% 分三段（−106% → −64% 停 → −62% → −16% 停 → −14% → 0），墨 50–82% 自上而下（`--c03-ink` + 4px 墨辊阴影），红版 88–100% 套印（`--c03-red`）；完成后 CTA 才变黑、副券可拖。
- 撕的触发：按住副券（`.c03-side.stub`，`data-act="tear"`，setPointerCapture）向左上拖；键盘 Enter / 空格直接撕。
- 几何：票面 334×236，副券 132×92（内角 (202,144)），上、左两条齿孔。两份票面：keep（页面）与 stub（券）各由 `c03Clips(p)` 给出互补多边形；撕口沿上边从右向内、沿左边从下向内同时推进，撕过的段用 `JU.fx.tearProfile` 的纤维偏移（上 22 段 ±3.4px，左 16 段 ±3.4px），未撕段保持直线齿孔；两条纤维带（白 / 灰）只画在已撕段上。
- 进度：`p = clamp((−dx + −dy·0.7) / 150)`。stub 变换 `translate(−12p, −9p) rotate3d(.57,−.82,0, −44p°)`（绕内角、垂直于对角线的轴抬起，`perspective:700px`），阴影 `14p 18p (22p+4) rgba(20,10,0,.18+.22p)`；抬起即显示页下（`.c03-under`：`--paper2` + 内阴影）。
- 落券：p ≥ 0.55 → `engine.tearTicket`（改期则 `acceptReschedule`）80ms → stub 加 `off`：`c03-fall` 760ms（线性动画 + 分段曲线）：0% 当前抬起姿态（`--c03-pose`）→ 38% `translate(−24px,22px) rotate(−11deg)`（向左荡出、压平）→ 80% `translate(−3px,77px) rotate(−4deg) scale(.9)`（直落进夹页口）→ 100% `translate(−2px,72px) rotate(−3deg) scale(.9)`（落定）。夹页 86px 深（前片 68px，右高左低的斜口，票底下约 4px 处），层级高于票，券的下半在前片后面被挡住；落定后**同一个元素**以末帧姿态留在袋里（`tucked`，内联 transform = 末帧，阴影收成 1px），只露出带纤维边的上沿和红字「副券」，袋签「夹页 · 存根 1 张」。不再换成另一个小标签。静态已撕票（跳到待联系 / 待赴约 / 已退出）同样画在袋里。
- 一次一个主要动作：联系层在落券开始后 820ms（落定之后）才升起；改期接受的 toast 在 1250ms。
- 回弹：p < 0.55 → 360ms `cubic-bezier(.34,1.5,.64,1)`。
- 失败：副券复位 + 行内「未能保存，请重新撕下副券」（改期：「新时间未保存，请重新撕下副券」）+ 按钮「再撕一次」——它只滚到票页并把副券轻抬到 .22 邀请再拖一次，不替用户完成撕票。
- `.scrub` 支持印制与落券关键帧；减少动态直接出纸 / 直接入袋；重播 `beforeReplay('tear')` 恢复撕前的数据快照与抬起姿态，再落一次。
- 证据：`evidence/C03/print/`、`tear/`、`fail-tear/`、`reschedule-reply/`（前半）。

### ③ 烧页（取消 / 退出 / 拒绝改期；M8 作废）
- 不再用共享的 fx-hole 圆环。C03 自己的 SVG mask：三道火线各是一个圆，有各自的起火点、终半径和起始时刻（`--s`）；`r` 走 `c03-grow`（0 → 14% 时 12% → 100% 终半径，`cubic-bezier(.32,.08,.58,1)`，时长 (1−s)·总时长，延迟 s·总时长）；三圆错时起步 = 沿边、侧向推进的不规则前沿。同一个 `feTurbulence` 位移（`c03-rough`，用户空间坐标）同时作用于洞、焦褐带与火线，三者共用一条毛边。
- 焦褐带：同一组圆描边 28px `#2a1a10`（.62）+ 54px `#7a5236`（.2），经 `c03-scorch`（位移 + 3px 高斯模糊）；描边内半被洞吃掉，外半成为洞缘的焦痕。火线 7px 橙色渐变，3–86% 可见后熄灭。
- 剩余形态：终半径的并集**不覆盖整张票**，留下一块不规则的票角（带票面字迹：标签、页码、局名残段）。燃烧末帧就是已烧毁态（`c03-burnt` 用同一组圆的终半径静态渲染 + 灰褐滤镜），不是空白之后再弹出一个画好的框。结果字在被烧掉的区域里 70–100% 淡入：`票根作废 · 主动退出 · 联系已关闭` / `新票作废 · 未接受新时间 · 席位已释放` / `票根作废 · 局主取消 · 不计你的退出` / 编辑部 `已取消 · 票根作废 · 联系关闭 · 归入往期`。
- 变体（票面 334×236，局卡条 334×96；[cx, cy, 终 r, 起始]）：
  - C 侧向推进（主动退出；已取消的首次打开）：左下页角起火 `[0,236,262,0] [0,84,212,.16] [334,236,104,.5]`，3000ms，残片在右上（标签 + 页码）。
  - B 卷边炭化（拒绝改期）：副券外角起火 `[334,236,205,0] [334,40,142,.22] [96,236,128,.3]`，3200ms，火沿右边与下边推进；同时副券以内角为轴卷起（`c03-curl`：30% `rotate3d(.57,−.82,0,−24deg)` → 100% −34deg，露出页下、投影加深、泛黄），残片在左上（JU. 票根 + 局名 + 时间上半）。
  - S 编辑部局卡条（取消这局）：`[0,96,236,0] [0,18,226,.15] [334,96,48,.55]`，2800ms，残片在右上。
- 纸灰：16 片（局卡条 12 片），放在各火线 f·r 处，前沿到达时才释放（延迟 ≈ (s + (1−s)·f^1.2)·时长·.9），1400ms 下落 70–140px、横移 ±34px、旋转 ±170°，35% 为浅灰屑；在 mask 外的兄弟层。
- 已撕票燃烧时袋里的副券不被烧（mask 在袋口区域留白，并在那块铺回纸色，焦痕不漏出）；夹页在所有票态都保留，烧前烧后不跳。
- 写入先于动效：写入回调里同一帧把票标为 `armed`（完整、转灰），380ms 后滚到票页并起火——不会先闪出已烧态。拒绝改期作废的是**新票**：未撕（不继承旧版 `ticket.torn`）、副券仍在、标签「新票作废」、区块注「新票作废 · 未撕」，时间仍是新时间并保留「原定」行。
- 静态：已退出 / 拒绝改期 / 已取消（首次打开之后或索引直达）直接渲染残片态；编辑部里已取消的局卡条也是残片态。
- 落点：局主侧头部「已取消」、进度行隐藏、成员行 void（不再显示预留倒计时）、安排区只剩惰性「再开一局」，返回目录后落在往期 · 已取消的焦边封面；参加者侧 CTA 变「查看退出结果 / 查看取消结果」→ 返回落在未成行的焦边封面。
- `.scrub` 定格任意帧（三圆各自 `delay = (s − frame)·时长`，往返确定）；暂停可停在半途；减少动态直接出残片 + 结果字；重播（`beforeReplay('burn')`）恢复完整票面再烧。
