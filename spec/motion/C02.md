# C02 站牌 · 动效与视觉参数

车站翻牌显示板 + 过闸卡：每局一行翻牌，状态翻一下就换；票是插进读卡槽的磁条卡；取消 = 卡在槽里过热作废。文件：`concepts/src/C02.dc.html`（所有 id 以 `c02-` 开头，CSS 只在 `.app` 根下；覆盖层根元素带 `c02-over`，列表行 `data-rid`，主要按钮 `data-act`）。下文所有数值均为**当前代码值**；「实际观察」指本代理在 `.build/C02.html` 私有构建上用 `tools/capture.cjs` 抽帧后用 Read 看过的帧（`evidence/C02/*/sheet.png`）；用户尚未审阅。

## 2. 三个核心动作

### ① 状态翻牌（M5 / M7 / M1 / M2 的落定方式）
- **触发**：任何翻牌键下的文字改变（`cells(key, text)` 在渲染时比较上一次文字）：审核通过 / 谢绝后管理盘头部状态「2 份申请待审 → 1 份申请待审」、出席记录「未记录 → 出席」、取消后「已取消」、参加者侧「待撕票 → 待联系 → 待赴约」、牌头标题「局主改了时间 → 新时间已确认」、列表行状态与时间（改期接受后时间格翻到新时间）。身份 / 分区切换用整板翻（见下）。
- **运动对象**：每格四层（`.c02-fh.top` 新面上半、`.c02-fh.bot` 旧面下半静止；`.fa` 旧面上半、`.fb` 新面下半旋转）。文字本身不位移，只有翻片在翻（REF33 的「只有边在走」）。
- **分段**（每格）：fa `rotateX(0→-90deg)` 170ms `cubic-bezier(.55,0,.9,.6)` 轴在格底；fb `rotateX(90→0deg)` 210ms `cubic-bezier(.2,.8,.3,1)` 轴在格顶，延迟 160ms；落定「咔」`translateY(1.5px)` 140ms 在 +340ms；格间错峰 55ms × 格序号（`--i`）。变换中心：fa `50% 100%`，fb `50% 0`；每格 `perspective:260px`；`backface-visibility:hidden`。
- **结束**：flip 类在 `60ms × 字数 + 620ms` 后移除（`forceUpdate`），各层回到静止（旧面 = 新面），文字清晰无残影（实际观察：`evidence/C02/manage/`、`end-att/` 中翻到一半与翻完的帧）。
- **整板翻（身份 / 分区）**：身份牌先 150ms 滑动并按覆盖像素反色（`.c02-plfg` `clip-path: inset(0 50% 0 0) ↔ inset(0 0 0 50%)`，REF15），同时所有行 `rotateX(0→-90deg)` 220ms（机械曲线，错峰 `min(i,9)×22ms`）→ 300ms 后换身份、滚动归零 → 行 `rotateX(90→0)` 320ms `cubic-bezier(.2,.8,.3,1)` 同样错峰；分区切换同构（240ms 换）。`perspective:1000px` 在 `.c02-list`。
- **中断 / 重播**：翻牌过程中切换数据只会让新文字再翻一次；`board` 忙时忽略再次切换；评审「重播」在 `beforeReplay('flap')` 里把最近翻过的键恢复成旧文字再翻一次；`.rm` 下 1ms 直接换面。

### ② 过闸撕票（M8 撕票 + 出票）
- **出票（打印的站牌版）**：触发 = 本版票第一次打开（`tear` 行的票面、改期新票、确认入局后 `formed`）。卡从读卡槽上方的出卡区**向上**分段露出：`c02-issue` 2200ms linear，`translateY 104%→70%`（0–18%）停（18–26%）`→30%`（26–48%）停（48–56%）`→-2%`（56–80%）`→1%`（88%）`→0`（100%）；印刷用 `--c02-ink`（`@property` 注册）驱动的自下而上 mask（`linear-gradient(0deg, #000 ink, transparent ink+10%)`）紧跟卡的上沿露出字迹；读卡灯琥珀、显示屏「出票中 · ISSUING」；出票中卡 `pointer-events:none`，提示「打印完成前不能插卡」。`.scrub` 下 `animation-play-state:paused` + `animation-delay:-frame×dur×k`；`.rm` 1ms。已出过的版本记在 `tk.printed`，再进不重印。实际观察：`evidence/C02/print/sheet.png`、`confirm-flow/`。
- **过闸（撕票）触发**：在 `.c02-gatecard`（ready 态，`cursor:grab`）按下并**向下**拖（`setPointerCapture`）；`p = clamp(dy / 150)`；卡 `translateY(p × 58%)` 跟手（无过渡）；显示屏「插入中 · NN%」，提示「再推一点 / 松手 · 读卡」。
- **释放**：`p < 0.55` → `spring` 240ms `cubic-bezier(.2,1.1,.3,1)` 回弹到 0；`p ≥ 0.55` → **先写入** `engine.tearTicket`（改期新票 = `engine.acceptReschedule`），失败则回弹 + 红灯故障条「…请重新插卡」+ 重试（重试直接再吞卡），成功才进入序列。
- **序列**（`gateSeq`，均用 `this.after`）：0ms 吞卡 `motor` 260ms 机械曲线到 58%（显示 FEEDING）→ 300ms 读卡（琥珀灯 READING，「请勿拔卡」）→ 1020ms 打孔：读卡器 `c02-shake` 120ms 下沉 2px，卡加 `punched`（真孔 mask），碎屑窗内圆片 `rest`：`translateY(-20px)→0 rotate(20deg)` 300ms `cubic-bezier(.4,0,.6,1.4)`（分离部分有重量地落入槽内 = 残留物）→ 1700ms 吐卡 `eject` 460ms `cubic-bezier(.3,0,.2,1)` 回到 0 → 2200ms 落定：绿灯「已过闸 · PASSED」，联系条 `translateY(14px)→0` + 透明度 300ms `cubic-bezier(.2,.9,.3,1)`（局主 · 微信号 · 复制 · 已加微信）。留下的卡 = 右下带孔的同一张卡，对应「已撕票待联系」；列表行状态翻成「待联系」。
- **变换中心**：卡 `transform-origin: 50% 100%`（槽口一侧）。遮罩：打孔 mask 作用在整张卡面；碎屑在读卡器槽内（卡面之外）。
- **中断 / 重播**：拖动中换数据集会重置；`beforeReplay('gate')` 把卡放回 ready、清空碎屑、收起联系条，再跑一次序列（不重复写入）。实际观察：`evidence/C02/tear/sheet.png`（17 帧）、`resched-accept/`、`punch-close/`。

### ③ 过热作废（M8 作废 / 燃烧）
- **触发**：局主「取消这局」→ 确认 → 700ms 处理中 → `engine.cancel` → 面板收起 380ms 后管理盘出现「取消中」区块，卡在槽口（`translateY(10%)`）开始过热；参加者「去不了了」确认退出 / 「新时间去不了」确认 → `engine.exitEvent` / `declineReschedule` → 票面切到作废场景；历史里「局主取消」首次打开烧一次（`burned[id]` 记忆），之后静态残骸；`j-d-exited` / `j-d-declined` 直接显示残骸。
- **运动对象**：同一张卡（`.c02-card.burning`），2800ms，所有子动画同一时长：槽口热浪 `.c02-glow`（0→1 @12%，.9 @70%，.25 @100%）；焦黑层 `.c02-char`（radial 焦黑 + 噪点）被 SVG mask 里的毛边圆揭出：圆心 (159,202) 即卡底中点，`r 0 → 30px @15% → 118px @60% → 152px @100%`，`cubic-bezier(.3,.05,.55,1)`，`filter:url(#fx-rough-strong)`；余烬环 `.c02-ember` 同半径同曲线，9px `#fx-ember-lin` 描边，78–100% 淡出；塑料起泡 5 枚 `.c02-bub`（22/14/18/12/9px 玻璃珠，`scale 0` 到 35%，1.15 @60%，.96 @75%，1 @100%，各自延迟 0/8/14/20/26% 时长）；磁条变黑（`#2a211c/#120d0b`），裂纹 `.c02-crack` 在 78–86% 出现；卡面翘曲 `c02-warp`：45% 起 `rotate(-1.4deg) skewX(1.5deg) scale(.985)` → 100% `rotate(-2.2deg) skewX(2.2deg) scale(.975) translateY(2px)`，圆角变 `9/9/14/6`。读卡灯红、显示屏「过热 · OVERHEAT」。
- **剩余形态**（`burnt`，`after(2800)` 落定）：mask 圆停在 152px（下半与磁条全焦黑，上缘时间仍可辨）、起泡保留、翘曲保留、余烬熄灭、显示屏「作废 · VOID」；参加者侧随后出现结果牌（翻牌「已退出这局」/「未接受新时间」+ 说明 + 「查看退出结果」→ 历史展开层）；局主侧头部状态翻成「已取消」、进度行隐藏、成员行「取消前已确认 / 取消前已预留」、安排区只剩「再开一局」（惰性）；返回列表落在 历史 › 已取消（高亮 1.4s）。
- **遮罩 / 阴影**：焦黑层在卡面内被 mask；余烬与 mask 在同一 `.c02-charsvg`（`overflow:hidden` 裁到卡）；热浪在卡外（`.c02-glow` 是 `.c02-face` 的兄弟）。
- **中断 / 重播**：`.scrub` 规则覆盖 face / glow / char / hole / ember / bub / crack 七组关键帧（`animation-delay:-frame×dur×k`）；`.rm` 直接 `burnt`；`beforeReplay('burn')` 把卡恢复为 done / ready（局主侧 `mtk:'idle'`）再烧一次。实际观察：`evidence/C02/cancel/`（11 帧 + 落定）、`burn-void/`、`decline-exit/`、`exit-burn/`、`rm-half-scrub/`（0.5× 与关键帧 30% / 70%）。

## 3. 其余动效族（简述）
- **M3 滚动折叠**：列表 `scrollTop > 56` 加 `compact`：板头 padding 50→40、品牌 28→18px、眉注与站钟收起（260ms `cubic-bezier(.2,.9,.3,1)`），身份牌与分区标签常驻，列头条常驻；`< 12` 还原（滞回避免抖动）。管理盘同理（`> 48` 标题 22→16px 单行省略）。
- **M4 行翻开成牌面**：点行 → `JU.fx.rectIn` 取行 y → 详情层：牌头行从原 y `translateY` 到 94px（420ms `cubic-bezier(.2,.9,.3,1)`，先 `getComputedStyle` 刷新再切 `in`），板上其余行文字淡出成空白翻片（200–260ms，行序错峰 18ms），牌面各行 `rotateX(90→0)` 320ms 错峰 60ms（`.c02-drow`），顶栏 300ms 下落；返回：牌面行 `rotateX(0→-90)` 200ms、牌头行飞回原行（若已换组先切分区并 `scrollIntoView`），440ms 后卸载，原行琥珀落点高亮 1.4s。索引跳转加 `jump` 类：全部 1ms 直接到位。
- **M5 审核结果**：按钮原位换成结果长翻片 `settle`（`translateY(6px)`+透明度 420ms）；申请计数、头部状态翻牌；新预留席位灯 `fresh` 点亮（500ms）；成员区新增「已预留 · 剩 06:00:00」。
- **M6 操作面板**：`translateY(104%→0)` 340ms `cubic-bezier(.2,.9,.3,1)` + 遮罩 300ms 到 55%；关闭反向 360ms 后卸载。
- **M7 改期**：改时间面板（date / time 输入、同时间校验、后果句）→ 确认 → 面板收起、toast「已改时间 · 等 N 位成员答复」、局卡条日期 `clip-path inset(0 0 100% 0)→inset(0)` + 7px 落位 420ms 重印、改期答复区闪烁 1.6s；参加者答复：旧票缩小置灰 + 红色「改期」胶囊（REF36），新票出票 → 过闸接受。
- **M9 散场与出席**：记为散场 → 头部状态翻牌、座位灯轨换成出席灯轨（`nRec/N 已记录 · 出席 n · 未出席 n`）、出席区三段按键；记录 → 结果翻牌（出席 / 未出席 / 待定）+ 灯点亮（500ms）+ 轨迹「更正 A → B · 时间」。
- **M10 草稿删除 / 撤销**：行 `max-height --rh → 0` 360ms（邻行让位）→ 写入 → 撤销条升起（10s 琥珀倒计时线）→ 撤销 → 行 `0 → --rh` 420ms 回到原槽；失败 → 行弹回 + 底部故障条。
- **M11 空态**：空态标题用翻牌格拼出（如「还 没 有 加 入 任 何 局」），一句说明 + 一个按键（跨模块入口用禁用钢键并注明「不在本范围演示」）。
- **处理中 / 失败**：按键 `busy`（文字隐去、钢面上一道扫光 900ms）；失败 = 发生处红灯故障条「故障 · 本机保存失败，请重试」+ 重试按键（面板内 / 申请行内 / 读卡器下 / 底部）。
- **Toast**：底部长翻片 260ms 上浮，2.6s 后退回。

## 4. 参考案例的落点（spec/concept-refs.md C02 节）
- **REF33**（clip-path 换态）→ 翻牌格四层结构：新面以上半 / 下半两道边揭出，文字位置不动（`.c02-fc` / `c02-fa` / `c02-fb`）。
- **REF36**（登机牌原位红胶囊）→ 改期答复页旧票时间旁的红色「改期」胶囊（`.c02-cpill`，300ms 弹出）；状态牌原位换面、行不重排。
