背景：静止夜色——四片径向色斑（蓝、紫、琥珀、深蓝）+ 五个模糊光斑（`.bk`，blur 10–16px）+ 六个清晰光点（`.pt`）。无循环渐变、无漂浮粒子。

### 材质规则（玻璃）
- 基础玻璃 `.g`：`backdrop-filter: blur(14px) saturate(1.35)`，表面 160° 线性渐变 α.11→.045→.075，`inset 0 1px 0 rgba(255,255,255,.34)`（顶边高光）+ `inset 0 0 0 1px α.10`（1px 边）+ `inset 0 -16px 26px -20px rgba(0,0,0,.5)`（底部内阴影 = 厚度）+ `0 20px 44px -24px rgba(0,0,0,.75)`（落影）；`::before` 顶部 40% 的反光。
- 最前玻璃（lead）：表面 α.16，顶边高光 α.55，落影更深 + 按 tone 色的外发光 `0 0 50px -20px var(--tone)`。
- 厚玻璃 `.g.thick`（弹层、联系层、底栏、撤销条）：深色底 α.78–.84 + `blur(26px)`，顶边高光 α.4。
- 暗玻璃 `.g.dark` / 书脊 `.spine`：几乎不透光的深色薄片，1px 边 α.05–.08，只有顶边 α.08–.12 的微光；pack 色 4px 边条。
- 通行证 `.piece`：更亮的玻璃（表面 α.2→.07→.13，`blur(16px) saturate(1.5)`，顶边 α.65，边 α.2）+ `::after` 112° 全息三色带（青 / 品红 / 金，`mix-blend-mode: screen`，静止；指针移动只平移 `--sx`）。副券是更薄的玻璃（表面 α.12→.05→.09，边 α.16）。齿孔 = 2px 点线 + 两端 16px 圆缺口。
- 景深：分组按纵深 `--z` 1 / .96 / .92（局主 1 / .965 / .945 / .92）缩放；远层分组里的玻璃板前后叠放：后一块向上 24px 插到前一块下面（`z-index` 前高后低，后一块 `padding-top:30px`，文字从不落在叠压区），所以后板的上沿隔着前板的玻璃被模糊、并承接前板的落影（`0 22px 26px -14px`）；远层玻璃表面 α 降到 .085 / .065，`.obj` 物件 blur 1.1 / 2px 并变暗；文字始终清晰。进入详情时 `.home.recede`：`scale(.93) blur(12px) brightness(.8) saturate(1.2)`。
- 抬起的详情 / 管理层 `.pane-bg` 是薄的烟色玻璃：α .36 → .46 → .60（上→下）+ 顶部 3.5% 白色反光；静止时后退失焦的局卡叠和夜空光斑仍透出来（「近处清楚、远处失焦」在落定后依然成立）。底部动作区是 α .90 → .97 的渐隐，等待态按钮是封闭的深色玻璃槽（不透明，不让内容透过禁用按钮）。
- 按钮重置写成 `.app :where(button)`（类选择器级），所以 `.g` / `.spine` / `.cta` / `.back` / `.cp` / `.cap` 在 `<button>` 上保留自己的表面（之前被重置吃掉）。
- 列表缩略通行证：改期行 = 旧票（去饱和、时间 α.62）+ 右上一个琥珀点，不再叠删除线 + 「改期」章；全息带在 44px 缩略里减到 α.5。
- 碎片：每块玻璃碎片的内部断口（不在票面外轮廓上的边）有 1px 白色高光 + 3.5px 青白内辉（`.sedge`，与碎片同一 delay 起亮），碎片表面 +4% 白，读起来是有厚度的玻璃而不是纸。

### 圆角 / 阴影 / 边缘
- 玻璃板 18px；lead 18px；书脊 12px；票面 16px；弹层顶部 28px；按钮 14px；胶囊 17px；输入 12px；珠串头像圆形（2px 深色隔离环 + 3.5px tone 环）。
- 阴影只有两种：落影（深、偏移向下）与内阴影（厚度）；边缘靠 1px 内描边 + 顶边 1px 高光，不用外描边。
- 碎裂边缘：裂纹 1.1px 白线 + 2px 青白 drop-shadow（`.crack path`）；撕口 `edgeglow` 4px 青白光带 α.55。

### 布局构图
- 首屏：标题「我的局」（左）+ 分区标签（右）→ 玻璃轨道角色切换（滑块）→ 纵深堆叠的分组玻璃板（要你回应 / 就快见面 / 还在等）→ 底部厚玻璃主导航。第一眼 = 最前玻璃板上的局名 + 琥珀倒计时 + CTA；第二眼 = 后面缩小变暗的板。
- 局主首屏同构：待你处理 / 改期中 / 招募中 / 已成局，最前板带席位条（局主紫 / 已确认绿 / 预留琥珀条纹 / 空位）与 CTA。
- 详情 = 玻璃板抬到前面占满屏：返回胶囊 + 弱动作（右上）→ 状态眉注（STAGE_EN + 状态词）→ **24px 局名**（与列表板上的局名是同一个主角）→ 15px 状态句（detailTitle / 结果页副文）→ 时间 · 地点 → 一条居中的玻璃纵列：本步物件（倒计时块 / 席位 / 通行证 / 联系层 / 记录）→「同局的」珠串 →「这一步的约定」玻璃板 → 底部动作区（渐隐在 44% 处变成实色 #060914，链接与按钮下面没有透出的文字）。只有「参加约定 ›」一个弱链接时，它放在约定板下方而不是浮在底部。作废空框里有一行蚀刻的局名 + 时间（α.34 / .26，上下 1px 反向阴影），物件身份在作废后仍可读。历史票根可点一下翻面（背面 `JU.` / 「有 JU，就开局」）；局内记录下方是「不对劲？举报」暗玻璃入口。
- 管理 = 宽玻璃控制台：返回 + life 灯 → 局名 → 状态 · 时间 → 进度玻璃 → 局卡条 → 胶囊标签（申请 / 成员 / 候补 / 联系信息 / 离开记录 / 改期答复 / 出席，含待办红点）→ 当前面板 → 这局的安排。
- **〔fix-r1〕席位座**：散场前的进度玻璃不再是一条分段条，而是一串玻璃珠座（每席一颗 34px 珠，容量几席就几颗，`grid repeat(cap)`）：局主紫环「主 / 你」、已确认绿环、已预留琥珀虚线环、空位 = 凹进去的深色座孔（内阴影 `inset 0 2px 6px`、1px 虚线边、下沿 1px 反光）；审核时下一个要被填的空座孔亮一圈局主紫（`next`）。珠下 10px 名字。散场后的出席段保持原分段条。审核分区打开时，席位座是一层贴在头部下面的玻璃搁板（`position:sticky; top:-18px`），随滚动加厚：底色 α 0→.8、`backdrop-filter: blur(0→22px)`、下沿发丝线与落影随 `--cs` 出现；此时 `.ps` 顶部羽化遮罩关闭（搁板自己遮住滚上去的内容）。
- **〔fix-r1〕申请审核 = 纵深队列**（取代「头像 + 认证 + 留言 + 两按钮」的行列表）：每份申请是一块玻璃板，前后叠放——还要处理的第一份站在最前（lead 玻璃：表面 α.16、顶边高光 α.55、局主紫外发光 `0 0 62px -18px` + 1px 紫边），之后的板每后退一步缩 2.8%（`scale(1 − d·.028)`，d 封顶 2）、玻璃变暗（表面 α.085、顶边 α.22）、上沿 12px 插到前一块板下面（`margin-top:-12px; padding-top:24px`，文字不落在叠压区）；已处理的板退到 d = 2。板内：称呼 16px 500 + 认证胶囊 + 右上「申请于 …」（Sora 11px）→ 留言刻线引文 → 决定槽。
- **〔fix-r1〕决定槽（玻璃摇杆）**：52px 高的凹槽（深色 α.62，内阴影 `inset 0 3px 9px -3px`，1px 边 α.12），左半「‹ 谢绝」、右半「发出邀请 ›」（右半是局主紫玻璃 α.05→.26），两端各一个 30px 座孔（左 = 磨砂圆片，右 = 和席位座同样的空座孔 + 紫环）；申请人自己的 40px 头像珠（紫环）停在中线。点一侧或把珠拖向一侧都可以：珠滑到那一端（260ms `--ease`），被推向的一侧亮起（右 = 紫光在座孔处聚集，左 = 灰雾），另一侧字样淡去。结果原位落在同一条 52px 槽里（下面的内容不移动）：邀请 = 琥珀「✓ 已发出邀请 · 等对方确认」+ 右端座孔变成琥珀虚线环（珠已离开）；谢绝 = 珠留在左端磨砂失色（`blur 1.1px saturate .15 brightness .78`）+ 灰字「已谢绝 · 对方会看到「这次没留住」」，整块板盖上一层磨砂（`::after` 径向白雾 + 细颗粒 + 下沉暗色，560ms 淡入），文字仍清晰在磨砂之上。
- 弹层 = 底部升起的厚玻璃（身份条 + 正文 + 受影响统计 + 两个按钮）；背景整体 blur 6px 变暗。举报层同材质：「发生了什么」文本框（≥4 字计数）→「谁」玻璃胶囊（含「（局主）」，可多选）→ 截图格（≤6，可移除）→ 提交 → 层内结果「已受理」章（`c04-mark`）+「可在“设置 → 帮助与反馈”查询进度。」；失败时层内红玻璃条「提交失败，内容已保留。请重试。」。提示条停靠位：首页在底栏上方 104px；管理页 / 无动作区的详情贴底 28px。

## 2. 三个核心动作

### ① 景深展开（局卡 → 详情 → 返回）
| 项 | 说明 |
|---|---|
| 触发 | 点任意玻璃板（整板是按钮）；`JU.fx.rectIn` 取该板矩形 `from` |
| 运动对象 | 详情层 `.pane`（厚玻璃）+ 内层 `.pane-in`；背景 `.home` |
| 起点 → 终点 | `.pane` 的 `clip-path: inset(top right bottom left round 18px)` = 板矩形 → `inset(0 round 0)`；`.pane-in` `translateY(from.y − 44px)` → 0（标题从板的位置出发）；`.home` scale 1 → .93，blur 0 → 10px，brightness 1 → .5 |
| 分段 | 0–20ms 置起始态并强制样式刷新（`flush`）；20–480ms 三者同时过渡；返回 400ms 反向，再 40ms 卸载并高亮落点 1.4s（`c04-land` 边光收敛） |
| 曲线 | `cubic-bezier(.2,.8,.2,1)`；返回同曲线 400ms |
| 变换中心 | `.home` 50% 40%；clip 以板矩形为准（无非等比缩放，文字不变形） |
| 遮罩 | clip-path inset（圆角 18→0）；`.pane-bg` 上溢 260px 避免平移露底 |
| 阴影变化 | 背景整体变暗 50% + 失焦；详情顶边 1px 高光常驻 |
| 中断 / 重播 | 展开中按返回 → 立即置 `closing`（层不再接收点击）并进入 out；收回中再点卡片 → 取消旧的卸载、按新 `tok` 重新展开；返回时若源板已换分组（终态）先切到历史分区再量矩形（`unscale` 还原 .93 缩放）；面板「重播」= `open-card`：先卸载详情再从同一板重新展开；跳转索引用 `noanim` 直接呈现 |

### ② 裂开撕票（副券 = 薄玻璃）
| 项 | 说明 |
|---|---|
| 触发 | 在副券（`.piece.stubp`，齿孔以下 72px）按住向下拖，`setPointerCapture`；`p = (dy + .25·dx) / 120` |
| 运动对象 | 副券薄玻璃（translate 0→18px、rotate 0→−2.4°，origin 左上）；裂纹 SVG（齿孔折线 + 3 条支裂 + 4 条竖向碎片界线）；主票底边 clip |
| 起点 → 终点 | 齿孔处从左向右渐进断裂：`JU.fx.tearClip` 按 p 把直线齿孔换成玻璃型折线（n=14, amp 3.2）；裂纹 `stroke-dashoffset` 随 p 揭示（主缝 0→1.15p，支裂与界线从 p≈.25 起依次出现）；`edgeglow` 断口光带随撕票点亮 |
| 阈值 / 回弹 | 松手 p ≥ .55 → `JU.engine.tearTicket`（或改期页 `acceptReschedule`）；否则 `spring` 回位 420ms `cubic-bezier(.2,1.25,.3,1)`，裂纹随 p 收回 |
| 碎裂分离 | 副券换成 7 块碎片（同一 DOM 模板、clip-path 多边形，上沿沿齿孔折线）：`c04-shard` 720ms `cubic-bezier(.4,0,.75,.4)`（重物下落），每块 delay i×85ms（从左到右），位移 (dx≈±14, dy 120–210px) + 旋转 ±22°，55% 后透明；碎片下落期间眉注 / 标题保持撕前（TEAR · 撕开，联系局主 / RESCHEDULED · 局主改了时间），票注「副券碎裂分离中」，无 CTA；820ms 后进入 `torn`：标题 settle 为「联系局主 / 待赴约」，主票底边保留折线断口 + 光带，票槽 272→208px 420ms 收拢，联系层 460ms 弹簧升起，CTA「已加微信」同时 `c04-rise` 出现；碎片断口在各自开始下落时亮起 1px 高光 |
| 变换中心 | 碎片各自质心（`transform-origin: cx cy`） |
| 遮罩 | 主票 / 副券 / 碎片均为 `clip-path: polygon` |
| 阴影 | 副券被拖时无落影变化（刚体），碎片带玻璃落影随透明度消失 |
| 中断 / 重播 | 拖动中松手未过阈值 → 回弹；出票动画进行中副券 `pointer-events:none`；面板「重播」= `shatter-stub`：重置 `fx` 与 `tear` 后再放碎裂段 |

### ③ 碎裂作废（取消这局 / 主动退出 / 拒绝改期）
| 项 | 说明 |
|---|---|
| 触发 | 弹层「确认取消 / 确认退出」→ 引擎成功，**同一回调**里进入 `hold`：页面继续按写入前的数据快照渲染（参加者：同一张完整通行证 + 写入前的眉注 / 状态句，动作全部失效；局主：取消前的头部 / 进度 / 胶囊 / 面板）→ 弹层收起（460ms）→ 作废序列。参加者另有一个入口：局主取消后**第一次**打开这张票（从历史 › 未成行点开）：详情落定 480ms + 完整通行证停留 420ms（状态句「局主取消了这局 · 票根即将作废」）→ 同一套碎裂；之后再打开（或索引直跳）都是静态空框（`seenVoid`）|
| 运动对象 | 同一张通行证（局主侧为「局主副本」，从局卡条下方 380ms 升起）：裂纹 SVG（9 条从起裂点 (68%,40%) 到边缘的射线 + 内环折线）、18 块径向碎片（内三角 + 外梯形，确定性随机 seed 17）、空框 `.frame` |
