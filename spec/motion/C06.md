## 2. 三个核心动作

### ① 拿起 / 放下（M4，所有 `p_detail` / `p_ticket` / `p_history` / H1 进入与返回）
- **触发**：点物件（`[data-rid]`）；`openOver()` 用 `JU.fx.rectIn` 取 bbox，按中心 + `offsetHeight` + `--rot` 反推未旋转矩形 `from{x,y,h,rot}`。
- **运动对象**：同一物件（`.c06-held.main`，复用列表的物件模型）；原位留虚线「灰尘轮廓」。历史里已退出 / 拒绝改期 / 已取消的局，被拿起的就是那张杯垫本身（不再换成看不见的票）。
- **起点 / 终点**：`translate(from.x, from.y) rotate(from.rot)` → `translate(25px, 80px) rotate(0)`；阴影 `0 7px 12px -7px` → `0 30px 50px -18px`。
- **分段**：phase `start` → 读一次布局 → 20ms 后 `in`；物件 430ms `cubic-bezier(.2,.8,.2,1)`；桌面 `brightness(.52) saturate(.8) blur(2.6px)` 380ms **[r1 改，原 brightness(.58) blur(1.6px)]** + 遮罩 `.42` 360ms；纸张从底栏下 `translateY(106%)` 推进 440ms、延迟 80ms；桌沿：铭牌 240ms 淡出 + 300ms 上移，身份标签 280ms 下沉淡出；返回标签带 240ms 淡入（延迟 200ms）。
- **放下**：`closeOver()` 先 `locate()`（换分区则先切分区），目标行不在可视桌面内（桌沿 150px 以下、底栏 74px 以上）时**只设置 `.c06-feed.scrollTop`** 把它移到中间（不用 `scrollIntoView`，`.app` 为 `overflow:clip`，`.app` 与宿主文档始终 scrollTop 0，探针 `evidence/C06/setdown-scroll/probe-scroll.txt`），重新测矩形 → phase `out`（物件 430ms 回原位、纸张 360ms 退回、遮罩褪去、铭牌与标签同时回来）→ 450ms 卸载；落点光晕 1500ms。放下中的覆盖层 `pointer-events:none`：这 450ms 内点另一件物件会立即拿起它（`openOver` 让旧的卸载 token 失效，卸载回调只在 `view.gen` 与 phase 仍是这次放下时执行，探针 `evidence/C06/reopen/probe-reopen.txt`）。写入处理中按返回：等这次写入结束（≤700ms）再放下，跳过结果动画。燃烧中途放下：烧着的层 140ms 淡出、烟灰缸 200ms 淡出，飞回桌面的是归档杯垫。
- **物件换形（拿着时状态变了）**：外出物件作为 ghost 画在上层并走自己的材料过程，新物件在下面接住，之后 `remeasure()` 让纸张 `top` / 夹板留白平滑跟随：
  - 记为散场：索引卡被抽离夹子滑出右侧桌沿（`g-slide` 500ms，先抬起 9px 再滑走旋转 12°），下面的拍立得上浮 10px 露出（`emerge` 500ms）。
  - 撤回申请 / 放弃预留 / 退出候补：便签沿中线对折（`scaleY 1 → .5`，压暗）再缩进杯垫圆环（`g-fold` 540ms），杯垫轻按一下（`press`）。
  - 确认后成局：便签缩成信封上的小贴纸（`g-stick` 620ms，落在信封前片右上角，贴纸 `已确认 · 全员 · 出票` 在 420ms 处淡入接替），随后信封被抽走（②前的出票）。
  - 确认后未成局：黄便签淡出到米白「等全员确认」便签（`g-fade` 420ms）。
- **中断 / 重播**：开启中可直接放下；连点被 phase 判定拦截；所有局内定时器带视图代号 `gen`（`alive(gen)`：同一次拿起且未在放下），重新打开同一物件不会被上一次的定时器改写；`.rm` 下全部 1ms；重播 `beforeReplay('lift')` 回到列表再拿起。换形期间物件与纸张保持写入前的状态（`freeze`），换形开始的同一帧才换成新物件，没有提前变身。

### ② 出票 + 桌上撕票（M8，`tear` 首次打开、确认成局、改期接受）
- **出票（信封抽开）**：舞台高度从头到尾 206px（信封高度），纸张不移位。信封前后两片各包在 `.c06-envclip` 里，裁切线就是纸张上沿（舞台高 − 8px）——信封按 `c06-pull` 2000ms 分段（0→54→56→124→126→200px，两次停顿）向下抽开时是**滑进纸张下面**，不盖纸张标题、提示与「同局的人」；票在信封背片与前片之间逐段露出。200px 时信封已完全在纸下，同一帧移除信封元素（无跳变）；40ms 后票留在打印位置，纸张上沿 400ms 上移 12px 压住票下沿（舞台 206 → 194），票与纸之间不露压暗桌面的字。打印中纸上说明为「出票中 · 信封抽开后，按住副券向下撕…」，出票后换成「按住票右侧的副券向下撕 · 没撕够会弹回…」（不再有挤在票与标题之间的 11px 居中提示）；「去不了了」等操作区按原位置预留但隐藏（`visibility:hidden`，不可点），出票完成后 320ms 淡入，纸张内容不跳。首次抽开后该局在列表上变成一张平放的票（不再是信封），再次打开直接是落定的票；中途返回再打开会从信封起点重来。`.scrub` 按 `--frame` 定位信封。
- **撕票触发**：按住副券（`.c06-tside.stub`，只在多边形内响应，`setPointerCapture`），向下 / 向右拖：`p = clamp((dx·0.9 + dy·1.1) / 170)`。
- **运动对象**：同一张票两份（keep / stub），`c06ClipV()` 以 x=252 竖向齿孔从上往下撕（已撕段是纤维轮廓，未撕段仍是直线齿孔）；副券绕左下附着点 `252px 180px` 转 `p·10deg`，撕口张开 `p·5px`；拖动中副券有抬起的投影（`.c06-stubw.lift` drop-shadow）。
- **释放**：p < 0.55 → 240ms 回弹；p ≥ 0.55 → `engine.tearTicket`（改期新票 `acceptReschedule`，120ms 处理）→ 成功后副券**落进票右侧的存根位**：`c06-stubdrop` 680ms（0% 撕开姿态 → 36% 被拉开、抬起 `translate(13px,26px) rotate(10.5deg) scale(1.035)` → 76% 落桌冲击 `scale(.982)` → 100% 静止 `translate(6px,4px) rotate(3deg)`），投影从抬起换成贴桌接触阴影。副券此后一直躺在票旁（列表、再次打开、燃烧时都同一位置），不压任何纸张内容。900ms 后局主名片从纸张上方滑入（名片所在的块用高度动画打开，下面的名单一起平滑下移）；撕票不出 toast（G12）。
- **改期接受的后续**：副券落定（700ms）→ 旧版票盖「作废」（印章 520ms）并褪色 → 1320ms 旧票滑出左侧桌沿（480ms，旋转 −9°）→ 1620ms 新票从下方槽位上移到主位（460ms），舞台 380→180、纸张同步上移 → 2100ms 名片 + toast「已接受改期 · 按新票根的时间见」（唯一保留的撕票类 toast）。放下时只有这一张新票回到列表。改期详情里旧版票只带「改期 / 作废」章、不再印旧时间，旧时间只在新票的「原定」行出现一次；副标题与 kv 不重复新时间。
- **失败**：写入返回 error → 副券回弹，副券下沿挂一条朱红标签带「未能保存，请重新撕下副券」（改期接受为「新时间未保存，请重新撕下副券」）+ ×；重新按住副券即清除并可再撕（再撕即重试）。

### ③ 烟灰缸（M8 作废 / 燃烧：主动退出、拒绝改期、局主取消、`cancelled` 首次打开）
- **触发**：确认层「确认退出 / 确认取消」→ 处理中（460ms / 取消 700ms）→ engine 成功 → `motion('burn')`。拒绝改期先让旧版票盖「作废」并滑出桌沿（0–1000ms），再烧新版票。首次打开已取消：被拿起的杯垫下面藏着那张作废票（缩到 .56 藏在杯垫后），700ms 后票从杯垫夹层滑出、飞进烟灰缸。
- **处理中**：确认纸条留在桌上，「确认退出 / 确认取消」三点步进；失败时红条出现在纸条内、按钮旁（退出 `无法保存退出，请重试`、拒绝改期 `保存失败，尚未退出。新时间仍待你答复，请重试。`），重试成功后纸条才收起。
- **运动对象**：同一张票（`.c06-tkw`，连同旁边的存根）或同一张索引卡（`.c06-cardburn`）；烟灰缸（SVG 玻璃碟）从左边推进 420ms（`c06-trayin`）。拒绝改期：旧版票盖「作废」滑出桌沿后，新版票先 480ms 上移到主位（纸张同步上移，不留空桌面），再入缸。
- **起点 / 终点**：票从舞台上的布局位置 → 碟心 (81, 714)：`translate(81 − (舞台 x + 170), 714 − (top + 90))px rotate(-14deg) scale(.56)` 620ms `cubic-bezier(.4,0,.6,1)`（新版票的 200px 偏移是 transform，会被替换，所以目标按舞台顶计算）。
- **燃烧（一条时间线，1×）**：0 票落向碟子、碟子推进 · 660 左下角 (30,172) 起火，遮罩圆洞 `r 0 → 326px` 2600ms（`fx-hole`，`#fx-rough-strong` 毛边），余烬环同步推进、85% 后淡出，焦黑线 + 焦痕晕跟着洞走、不淡出；9 粒纸灰在兄弟层落进碟里；碟里的灰堆是 `c06-pile` 2600ms（0–34% 无，60% 半堆，100% 满）——和洞同一时长、同一起点，所以 `.scrub` 拖到 50 / 70 / 90% 时看到的是对应进度的洞、焦边、灰堆。
- **剩余形态（660 + 2600）**：火线停在远端（右上）角之前，烧剩的那一角带焦边留在碟里——就是同一张纸，没有替换素材；被遮罩的子树里没有 box-shadow，烧掉的部分不留轮廓或空白矩形。
- **归档（+360ms 起，一次连续落定）**：+360 烟灰缸连同残角与灰一起被推出左侧桌沿（`c06-trayout` 420ms，残角同曲线同步离开）· +800 结果落定为**一次**位移：归档杯垫被「放下」到票 / 索引卡留下的位置（`setdown` 460ms），纸张上沿 / 夹板留白 480ms 跟随新高度，同一帧结果块与消失的块用 `grid-template-rows` 0fr↔1fr 480ms `cubic-bezier(.42,.08,.22,1)` 打开 / 合上——燃烧期间纸张一直是写入前的状态（`freeze`），不会先被结果块推下再被拉回（逐帧探针 `evidence/C06/land-reflow/probe-land.txt`：退出单帧最大位移 24px、拒绝改期 31px、局主取消 12px，原来是 66–137px 一帧跳）。参加者：成员行「你」原位改成「位置已释放」（不换行序）；局主：杯垫夹在夹子下，纸上「已取消 · 不能撤销」与消失的进度行同帧打开 / 合上（标题位置基本不动）、成员 void、安排只剩惰性「再开一局」。放下时杯垫直接飞回历史 › 未成行（或 历史 · 已取消）里的同一张杯垫。首次打开已取消时杯垫本来就在手里，烟灰缸只是带着残角退出桌面。
- **中断 / 重播**：`.scrub` 暂停洞、余烬、焦边、纸灰、灰堆并按 `--frame` 定位（`evidence/C06/burn-scrub/`）；`.rm` 直接呈现归档结果；重播 `beforeReplay('burn')` 复原票 / 卡、清空碟、撤回归档杯垫，并让上一轮燃烧的定时器失效（`_burnTok`）。
