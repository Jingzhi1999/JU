## 2. 三个核心动作

### ① 走纸打印（出票）
- **触发**：第一次打开某一版还没打印过的票（`tear` 首次、改期新版票首次、`confirmReservation` 返回 `formed:true`）；评审面板「重播」。已打印过的版本（`state.printed["eventId@version"]`，放在 view 之外，离开详情不清除，F10）以及已经撕过的票，进入时**直接是 ready**，只随正文一起走纸，不再重印、也没有「出票中」。
- **纸面顺序 = 打印顺序**：第二层纸先印 头部（齿孔 · 页面标题 · 地点 · 一句说明，520ms `c01-feed2`）→ **票**（`.c01-pr.idle` 高 0 → `printing feed3`）→ 票落定后才印 尾部（联系层、同局名单、参加约定、动作、页脚；700ms `c01-feed2`）。尾部在票打印完成前根本不存在，所以没有任何已印内容被「插入」或被往下推；头部那句说明打印后不再改字。
- **运动对象**：票自己的那截纸（`[data-tk] > .c01-pr`，250px）。票面文字随纸露出，不缩放、不移动。
- **分段**（2200ms × k）：0–24% 走到 34%，24–34% 停顿，34–60% 走到 72%，60–70% 停顿，70–96% 走完，96–100% 停稳；`linear` 分段（步进电机）。完成由该元素自己的 `animationend(c01-feed3)` 决定（另有守护：动画丢失时才补完），不靠计时器。
- **变换中心**：顶边（高度动画，`overflow:clip`，不破坏常驻头的 sticky）。
- **遮罩 / 阴影**：印头处 10px 向下暗渐变；打印中副券不可拖，副券写「出票中」，票下提示「出票中 · 打印完成前不能撕」。
- **中断 / 重播**：关键帧滑杆下换用同名副本 `c01-feed3-s`（新实例）并按 `--frame` 定位；松开时以 `--c01-rf`（松开时的帧）作负 `animation-delay` 让原动画从该帧继续；`.rm` 直接终值；重播 `beforeReplay('print')` 把票置回 idle、尾部收起，再按纸面顺序重印。

### ② 沿孔撕票
- **触发**：在副券右端按下（`setPointerCapture`），向左 / 向下拖；`p = clamp((−dx + 1.15·dy)/175)`。
- **运动对象**：同一张票渲染两份（keep / stub），`clip-path` 由 `c01TearClip`（从右向左）生成；已撕段 = 纤维轮廓 + 1.6px 亮纤维带 + 软影，未撕段 = 直线齿孔。
- **过程**：副券以左上角为轴 `rotate(p·12deg) translateY(p·4px)`，撕口张开 `p·6px`；p < 0.55 释放 → 220ms ease-out 回弹。
- **落点**：p ≥ 0.55 → 先写入（`tearTicket` / 改期新票 `acceptReschedule`）；**失败**：副券回弹，底部红条写本动作的话「未能保存，请重新撕下副券」/「新时间未保存，请重新撕下副券」，只有「知道了」（要求重新撕，不做盲重试）。成功后副券 `off`：820ms `cubic-bezier(.45,.02,.75,.5)` 落下（全程票面可读，rotateX ≤ 40°，scale ≥ .82），`translateY(--drop)` 落到底栏槽口；`animationend(c01-stubfall)` = 接住：槽口亮一下（560ms）、存根堆弹入一片并计数，票高 250→184、底边锯齿；340ms 后联系层墨迹揭示。改期接受时旧票同刻盖「作废」，回执「已接受改期 · 按新票根的时间见」。
- **中断 / 重播**：滑杆用 `c01-stubfall-s` 定位、松开续跑；重播只复原刚撕的那张（旧票保持原样）。

### ③ 焦卷作废（取消 / 退出 / 拒绝改期 / 局主取消后首次打开）
- **触发**：确认便签在写入期间**一直开着**（按钮三点），写入成功才收起便签，280–300ms 后起火；写入失败时红条印在便签里（C9 / p_exit），可重试。参加者第一次打开「局主取消」的历史条目时，取消时的票快照（盖「作废」）随正文印出后烧一次（`state.seenCancel`），之后只剩焦条。
- **一条时间线**：票 `--seq: 2650ms`、工单活动条 `2860ms`。起火时同一刻挂上 `.burning`，全部是 CSS 关键帧：洞 / 炭圈 / 余烬 `c01-hole` 0→98% 半径 0→`--reach`（`cubic-bezier(.35,.05,.5,1)`，`#fx-rough-strong` 毛边）；余烬 78–96% 淡出；64% 起残余向下折叠（`c01-burnbox`：`max-height --bh→0`，`cubic-bezier(.25,.6,.3,1)`，82% 到 0），同刻焦条 `.c01-charslot.seq` 在让出的位置升起（64–80%，`translateY 10→0` + 淡入）；盒子的 `animationend(c01-burnbox)` = burnt（灰堆 +1、结果块墨迹揭示）。
- **纸灰**：10 粒，在**机壳层** `.c01-ashlayer`（不在滚动的纸里）按起火点的屏幕坐标落向底栏，`1500ms ease-in`，各自 0–1100ms 延迟，`±46px` 横漂、旋转，被底栏上沿裁掉 = 落进槽里。
- **构图保持**：起火 / 写入成功的那一刻，第二层纸锁住至少「当前滚动位置 + 视口」的高度（`min-height:max(100%, Npx)`），残余折叠时视图不跳、纸也不会比屏幕短，下面的列表永远不会从纸下露出；纸灰不再撑大滚动区域。
- **剩余形态**：深棕锯齿焦条，灰字「原定 时间 · 局名 · 结果句」（取消：`局主取消 · 票根作废 · 联系已关闭`；退出：`票根作废 · 联系已关闭 · 记为主动退出`；拒绝改期：`新版票作废 · 席位已释放 · 不记主动失约`，旧票同时盖「作废」）。
- **结果一致**：工单头「已取消」、活动条只剩焦条、成员「取消前已确认 / 取消前已预留」、口径「已取消 · 取消前已确认 N（含你）」（不再写预留数）、安排只剩「再开一局」（惰性）；返回落在 历史 › 已取消。参加者：结果块印在焦条下，页面标题保持打开时的那一行（不重复印结果标题）。
- **中断 / 重播**：关键帧滑杆按 `--frame × --seq` 定位洞、折叠、焦条、纸灰（`*-s` 副本），能拖到 66% 折叠、86–95% 焦条落定；松开用 `.c01-rsm` + `--c01-rf` 从松开的帧继续（不再从起火点重烧）；`.rm` 直接焦条 + 结果；重播 `beforeReplay('burn')` 复原票 / 活动条再烧。

## 3. 其余动效族（简述）
- **进入详情**：点行 → `rectIn` 取矩形 → 第二层纸 110ms 内变实（底层纸带同时退到 18% 墨色），**之后** 100ms 起行副本从原位 420ms `cubic-bezier(.2,.8,.2,1)` 滑到返回行之下 → 480ms 起正文走纸。列表的倒计时 / 出席章与副文在行副本落定后交给详情里唯一的那一处（倒计时只在截止行上；出席章盖到归档票上）。
- **返回**：`out`：正文与返回行 120–140ms 抬离，第二层纸保持实色 → 110ms 后行副本 380ms 飞回原位（底层列表此时仍被纸挡住，不会两层叠字）→ `land`：纸 140ms 变透明、列表墨色同时恢复、原行描边 1.6s → 卸载。卸载只在 `phase==='land'` 且仍是同一次关闭时执行，关闭途中再点同一行会正常重新打开（`out / land` 时第二层纸 `pointer-events:none`）。写入进行中返回行显示为不可用、点击无效。若条目换了分区，先在纸下切到新分区并把滚动归零再取落点。
- **常驻头**：第二层纸的返回行 `sticky`；滚过 118px 后返回行换印单行省略的局名（180ms 交叉），工单标签行贴在它下面（`top:44px`）。
- 身份切换：旧卷 430ms 收回出纸口，新卷**头先出**（`c01-rollin` 640ms，可见长度 0→400px→停顿→840px）。分区切换：正文 420ms 重印；打印中组名行改为 `position:relative`，且打印容器用 `overflow:clip`，组名行不会压在半截行上。
- 便签：右侧滑入 380ms `cubic-bezier(.2,.9,.3,1.05)`，落定 −1.2°，背景压暗 45%；写入中便签不收起。
- 回执小条（toast）：从底栏槽升起 420ms，停留 2.6s。
- 印章（出席）：560ms 从 1.9 倍落下；「未出席」「待定」用灰墨（不是红），章内不换行（46px）。
- **草稿删除 / 撤销**：行 360ms 收到恰好一条撤销条的高度（62px）并**保持收起**，直到引擎删除成功才换成撤销条（印在原行位置，不在列表顶部）；相邻条目只移动一次。失败则行回原位并出红条。撤销 → 行从 62px 展开回原高 420ms。
- **减少动态**：只缩短动画；撤销窗 10s、回执 2.6s、「已复制」2.2s 用不受 rm 缩放的 `hold()`（仍随 0.5× 放慢、随暂停 / 滑杆暂停）；rm 下撤销条隐去移动的墨线，保留「10 秒内可撤销」字样。
- **失败文案按动作**：撕票「未能保存，请重新撕下副券」、接受改期「新时间未保存，请重新撕下副券」、确认「保存失败，请重试。你还没有确认。」、撤回 / 放弃 / 退出 / 退候补 / 拒绝改期各自一句（如「保存失败，尚未退出。新时间仍待你答复，请重试。」）、局主取消 / 改时间 / 散场 / 出席 / 审核「这一步没有生效，请重试。…」、举报「提交失败，内容已保留。请重试。」。便签里的写入失败印在便签内。
- **历史展开（p_history）**：散场 = 归档的那张已撕票（锯齿底、局主章：出席红 / 未出席灰 / 待定灰虚 / 等章点线），点一下 560ms 翻面，背面 `JU.` / `有 JU，就开局`；下面是 出席记录（局主记录的事实，不评分）、局主、局主微信（散场 <24h 才显示，否则写已关闭）、局内记录，以及「不对劲？举报 ›」便签：「说说发生了什么」（≥4 字计数）、「谁」chips（含「（局主）」）、截图 0/6（演示不上传）、提交 → 便签收起，局内记录多一行，印出举报回执「已受理 · 可在“设置 → 帮助与反馈”查询进度。」+ 惰性「查看进度 ›」。没有私人笔记。未成行：有票的留焦条（「原定 …」），没票的留作废小条；有记录才印局内记录。
- 撤回 / 放弃预留 / 退出候补的结果：原来手里的那张小条（申请单 / 预留单 / 候补号）在原处作废并盖章（墨迹揭示 + 章 560ms 落下），下接结果块；页面标题保持不变。
- 改时间便签：打印的 24h 日期块（`周四 12.24`）与时间块（`20:00`）各带 ‹ › 步进（±1 天 / ±15 分钟，不早于今天）；原生日期 / 时间控件透明地叠在打印值上，点打印值即调起系统选择器，不再露出 `12/23/2026`、`07:30 PM`。
- 待全员确认详情：头部印每席一段的座位条 + `c/cap 已确认（含局主）`，成员行写「等成局出票」；他人的预留写 `已预留 Nh`（向上取整），自己的倒计时只在截止行。
- 空态：保留其他模块的惰性入口（点线框「去找局 ›」/「去开局 ›」+ 一行说明），不划线。草稿行的「继续编辑 ›」同样是点线框惰性入口 + 「在「开局」里」。

## 4. 评审辅助
- 失败 / 重试用评审面板自带的「下一次保存失败」（产品画面外没有 C01 自己的演示控件）。
- 选择器（§10）：覆盖层根 `.c01-over`；列表行 `data-rid="r-{id}"`；票 `[data-tk=main|old|fresh]`；按钮 `data-act`：`confirm` `release` `withdraw` `exit` `decline` `tear` `accept` `copy` `contacted` `rules` `flip`（归档票翻面）`report`（举报便签的入口与提交）`approve` `reject` `propose` `cancel` `end` `card` `attend-present` `attend-absent` `attend-pending` `correct` `delete` `undo` `back` `close` `retry`。改时间步进按钮用 `aria-label`（前一天 / 后一天 / 早 15 分钟 / 晚 15 分钟）。
- 第 3 轮捕获见 `evidence/C01/`（每个目录含 sheet.png 与 log.json，errors 均为空；`coverage/` 50 个状态）。
