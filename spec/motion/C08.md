## 2. 三个核心动作

### ① 改期滑动（M7）—— `slideVals()` / `acceptReschedule()` / `.c08-slide`
- **答复面（p_answer_time）**：标题「局主改时间」。局部尺 40px（5 分钟一刻，`ppm = gap / |Δ分钟|`，gap = clamp(|Δ|×1.8, 108, 200)px；提前改期时 gap ≥ 新票高 + 24）。尺沿两个 V 刻痕：「原定」空心、「改为」红色；整点标签避开刻痕 16px。区内：上 = **持有的旧票块** `.c08-sblk`（60px，票纸 + 135° 斜纹 + 1px 虚线，已撕则右沿撕口，「旧票 V1 · 已撕 · 答复前暂停使用」，不写时间）；中 = 红色虚线箭头 + 「晚 1 小时」胶囊；下 = **新票 V2**（254×180，品牌「JU · 票根 V2」、「时间已改」章、大号新时间、`原定 ~~周五 12.18 · 20:30~~`、地点 · 集合 · 局主，副券「撕下，确认新时间」）。新票**首次打开时从改为刻痕处的出纸口打印**（见 ② 打印段），之后（同版本）直接呈现。G10：旧时间在答复面只出现在新票的「原定」一处；hero 状态行只留「改期」胶囊。
- **接受（按钮或把新票副券拖过 55%）**：写入 320ms（拖动时副券保持在松手姿态，提示「保存中…」）→ 旧票块提升到最上层，`top` 旧位 → 新位 720ms `cubic-bezier(.45,.05,.25,1)`，运动中投影加深；箭头淡出；旧位 400ms 淡入虚线淡影「原定 · 旧票不再使用」→ 760ms 块落在新票上沿：先 110ms 文字淡出，再 240ms 纸面淡出并缩到 .97（溶进新票）→ 1040ms 新票副券撕下并落进存根槽（见 ②）→ 落定 340ms 后联系层出现 → 1200ms 后 toast「已接受改期 · 按新票根的时间见」。说明行换成同高的「已接受新时间 · 旧票 V1 不再使用」，避免版面跳动。
- **拒绝（新时间去不了 → 确认退出）**：写入 → 抽屉关闭期间面板结构不变（局部尺、旧票块、新票、存根槽、提示、成员都在）→ **新票原位燃烧**（见 ③）→ 焦痕滑进局部尺下方长出的历史尺 → 旧票块淡出为「原定 · 位置已释放」淡影 → 结果构图「未接受新时间」。
- **中断 / 重播**：`beforeReplay('slide')` 把块放回旧位、副券复位；`.rm` 下块直接到位、票直接印好、联系层直接出现。
- **观察值**：`evidence/C08/resched-accept/`（0.5×，180ms 间隔）：f04–f09 块沿尺下行，f10–f11 溶进新票，f13–f18 副券撕下落槽，f20+ 存根槽 V1 · V2、联系层；`resched-drag-accept/`：拖新副券接受；`decline-burn/`：f05 抽屉关闭时结构不变，f07–f13 新票燃烧，f15–f21 焦痕入槽、淡影「位置已释放」，f26 结果。

### ② 打卡撕票（F09）与出票打印（F10）—— `ticketVals() / tearDown/Move/Up() / dropStub() / startPrint()` / `.c08-tkw`
- **打印**：需要打印时**第一帧就是 `pwait`**：票纸整张藏在出纸口里（`translateY(-101%)`，`.c08-tkw{overflow:hidden}`），票的位置只剩一道出纸口——hero 块下沿 12px 处一条 10px 的墨色出纸缝（内 2px 缝口 + 顶部高光，右上「JU · 出票口」小字）。560ms 后 `printing`：注册属性 `--c08-feed` 2200ms 线性关键帧 `0 → 31%（18%）停（30%）→ 65%（50%）停（62%）→ 100%（84%）`，纸 `translateY(calc(var(--c08-feed) - 100%))` 从缝里分三段送出；印头就是缝口，墨迹用同一个变量做遮罩 `linear-gradient(to top, #000 feed−9%, transparent feed−3%)`，所以刚出缝的 6% 是空白纸、字随纸出缝显影；打印中副券与弱动作都不出现、提示「出票中 · 打印完成前不能撕」。结束 → `issued`：纸 340ms 落定（−3px → +1.5px → 0），出纸缝 380ms 淡出压扁；改期新票的「时间已改」章 520ms 盖下（`scale 1.9 rotate −16° → 1 / −6°`）。同一票版本只打印一次（`printedV`），离开不清除。确认成局后同样先渲染为 `pwait`，抽屉关闭 380ms 后开印，不会先闪现完整票面。
- **撕票**：副券 `onPointerDown`（`setPointerCapture`），`p = clamp((dx + dy·.35)/110)`；拖动中撕口只在 `y ≤ p·h` 段呈纤维轮廓（两侧纤维带随之出现），未撕段仍是直孔列；**整块副券纸**（纸面、孔列半孔、纤维、「撕下，联系局主」字样与拖把手）以仍连着的左下角（`transform-origin: 撕口 x, 100%`）为轴 `translate(3p, −p) rotate(10p°)` 外翻——上端先离开，下端仍贴着孔列。松手 p < 0.55 → 240ms `cubic-bezier(.2,.9,.3,1.25)` 回弹，撕口轮廓同时插值回直线（`clip-path` 同点数过渡）。
- **落点**：p ≥ 0.55 → 副券停在松手姿态等待写入（260ms，「保存中… 写入后副券落下」；失败 → 回弹 + 「未能保存，请重新撕下副券」+ 重试）→ 撕口 170ms 补全 → 副券 900ms 关键帧：24% 继续外翻 `translate(10,−8) rotate(17°)`，之后加速下落并缩小，86% 稍越过槽底，100% 恰好落在存根槽里预留的槽位上（落点由测量得到：`translate(槽左 − 撕口x, 槽底 − h) rotate(−6°) scale(28/h)`）。存根槽 `.c08-stubtray` 就在票下方 10px，槽位在右侧、正对副券，所以副券几乎垂直落下、不经过票面文字；槽里的小存根是**同一套 DOM**（纸面、孔列、纤维、字样、`clip-path`）按同一变换缩放，落地与替换无缝。之后打卡孔 360ms 弹出、纸屑 700ms 落下，提示 / 弱动作在下落期间保持原位（不跳版），340ms 后联系层出现并滚到 toast 带之上。
- **观察值**：`evidence/C08/tear/`：f01–f04 半拖、f05–f07 回弹、f08–f13 撕口推进与副券外翻、f14–f16 保存中（副券停在松手姿态）、f17–f22 补全—外翻—下落—入槽、f23+ 打卡孔与联系层；`print/`：f02 只有出纸口、f03–f11 三段送纸、f12 落定；`confirm-flow/`：确认 → 空出纸口 → 打印；`fail-retry/` 后半：撕票写入失败回弹与重试。

### ③ 尺上作废（F08 / M9 归档）—— `burnTicket()` / `cancelEvent()` / `retractBlock()`
- **触发**：参加者「去不了了 → 确认退出」、「新时间去不了 → 确认退出」、局主取消、`cancelled` 票根首次打开（760ms 后自动烧一次，之后静态）。写入先于动效；写入后到起火前，票件 / 局卡条一直渲染（局主取消时局卡条进入 `armed`，抽屉关闭期间不消失）。
- **运动对象**：同一张票（302×156 / 新票 254×180）或局卡条（302×98）。
- **燃烧前沿**（2600ms，注册属性 `--c08-bp` 0→1，`cubic-bezier(.35,.1,.6,1)`）：一条不规则焦线（27 点，中间高两侧低的高斯拱形 A = 0.42h + ±5px 抖动，`#fx-rough` 打毛）**从票的下沿中点起火，沿尺的方向向上推进**，线下方被 SVG 遮罩吃掉；同一条线画三次并同步平移：34px 模糊热晕（26%）、13px 焦炭带、3.5px 余烬线（`#fx-ember-lin` + 3px 橙辉光，85% 后随 `--c08-bp` 淡出）。12 粒纸灰在前沿经过处依次落下 1400ms。不再用正圆洞。
- **残留与归档（三步交叠）**：78% 时票上沿下方的**焦痕**（16px 焦炭条，粗糙上下沿）在纸下 480ms 显出；90% 时票的占位从 156px 收到 16px（600ms），同时下方**历史尺**长出（560ms，`max-height` + 边距）；100% 纸完全消失；+560ms 焦痕按测量得到的矩形 780ms 平移缩放进历史尺的槽（`translate + scale`，`transform-origin:0 0`）；+800ms 槽变实心焦痕；+320ms 结果构图。全程没有空白票框：纸烧尽前占位已开始收拢。
- **空刻痕（撤回 / 放弃预留 / 退出候补，没有票可烧）**：写入 → hero 块原位**收回成空刻痕**：内容 150ms 淡出，`max-height` 520ms 收到 46px，边框变 1px 虚线、底变透明，440ms 后显出刻痕形态（结局字形 + 局名 + 状态词）→ 720ms 历史尺长出 → 1320ms 一枚同形的刻痕从 hero 飞进历史尺的槽（680ms，测量得到的平移缩放）→ 槽显出该结局的字形 → 结果构图（标题 + 事实副文 + 「这一格在历史尺上是一道空刻痕：没有出票，也没有烧掉什么。」+ 回到列表 + 惰性的「重新申请」）。
- **收起再落定（第 3 轮）**：槽变实心的同一帧，结果构图不再有的部分——已收拢的票占位、存根槽、已关闭的联系层、提示、成员表（改期答复面则是整段局部尺）——各自包在 `.c08-fw` 里，用 `grid-template-rows: 1fr → 0fr` + 透明度 280ms 原位收起；320ms 后结果块（标题 / 事实副文 / 刻痕说明 / 回到列表）以 `c08-settle` 淡入，落在历史尺下方。空刻痕流程同样在刻痕入槽那一帧收起成员表。
- **结果一致**：参加者返回落在历史 › 未成行，该行就是同形的焦痕 / 空刻痕，左侧 3px 红色落点条 1.6s（焦痕行裁切了投影，所以落点画在尺与块之间）；局主取消后 hero 虚线、进度隐藏、局卡条由历史尺里的焦痕代替、成员「取消前已确认 / 已预留」且不显示倒计时、安排区只剩「再开一局」（惰性）。
- **中断 / 重播 / 关键帧**：`.scrub` 下燃烧不再暂停动画，而是 `--c08-bp: var(--frame)` 直接驱动（遮罩与焦线读同一个变量，往回拖也同步）；纸灰 `animation-delay = (d0 − frame·2600ms)·k`。**释放滑杆后从拖到的位置续烧**（第 3 轮）：燃烧的全部定时器由 `burnClock()` 收在一起，释放时 `resumeBurnAt(frame)` 用缓动曲线的反函数 `bezInv(.35,.1,.6,1)` 把前沿位置换算成时间比例 τ，按 `(τ − τ_定时器) · D` 平移所有未触发的定时器，并把 `--c08-from = τ` 写到燃烧容器上（`animation-delay: −τ·D·k`，纸灰同样减去 τ·D），所以纸不会长回来、收尾也不会提前切到结果（probe：滑杆 70% → 释放 40ms 后 bp 0.75 → 0.84 → … → burnt）。`.rm` 下直接呈现结果。重播 `beforeReplay('burn' | 'retract')` 复原票件 / 局卡条。
- **观察值**：`evidence/C08/exit-burn/`：f06 抽屉关闭时结构不变（票、存根槽、已关闭的联系层、成员），f08–f14 焦线上行，f15–f17 焦痕显出、占位收拢、历史尺长出，f18–f20 焦痕入槽，f25 结果；`cancel/`：局卡条全程在场并原位燃烧；`withdraw-retract/`：块收回成空刻痕 → 刻痕入槽 → 结果；`history/`：`cancelled` 首次打开；`scrub-burn/`：关键帧前后拖动；`history-return/`：返回后的落点。
