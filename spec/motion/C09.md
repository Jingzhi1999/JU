## 2. 核心动效 ①：撕贴纸 → 露出下一层（局卡 → 详情，M4）

- **触发**：点击任一 `.c09-row`（也用于局主行 → 管理、草稿行 → 摘要）。`tryOpen()` → `openOver()`；关闭 `closeOver()`。
- **运动对象**：① 贴纸复制层 `.c09-peel`（z 26，在详情层之上；用同一份行模型、同一套行页标记渲染，与被点的页像素一致）；② 下一层 `.c09-over`（详情 / 管理 / 草稿摘要）；③ 背景 feed；④ 源行（`src` = visibility:hidden，由复制层顶替，不再在下一层底下白转）。
- **起点 / 终点**：源行矩形取自布局（`rowRect`：offsetTop − feed.scrollTop，不受 feed 退后缩放影响），开与关一致。覆盖层 `clip-path: inset(top right bottom left round 3px)` = 行的上下左右四边（下边 = 行的底边，行伸出屏幕时为屏幕底）→ `inset(0)`；内层 `translateY(from.y − 100)` → 0。贴纸复制层：`perspective(1100px)`，`transform-origin: 50% 0`（铰链 = 裁切上沿），`translateY(−from.y) rotateX(122°) rotateZ(−2.5°)`——页的下边朝人翻起、越过 90° 后露出白色光面背胶（`.c09-peel-back`，rotateX 180° + backface hidden），铰链随裁切上沿一起升到屏顶；正面翻起时叠一层自上而下 0 → .28 的阴影（背光面变暗）。feed `translateY(−10px) scale(.975)` + `contrast(.92) brightness(.82) grayscale(.25)`。
- **分段（打开）**：`start`（复制层平贴在原位、覆盖层裁切 = 行矩形，读一次布局）→ 24ms `in`：裁切与内层 430ms `cubic-bezier(.2,.8,.2,1)`；复制层翻起 430ms 同曲线，透明度 220ms 起 200ms 淡出；feed 420ms。
- **层的前沿（第 2 轮）**：`.c09-oedge`（z 24，在 feed 之上、覆盖层之下）= 1px 深线 + 18px 投影，`left / right / translateY` 与裁切的左 / 右 / 下沿用同一条 430ms 曲线走，所以裁切下沿扫过下面的行时，读起来是「一张纸盖过去」，不是把字切成两半（`card-detail-back/` f02–f04）。`in` 时停在屏幕下沿外；减少动态下不渲染。
- **分段（返回 = 贴回去）**：`locate()` 换到该局现在所在的分区并 `scrollIntoView` → 30ms 后重新量行矩形 → `out`：详情内容与黑色吸顶页头 130ms 淡出（不再有页头在列表中间漂、也没有半透明重影）；裁切 430ms 收回行矩形；复制层**不透明**（60ms 线性显出，翻过 90° 之前已经是实的，背面先出现）从翻起姿态 30ms 起 400ms `cubic-bezier(.3,.6,.25,1)` 落回平贴——落下的是列表行本身的版式；440ms 卸载覆盖层与复制层，源行在同一帧显示（与复制层重合，无硬换）→ 粉色描边 1.1s 淡出（`c09-land`）。
- **中断 / 连点**：覆盖层 `start/out` 期间 `pointer-events:none`；层打开中再点行 = 忽略；层关闭中点行 = 排队（`_queuedOpen`，最后一次有效），关闭落定 30ms 后执行。`beforeReplay('open-entry')` 回到列表后重播；跳转索引 `instant=true` 直接 `in`（复制层隐身）；减少动态 `.rm` 下不渲染复制层。
- **观察**：`evidence/C09/card-detail-back/sheet.png`（0.5×）f02–f04 页从下边翻起、背胶露出、详情在下面展开（下沿带投影线），f05–f09 详情，f10 详情内容与页头淡出，f11–f12 不透明的页落回原位，f13 起落点描边；`manage-open/` f02–f04 局主 lead 页同一机制，f08 折叠头，f10–f13 贴回。

## 3. 核心动效 ②：影印出票 + 剪票（M8 打印 / 撕票）

### 2a 影印出票（`printTicket`，`.c09-copier.printing`，`--c09-pd: 2600ms`）
- **触发**：`tear` 首次打开（`printed[id:version]` 未记录）在 520ms 后；`reschedule` 新票同样；确认入局即成局时 260ms 后。跳转索引 = 直接 `ready`。
- **对象**：出纸口 `.c09-slot`（指示灯 `em.lit` 变绿）、扫描灯 `.c09-scan i`、票纸 `.c09-tkw`、碳粉覆盖 `.c09-blank`。
- **关键帧（占 2600ms 的百分比）**：扫描灯 0–20% 自左向右扫过出纸口（`translateX(−110% → 280%)`，3% 亮、23% 熄）；之后出纸口里的定影灯 `.c09-slot::after`（2px 绿线）在走纸段亮 .7、停顿段暗 .15；票纸 `translateY`：0–22% 停在 −104%（扫描中）→ 40% −58%（第一段露出）→ 48% −56%（停顿）→ 72% −14% → 80% −12%（停顿）→ 94% +1.2% → 100% 0（回弹落定）。
- **纸看得见（第 2 轮修正）**：`.c09-blank` 只盖墨迹区（`left/right/bottom 2px; top 22px`，即票框以内、黑带以下），底色 = 票面白 + 网点，所以走纸时一直看得到纸边、2px 黑框和黑带。它**自下而上**收（`clip-path: inset(0 0 X 0)`，px）：0–26% `0` → 40% `56px` → 48% `82px` → 72% `144px` → 80% `170px` → 94–100% `176px`（= 全部显出）。换算到票面坐标：空白区的下沿 = 出纸口线 + lag，走纸段 lag ≈ 26px（刚出口的一截还是白纸，墨迹在后面显影），停顿段 lag 收到 4px（墨迹追上出口）——「露出—停顿（显影）—再露出」在纸上看得见。
- **结束**：`after(2620)` → `phase:'ready'`，剪刀把手此时才出现（`hasScis` 要求 `phase === 'ready'`，打印中不渲染），贴纸钉在票上；打印中提示「影印中 · 出纸完成前不能剪」。
- **scrub**：`.scrub .printing .c09-tkw / .c09-blank / .c09-scan i / .c09-slot::after` 暂停并 `animation-delay: −frame × 2600ms × k`。
- **观察**：`evidence/C09/print/sheet.png`（0.5×）f03–f09 扫描（纸还在口里），f10–f15 票的下沿带框露出、贴纸与副券字先出来、出口下方一截白纸，f16–f24 第二段走纸、黑带最后出口，f25 落定 + 剪刀出现；`confirm-flow/` f02 起确认层处理中 → 收起 → 确认入局即成局，同一出纸过程。

### 2b 剪票（`cutDown / cutMove / cutUp / finishCut / stubFall`）
- **触发**：按住 `.c09-scis`（剪刀把手，`data-act="tear"`；新票 `"accept"`）沿剪刀线向下拖；进度 `p = (clientY − y0) / 185`。轻点 / 键盘 = 剪刀自走（`cutTap`：10 步 × 48ms）。
- **对象**：同一票面渲染两份：主券 `.c09-side.keep`（`tearClipV side:'stub'` = 剪刀线 x=236 左侧）与副券 `.c09-side.stub`（右侧）；断口线 `.c09-cut`（`side:'edge', edge:1`）；剪刀把手 `top = p × 184 + 22`。
- **过程**：锯齿 `c09Zig(46, 3)` 自上而下随 p 显现（已剪部分有锯齿 + 深灰断口，未剪部分仍是虚线）；副券 `translate(5px × p, 0) rotate(−7° × p)`，绕右下角张开。
- **阈值**：释放时 `p ≥ 0.55` → `finishCut`；`p < 0.55` → 回弹到 0，提示「没剪够 · 剪过一半才会断开」。
- **写入期间布局不动**：`finishCut` 先量好落点（口袋下一个空槽 `c09Slot(i)`），把页面此刻的说明行 / 页贴纸 / kicker 冻结在 `view.hold`，提示行换成「剪开了 · 副券落进下面的口袋」（提示行始终占位），再 `JU.engine.tearTicket / acceptReschedule`（140ms）；票上方是固定一行的说明（`.c09-need2.tk`，单行省略），所以写入时票不会上跳。口袋在屏幕外时平滑滚到可见（落点是页面坐标，滚动不改变目标）。失败 → p 回 0，提示行原位显示「本机保存失败，请重试 · 副券还在票上 [重试]」，重试 = 剪刀自走一遍。
- **落点 `stubFall`（1000ms，`.c09-copier.falling` z 5、托盘出纸后 `overflow:visible`）**：同一个副券元素关键帧（原点 = 票右下角）`0% translate(5px,0) rotate(−7°)` → `28% translate(9px,38px) rotate(9°) scale(.94)`（ease-in，脱离铰链下坠）→ `85% translate(dx,drop) rotate(槽位角) scale(.3)`（减速落进槽位）→ `100%` 再下沉 12px 并淡出（滑到口袋前片后面）。850ms：口袋里同一张副券的缩小复本（同样的 316×200 票面 + 副券裁切，`scale(.3)`，口袋 `overflow:hidden`，前片盖住下半）240ms 自上滑入，计数「空 → 副券 × 1」（改期「× 1 → × 2」）放大一下（`c09-bump` 420ms）。1000ms：副券元素卸载、主券变为已剪态，冻结的说明行 / 贴纸换成新状态（「副券已剪下 · 8 小时内加局主微信」、贴纸「已剪 · 待联系」）。1250ms：联系便签上移淡入（360ms）；新票剪开时旧票贴纸改「作废」+ toast。
- **口袋规则**：口袋里只放这张票视图真正收到的副券（进来之前就已剪开的票，开页时就在口袋里；当场剪下的，落到才进口袋）——不再出现「副券还没落、口袋已经有一张」。
- **scrub**：`.scrub .c09-side.stub.off` 暂停于 `−frame × 1000ms`。减少动态：`.rm` 下 1ms 直接落定。
- **观察**：`evidence/C09/tear/sheet.png` f02–f06 拖 70px、f07–f08 回弹 + 没剪够，f09–f16 拖剪过阈值，f16–f20 副券下坠、缩进口袋，f21 起「副券 × 1」+ 已剪主券（锯齿断口、无虚线孔、无竖排副券），f24 联系便签；`resched-reply/` f02–f07 新票副券落进口袋（× 2），旧票改「作废」；`fail-retry/` f10–f11 剪票失败原位提示与重试。

## 4. 核心动效 ③：影印烧黑（M8 作废 / 燃烧，取消 · 退出 · 拒绝改期 · 取消的局首次打开）

- **触发**：局主 `确认取消`（`submitCancel`）；参加者 `确认退出` / `确认退出（改期）`（`leaveFlow` → `burnTicket`）；`cancelled` 历史首次打开（700ms 后，`burntOnce[id]` 记一次，之后静态）。
- **写入在确认层里进行（第 2 轮）**：确认层的主按钮显示处理中（`busy` 黄条），「再想想」暂时失效、点遮罩不关；写入成功 → 确认层收起（320ms）→ 300ms 后才点火（同一时刻一个主要动作）；写入失败 → 确认层**不关**，粉色 `.c09-ialert` 出现在按钮上方（退出 `保存失败，尚未退出 · 票根仍然有效，请重试`；拒绝改期 `保存失败，尚未退出。新时间仍待你答复，请重试。`；撤回 `本机保存失败，请重试 · 申请还在`；取消这局同理），重试 = 再走一次同一流程（`fail-leave/`）。
- **燃烧前快照**：`leaveFlow` 在写入前把要烧的那张票（退出 = main，拒绝 = fresh）此刻的贴纸、时间、编号冻结到 `ticket.frozen`（从写入开始一直生效到烧完；失败时清掉），把页面说明行 / 页贴纸 / kicker 冻结到 `view.hold`——退出「待赴约」的票时，烧的就是那张贴着「待赴约」的票。烧之前把票平滑滚到可见（`revealTicket`）。
- **对象**：票面 `.c09-tk.fx-burn` 自己被 SVG mask 吃掉——没有底层「残余板」；兄弟层 `.c09-flakes`（12 片碳粉）。作废票面 `.c09-face.void` 不透明（灰度 + 对比，不再 0.75 透明），烧到之前看不到任何东西。管理页头页 `.c09-mg-head.fx-burn` 同前（下层是焦边空白页）。
- **起火点 / 收口**：完整票 `(304,188)`、`--fx-reach 250px`；已剪票 `(224,188)`（主券右下角）、`200px`。半径到收口就停——左上角留下一块原票残片（黑带「JU · 自制票」+ 局名、时间开头），不是整张烧没再换图。SVG 自带滤镜 `#c09-rough`（userSpaceOnUse，与洞同一张噪声），已剪票的 SVG 再按主券轮廓裁切，火线不会画到副券的空位上。
