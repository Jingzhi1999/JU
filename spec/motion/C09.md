## 2. 核心动效 ①：撕贴纸 → 露出下一层（局卡 → 详情，M4）

- **触发**：点击任一 `.c09-row`（也用于局主行 → 管理、草稿行 → 摘要）。`openOver()`。
- **运动对象**：① 被点的页面（`.c09-row.src`）；② 覆盖层 `.c09-over`（下一层）；③ 背景 feed。
- **起点 / 终点**：覆盖层 `clip-path: inset(top right bottom left round 3px)` = 该行矩形（`JU.fx.rectIn`）→ `inset(0)`；内层 `.c09-inner` `translateY(from.y − 100px)` → `0`（详情页的页头对齐被点行的顶边）；源行 `perspective(900px) rotateX(−58deg) translateY(−6px)` + opacity 0（贴纸从底边翘起）；feed `translateY(−10px) scale(.975)` + `contrast(.92) brightness(.82) grayscale(.25)`（下层纸退后变灰，影印复印件感）。
- **分段**：`start`（渲染一帧，`getBoundingClientRect` 强制刷新）→ 24ms 后 `in`：clip 与 translate 同时 430ms `cubic-bezier(.2,.8,.2,1)`；源行 380ms 同曲线；feed 420ms。返回：`closeOver()` 先 `locate()` 换分区并 `scrollIntoView` 源行 → 30ms 后 `out`（反向 430ms）→ 440ms 卸载 → 源行 `landed` 粉色描边 1.1s 淡出（`c09-land`）。
- **变换中心**：源行 `transform-origin: 50% 100%`；覆盖层无缩放（只裁切 + 位移，文字不变形）。
- **遮罩 / 阴影**：裁切即遮罩；页面阴影随 clip 同步。
- **中断 / 重播**：覆盖层 `start/out` 期间 `pointer-events:none`；`beforeReplay('open-entry')` 回到列表后重播；跳转索引时 `instant=true` 直接 `in`。
- **观察**：`evidence/C09/card-detail-back/sheet.png` f02–f06 展开、f09–f13 收回、f13–f15 落点描边；`manage-open/` f02–f06 局主行同一机制。

## 3. 核心动效 ②：影印出票 + 剪票（M8 打印 / 撕票）

### 2a 影印出票（`printTicket`，`.c09-copier.printing`，`--c09-pd: 2600ms`）
- **触发**：`tear` 首次打开（`printed[id:version]` 未记录）在 520ms 后；`reschedule` 新票同样；确认入局即成局时 260ms 后。跳转索引 = 直接 `ready`。
- **对象**：出纸口 `.c09-slot`（指示灯 `em.lit` 变绿）、扫描灯 `.c09-scan i`、票纸 `.c09-tkw`、碳粉覆盖 `.c09-blank`。
- **关键帧（占 2600ms 的百分比）**：扫描灯 0–20% 自左向右扫过出纸口（`translateX(−110% → 280%)`，3% 亮、23% 熄）；票纸 `translateY`：0–22% 停在 −104%（扫描中）→ 40% −58%（第一段露出）→ 48% −56%（停顿）→ 72% −14% → 80% −12%（停顿）→ 94% +1.2% → 100% 0（回弹落定）；碳粉 `.c09-blank clip-path: inset(top)` 0 → 38% → 42% → 82% → 86% → 100%，始终落后纸边 2–6%（墨迹跟在纸后显出）。
- **结束**：`after(2620)` → `phase:'ready'`，剪刀把手出现在剪刀线顶端，贴纸钉在票上；打印中剪刀隐藏、提示「影印中 · 出纸完成前不能剪」。
- **scrub**：`.scrub .printing .c09-tkw / .c09-blank / .c09-scan i` 暂停并 `animation-delay: −frame × 2600ms × k`。
- **观察**：`evidence/C09/print/sheet.png` f01–f03 扫描、f04–f09 三段走纸 + 墨迹、f12–f14 落定。

### 2b 剪票（`cutDown / cutMove / cutUp / finishCut / stubFall`）
- **触发**：按住 `.c09-scis`（剪刀把手，`data-act="tear"`；新票 `"accept"`）沿剪刀线向下拖；进度 `p = (clientY − y0) / 185`。轻点 / 键盘 = 剪刀自走（`cutTap`：10 步 × 48ms），以保证每个按钮都有可见结果。
- **对象**：同一票面渲染两份：主券 `.c09-side.keep`（`tearClipV side:'stub'` = 剪刀线左侧）与副券 `.c09-side.stub`（右侧）；断口线 `.c09-cut`（`side:'edge', edge:1`）；剪刀把手 `top = p × 184 + 22`。
- **过程**：锯齿 `c09Zig(46, 3)` 自上而下随 p 显现（已剪部分有锯齿 + 深灰断口，未剪部分仍是虚线）；副券绕右下角 `rotate(−7° × p) translate(5px × p)` 张开。
- **阈值**：释放时 `p ≥ 0.55` → `finishCut`：p 置 1、`snap` 回弹过渡 320ms，再 `JU.engine.tearTicket / acceptReschedule`（140ms 处理）；失败 → p 回 0 + 提示「未能保存，请重新剪下副券」；`p < 0.55` → 回弹到 0，提示「没剪够 · 剪过一半才会断开」。
- **落点**：写入成功 → `stubFall`：副券 `.off` 1000ms `cubic-bezier(.35,0,.6,.35)` 关键帧 `translate(0,0) → (14px,70px) rotate(16°) → (dx, drop) rotate(−8°)`，`drop / dx` 由 `.c09-pocket` 与票的实时矩形算出 → 1000ms 后副券卸载、口袋 `.c09-pstub.new` 从上滑入（360ms）；1250ms 后联系层便签 `.c09-contact` 上移淡入（360ms），贴纸换成「已剪 · 待联系」；新票剪开时旧票贴纸改「作废」+ toast。
- **scrub**：`.scrub .c09-side.stub.off` 暂停于 `−frame × 1000ms`。减少动态：`.rm` 下 1ms 直接分离。
- **观察**：`evidence/C09/tear/sheet.png` f02–f07 拖剪、f08–f10 落入口袋、f11–f15 联系层；`resched-reply/` f10–f13 新票剪开。

## 4. 核心动效 ③：影印烧黑（M8 作废 / 燃烧，取消 · 退出 · 拒绝改期 · 取消的局首次打开）

- **触发**：局主 `确认取消`（`submitCancel`，写入成功后 700ms）；参加者 `确认退出` / `确认退出（改期）`（`leaveFlow` → `burnTicket`）；`cancelled` 历史首次打开（700ms 后，`burntOnce[id]` 记一次，之后静态）。
- **对象**：票面 `.c09-tk.fx-burn` 或管理页头页 `.c09-mg-head.fx-burn`，同一元素被 SVG mask 吃掉；兄弟层 `.c09-flakes`（12–14 片碳粉 `c09Flakes`）；残余层 `.c09-ashed` / 焦边空白页 `.c09-char`（z-index 0，**烧之前就在下面**，随孔洞扩大被露出）。
- **起火点**：票右下角 `(326,186)`；页头页右下角 `(350,290)`；`--fx-reach 430 / 520px`（盖满对角线）。
- **过程（`--fx-dur: 3000ms`）**：`fx-hole` 关键帧 `r: 0 → 5% → 100%`，`cubic-bezier(.3,.05,.55,1)`，边缘 `filter:url(#fx-rough-strong)` 毛化；焦边 `.c09-char-ring` 同一关键帧、26px 描边、渐变 `#ff7a1a → #3a1d0c → #000`（薄薄一圈橙在最外，里面是发黑卷边）；碳粉片 `c09-flake` 1500ms ease-in 按 `--d` 延迟逐片落下（`opacity 0 → .95 → 0`，位移 `JU.fx.scatter`）。
- **结束**：票：`after(3150)` → `burnt`（`.fx-burn.burnt` 隐藏）+ 残余层已显示：焦边空白票（锯齿焦缘 + 右下黑烟渐变）+ 黑点「局章」`.c09-char-dot` + 灰贴纸「主动退出 · 已作废 / 拒绝改期 · 已作废 / 局主取消 · 已作废」，然后结果块（贴纸 + 标题 + 副文）。管理页：`after(2940)` → `charred:true`，页头换成焦边空白页（「已取消」+ 黑点 + 原定时间 + 不能撤销句），成员区 void（取消前已确认 / 取消前已预留），安排区只剩惰性「再开一局」；返回列表 → 行进入「历史 · 已取消」（灰页 + 黑点）。
- **scrub / 减少动态**：`.scrub .fx-burn.burning .fx-hole / .c09-char-ring` 暂停并按 `--frame` 定位；`.rm` 1ms 直接到残余态。
- **中断 / 重播**：`beforeReplay('burn')` 清 `burning/burnt/flakes` 与 `result`（管理页清 `burn/charred`）。
- **观察**：`evidence/C09/exit-burn/sheet.png` f03–f09；`decline-burn/` f04–f11；`cancel/` f02–f09（页头被吃掉、焦边页露出）、f13 历史落点；`history/` f01–f08 取消局首次打开烧一次。

## 5. 其余动效族（简）

M1 两本 zine 切换 `book-swap`：feed `translateX(−18%) rotateY(16°)` 260ms 出 → 换本 → `c09-bookin` 420ms 入；分区与滚动按本记忆。M2 纸胶带标签：`restack` 页序列 340ms 错位 36ms。M3 滚动 44px 后页头 `compact`（标题 36→22、本高 40→32，260ms）。M5 审核：按钮处理条 → 原位结果行 420ms `c09-settle` + 贴纸 `c09-slap` 260ms（scale 1.5→1）+ 席位 `c09-seat` 500ms（scaleY .4→1.08→1）。M6 便签弹层 320ms 上滑 `cubic-bezier(.2,.9,.3,1)` + 遮罩 .5。M7 改时间：日期 `c09-reprint` 420ms（clip 自上而下 + 7px 落位）→ 改期答复页。M9 出席贴纸 `slap` 仅新鲜记录 2.4s；轨迹列表；历史不重放。M10 草稿 `leaving` max-height 260ms → 撤销条 10s → `entering` 300ms + landed。M11 空态 = 空白页贴纸 + 手绘弧线 + 惰性入口。
