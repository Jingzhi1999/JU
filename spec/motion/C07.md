## 2. 三个核心动作

### ① 格子重排（状态变化后格子改尺寸，所有格 FLIP 到新位置）
- **触发**：任何经 `JU.engine` 的写入改变了分组 / lead / 分区（确认入局成局、审核通过、撕票、散场、删除草稿）；在展开层内写入时盘面先冻结（`state.frozen` 指向写入前的数据），返回收回原格后再释放 → 重排在视线内发生。
- **运动对象**：全部 `.c07-tile`（绝对定位，由 `C07.pack()` 计算 left/top/width/height）与组头 `.c07-head`。DOM 顺序固定（按 `data.joined` / `data.hosted` / 草稿初始顺序），位置只由布局结果决定，所以同一张格在运动前后是同一节点。
- **起点 / 终点**：旧 left/top/width/height → 新值；离开本分区的格 `off`（透明度 0 + scale .92 + 240ms 后 visibility hidden）；进入的格反向。
- **分段**：位置与尺寸 520ms `cubic-bezier(.2,.8,.2,1)`；格内布局因尺寸级别变化（L↔W↔S）切换模板时内容 320ms 淡入；盘高 520ms 同曲线；落点格外圈 2px 分区色描边 1.9s（`landed`）。
- **变换中心**：各格左上角（left/top），不用 scale 拉伸文字。
- **遮罩 / 阴影**：无遮罩；lead 格底唇与投影随类名切换（300ms）。
- **中断 / 重播**：期间再点击直接进入新格；`.rm` 1ms 直达；`.swap`（分区 / 身份切换）关闭过渡，改为按 `--i` 错峰 45ms 的 `c07-tile-in`（位移 14px + 3px 模糊 + 透明，REF16 的错峰替换）；重播 `beforeReplay('reflow')` 把 `frozen` 复位为写入前数据再释放。
- 证据：`evidence/C07/confirm-formed-print/`（brunch 确认 → 成局出票 → 返回 → brunch 从 2×2 缩成 2×1、livehouse 升为 lead）、`draft-undo/`（删除让位 / 撤销回位）、`switch-scroll/`。

### ② 刮落撕票（通行证副券像素列被拖动刮下）
- **触发**：在 `.c07-stub`（右侧 3×14 像素列）按下（`setPointerCapture`）向下 / 向左拖，`p = clamp((dy·1.0 + max(0,−dx)·0.8)/150)`；键盘 / 评审用 `data-act="tear"`（改期新票 `data-act="accept"`）按钮走同一路径（自动 p=1，380ms 后提交）。打印中、旧票、已撕、作废时不可刮。
- **运动对象**：42 粒 `.c07-sc`（8px 像素，每粒带确定性抖动 `--jx/--jy/--jr` 与落下延迟 `--d = 行×26ms + 0–40ms`）。
- **过程**：行序 `row/14 < p` 的粒子加 `det`：`translate(dx·.55 + jx, dy·.55 + jy) rotate(jr)`，110ms 跟手；提示文「再刮一点」→ p ≥ .55「松手就撕下」；未过阈值释放 → 260ms `cubic-bezier(.2,.8,.2,1)` 回到格位。
- **落点**：过阈值释放 → 先写入（`engine.tearTicket` / `acceptReschedule`，220ms 处理）→ 成功后 `.falling`：每粒 `c07-sc-fall` 620ms（下落段 `cubic-bezier(.55,0,1,.6)` 重力加速 → 82% 触底 → 91% 回弹 2px → 落定），从跟手位置落进副券列底部的**存根槽堆**（6 × 7 个半尺寸像素，按落下先后自下而上排，`--hx/--hy` 由 `stubCells` 确定），同时缩到 .5、转正，按 `--d`（行 × 26ms + 0–40ms）错峰，总 ≤1.0s；1000ms 后副券位变成点线「存根槽」（`slot`），同一批 42 个节点静止在堆里（不换素材），标签换成「存根」；1280ms 后联系层子格（局主 · 微信 · 复制 · 已加微信）错峰进场。
- **改期接受**：刮下新版副券时先给旧票拍快照（`passes.main.snap` = 写入前的行），落下期间旧票子格保持自己的 V1 内容（灰化、删除线时间、「改期」标）；1000ms 新票落定后旧票子格 `leaving`：`grid-template-rows 1fr→0fr` + 内边距 / 外边距 / 透明度 380ms 收起后卸载；新票原位改标题为「通行证」，toast「已接受改期 · 按新票根的时间见」。屏幕上任何时刻只有一张新票。
- **失败**：写入失败 → 粒子 260ms 回位 + 票下方红条「未能保存，请重新刮下副券（本机保存失败，请重试）」+ 重试（重试 = 自动再刮一次）。
- **变换中心**：每粒自身中心；落下在票框之外可见（`.c07-void` 不裁切）。
- **遮罩 / 阴影**：无遮罩；副券区 4% 墨色渐变暗示可刮；已撕后只剩虚线槽。
- **中断 / 重播**：`.scrub` 暂停落下关键帧并按 `--frame` 定位（1000ms 轴）；`.rm` 直接呈现已撕；重播 `beforeReplay('tear')` 复原未撕、收起联系层后再刮。
- 证据：`evidence/C07/tear/`（真实拖拽：短拖回弹 → 长拖逐行脱离 → 阈值提示 → 落进存根槽堆 → 联系层）、`resched-accept/`（旧票保持 V1 → 收起）、`fail-retry/`、`replay/`。

### ③ 像素作废（取消 / 退出 / 拒绝改期：同一张通行证从起火角逐格脱落、碎片落地成堆、再聚成灰格里的残骸）
- **触发**：局主「取消这局」操作盘确认 → 460ms 处理 → `engine.cancel` 成功 → 操作盘收起 120ms 后局卡·通行证开始作废；参加者「去不了了」确认 → `engine.exitEvent`（`effect.burn`）→ 主票作废；「新时间去不了」→ `engine.declineReschedule` → 新票作废（旧票同样拍快照保持 V1，作废结束后收起）。作废期间 hero 保持写入前的状态（`view.hold`），落定时才翻为灰色终态。
- **为什么不用 SVG mask**：第 1 轮评审实测 Chrome 不会可靠地重绘「HTML `mask:url(#svg)` 里被 CSS 动画的 rect」（41/96 格后停住、最后一帧整块消失）。v2 不再依赖它：
  - **票面缺口** = 同一个 `.c07-pass` 的多层 CSS 遮罩：每个还站着的格子一层 `linear-gradient(#000,#000)`（按实测票面 W×H 切 12×8，`mask-position/size` 用 px），由 `state.voidT` 驱动；`voidRun()` 用 `after(60)` 每 60ms 推进一步（随倍速缩放、随暂停冻结），所以 off 数随时间单调增加到 96（实测 1×：96→92→87→75→64→48→31→20→11→1→0；0.5× 同序列放慢一倍；任意时刻「剩余层数 + 已出现碎片」= 96）。全部格子脱落后票面 `visibility:hidden`。
  - **碎片** = 兄弟层 `.c07-vf` 里 96 个与格子等大的像素（颜色按格位取：QR 区墨 / 白交错、副券列墨 / 白、其余白 + 12% 灰），每个延迟 `d` 与它的遮罩格完全相同（都量化到 60ms 步）。
- **过程**（总 3300ms，scrub 轴同长）：
  - 0–2040ms 脱落：`d = ((到右上角距离 / 最大距离)^1.05 × 1900 + 0–140)`，向上取整到 60ms。到时刻该格从票面消失，同一时刻碎片 `c07-vf-fall` 720ms：0–18% 上抬 7px（`cubic-bezier(.2,.7,.4,1)`）→ 18–80% 重力下落（`cubic-bezier(.55,0,1,.6)`）、旋转 ±120°、缩成 6px 像素、颜色 → 灰（墨 `#6E747A` / 白 `#E2E3DE` / 灰 `#9AA0A5`）→ 80–90% 触底回弹 2px 并转正 → 落定。
  - 落地成堆：碎片按落下先后落在票框底部 7px 宽的格位里（`hgt[bin]++`，比邻格高 2 层以上就滑向邻格 = 沙堆规则），在框底形成一道起伏的灰色像素瓦砾，票面剩余部分仍在原位继续被吃掉（缺口沿对角线向左下推进）。
  - 2760–3280ms 聚合：所有碎片 `c07-vf-gather` 520ms `cubic-bezier(.3,.7,.2,1)` 从瓦砾位飞到灰格左侧 10×10 残骸格里自己的槽位（列优先对应列优先，跳过右上角 4 个缺格），颜色换成槽位色（定位块深灰、其余浅 / 中灰）；同时 `.c07-void` 高度 `--vh`（票面实测高，约 196–198px）→ 102px（`c07-void-h`，83.6%–99.4% 段），灰格底板与文字 84%–97% 淡入。
  - 3300ms `dropped`：碎片层与票面卸载，灰格静态渲染同一组 10×10 像素（位置、颜色与碎片终点一致 → 无跳变）。
- **剩余形态**：灰格「已作废 · 局主取消 / 主动退出 / 拒绝改期」+ 后果句（「不计为未出席，也不影响成局信用。」/「票根与联系入口已关闭」/「席位已释放 · 旧票不恢复」）+ 票码；分区小注同步为「已作废 · 原因」；参加者侧随即出现结果子格（已退出这局 / 未接受新时间 / 回到格盘）。
- **结果一致**：局主 hero「已取消」、进度格隐藏、成员行「取消前已确认 · 票根作废 / 取消前已预留 · 预留已结束」（不再显示倒计时与进度条）、安排区只剩「再开一局」（本范围内不可点）；返回列表时落在 历史 › 已取消 的灰色 1×1 格；参加者历史的 `cancelled / exited / declined` 首次打开直接显示同一个灰格（不重放）。
- **变换中心**：碎片各自中心（`transform-origin:50% 50%`，translate 以中心对中心计算）；遮罩坐标 = 票面 border-box 像素坐标。
- **遮罩 / 阴影**：遮罩只作用在 `.c07-pass`（遮罩开始时票的外投影随之消失）；碎片在兄弟层，不被裁切；灰格无投影（失效物件不离开盘面）。
- **中断 / 重播**：`.scrub` 暂停 `.c07-void` 高度、灰格淡入、两组碎片关键帧（`animation-delay: d·k − frame·3300ms·k` 与 `2760ms·k − frame·3300ms·k`），遮罩改用 `frame × 3300ms` 作时钟 → 拖动关键帧时缺口、碎片、瓦砾、聚合逐帧可见；`.rm` 直达灰格；重播 `beforeReplay('void')` 让旧时钟失效（`_voidRun++`）、复原票面后再作废。
- 证据：`evidence/C07/cancel/`（1×）、`cancel-half/`（0.5×）、`void-exit/`、`resched-decline/`、`scrub/`（15 / 35 / 55 / 75 / 87 / 93 / 100% → 释放续播）、`half-rm/`、`replay/`。

## 3. 其余动效族（简述）
- **M1 身份切换**：两块盘在 200% 宽轨道上 440ms `cubic-bezier(.25,.9,.3,1)` 横移，深色指示块 420ms 同曲线滑到另一格，分区行当帧换内容；进入的盘按 `--i` 错峰 45ms 进场。
- **M2 分区切换**：`swap` 关过渡，离开的格 240ms 淡出 + scale .92，进入的格 420ms 错峰（位移 + 模糊 + 透明）。
- **M3 滚动与顶部层级**：盘面 `onScroll` → `--sc = clamp(scrollTop/56)`，标题行高度 40→8px、透明度 1→0、上移 8px 连续插值；身份双格与分区行常驻；分区行右侧写真实排序口径（先回应 · 再按日期 / 先处理 · 再按日期 / 新的在前）。展开层（参加者详情 / 管理这局）为独立滚动层：hero 离开时（`scrollTop` 70→160px）顶栏返回键与色轨之间淡入单行省略的局名（14.5px / 600，`--t` 0→1，同时上移 6px→0）。
- **M4 展开 / 收回**：点格 → `JU.fx.rectIn` 取矩形 → 展开层 `clip-path: inset(格矩形 round 18px)` + `translateY(格y − 92)` → 460ms `cubic-bezier(.2,.8,.2,1)` 到 `inset(0)`（hero 子格与原格同色同字号，是同一个物件放大）；底层盘面 scale .94 + 1.5px 模糊 + 压暗（开操作盘时 .9）；子格按 `--i` 错峰 55ms 进场（REF27 的正文从卡底长出 + REF08 的分批进场）。**返回**：落点由布局计算（`layoutsFor` 与盘面同一套 `C07.pack`），写入前（frozen）与写入后两个槽位都已知：① 换了分区 → 先切分区再定位新槽；② 同分区且两槽能同屏（跨度 ≤556px）→ 盘面滚到两槽都完整落在折叠头部（168px）+12 与底栏 −12 之间，层收回旧槽，释放冻结后重排在视线内发生；③ 两槽太远 → 先在层下重排（目标格 `pin` 不过渡），层直接收回新槽。层体先回到顶部（落进格里的是 hero），440ms 收回，最后 110ms 淡出到同一矩形里的真实格（不再出现空白格）；矩形用 offset 计算（不受底层 scale 影响）。落点描边 1.9s。实测：run3k 返回落在 604–748（头部 168 / 底栏 760），bar 全部审完后落在 招募中 592–748。
- **M5 审核 / 计数 / 席位**：按钮原位换成结果行（`c07-settle` 420ms 上浮淡入），席位像素格 `c07-seat-pop` 520ms（scaleY .4→1.12→1）只在新格；hero 状态、组头计数、列表大格数字同帧重算。
- **M6 操作盘**：贴底（`left/right/bottom 8px`，高度随内容，`max-height: 100% − 70px`）的格 380ms `cubic-bezier(.2,.9,.3,1)` 从 100%+20px 升起，遮罩 320ms 到 42% 墨；关闭 400ms 反向；改时间 / 取消 / 散场 / 局卡 / 阅读层 / 举报 / 各确认层同构（展开层基类 `.c07-over:not(.c07-sheet)`，操作盘不再被拉成整屏）。改时间的「原定 / 改为」上下两行对照，时间 `nowrap`。

- **M8 打印**：出票前（`phase:'idle'` → `.pre`）票面全遮、顶边就是一条 6px 像素「出票口」（3px 墨条 + 5/3px 齿）+ 橙色扫描线，不再出现空白白框；`.c07-pass.printing` 上 `--c07-ink` 关键帧 2000ms（第一帧即点亮首行 7% → 停 → 34% / 停 / →68% / 停 / →100%，每段 `steps(7–8)` 像素行跳进，出票口与扫描线 94% 后淡出），票面与副券用 `linear-gradient` 硬边 mask 逐行点亮，3px 橙色扫描线领先于墨线并在 94% 淡出；打印中副券禁用、不显示刮券按钮；本版打印过的票离开再进不重印（`state.printed`）；`.scrub` 按 `--frame` 定位。
- **M9 散场 / 出席**：记为散场后 hero 转深格、席位格换成出席格、出席子格错峰进场；三段按钮点选当帧写入，3×3 像素章 `c07-stamp-pop` 9 格 42ms 错峰（仅 2.5s 内新鲜记录），更正留轨迹行；历史列表的章静态。
- **M10 草稿删除 / 撤销**：行走 engine → 该格 `off`（240ms 淡出缩小），邻格 520ms 让位；撤销条 10s 橙色倒计时线；撤销 → 格在原槽位淡入、邻格回位、落点描边。
- **M11 空态 / 结果态**：空态 = 2×2 空格（标题 / 一句说明 / 唯一动作，跨模块的用虚线惰性钮）+ 四个虚线空格；结果态 = hero 灰化 + 结果子格 + 灰格残留，整屏仍是完整构图。
- **处理中 / 失败**：被按下的那颗按钮文字隐去、三粒像素步进（720ms steps(3)），同组另一颗只置灰（`.dim`）；失败红条在发生处（行内 / 票下 / 操作盘内 / 列表底部），标签单行、说明另起一行、「重试」在右，重试可成功（`fail-retry/`）。
- **减少动态**：所有动效 1ms 直达结果；语义时长不缩放 —— 撤销窗口 10s、toast 2.6s、「已复制」2.6s 用 `afterReal()`（rm 下按真实时长、仍随倍速与暂停），撤销条的倒计时线在 rm 下隐藏（`half-rm/`：删除后 5s 撤销条仍在，撤销恢复）。核心 `after()` 在 rm 下把所有定时器缩到 0，其他方案可能有同样问题（已报主负责人）。
- **散场票根翻面**：`p_history` 散场的票根「点一下 · 看背面」：票面与深色背面（像素 `JU.` + 「有 JU，就开局」+ 票码）在 `perspective:1100px` 里 640ms `rotateY(180deg)`，`cubic-bezier(.3,.7,.2,1)`，正反面 `backface-visibility:hidden`。
