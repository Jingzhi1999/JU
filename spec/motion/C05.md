### 材质规则
- 台面 = 坯布：3px 经纬重复渐变（横 `rgba(255,255,255,.28)` / 纵 `rgba(70,58,36,.08)`）+ 整屏一层 `feTurbulence baseFrequency .9` 极细纤维噪点（alpha ≤ .11，`.c05-grain`）。只有一束光，从左上：所有投影偏右下（裁片 `drop-shadow(1px 2px 0) + (5px 9px 9px)`，lead `9px 15px 14px`）。
- 裁片 = 漂白布块：矩形 + 右上 26px 斜切角（`clip-path` 多边形；阴影用 `filter: drop-shadow` 跟随切角）；lead 与详情裁片沿边内 10px 有一圈粉笔缝份线（描线轮点线 1.6/5px，切角处让开；第 1 轮前的 26px 方格读作方格纸，已去掉）；左边一个三角牙口（裁缝对位记号）；表面 160° 高光渐变。详情 / 订单簿的布不再铺在整张裁片上，而是分别铺在上半片（`.c05-pc`）与翻片（`.c05-flap`）上：翻片折起时下面露出台面，不再有一块硬卡纸垫底；翻片下沿 2px 毛边（台面色纬线缺口）。
- 四针白标（`.c05-lab`）：白底，两端各缝两针（1.3×5px 竖针，上下各一）+ 两针之间一个针孔点（共四针；第 1 轮前的四角斜线读作括号）；状态只换文字颜色：红粉笔 = 要你回应，蓝 = 等待，绿 = 就快见面，灰 + 布色底 = 未成行。
- 缝线：`.c05-seam` = 深线 6/10 虚线 + 下方 1px 白线（针脚阴影）；基线进度条 `.c05-bast` = 已走过的部分是针脚，剩余是针孔点；席位针脚 `.c05-stitches`：局主 = 双线，已确认 = 实线，预留 = 疏缝虚线，空位 = 针孔点，出席 / 未出席 / 待定 = 实线 / 灰虚线 / 棉线色。
- 织带按钮（主要行动）：靛蓝 45° 斜纹 + 内 5px 白色跑针虚线；处理中文字隐去、中央一段 12px 周期的跑针动画（仅处理中）。粉笔描边按钮：1.5px 蓝描边，四角圆角不等（3/7/4/8）像手画的方框。
- 吊牌：232×176 硬卡纸，左上 14px 切角，18px 金属扣眼；棉线两层（暗底 + 亮面 2.6/1.4 虚线 = 捻线）。存根袋：裁片底部 68px 一条略深的布袋，上沿白边 + 内阴影 + 针脚线。右侧 26px「翻起的布边」（`.c05-edge`）带投影，吊牌从它底下抽出。
- 订单簿（管理）：裁片仍是头部物件；下面是一页米色账本 `#f9f6ee`，只在账本头（订单名一条、标签页一条）有两道横格线，正文行用各自的点线分隔（横格线不再穿过名字与按钮）；左侧针脚装订线、右下投影；标签页是小布标（选中 = 白标）。出席行 = 两行网格：头像 · 名字 · 三段选择 / 微信号 + 复制（对齐名字列，`nowrap`）/ 更正轨迹。
- 弹层 = 翻起的布角：底部整块裁片上滑，顶部 18px 折边渐变 + 针脚线；背景压暗 `rgba(50,40,25,.4)`。
- 未成行 / 已取消 / 草稿：只画粉笔 / 灰线轮廓（无填充、虚线描边、切角仍在），已取消再在切角处留一小块焦痕；文字换 `--ash` / `--ink3`。历史里展开的未成行裁片沿用同一轮廓材质（虚线边 + cloth3 半透明底，`.c05-sheet.closed`），无票的结局配一枚「没有出票」的虚线小吊牌 + 粉笔叉（`.c05-voidtag`）。
- 候补回执（`.c05-receipt`）：白纸条，上沿针脚、下沿花边剪（锯齿 mask），`JU. 候补回执` · `已加入候补 / 位置已预留` · 右侧大号 `02 位` / `已预留`。
- 失败 = 原位红粉笔虚线框 `.c05-alert`（申请行内、出席行内、吊牌区下、联系白标内、弹层内、记录框下）；列表级（草稿删除）才用底部白标条。
- 圆角：几乎没有（按钮 2–3px）；边线 1–1.5px；噪点只在台面一层，文字永远在纯色裁片上。

### 布局构图
- 列表：顶部 158px（品牌行 · 36px 标题 + 一行待办小字 · 右侧两张「台」的身份标签 · 分区行 + 排序口径；台面实色铺到分区行下沿 +6px 再 13px 羽化）→ 组头（粉笔字 + 计数 + 口径，下面一条 `fx-rough` 粉笔线）→ 裁片（lead 含倒计时 + 基线进度 + 说明 + 织带 CTA；其余只有白标 / 时间列 / 局名 / 副文 / 行内入口「动词 ›」；票件行右上挂一枚小吊牌，散场行右上一枚出席白标）→ 页脚粉笔字 → 70px 布边底栏（找局 / 开局 / 我的局（白标）/ 设置，其余 disabled）。列表底部留 110px 安全区。
- 覆盖层顶栏 = sticky 58px（台面实色）：返回 · 局名（折叠后单行省略）· 状态白标 / 角注；滚过 96px 后返回文字收起、局名从下方 20px 升入栏内（320ms），栏下出针脚线与投影。允许的 toast（复制 · 改期已发出 · 接受改期）占顶栏右侧这一格（白标，2.6s），永不盖住内容。
- 详情 = 同一张裁片翻开：头部与列表行同构（白标 / 时间 / 局名 / 布纹箭头），折线（粉笔虚线 + 折痕阴影）下是翻开的下半片：标题 → 倒计时 / 说明 → 候补回执 → 吊牌区（粉线叉 · 棉线 · 吊牌 · 存根袋 · 布边）→ 原位失败 → 结果白标（只写后果；在吊牌下方，烧之前就占好位置）→ 联系白标 → 行动 → 席位针脚 + 名单（灰标签 + 黑值）→ 候补 → 规格表（时间 / 地点 / 局主 / 局主说）→ 历史：出席记录 / 局内记录 / 补充 / 举报 → 参加约定 ›。
- 管理 = 裁片头 + 订单簿：头部多一行状态（待办红粉笔）、进度行 + 席位针脚、formedLine、查看完整局卡 ›；账本：订单名 + 英文日期 → 标签页（申请 · 成员 · 候补 · 改期答复 · 出席 · 安排）→ 当前区块。
- 草稿 = 未裁的样板：只有粉笔虚线轮廓的裁片，缺项红字；删除 → 行原位收起 300ms → 底部白标撤销条 10s。

## 2. 三个核心动作（REF 对应见 §4）

### ① 翻开裁片（局卡 → 详情，M4；同一机制用于管理与草稿）
- 触发：点裁片任意处（`.c05-hit`）或 lead 的织带 CTA。运动对象：覆盖层 `.c05-over.c05-full`（clip-path 从行矩形到全屏）+ 内层 `.c05-sheetwrap`（translateY 从 `行.y − 58` 到 0）+ 裁片下半片 `.c05-flap`（`perspective(1400px) rotateX(−72deg) → 0`，变换中心 50% 0 = 折线；负角 = 下半片向后垂着、再向下摆平，不再朝镜头放大裁切）。
- 起点：`JU.fx.rectIn(行, .app)`；`phase:'start'` 渲染后 `void getBoundingClientRect()` 刷新样式再切 `'in'`。从普通行（非 lead）打开时 `.fromrow`：start / out 两端头部用行的字号（时间 27px、局名 19px 墨色、内边距 18/20），`in` 时 460ms 过渡到 42 / 24px 粉线蓝——没有字号跳帧。
- 分段：0–460ms clip-path + 位移（`cubic-bezier(.2,.8,.2,1)`）；150ms 延迟后 560ms 翻片落平（`cubic-bezier(.3,1.18,.32,1)`：越过 0 约 3° 再回到 0 = 布料落平后回摆一次，REF37）；翻片上方折痕阴影（`rgba(40,30,20,.38) → 0`）同步淡出；900ms 后 `'flat'`：移除 clip-path / transform / 阴影层，文字以恒等变换栅格化。布只铺在上半片与翻片上，翻片折着时下面是台面。背景：头部、台面、底栏加 `.back`（`blur(2px) brightness(.9)`，420ms）。
- 顶栏：`.c05-stick` sticky；滚过 96px → `.collapsed`：返回文字 300ms 收起，局名（单行省略）从 +20px 升入栏内 320ms，栏下针脚线 + 投影；返回键始终在。
- 返回：`scrollTop=0` → 若行换了分区先切分区 → `scrollIntoView` → 翻片 300ms 折回（`cubic-bezier(.5,0,.8,.4)`）且 20ms 后 190ms 淡出（半折的下半片文字不会留在画面上）→ 覆盖层底色 220ms 后 200ms 变透明（看得见退后的列表）→ 120ms 后 clip-path / 位移 460ms 收回行矩形 → 400ms 起列表去模糊 → 620ms 卸载；落点行在收回期间隐藏（`.landing`，不出现两张同样的裁片），卸载后原行 1.7s 粉笔蓝高光（`.landed`）。找不到原行 → 收回到打开时的矩形。
- 中断：每次打开 / 关闭递增 `_ov` 序号，所有延时步骤（切 in / flat、卸载、去模糊）只在序号未变时执行——返回后 120ms 内点另一行，新详情不会被旧的卸载吞掉（探针：t+300ms detail/in，t+1200ms detail/flat）。`after()` 随面板暂停；`beforeReplay('open')` 回到列表再播；`.rm` 下 1ms 直接到位。
- 证据：`evidence/C05/card-detail-back/sheet.png`（0.5×，28 帧：打开 9 帧 / 滚动折叠头 3 帧 / 折回 11 帧）、`stress/`。

### ② 剪线撕票（吊牌断线，M8；`tear` 首次打开先走「挂牌」= 出票）
- 挂牌（出票）：`phase idle → printing`：`.c05-tagwrap` keyframes `c05-tagin` 2000ms linear：`translateX(130% → 84%（18–30% 停）→ 38%（50–62% 停）→ −1.5% → .8% → 0)` = 三次抽出、两次停顿，吊牌从右侧布边底下露出；2000ms → `tying`：棉线 `stroke-dashoffset 400 → 0` 520ms，480ms 后线结 `scale(0 → 1)` 260ms；2700ms → `ready`。挂牌期间行动行占位但不可见（`.c05-acts.hold`，visibility hidden，名单不跳），需求行「出票中 · 吊牌正在系上」。
- 断线（撕票）：`onPointerDown`（setPointerCapture）→ `onPointerMove` 把 `dy` 映射到 `p = dy / 36`：吊牌 `translateY(p·36)`、投影抬高、棉线垂度 `24·(1−p)` → 0、线宽 2.6 → 1.5。`p > .75`：亮面那股线先断（`.fraying`，亮股淡出 = 双股变单股），离结 30% 处长出 5 根 3–6px 毛刺（随 p 变长）。释放 `p ≥ .55`：需求行「线绷紧了 · 正在记录」、「去不了了」变虚线禁用占位（`.wait`）→ `engine.tearTicket`（160ms）→ `motion('tear')`：线在结处断开，线头 `.c05-stub` 以结为轴 `rotate(−58° → 16° → −7° → 0)` 560ms 回弹，末端 4 根 5–8px 纤维；吊牌一侧残线 900ms 摆动；吊牌 `c05-tagdrop` 700ms 落进存根袋（「线断了 · 吊牌落进存根袋」）。740ms → `torn`；1020ms → 联系白标从吊牌下翻出（`c05-turnout` 520ms：max-height 0 → 自身、`rotateX(−64° → 0)`，下面整段平滑下移）。`p < .55` 释放：420ms 回弹。写入失败：吊牌弹回 + 吊牌区下原位红框「未能保存，请重新撕下副券」+ 重试（或直接再拉）。
- 结束态：粉线叉上留一截线头，吊牌在存根袋里仍可读，列表小吊牌的线变断头。
- 改期接受 = 同一动作作用于新版吊牌（`acceptReschedule`）：落袋后旧吊牌盖灰色「作废」章（`fx-stamp` 520ms）并灰化；顶栏右格 toast「已接受改期 · 按新吊牌的时间见」。
- 证据：`evidence/C05/print/`（挂牌 13 帧）、`tear/`（拉 14px 回弹 + 0.5× 拉断 8 帧（含毛刺）+ 断线落袋 12 帧 + 联系白标翻出 + 复制 + 已加微信）、`reschedule-reply/`、`confirm-flow/`、`fail-retry/`。

### ③ 布面烧焦（取消 / 退出 / 拒绝改期 / 已取消首次打开，M8 + M11）
- 写入先于动效：确认层保持打开、确定键跑针（处理中），失败就在层内红框重试；成功 → 确认层 360ms 收起，联系白标同时 380ms 折回（`c05-foldaway`），吊牌下方立刻占好结果白标的位置（「吊牌作废中 · 联系已关闭」），420ms 后才起火——烧的过程中与烧完后版面都不再移动。
- 对象：同一张吊牌（参加者）或管理页的裁片头（局主取消），`.fx-burn` + SVG mask（`id="c05-hole-{uid}"`，`userSpaceOnUse`，洞用 `fx-rough-strong` 打毛）。起火点：吊牌右下角（222,168），裁片右上切角（338,12）。
- 火线：`@keyframes c05-hole`：0–12% 慢点燃（缓入到 reach×7%）→ 12–88% ease-in-out 推进 → 88% 恰好吃完最远角 → 88–100% 停住。reach：吊牌 296px（起火点到最远角 278 + 毛边余量）；裁片按实测高度 `√(338² + (H−12)²) + 18`。`--fx-dur` 吊牌 2600ms / 裁片 3000ms。洞缘三圈描边（内侧一半被 mask 裁掉）：琥珀火线 3px → 焦黑 12 / 16px → 焦黄晕 32 / 40px α.6 → 灰棕起毛 3px；85% 后火线淡出。
- 残余从同一块布里显出来：灰线轮廓 `.c05-tagash` / `.c05-pieceash` 在燃烧期间用反相 mask（`c05-res-{uid}`，同一个毛边洞的白色版）只显示「已经烧掉的那部分」，并按 `c05-resin` 0 →（14%）→ .4（40%）→ .75（72%）→ 1（90%）浮出——轮廓紧跟在焦边后面出现，没有「空槽 → 换一张画好的轮廓」。轮廓上保留两道静态焦痕：起火角一小段弧、最后被吃掉的远角一段弧（吊牌 r=250，裁片 r=0.93·reach）。
- 棉线一起烧：58–74% 亮股淡出，62–97% 暗股变焦黑（`#4a3020 → char`）并从扣眼一端缩回到粉线叉下 11px 的焦线头（`stroke-dasharray 110 → 11`），线结 80–94% 变黑；烧完后历史里也显示这截焦线头（`.charred`）。已撕的票：叉上的线头本就断开，不着火；吊牌上的残线随吊牌在 58–74% 淡掉。
- 灰烬：14–16 粒，出生在火线经过的位置（按 `c05-hole` 同一曲线算出 17–81% 各时刻的半径，取吊牌内的点），各自在火线到达那一刻（`animation-delay = f·dur`）才开始飘落 1400ms——焦圈半径 >20px 前没有灰（位于 mask 之外的兄弟层）。
- 结束：2680 / 3080ms 后 `.burnt`；轮廓去掉 mask 保持 1；结果白标在原位由「作废中」换成后果一句（退出：「记为主动退出，占同一账户每年 4 次机会之一（只陈述，不评分）。」；拒绝改期：「这是局主改期：不记你的主动失约…」）；拒绝改期时旧吊牌同时盖灰色「作废」章，席位块变为 `4/5 含局主 · 你的席位已释放`，名单里你的那行换成「你已离开 · 席位已释放」、你的那针变回针孔（core 的 `declineReschedule` 不改成员状态，见 §5）。局主侧：裁片头变灰线轮廓 + 「已取消 · 不能撤销，票根作废、联系关闭」，成员区 void，安排区只剩再开一局（惰性）。
- `.scrub`：`c05-hole` / 三圈 / 毛边 / 残余浮出 / 棉线 / 线结全部以 `--frame` 定格（`evidence/C05/rm-scrub/` 5/15/30/50/70/80/88/96/40%）；`.rm` 直接到灰线轮廓 + 焦线头；`beforeReplay('burn')` 恢复整张吊牌 / 裁片、结果白标回到「作废中」占位后重播。
- 证据：`evidence/C05/burn-void/`（退出，0.5×，33 帧）、`decline-burn/`（拒绝改期 30 帧 + 席位释放）、`cancel/`（局主取消 29 帧 + 历史落点）、`cancelled-history/`（首次打开烧一次，再开静态）、`rm-scrub/`。

## 3. 其余动效族（M1–M11 落点）
- M1 身份切换：当前台 200ms `translateX(−10%)` + 淡到 .1 → 换数据 → 新台 `c05-tablein` 440ms 从 `translateX(12%)`、.1 滑入（任何一帧都不是空台）；身份标签下划线 240ms。每个身份记住自己的分区与滚动位置（F03），切回来恢复原分区、原 scrollTop 与折叠头。
- M2 分区切换：粉笔下划线 `scaleX` 200ms；内容重挂 `c05-secin` 200ms（6px 上浮）。
- M3 滚动：`scrollTop > 48` 加 `.compact`：标题 36 → 20px、品牌行淡出上移、待办小字淡出、身份标签上移、分区行上移，280ms；头部台面实色到分区行下沿 +6px 再 13px 羽化。`compact` 由 `componentDidUpdate` 按真实 scrollTop 同步；`jumpTo / reset / loadVariant` 都把台面滚回顶部。覆盖层的折叠顶栏见 ①。证据 `evidence/C05/switch-scroll/`。
- M5 审核：按钮原位换成结果行（`c05-settle` 420ms），席位针脚新增一针 `c05-stitchin` 500ms，计数 / 头部状态同帧重算；不弹 toast。写入期间所有审核按钮 `disabled`（连点三下只写一次，不再出现假失败）；失败在该申请行内红框 + 重试。证据 `evidence/C05/approve/`、`fail-retry/`、`stress/`。
- M6 弹层：翻起的布角 360ms（`cubic-bezier(.2,.9,.25,1)`）上滑 + 压暗 320ms；关闭 `cubic-bezier(.5,0,.8,.4)`。所有确认层在写入期间保持打开（确定键跑针、取消键禁用），失败在层内红框。开 / 关带 `_sl` 序号：关后 150ms 内再开，新层不会被旧的卸载清掉。
- M7 改期：局主确认后弹层收起 → 滚到顶 → 顶栏右格 toast「已改时间 · 等 N 位成员答复」→ 切到「改期答复」。新日期 / 时间是两枚白标布签，显示 `周四 12.24` / `20:15`（Cormorant 数字），系统日期控件透明地叠在布签上（点开仍是原生选择器）。参加者旧吊牌保留、新吊牌挂牌 → 断线接受；拒绝走 ③。
- M9 散场 / 出席：记为散场后切到出席区（无 toast）；出席行两行网格；记录时白标 `c05-markin` 520ms（仅 2.5s 内新鲜记录），记录期间三段键禁用；更正留轨迹（新的在前）；历史侧行文 `n/N 人到场 · m 人待记录`。证据 `evidence/C05/end-attendance/`。
- M10 草稿：行高 → 0 300ms 同时裁片右滑淡出；撤销条白标；撤销后 `c05-grow` + `c05-enter` 回到原槽位；删除失败在撤销条位置出红框 + 重试。证据 `evidence/C05/draft-delete-undo/`。
- M11 空态：粉笔虚线裁片 + 粉笔词（待裁 / 余白 / 未归档 / 无样板 / 草稿还在）+ 标题 + 一句 + 唯一动作。读取失败：面板「下一次保存失败」也让下一次台面读取（切身份 / 切分区）失败 → 红粉笔「读不出 · 本机记录暂时读不出来 · 你的局没有丢，只是这台设备暂时读不到。· 重新读取」，重读成功。证据 `evidence/C05/empty-state/`、`fail-retry/`。
- 历史票根：散场吊牌「点一下 · 看背面」→ 560ms `rotateY` 翻面（背面 `JU.` / `有 JU，就开局` / 编号，扣眼换到右上），再点翻回；预留到期展开显示 `00:00:00` 空进度条；候补 / 候补轮到显示候补回执。证据 `evidence/C05/history-note/`。

## 5. 已知限制（代理自报）
- `JU.engine.declineReschedule` 只改 stage、不把你的成员状态设为 declined，`counts.confirmed` 仍含你；本方案在详情里自行把你的席位显示为已释放（4/5）。需要主负责人在 core 里补上（会影响十套）。局主侧「改期答复」名单由 core 派生，未改。
- 吊牌区几何（棉线、存根袋、布边）按 314×304px 固定坐标绘制；360 宽下吊牌右缘被布边多盖 ≈ 15px（可读性不受影响）。
- 倒计时为静态（`JU.NOW` 固定），基线进度条只在值变化时过渡。
- 燃烧的洞是单圆扩张（毛边滤镜打散），没有多点起火；轮廓 / 裁片的燃烧 mask 坐标按 350px 宽的裁片写，非 390 宽时 mask 随 viewBox 拉伸。
- 翻片仍是一整片绕折线旋转（加了向后垂、回摆、毛边与布只铺在两半上），没有分 2–3 条错时折。
- 列表与历史里轮廓裁片的切角仍是「虚线方角 + 台面色三角」的折角画法（与第 1 轮一致）。
- toast 与顶栏右格共用位置：顶栏折叠时会暂时盖住状态白标 2.6s（不盖页面内容）。
