# 「设置」十套方向卡 · 差异矩阵（设置 SC01—SC10）

编号前缀 SC = 设置（Settings Concept），与上一轮「我的局」C01—C10 无关。每套先回答六件事：① 首页构图与信息组织 ② 中文排版与比例 ③ 控件与编辑器构造 ④ 材质与空间层级 ⑤ 空间过渡与运动 ⑥ 三个代表性动作。任意两套至少在四个维度上有可见、可操作的区别。十套共用同一份设置状态契约（`settings/src/core/jus-data.js`）、同一评审面板与同一组接缝（入局 01 / 我的局）。

方向不是预先按「风格」分配的；每套都从一个设置的产品问题出发（见「回答的产品问题」列）。

| 编号 | 名称 | 一句话 | 回答的产品问题 | 来源类型 | 信息组织 | 展开方式 | 开关形态 | 记录形态 |
|---|---|---|---|---|---|---|---|---|

## SC01 登记表 Form Sheet

1. **首页构图与信息组织**：整屏是一张登记表。表头：「JU 设置登记表」小字 + 编号 + 填表人（称呼大字，约 30px）；表体每行三格：字段名 ｜ 当前值 ｜ 状态章；粗线分六组：个人资料 / 收藏与城市 / 通知 / 外观 / 我的记录与举报 / 帮助与账户。第一眼：称呼与各行右侧的朱红状态章；第二眼：当前值。收藏是「收藏的局 · 3」一行，展开成附表。
2. **中文排版与比例**：字段名 Noto Serif SC 400 12px 灰墨；当前值 Noto Sans SC 500 16px 黑墨；数字 IBM Plex Mono；行高 52px 节奏，长值在格内折行撑高该行而不缩字；表线 1px #1b1a17；章用朱红 #b8322a 半透明。
3. **控件与编辑器构造**：开关 = 方格内盖「开」/ 划线 + 盖「关」；单选 = 一排小格勾选；文本编辑 = 该格放大成填写区（上方浮出填写说明、下方校验行）；记录 = 附表（序号 / 日期 / 事实 / 状态）；危险操作 = 表尾红框区「撕角处」，需沿虚线拖开才生效。
4. **材质与空间层级**：米白表格纸 #f3efe4 + 极淡网格底纹；黑墨印刷线；章有轻微晕染（fx-ink 滤镜）；纸只有边缘一条阴影；没有卡片、没有圆角容器。
5. **空间过渡与运动**：二级 = 该行下方展开附表（行高增长，其他行让位）；返回 = 收回到该行；编辑 = 格 FLIP 放大；键盘出现时表格整体上移并保留当前行可见。
6. **三个代表性动作**：① 盖章开关；② 填表保存（墨由浅到深 + 「已更新」小章）；③ 附表展开与划线删除（取消收藏）。

## SC02 面板 Hardware Panel

1. **构图**：奶白搪瓷面板，顶部黑色铭牌刻着称呼（大）与微信 / 邮箱（小刻字，验证状态为一枚绿 / 灰 LED）。下方模块化：每个模块一块略凹入的面板，带拨杆（开关）、旋钮（城市 / 外观）、LED（权限 / 服务）、小 LCD 读数（当前值）。收藏是「卡槽」模块显示数量与最近一张。第一眼：铭牌与亮着的 LED；第二眼：各模块读数。
2. **排版**：刻字 Noto Sans SC 500；标签 Space Grotesk 大写 + 中文并置，字距 .08em；LCD 读数 DM Mono；字号偏小但对比高。
3. **控件**：拨杆（有行程与回弹）；旋钮（刻度 detent）；LCD 行输入（光标闪）；记录 = 可滚动的 LCD 日志；危险操作 = 带透明保护盖的红色按钮（先翻盖再按）。
4. **材质**：搪瓷 / 磨砂塑料面板，左上单一光源，凹槽内阴影；黑色铭牌有细微反光；橙色点缀；LED 有小范围发光晕。
5. **过渡**：模块被点击后抬起到前面成全屏面板（其余模块暗下退后）；返回 = 落回凹槽。
6. **动作**：① 拨杆开关；② 旋钮选城市（detent + 读数滚动）；③ 保护盖红钮（退出登录 / 清除演示数据，只作用隔离数据）。

## SC03 文件袋 PP Folders

1. **构图**：一叠半透明磨砂 PP 文件袋，右侧边缘露出彩色索引标签（资料 / 收藏 / 偏好 / 记录 / 帮助）；最前面的袋子透出称呼大字与收藏数。第一眼：索引色块 + 透出的大字；第二眼：标签上的小字当前值。
2. **排版**：透出的大字 Noto Sans SC 700 28px（被雾化柔化）；标签字 12px 黑；数值 DM Mono。
3. **控件**：按扣开关（扣合 / 弹开）；彩色索引夹 = 分组选择；纸片抽出 = 文本编辑；记录 = 袋内多张纸；危险操作 = 封口贴，撕开才能按。
4. **材质**：磨砂半透明塑料（backdrop blur + 白雾层 + 边缘高光 + 轻微塑料纹）；纸片有叠压与颤动；标签是哑光彩色贴纸。
5. **过渡**：点标签 → 该袋从叠中抽出到最前（其余后退、更模糊）；纸片从袋口抽出成全屏；返回插回。
6. **动作**：① 抽袋；② 按扣开关；③ 抽纸编辑保存。

## SC04 手册 Booklet

1. **构图**：手册翻开到身份页：称呼大字（Noto Serif SC 600 34px）、微信、邮箱与验证小方章；右侧页边是拇指索引（资料 / 收藏 / 偏好 / 记录 / 帮助 / 关于），当前章节的索引块更深。第一眼：身份页的名字与章；第二眼：索引。
2. **排版**：正文 Noto Sans SC 400 14px；页码 Cormorant Garamond；版心严格、外边距大；记录条目「日期 ｜ 事实 ｜ 状态」用细线表格。
3. **控件**：开关 = 页上的实心 / 空心圆（● ○）；选择 = 勾选格；文本 = 页上横线填写；记录 = 按日期的条目 + 小方章（待核实 / 已核实 / 已补充）；补充 / 申诉 = 夹页；危险操作 = 封底撕下页角。
4. **材质**：压纹卡纸封面、薄内页（背面透印）、书脊阴影、翻页弯曲；章为朱红或靛蓝。
5. **过渡**：翻页（书脊为轴）；二级 = 翻到对应章节；编辑 = 拉出夹页。
6. **动作**：① 翻页到章节；② 补充夹页；③ 书签收藏（取消时书签滑出飘落）。

## SC05 冰箱门 Fridge Door

1. **构图**：竖向冰箱门（奶白搪瓷，右侧一条门封）。上面用磁贴固定：顶部「我的名片」（称呼 / 微信 / 邮箱），中部收藏的局传单（2–3 张可见 + 数量磁贴），白板贴纸列着通知偏好与城市，门把手旁小磁贴是帮助 / 关于 / 账户；记录是一个磁性小盒。物件 ≤3° 小角度错落，文字保持水平。第一眼：名片与最大的传单；第二眼：白板勾选。
2. **排版**：Noto Sans SC 500 为主；数字 Fraunces；便签上的小批注 Long Cang（仅批注，不用于正文）。
3. **控件**：磁贴翻面 = 开关；字母磁贴排出当前值 = 选择；换便签 = 文本编辑；便签叠 = 记录；危险 = 取下磁贴后出现确认纸条。
4. **材质**：搪瓷门面（微反光 + 门封阴影）、纸（厚度 / 边卷 / 阴影）、磁贴（塑料高光 + 下方小阴影）。
5. **过渡**：点一张纸 → 从门上「取下」拿到眼前（放大、阴影加深、旋正）；返回 = 贴回原位，磁贴吸住（snap）。
6. **动作**：① 磁吸贴回 / 取下（收藏 / 取消收藏）；② 翻面开关；③ 换便签（资料编辑保存）。

## SC06 内衬 Garment Inside

1. **构图**：外套翻开的里侧：顶部一枚织唛印着称呼与账号（四针白线缝住的标 = 「我」），下方 4–5 个内袋（拉链袋 / 贴袋），袋口织带标签写分组名与当前值；洗标（care label）排着通知与外观的符号行；记录缝在最里层的口袋里。第一眼：织唛；第二眼：袋口标签。
2. **排版**：织唛 Noto Sans SC 500 小字密排 + Archivo Narrow 大写拉丁；洗标符号 + 10px 小字；里布上不放长文。
3. **控件**：按扣 / 拉链头 = 开关；织带上的分段标（S / M / L 式）= 选择；吊牌 / 手写洗标 = 文本编辑；袋内卡片 = 记录；剪标线 = 危险操作。
4. **材质**：里布（细斜纹织纹）、织唛（纤维边缘、织字锯齿）、金属拉链牙与拉片、缝线与四针白线。
5. **过渡**：拉开拉链 → 袋口张开露出内容（二级从袋口展开）；返回 = 拉合。
6. **动作**：① 拉链展开；② 按扣开关；③ 重织织唛（资料保存）。

## SC07 墨水屏 E-ink

1. **构图**：电子纸灰白底、纯黑字；顶部称呼大字；分组用黑底白字组头 + 粗横线；每行「项目名 … 当前值」靠引导点对齐；信息密度高、秩序严格；屏角一枚指示灯色（唯一彩色）用于「需要处理」。第一眼：黑组头与大字；第二眼：引导点对齐的值。
2. **排版**：Noto Serif SC 大字 + Noto Sans SC 正文；4 级灰；无阴影、无圆角渐变。
3. **控件**：实心 / 空心方块 = 开关；黑底反白选项 = 选择；下划线输入 + 慢闪光标 = 文本编辑；记录 = 清单页；危险 = 全屏确认页。
4. **材质**：电子纸（无光、纸质灰白、文字边缘微颤）；屏四周薄框；按钮边缘硬。
5. **过渡**：切页 = 局部刷新（区域反相一闪 → 新内容 → 残影 300ms 清除）；减少动态下刷新本身即结果。
6. **动作**：① 刷新翻页；② 方块开关；③ 反相落定（保存）。

## SC08 门厅 Lobby

1. **构图**：深色门厅。顶部黑色导览板，白字牌逐行列出分区与当前值（你的名字在第一行）；中部黄铜信箱格阵列 = 通知偏好（每格一类，格门开 / 关，格上刻名牌）；下方门铃面板 = 隐私与联系（谁能联系你，按现有规则显示）；侧面小牌 = 帮助 / 关于 / 账户；记录 = 门卫登记簿。第一眼：导览板与黄铜格；第二眼：格门状态与门铃灯。
2. **排版**：导览板 Noto Sans SC 500 白字 + DM Mono 字母牌；黄铜名牌刻字（深色凹字）。
3. **控件**：信箱格门 = 开关；滑动字牌 = 选择；名牌更换 = 文本编辑；登记簿翻页 = 记录；换锁 = 危险操作。
4. **材质**：黑漆板（细微反光）、黄铜（氧化 + 一条反光带）、磨砂玻璃门。
5. **过渡**：点导览板一行 → 牌面像抽屉从板中拉出成面板；格门沿铰链打开（透视）。
6. **动作**：① 字牌滑入；② 信箱门开关；③ 门铃灯（谁能联系你）。

## SC09 软体 Soft Bodies

1. **构图**：浅暖底；首屏是大小不等的软体（胶囊 / 圆角块）：最大的一团是「我」（称呼 / 微信 / 邮箱），其余按重要度排列（收藏、通知、城市、外观、记录、帮助），每团显示名称 + 当前值。第一眼：最大的一团；第二眼：其他团的值。
2. **排版**：Noto Sans SC 600 + Manrope 数字；字号差异明显；容器变形时文字 reflow，不拉伸。
3. **控件**：胶囊内滚动的软球 = 开关；分段胶囊（选中段膨胀）= 选择；软体放大成输入面 = 文本编辑；软体堆叠 = 记录；变红 + 长按压缩 = 危险操作。
4. **材质**：哑光软体（内阴影 + 高光），低饱和有活力的色（鼠尾草绿 / 杏 / 灰蓝）；无玻璃、无渐变背景。
5. **过渡**：点一团 → 弹性膨胀成全屏（其余被挤开缩小）；返回收缩回原位。
6. **动作**：① 膨胀进入；② 软球开关；③ 保存脉冲。

## SC10 吊牌 Hang Tags

1. **构图**：顶部一根挂杆，下面吊着一排吊牌（分区名竖排，当前值横排），第一张最大是「我」的吊牌；第二根杆挂着收藏的局（每局一张小吊牌）；第三根杆挂偏好；底部杆挂帮助 / 关于 / 账户。第一眼：最大的吊牌与收藏杆；第二眼：各牌的值。
2. **排版**：Noto Serif SC 500（竖排分区名）+ Instrument Serif 数字；值横排 Noto Sans SC 14px；吊牌比例 2:3。
3. **控件**：打孔 = 开关（打孔机打孔表示开；关闭 = 补孔贴）；多张小吊牌挂一张 = 选择；牌面重印 = 文本编辑；一串小吊牌 = 记录；剪绳 = 危险操作。
4. **材质**：卡纸吊牌（厚度边缘）、棉绳（略松弛的曲线）、金属孔眼；只在交互时摆动。
5. **过渡**：拉下吊牌 → 放大到眼前（绳跟着拉长）；松手 → 回弹悬挂。
6. **动作**：① 拉牌；② 挂牌收藏 / 剪绳取消（邻牌让位，空杆空态）；③ 打孔开关。

## 差异矩阵核对（任意两套 ≥4 维）

| | 构图 / 信息组织 | 排版比例 | 控件构造 | 材质 | 过渡 | 核心动作 |
|---|---|---|---|---|---|---|
