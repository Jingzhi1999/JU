## 核心动作 ①：盖章开关（通知偏好六类 / 减少动态）
- 触发：点状态格 `.tcell`；`act('setNotifyPref' | 'setReduceMotion')` 立即写入（即时型），失败时不盖章，行下印一行朱红「✗ 本机保存失败，请重试」+〔重试〕。
- 落点（REF45）：章心 = 格心 + 指尖相对格心的偏移（夹 ±7 / ±5px）+ 每次交替 ±5 / ∓3px 的错位；角度每次 `rand()*6−3`°。
- 开 → 关：先在上一枚「开」上画一道斜线（`.strike` 40×40 的 SVG 线，`pathLength=1` 描边 200ms ease-out），150ms 后「关」落下压在上面；关 → 开：新「开」落在旁边压住上一层。
- 落章 `sc01-land`：520ms `cubic-bezier(.2,1.1,.3,1)`：0% `scale(1.75) rotate(rot−7°)` 透明 + `blur(1.2px)`；60% `scale(.94)` 不透明 .86、无模糊；100% `scale(1)`。
- 层叠：一格最多留 3 层，旧层（非最新）`opacity:.34`、斜线 .35，最新一层完整；本来的基础章（来自数据态）不播放落章。
- 实际观察（`motion-1/`，0.5×）：f03–f06 斜线先划、「关」后落；f12 关在开的右上方压住；f26 第三次「开」落在左下，旧层退淡，首页「提醒」行计数 6/6 ↔ 5/6 同步。减少动态（面板 `.rm` 与用户 `.rm-user`）：章直接出现，结果完整。
- 建议值：真机上落章可用 `haptic` 轻击；斜线长度可按章的实际像素宽（当前固定 40px 对角线）。

## 核心动作 ②：填表保存（个人资料）
- 触发：附表 1 的〔修改资料〕；三格当前值各自 FLIP 成填写区：`.fill` 由 24px（印刷行高）长到实测内容高（`grow('fill:*', 24)`，`sc01-grow` 380ms `cubic-bezier(.2,.8,.2,1)`），说明行与校验行 120ms 后 260ms 淡入；状态格印「填写中」；附表底部换成〔取消〕「有改动 · 未保存」〔保存〕。
- 校验：输入时清该格错误；保存先 `validate`（`invalid` 逐格在校验行印朱红文案，底线转实线朱红）；邮箱改动 → 「邮箱验证」纸条：〔发送验证码〕→ 6 位 mono 码（字距 .42em）+〔验证〕+ 59s 重发倒计时（`holdKey('resend',1000)` 自链）→ 通过后邮箱行状态格落「已验证」章；未验证不能保存（引擎规则）。
- 保存：按钮「保存中…」≥420ms（`after(420)`）→ 引擎 → 成功：`inks` 标记该格与表头称呼 → 三格收回 24px（`sc01-shrink` 360ms），收回过程中格内已显示新值并以 `sc01-ink`（720ms：opacity .06 → .5 → 1，blur .8 → 0）重新印上；收回完成再 360ms 后状态格落「已更新 12.17」小章；[注] toast「已保存 · 新资料只用于之后的报名」2600ms。失败：输入保留，附表内印「✗ 本机保存失败，请重试」+〔重试〕（`edge-fail.png`）。未保存返回：纸条确认层「有没保存的修改 / 离开会丢掉刚才的输入」〔继续编辑〕〔放弃修改〕。
- 实际观察（`motion-2/`）：f02–f05 三格依次长高；f14–f18「保存中…」→ 格收回同时「阿禾二」由淡到深；f20+ 章落下、表头称呼同步重印；`saved-home.png` 首页该行带章。
- 建议值：真机键盘弹出时应把当前填写行滚到可见（代码里只在打开行时 `scrollTo`，未处理键盘）；`nothing`（无改动）时也走一遍重印，可改为只印回不落章。

## 核心动作 ③：附表展开与划线删除（收藏的局）
- 展开：点「收藏的局」行 → 行下 `.exp` 由 0 长到实测高度（`start` 渲染内容 → 16ms 后测 `scrollHeight` → `in` 播放 `sc01-grow` 380ms → `open` 高度 auto）；同时 `.sheet.scrollTo` 把该行滚到顶（smooth）；其他行随文档流让位；状态格「附表 2」变「收合 2」，行底色加深 .035。返回：`sc01-shrink` 360ms 收回到该行，内容在收回期间保持（`open` 延后清空）。同一时刻只开一张附表，切换时旧的收、新的长并行。
- 划线删除：点行尾 ✕ → 行文字 .55 透明，一道朱红横线从左到右描过（`.sline` `pathLength` 240ms）→ 260ms 后该行 `favrow:<id>` 收到 0（360ms）→ 引擎 `unfavorite` → 其余行序号与首页计数重印（`inkin`）→ [注] toast「已划去 · ×× 〔恢复〕」10s（`holdKey('undo')`）；最后一项删除 → 完整空态「还没有收藏 / 遇到想去的，留在这里。/〔去找局〕」。恢复：`favorite` → 行以 0 高度渲染后长出（按收藏时间倒排，落在序号 01），序号重印。
- 嵌套：附表内点一行 → 行下再长出「局 · 详情」纸条（`sub:fav:<id>`，同一套 grow/shrink）；记录 / 举报 / 找局 / 我的局的行内详情与表单同理（`sub:rec/rep/feed/mine`、`form:rf/rs/fb`）。
- 实际观察（`motion-3/`，0.5×）：f01–f07 附表长出、页面随之滚到该行；f10–f13 第三行划线、淡出、收起，f14 首页「3 个局」→「2 个局」重印；f16 撤销条；f19+ 恢复行长出在首位，序号重印。
- 建议值：划线时可让 ✕ 也变成「已划」小字；多行连续删除时撤销只保留最后一条（当前行为，可改为队列）。

## 减少动态与关键帧
- 面板「减少动态」`.rm` 与用户偏好 `.rm-user` 下所有过渡 / 动画 1ms：附表直接出现、章直接盖上、重印直接呈现（`.build/sc01-rm` 已验证）；`after()` 在面板减少动态下为 0ms。
- 关键帧 `.scrub`：附表长 / 收（`sc01-grow/shrink`）、落章、重印、划线、勾选描边全部用 keyframes，`animation-play-state:paused; animation-delay: calc(-1 × --frame × --sc01-dur)` 可拖动查看。

## 已知问题（主负责人自检）
1. 文本编辑未处理真机软键盘遮挡（只在打开行时滚动）。
2. 附表切换时旧附表若含嵌套详情，收回期间内容保持，但若 400ms 内再切回同一行，会先收到 0 再长出（无中断续播）。
3. 章的 `filter:url(#sc01-ink)` 在 SwiftShader 下渲染正常；真机 GPU 下建议复核边缘噪点强度（`scale=1.6` 可降到 1.2）。
4. 撕角只按位移判定（>70px），未做撕裂纤维边（`JU.fx.tearProfile` 未用）；可作为后续细化。

## SC02 面板 · 动效与视觉参数记录

源文件 `settings/concepts/src/SC02.dc.html`；证据 `settings/evidence/SC02/`（`motion-1/ motion-2/ motion-3/` 各含 `sheet.png` + `log.json`）。「当前代码值」= 源码里的数；「实际观察」= 看截图帧序列得到的；「建议值」= 复看后认为更好的数（未改代码）。时长全部乘 `--k`（0.5× 时 ×2；评审减少动态 `.rm` 与用户偏好 `.rm-user` 下一律 1ms，并把 transition-delay 归零）。

## 0. 构造一句话

奶白搪瓷面板：黑色铭牌（身份）在最上，下面是模块化的凹槽，每个凹槽里放一件真实硬件——拨杆（偏好）、旋钮（城市 / 外观）、LED（系统权限 / 提醒服务 / 需要处理）、LCD 读数（当前值）、卡槽（收藏）、透明保护盖下的红钮（账户）。点一个模块，它从凹槽里抬起来变成全屏面板；面板内部的二级用 iOS 推入；返回时落回凹槽。

## 核心动作 ①：抽袋（点或拖索引标签）
- 触发：点标签（`tabClick`）、点袋带（`.strip`）、或拖标签过阈值；再点抽出袋自己的标签 = 放回。
- 起始：`setState({pull:{key, phase:'pulling'}})`；该袋的静态几何立即写成抽出位（top 70 / height 710 / z 9），其余四袋 `top` 过渡到新槽（420ms `cubic-bezier(.2,.8,.2,1)`）并 `scale(.97)`、前片雾 .34→.62、内容 blur 0→1.3px。
- 受力 / 关键变化：`@keyframes sc03-pull` 560ms `cubic-bezier(.4,.05,.2,1)`（`animation-fill-mode both`，`.fold.pulling{transition:none}` 防止 top 过渡叠加）：0–26%：以左下角为支点（`transform-origin: 0 100%`）`rotate(-6deg) translateX(10px)`，高度保持 456，z 仍为原层级（REF43 扇开）；26→30%：z 跳到 9；30–100%：`translateY(var(--dy0)) → 0`、高度 456→710、旋转回 0（REF17：其余袋退后 3% 加雾）。
- 内容接替：`.fbody` 同步 `sc03-focus`（0–45% blur 1.4px → 100% 0），`.ffront` `sc03-clear`（.34 → .12）：内容随袋子到前而对焦。
- 落定：560ms 后 `phase:'pulled'`（静态几何，无 transform），`.fbody` 改为可滚动；标签带内出现「‹ 放回」贴纸。
- 返回（插回）：`phase:'out'`：静态几何直接写回首页槽位，`sc03-insert` 420ms 从 `translateY(-dy0)`、高 710 回到 0 / 456，z 在 68→72% 时从 9 回到原层级（滑入叠中被前袋遮住）；其余四袋同时过渡回原槽（REF40 后袋顶上）。420ms 后 `pull:null`。
- 中断 / 重复：抽出中再点别的标签 → 先插回（300ms 后）再抽；`afterKey('pull')` 保证只有一个落定定时器；减少动态下所有 1ms + `after` 归零，直接呈现抽出态；重播（`motion('pull')`）前 `beforeReplay` 先把 `pull` 清空。
- 实际观察（`motion-1/`，关键帧 0/10/20/30/42/56/72/90% + 插回 0–80%）：f01–f03 袋子以左下角为轴向右上扇出、标签抬起；f04–f07 向上滑到最前、变高、文字由糊到清；插回时整袋向下滑入槽位，其余带回位。
- 建议值：扇开阶段可再加 2px 的 `translateY(-2px)` 抬起感；插回时可让下一袋先抬 4px 再落（当前只有槽位过渡）。

- 编辑：「编辑资料」→ 同一张纸进入编辑态（顶栏「取消 ｜ 编辑资料 ｜ 保存」，SU08），三行印刷线输入 + 逐字段校验；邮箱改动 → 发送验证码（本机测试码，59s 重发倒计时 `holdKey('resend')`，5 分钟过期）→ 验证通过才可保存；保存 420ms「保存中…」→ 引擎写入 → 回到查看态并印「✓ 已保存 · 刚刚 · 新资料只用于之后的报名」；失败 `.alert` 抖动 360ms + 重试，输入保留；未保存返回 → 纸条确认层（继续编辑 / 放弃修改）。
- 返回（插回）：`.pbig.dropping` `sc03-drop` 420ms 回到起点矩形；`.pbody/.phead` 100ms 淡出、`.carry` 立即显示新值；420ms 后卸载，源纸片取消 `ghost`，袋面透出新称呼（「阿禾二」）。无起点（索引跳转打开的纸）用 `DEFAULT_FROM` 落进袋内。
- 实际观察（`motion-3/`，关键帧 0/15/30/50/75% + 插回 15/40/65/88%）：纸从袋内槽位升起放大、带着「阿禾」大字，落定后表单淡入；保存后查看态出现「已保存」；放回时纸带着「阿禾二」缩回槽位，袋面随即显示新值。
- 建议值：纸抽出时可在前 80ms 加一次 −2° 的微旋（手指拉纸的随机感）；插回后可让下一张纸（隐私）上抬 3px 再落。

## 接缝手势（入局 01）—— V27 参数逐字（`JUS.FAV`）

## 核心动作 ①：翻页到章节（拇指索引 → 页绕书脊翻过 → 落定 → 翻回原处）
- 触发：点右缘拇指索引（`data-rid="ch-*"`），或目录条目、相关列表、底部导航（我的局 / 找局 / 设置也是翻页）。方向：章序号增大为向前（右→左），减小为向后；返回 `pop()` 总是向后。
- 结构：`.leaves` 里固定三片叶 `.leaf`（槽 0 / 槽 1 / 翻页背面 `.flap`），用同一段页面模板循环渲染，所以翻页中旧页、新页、背面三者都是真实 DOM，落定后只剩新页（不缩放、不截图、无白块）。
- 起始（t=0）：旧页 `.leaf.turning` 完整，新页 `.leaf.under` 在其下完整排好版（滚动位 0），`.flap` 在右侧页外。
- 受力 / 关键变化：注册属性 `--sc04-t` 由 keyframes 从 0 → 1；折线 f = (1−t)·W 从书口走向书脊。旧页 `clip-path: inset(0 t·100% 0 0)` 只留折线左侧；背面 `.flap` 是旧页内容的镜像（`transform-origin:0 0; transform: translateX(2f) scaleX(-1)`，本地裁剪 `inset(0 0 0 f)`），内容 `opacity .25` = 25% 透印（REF38）；折线处 72px 渐变 `rgba(40,28,10,.34)→0` 压在背面上（REF39 的渐变页边），背面自由边 34px 白色高光做纸卷；新页上折线右侧 90px 投影 `.foldshadow`（`.32→0`，透明度随 1−t 衰减，落定为 0）。t=.5 时旧页正面全部被背面盖住，右半已是新页；t=1 背面整张滑到书脊左侧（屏外），只剩新页。
- 时长 / 曲线：向前 480ms、向后 400ms（≤ 向前，SM03），`cubic-bezier(.32,.06,.18,1)`；0.5× 时 `--k=2` 翻倍；减少动态 1ms（面板 `.rm` 与用户偏好 `.rm-user` 都已验证直接落定）。关键帧：`.scrub` 下 `animation-play-state: paused; animation-delay: calc(-1 * var(--frame) * 480ms * var(--k))`（向后 400ms）。
- 内容接替：新页在翻页开始时就完整在下面，不淡入；旧页的滚动位置在 `push()` 时记进返回栈（`{view, scroll}`），`pop()` 时在新页渲染后 16ms 写回 `scrollTop`，背面也同步同一滚动位，所以翻回时正好落在原条目（SM03 的「父页滚动位置与高亮行保持」）。
- 落定：`after(480|400)` 后清空旧槽，`cur` 切到新槽；拇指索引当前章变墨底。
- 重复 / 中断：翻页中 `turn` 非空时拒绝新的翻页与索引点击（`goChapter / goNav / turnTo` 先判断）；`jumpTo` 清计时器并重建状态；重播（`beforeReplay('turn')`）先把两槽、栈、tab 恢复到翻页前再重翻。
- 实际观察（`motion-1/`，关键帧 0/10/…/100%）：f03–f07 可见背面镜像的淡字与折线阴影一起从右向左扫过，新页文字始终清晰（它没有被变换）；f11–f19 翻回时身份页的背面先从左缘压进来，再露出正面，落定在原滚动位。
- 建议值：背面的 25% 透印在落日 / 光晕桌面下可略降到 .2；折线阴影在 t>.85 时可更快归零（当前线性）。

## 核心动作 ②：补充夹页（从条目拉出 → 横线上书写 → 保存 → 夹回页间留一角）
- 触发：记录详情 / 举报详情 / 帮助页的 `.sbt`（「夹页 · 补充说明 / 出席异议 / 信用申诉 / 补充材料 / 写反馈」）。起点矩形取 `ev.currentTarget.closest('.slipsrc')`（记录 / 举报 = 事实框 `.fact`，反馈 = 按钮本身），用 `JU.fx.rectIn(el, .leaves)`。

- 失败：`.alert` 朱红左线 + 抖动 360ms + 「重试」，输入保留；校验（<4 字）走横线下的朱红小字。

- 实际观察（`motion-2/`，0.5×）：f01–f06 夹页从事实框长出、落定、正文淡入；f08–f17 保存中 → 收回到条目右下 → 列表里出现第二张夹页 + toast。
- 建议值：收回时可先在条目上方停 60ms 再滑入（当前直接缩回）；横线纸行距 28px 与 15px 字体匹配，长文输入可考虑 26px。

## 核心动作 ③：书签收藏（取下 → 书签滑出飘落 → 相邻条目合拢 → 最后一张空态 → 放回）
- 触发：收藏页每条的「取下书签」(`data-act="unfav"`)、详情页「取下书签」、我的局书签标记、入局左滑。
- 阶段 1 `falling`（480ms）：`.ribbon` `transform: translate(110px,170px) rotate(18deg)`，`520ms cubic-bezier(.5,0,.85,.5)`（重力式加速）+ 140ms 后 380ms 淡出；该条 `.frow.falling` 提升 z 顺序、`overflow` 可见，所以书签飘过下面的条目；条目正文降到 .3。
- 阶段 2 `closing`（320ms）：`.frow.closing` `max-height 260→0`、内边距 → 0、底线透明、`overflow:hidden`，下面的条目随布局过渡合拢（页面合上）。

- 实际观察（`motion-3/`，0.5×）：f02–f06 书签向右下滑出并淡去、压过下一条；f07–f10 该条高度合拢、其余上移；f12 撤销条；f17 最后一张取下后完整空态；f21 放回后 1 条书签 + toast。

## 核心动作 ①：拿起 / 贴回（磁吸）—— 进入与返回任何二级页
- 触发：点门上任一物件（名片 / 传单叠 / 白板行 / 铁盒格 / 字磁贴 / 便签）。
- 起始：`open()` 用 `JU.fx.rectIn(el.closest('.paper'))` 取物件矩形；物件本体加 `ghost`（opacity 0），`.sheet` 以内联 `left/top/width/height` + 旋转角（名片 −1.2° / 白板 1° / 便签 −2.4°）出现在同一位置，`.carry` 层显示该物件的内容（称呼 / 微信 / 邮箱；传单标题；白板行；铁盒两格；磁贴字；便签字）。
- 受力 / 关键变化（`in` 阶段，16ms 后）：`.sheet` 过渡到 (14,40,362,760) 与 0°，`transition: 420ms cubic-bezier(.2,.9,.3,1.02)`；门 `.lifted`：`scale(.975)` + `brightness(.88) saturate(.9)` 420ms；遮罩 `rgba(40,28,12,.32)` 380ms；字磁贴 / 便签 / 白板起点时面板底色为该物件的颜色（`c-word / c-sticky / c-board`），`in` 后 420ms 过渡到纸色。
- 内容接替：`.carry` 60ms 后 160ms 淡出；页头 200ms 后 240ms 淡入；正文 240ms 后 260ms 淡入。
- 落定：面板静止，磁贴 `.mag.pin` 固定在顶边中点。
- 返回：`close()`：面板回到起点矩形（同 420ms），内容淡出、`.carry` 淡入；门恢复；430ms 后卸载面板，物件取消 `ghost`，其磁贴播放 `sc05-snap`（520ms `cubic-bezier(.18,1.5,.36,1)`：`translateY(-10px) scale(1.25)` → `(1px,.96)` → `(0,1)`，投影随之收小）。
- 中断：返回途中再点其他物件被 `lift.phase==='out'` 挡住（新 open 直接以 `in` 态打开）；面板内多级（收藏 → 详情）用 `.pg` 的 `sc05-pushin`（42px → 0，320ms）/ `sc05-popin`（−30px → 0）。
- 实际观察（`motion-3/`，0.5×）：名片内容随面板一起放大、页面内容在落定前后淡入；返回时面板缩回名片位置并显示更新后的「阿禾二」，磁贴弹跳一次。
- 建议值：面板缩回时可在最后 80ms 加 2px 的「吸附」位移（当前只有磁贴弹跳）；减少动态下全部 1ms（已验证 `.rm` / `.rm-user`）。

## 核心动作 ②：翻面开关（通知偏好 / 减少动态）

## 核心动作 ③：取下 / 放回（收藏管理）与门上的磁吸
- 触发：收藏页每张传单右上角 `×`（`data-act="unfav"`）。
- 变化：该格 `.fcell.leaving`：`translateY(120px) rotate(6deg)` + 淡出，`380ms cubic-bezier(.2,.9,.3,1.04)`；380ms 后 `act('unfavorite')`，网格重排；底部撤销条 `.undo` 上滑 300ms；`holdKey('undo', 10000)`。
- 放回：`act('favorite')` → 传单回到网格首位（按收藏时间倒序），toast「已放回 · …」；最后一张取下 → 空态「还没有收藏 / 遇到想去的，留在这里。/ 去找局」（去找局进入入局接缝）。

- 实际观察（`motion-1/`，13 张收藏变体，0.5×）：第 2–6 帧取下的传单向下滑出，第 7–10 帧相邻格沿网格滑行补位（可见两张传单短暂交叠，属 FLIP 过渡中的正常现象），撤销条上滑；放回后传单从首位出现，其余格再滑回原位。
- 建议值：取下的传单落点可做成「滑入门底回收槽」（当前只是向下淡出）；FLIP 位移可改为 320ms 更轻快。

## 核心动作 ①：拉链展开 —— 进入与返回任何口袋（`motion-1/`）
- 触发：点口袋任何位置（`.pkhit`，整行可点，不露控件 — Yohji SS99），或拖动橙色拉片 `.pull`（`setPointerCapture`，`touch-action:none`）。贴袋（城市 / 洗标 / 最里层）没有拉链，直接从袋口展开。
- 起点：`JU.fx.rectIn(el.closest('.pk'))` 取口袋矩形，袋口 `mouth = {x: from.x + zx·wk, y: from.y + mouth·wk, len: zw·wk}`；`.bag` 以 `translateY(mouth.y)` 挂在袋口，`clip-path: polygon` 只露出一条从 `mouth.x` 到 `mouth.x + len·p` 的缝（高 `10 + 48p` px），缝的下沿是一条会被拉下来的下唇 `.lip`（下半排牙 + 布带，`top = h − 16`）。
- 受力 / 关键变化（zip 阶段）：点击时 `p 0 → 1`，`clip-path 380ms linear`，拉头同速滑到右端；拖动时 `p = dx / (len − 22)`，`transition:none`，缝随手指张开，松手 `p ≥ .45` 补完（380ms），否则 `unzip`（300ms）拉回；轻点拉片等同点击。
- 内容接替：缝里直接露出袋布与页头（「个人资料」的标题从缝里露出来），不另做载体层——口袋里的东西就是页面。
- 落定（expand 阶段）：`clip-path` 从缝过渡到整个袋面、`transform` 从袋口回到 0，`480ms cubic-bezier(.2,.8,.2,1)`；下唇同节奏滑到底并淡出；遮罩 `rgba(10,8,12,.3)` 420ms、里布 `brightness(.66) + scale(.985)` 460ms。然后 `phase:'in'`，`clip-path` 保持整面多边形（为返回插值）。
- 返回（collapse → unzip）：袋面 420ms `cubic-bezier(.4,0,.6,1)` 缩回袋口的缝并移回 `mouth.y`，再 300ms 拉合（缝的右端随拉头回到左端），卸载后拉头 `sc06-pullback` 回弹 6px（420ms）。从索引跳进（无起点）时返回为 240ms 淡出。
- 中断 / 重复：拖动中松手未过阈值 → 拉合；`goBack` 只在 `phase==='in'` 响应；再次点口袋在动画中被 `bag` 存在挡住；重播（面板「重播上一动效」）先 `beforeReplay('zip')` 卸载袋子再用记住的袋口矩形重放。
- 实际观察（`motion-1/`，0.5×）：f01–f05 缝随拉头张开、「个人资料」标题从缝里露出，f05–f06 袋面向上展开盖满，f14–f19 返回时缩回缝再拉合；f26–f33 拖动收藏袋拉片到 75% 松手后补完并展开。减少动态下（`.rm` / `.rm-user`）全部 1ms，直接呈现落定态。
- 建议值：zip 阶段可按拉头位置做 2–3px 的布面起皱（当前缝是直边矩形）；clip-path 为 transition 而非 keyframes，面板关键帧滑杆对它不生效（只对按扣与重织有效）。

## 核心动作 ②：按扣开关（`motion-2/`）
- 触发：通知页六类提醒的 `.snap`（`onPointerDown` 压下、`onClick` 扣合）与外观页「减少动态」。写入 `setNotifyPref / setReduceMotion` 立即生效（失败：面板武装后帽子停在原态 + 提示）。
- 分段：按下 → `.pressing`：帽 `scale(.86)`、投影消失（凹陷）；松开 → 引擎写入（开 ↔ 关的帽面即时换）→ `.clicked` 播 360ms `sc06-snapclick`（.86 → 1.08 → .98 → 1）；文字 ON / OFF · 开 / 关 同时更新（不只靠颜色）。
- 实际观察（`motion-2/`，0.5×）：f01 压下（帽缩小），f02 起帽面变为灰底座「OFF 关」并回弹，f11 再点回到橙帽「ON 开」。

## 核心动作 ③：重织织唛（资料保存，`motion-3/`）
- 触发：编辑资料 → 「保存 · 重织织唛」。按钮 420ms「重织中…」→ `saveProfile`（校验不过 → 逐字段红字；武装失败 → 「本机保存失败，请重试」+ 重试，输入保留）→ 成功回到资料页（`.pg.pop`）→ 若称呼改变，织唛上的名字层 `.wv` 播放：`.ly.old` `sc06-unpick`（`clip-path:inset(0 0 0 0 → 0 0 0 100%)`，640ms `cubic-bezier(.4,0,.6,1)`，旧字从左到右被拆掉，拆线梭 `.sh.un` 同步从左扫到右，拖着两根松线）→ `.ly.new` `sc06-weave`（`inset(0 100% 0 0 → 0)`，900ms，延迟 640ms，新字从左到右织出，织梭 `.sh.we` 同步）；总长 1540ms；`afterKey('reweave',1600)` 后清掉动画层。toast「已保存 · 织唛已重织，新资料只用于之后的报名」2600ms。
- 关键帧：`.scrub` 下两段都 `animation-play-state:paused`，`animation-delay` 按 `--frame` 反推（第二段 `calc((640ms − frame·1540ms)·k)`），滑杆可停在拆到一半 / 织到一半。

## 核心动作 ①：刷新翻页（进入任何二级页 / 切换底栏 / 返回）
- 触发：点首页任一行、底栏任一段、页头「‹ 返回」、表单保存成功后的回退。`go() / root() / pop()` 都走 `refresh(fn)`。
- 起始 → 反相（0–120ms）：`.e-body.flash{filter:invert(1)}`——内容区整块反相（底色变成近黑 `#16171b`，黑字变白，橙方块变蓝），状态条与底栏不动（只刷新内容区）。时长 `after(120)`，随 0.5× 变 240ms。
- 内容接替（120ms）：定时器到点后一次性换页（`setState({view})`），同时反相撤销，新页以 `.e-pg.settle` 出现。不做位移、不做缩放（SM03 的 fade-through 只取「不共享位移方向」这一点）。
- 残影清除（120–~420ms）：`.e-pg.settle>*` 每个直接子元素跑 `sc07-settle`（160ms linear，`opacity .32` 保持到 70% 再到 1），延迟按行错峰 0 / 60 / 120 / 180 / 240 / ≥300ms（REF16 的按列错峰）；灰色半透明的新内容就是「残影」，逐行变黑即「清除」。
- 落定：`afterKey('settle', 520)` 去掉 `.settle`；首页返回时 `after(20)` 恢复离开前的 `scrollTop`，二级页回到顶部。
- 返回：与进入完全相同的一次局部刷新（没有「反向」动画，墨水屏只有刷新）。
- 中断 / 重复：刷新进行中再触发导航，`refresh()` 直接套用新状态、不叠加第二次反相；`.rm`（评审）下 `after` 为 0ms、动画 1ms → 直接结果；用户偏好「减少动态」下 `refresh()` 跳过反相与 settle（一帧完成，`flashRow` 也跳过）。关键帧：`.scrub .e-pg.settle>*` 用 `animation-delay: calc(-1 * var(--frame) * 460ms)` 冻结。重播：`beforeReplay('refresh')` 把 view / stack / tab 放回起点再执行同一次导航。
- 实际观察（`motion-1/`，0.5×）：f01–f02 两帧整块反相（约 240ms），f03 起我的记录页以灰字出现，f03→f05 组头与条目逐行变黑，f06 稳定；返回 f12–f13 反相、f14–f16 首页从灰到黑、滚动位置不变。无白块、无文字错位。
- 建议值：真机墨水屏的反相常在 80–100ms，这里为可见性取 120ms；若用于真实产品，残影阶段可改成「旧页灰化 + 新页叠印」（需要保留旧页快照），当前实现只对新内容做灰→黑，是一种可被接受的简化。

## 核心动作 ②：方块开关（通知六类、减少动态）
- 触发：点 `.e-trow`（整行可点，`data-act="toggle"`），`act('setNotifyPref')` 立即写入；失败（面板武装）则数据不变、状态行写「本机保存失败，请重试 · 开关保持原状」，方块停在原态。
- 变化：`.e-sq` 的 `background-color 80ms linear`（SM01 ≤100ms，无过冲）；「开 / 关」字即时换；同一帧给该行加 `.flash`（`filter:invert(1)`，行底色是纸色所以反相为黑行白字），`afterKey('rowflash', 110)` 撤销 —— 这就是「伴随局部刷新」。
- 中断 / 重复：连点同一行时 `afterKey` 保证只有一个撤销计时器；重播：`beforeReplay('toggle')` 先把该项写回点击前的值，再重做一次同向切换。减少动态：行不反相，方块 1ms 变色。
- 实际观察（`motion-2/`，0.5×）：f02 该行整行反相一帧（约 220ms）且方块已变空心，f03 恢复、字变「关」；再点 f09–f10 同样反相后填实。其他行不动，文字不糊。
- 建议值：可在反相撤销后让「开 / 关」字多留 40ms 的灰态作为微残影；当前为干脆起见未做。

## 核心动作 ③：反相落定（资料保存、补充 / 异议 / 申诉保存、举报补充、反馈提交）
- 触发：资料编辑页「保存」→ 按钮变「保存中…」并禁用（`after(360)` 可见的处理中）→ 引擎写入。
- 发展：写入成功后走一次 ① 的局部刷新回到查看页（`doNav`，mode `pop`），刷新结束后 `after(150)` → `commit(changed)`：被改动的行（`.e-kv.print` / `.e-row.print`）跑 `sc07-print`（520ms，`steps(1,end)`：0–62% 黑底白字「印出」新值，62% 后瞬间回到纸色黑字）；标签、引导点在反相期间都跟随 `currentColor` 变白。
- 落定：`afterKey('print', 640)` 清掉 `print`，页面静止；查看页顶部留一只薄框「已保存 · 新资料只用于之后的报名」。失败：编辑页出现黑底白字的「没有保存」框 + 「重试」，输入保留；校验失败：各字段下一行错误文字（前置橙方块），不写入。

- 中断 / 重复 / 重播：`commit()` 先清空再 16ms 后置位，保证重播能重新触发动画；`.scrub .e-kv.print` 以 `--frame` 冻结；减少动态 1ms。
- 实际观察（`motion-3/`，0.5×）：f03–f06「保存中…」禁用态约 700ms；f07–f08 内容区反相；f09–f12 个人资料页灰→黑，称呼行黑底白字印出「阿禾二」；f13 起恢复、薄框「已保存」在位；返回首页后称呼、组内「称呼」行都是新值。
- 建议值：印出时长可随改动字段数递增（1 行 520ms，3 行可错峰 60ms），当前三行同时印。

## 接缝手势（入局 01）—— V27 参数逐字

## 核心动作 ①：膨胀进入 / 收缩返回（点任一软体 → 全屏页）
- 触发：点首页任一软体（或接缝列表行）。`open()` 用 `JU.fx.rectIn(el.closest('.sb'))` 取起点矩形、`getComputedStyle` 取起点圆角与底色、标签字号 / 颜色，写入 `.page` 的内联变量 `--sc09-x0/y0/w0/h0/r0/c0/t0/tc0`；同时为首页其余 `[data-rid]` 软体计算远离起点中心的单位向量 × 54px，写成内联 `transform: translate(dx,dy) scale(.86)`。
- 起始：被点的软体加 `ghost`（opacity 0），`.page` 以关键帧 `sc09-inflate` 从起点矩形 / 起点色开始（`from{left:var(--sc09-x0)…}`），`.carry` 层在同一位置显示该软体的内容（我：称呼 / 微信 / 邮箱；其余：值 + 副文；列表行：标题 + 时间地点）。
- 受力 / 关键变化：页面 `480ms cubic-bezier(.3,.75,.3,1)` 膨胀到 `0,0,100%,100%`，圆角到 0，底色从软体色过渡到页面底色；页头 `.phead` 内边距 `16/20px → 54/18px`、标题字号从软体标签 `--sc09-t0`（13px 灰）长到 22px 墨，返回按钮宽度 `0 → 40px`（头部始终钉在膨胀体的顶边，REF69）；其余软体用 `520ms cubic-bezier(.3,1.45,.5,1)` 的弹簧被挤开并缩到 .86。
- 内容接替：`.carry` 延迟 40ms、220ms 淡出；`.pbody` 延迟 200ms、260ms 淡入；页副标题延迟 260ms 淡入。列表行来源（`rowlift`）时页标题改为延迟 200ms 淡入，避免与行标题重叠。
- 落定：`animation-fill-mode: both` 保持全屏；`.scrub` 下 `animation-play-state: paused` + `animation-delay: -frame × 480ms`，关键帧可拖。
- 返回：`close()` → `deflating`：独立关键帧 `sc09-deflate`（400ms `cubic-bezier(.45,.05,.35,1)`，从全屏到起点矩形；不用 `animation-direction: reverse`，因同名动画不会重启）；`.pbody` 140ms 淡出，`.carry` 延迟 160ms 淡入；400ms 后卸载，首页挤开的软体弹回，被点的软体播 `sc09-settle`（`scale 1.04 → .985 → 1`，460ms）。
- 外观页为半高：`sc09-inflate-half` 到 `top:300px; height:calc(100% - 300px)`，上方挤小的软体直接显示预览色。
- 中断 / 重复：`lift.phase==='out'` 期间再点软体会直接以 `in` 打开；页内多级（收藏 → 详情）用 `.pg.push`（36px 滑入 320ms）/ `.pg.pop`（−24px）。重播：`beforeReplay('inflate')` 先无动画关页，再重放保存的起点与挤压向量。减少动态下全部 1ms（`.rm` / `.rm-user`）。
- 实际观察（`motion-1/`，0.5×）：f01–f04 页面从「我」的矩形长到全屏，称呼 / 微信 / 邮箱随页面一起放大后淡出，其余软体向外被挤小；f12–f17 收缩回「我」的位置，挤开的软体弹回，无白块、无残影；0.5× 下 920ms 的膨胀被约 150ms 一张的截图抽成 6 帧。
- 建议值：膨胀曲线可再慢 40ms 的首段让起点更可读（480 → 520ms）；返回时可在最后 60ms 加 2px 的「落座」位移（当前只有 settle 缩放）。

## 核心动作 ②：软球开关（SM01 三层节奏）
- 触发：点 `.tg`；`act('setNotifyPref')` 立即写入，`tgMoved[key]=true` 后才挂关键帧（避免页面打开时自动演一遍）。
- 分段（当前代码值，总长 100ms）：① 轨道颜色 `--clay2 → --sage`，`40ms linear`（先于位移，≥33ms 可感知）；② 球 `sc09-roll-on` 100ms linear：0% `x0 scale(.75)` → 30% `x3 scale(.9)` → 62% `x16 scale(1.2,.84)`（挤压胶囊）→ 86% `x25.5`（1.5px 过冲）→ 100% `x24 scale(1)`；轨道同步 `sc09-trk`（55% 处 `scale(1.04,.93)`）；③ 勾 `.ck` 延迟 60ms、40ms 淡入。关态 `sc09-roll-off` 镜像但不过冲（42% 处挤压，终点 `scale(.75)` 小球、无勾）。

- 实际观察（`motion-2/`，0.5×）：f01 轨道已褪色而球未动（颜色先走）；f02 球在中段呈扁椭圆、勾已淡；f03 球到左端缩小；反向 f09–f12 轨道先变鼠尾草、球滚到右端放大、勾最后浮出。
- 建议值：真机 60fps 下可把轨道色阶段提到 50ms；过冲 1.5px 在 2× 屏上约 3 物理像素，符合 SM01「1–2px」。

## 核心动作 ③：保存脉冲（显式保存：资料 / 补充 / 异议 / 申诉 / 举报补充 / 反馈）

- 第一杆：「我」大牌 140×228（称呼竖排 Noto Serif SC 500 32px，>3 字时 20px 多列竖排，`right:34px` 以免压到右侧竖排「个人资料」小标；微信 / 邮箱横排 12.5px 标签 + Instrument Serif 14px 值；右边缘 7.5px 竖排循环小字「JU ✕ 2026 ✕ NYC」）；「记录」「举报」中牌 96×132（竖排分区名 15px + Instrument Serif 24px 数字 + 11px 状态行，待核实 / 需补充用红）。
- 第二杆：收藏小牌 84×126，每局一张（标题 11.5px 最多 3 行、日期 Instrument Serif 12px、城市 / 街区 10px；底部 9px「可报名」+ 报名关系），间距 96px，`.favrail` 横向滚动（`many` 变体 13 张）；空杆 = 虚线小纸条「杆上还空着」。
- 第三杆：偏好牌 80×116（城市 / 通知 / 外观 / 动态：竖排分区名 14px + 13.5px 当前值，数字用 Instrument Serif 22px）。第四杆：64×84 小牌（帮助 / 隐私 / 账户 / 关于，只有竖排名）。底部 64px 导航搁板 `.ledge`（四个挂钩符号，当前项红）。

## 核心动作 ①：拉牌（拖下一张吊牌 → 它变成页面；松手回弹悬挂）
- 触发：首页任一吊牌上 `pointerdown` → 纵向位移 >6px 判定为拉（横向交给收藏杆滚动，`touch-action:pan-x`）；点击（无位移）同样打开。
- 受力：`dy = clamp(0, Δy × .9, 110)`；`.hang.pulling` 无过渡，绳 SVG 高度 = L + 12 + dy（绳跟着拉长），侧弯随 dy 减到 0（绷直），牌 `scale(1 + dy/520)`，落影放大到 `0 24px 30px -14px`；`dy > 64` → `.over`：绳变红、杆钩处剪刀 220ms `cubic-bezier(.18,1.5,.36,1)` 弹出。
- 释放：过阈值 → `openItem`：用 `JU.fx.rectIn(.tag)` 取牌的当前矩形（已含拉下位移与缩放），`.sheet` 以内联 `left/top/width/height` 出现在该处（`start`），牌本体 `.ghost`；16ms 后切 `in`，`left/top/width/height` 以 440ms `cubic-bezier(.2,.9,.3,1.02)` 过渡到整页；墙 `.dim` 420ms；`.carry` 层（竖排称呼 + 微信 / 邮箱）延迟 200ms 用 200ms 淡出，页头 200ms 后 240ms 淡入，正文 240ms 后 260ms 淡入。未过阈值 → `pull=null`，绳与牌回到原长（380ms `cubic-bezier(.2,.9,.3,1.04)`），并播放摆动。
- 摆动（REF37 的滞后）：外层 `.hang` 以杆钩为轴 `sc10-swing` 1100ms（0 → −5° → 3.4° → −1.4° → 0），内层 `.tag` 以孔眼为轴 `sc10-swing-lag` 同时长但相位相反（0 → 2.6° → −1.9° → .7° → 0）：孔眼先动、牌底拖尾，过摆两次后静止；只在交互后播放，无常驻动画。
- 返回：「挂回」→ `out`：页面回到起点矩形（440ms），页头 / 正文 120ms 淡出、`.carry` 淡入；440ms 后卸载页面，牌取消 `.ghost` 并播放同一摆动（`swingTag(item)`）。索引跳转打开的页面没有起点矩形，返回时 200ms 下沉淡出。
- 中断 / 重复：打开途中再点其它牌被 `lift` 挡住；页内多级（收藏 → 详情、记录 → 详情 → 表单）用 `.pg` 的 `sc10-pushin`（42px → 0，320ms）/ `sc10-popin`（−30px → 0）；重播（`beforeReplay('pull-tag')`）先回到首页再重放。
- 实际观察（`motion-1/`，0.5×）：f01–f06 绳随拖动拉长、f06 变红并出现剪刀；f07 页面从牌位放大（携带称呼与微信 / 邮箱）；f09–f13 页面落定；f14–f16 页面缩回牌位并显示牌面内容；f17–f19 牌回到杆上并摆动。
- 建议值：拉牌时可给相邻两张牌 1–2px 的反向位移（杆受力）；真机上阈值 64px 可按屏高比例取 7.5%。

## 核心动作 ②：挂牌收藏 / 剪绳取消（邻牌让位，空杆空态）
- 剪绳：收藏页每根绳上有剪刀按钮（`data-act="unfav"`）。点下 → `.fcell.cut`：绳变红并 `clip-path` 只留上段 40%（`sc10-strcut` 560ms），牌 `sc10-fall` 560ms `cubic-bezier(.5,0,.85,.4)`：`translateY(150px) rotate(9deg)`，后 70% 淡出；杆 `.rail.spring` 520ms（−2.5px → 1.2px → 0）回弹。560ms 后才调用 `engine.unfavorite`（数据修改与牌落下同步）。
- 让位（FLIP）：调用引擎前记录所有 `.fcell[data-rid]` 的矩形（`measureCells`），`componentDidUpdate` 里量新矩形，差值写成内联 `transform:translate(dx,dy)` + `.noT`（无过渡），20ms 后清除 → 以 `.hang` 的 380ms `cubic-bezier(.2,.9,.3,1.04)` 过渡到新位置（跨行补位也成立）。
- 挂回 / 收藏：底部纸条「已剪下 · … · 挂回」（`holdKey('undo', 10000)`）或详情页「挂上 · 收藏」→ `hangFav`：引擎写入后新牌 `.hung`：`sc10-hung` 1100ms（从 −26px、−7° 落到杆上，再 5° → −3.2° → 1.3° → 0 摆两下），内层牌同样滞后；相邻牌同样 FLIP 让位。最后一张剪下 → `effect.last` → 列表为空杆 + `COPY.favEmpty`「还没有收藏 / 遇到想去的，留在这里。/ 去找局」，首页第二杆变成「杆上还空着」小纸条。
- 实际观察（`motion-2/`，0.5×）：f02–f06 绳断、牌旋转下落淡出；f06–f08 右侧「深夜救急火锅局」平滑补到中间；f09 撤销纸条；f12–f14 点「挂回」后新牌从上方落到首位并摆动，其余两张右移让位；计数 2 → 3。
- 建议值：落下的牌可在离开可视区前与下一根杆碰一下（目前直接淡出）；撤销窗口 10s 可缩到 6s。

## 核心动作 ③：打孔开关（通知偏好 / 减少动态）
- 触发：`.punch` 按钮（`data-act="toggle"`）；`act('setNotifyPref')` 立即写入，失败时控件不变并 toast。
- 开（打孔）：`.punching` → 钢制冲头环 `.die`（30px，3px 深灰描边）`sc10-die` 340ms：`scale(1.7)` 淡入到 `scale(1)` 停 25% 再放大淡出；圆孔 `.hole` 200ms 从 `scale(.001)` 张开（透光：径向高光 + 内阴影 + 外发光）；纸屑 `.chad` 延迟 120ms 落下 520ms（`translate(6px,26px) rotate(70°)` 淡出）；补孔贴 `.patch` 同时 `rotate(−10°) scale(.6) translateY(−6px)` 剥离淡出。
- 关（贴补孔贴）：`.patching` → 牛皮纸方贴 `sc10-patch` 300ms `cubic-bezier(.18,1.4,.36,1)`：从 `rotate(14°) scale(1.3) translateY(−10px)` 压到 `rotate(7°) scale(1)`；圆孔缩回。「开 / 关」字随之切换（HIG：形状 + 文字，不只靠颜色）。
- 实际观察（`motion-3/`，0.5×）：f02 点后补孔贴压到孔位、计数 6/6 → 5/6；f08–f09 再点出现冲头环与透光孔，f10 后静止；文字全程清晰。
- 建议值：冲头落下时可加 1px 的整行下压（`translateY(1px)` 80ms）作为「受力」。

## 其他运动
- 挂一张（城市 / 卡纸样）：`.opt.hung .otag` 上提 24px + 出现 20px 绳，380ms `cubic-bezier(.2,.9,.3,1.04)`；新挂的那张再播 `sc10-optswing` 900ms（−4° → 2.6° → −1° → 0）。外观：预览只改 `data-skin`（视图态），「应用」写入并显示「已应用」2600ms，「取消预览」恢复；`--stock/--wall/--ink` 650ms `cubic-bezier(.22,1,.36,1)`。
- 重印牌面（资料保存）：按钮 420ms「重印中…」→ 引擎写入 → 回到查看页：`.reprint` 滚筒条从顶到底 640ms `cubic-bezier(.4,0,.3,1)`，字段 `.inkin` 520ms 由 15% 墨到实墨；失败：`.alert` 抖动 360ms + 重试，输入保留。
- 剪绳退出（账户）：确认牌从顶端垂下 420ms（绳为红），会话绳上挂剪刀；确认后 `.hang.sess.cut`：绳断、会话牌落下 600ms → 引擎 `endDemoSession` → 「演示会话已剪断」+ 红色绳头；「重新挂上」恢复。
- 入局接缝滑动（V27 逐字）：死区 6px、轴比 1.25、右滑 >82px 挂上 / 左滑 <−82px 拿下、错误方向 ×0.26 + 灰洗层「已经收着了 / 还没收藏」、夹 ±190px、旋转 `dx×0.012°`（以牌顶两只孔眼连线为轴）、释放 `.5s cubic-bezier(.2,.9,.3,1.04)`；收藏角标 = 牌角透光小孔里的红 ★ `scale(.35→1)` 520ms。观察（`motion-seam-swipe/`）：收进 / 拿出 / 未收藏时左滑的阻尼三种情形与设置列表、我的局挂钩同步。
- 减少动态：`.rm` / `.rm-user` 下全部 1ms；状态（孔 / 贴、挂 / 平、页面、纸条）直接呈现。

## 已知问题（主负责人自检）
1. 拉牌时内容层只携带称呼与两行值，页面落定前约 100ms 牌面偏空（已把 carry 淡出延后到 200ms，仍可再贴近落定时刻）。
2. 收藏杆小牌只有标题 / 日期 / 地点，跨城市只显示城市名（无时区）；详情里才有「当地时间」。
3. 无真机触控验证：`touch-action:pan-x`（首页吊牌）与 `pan-y`（接缝行）只按规范设置。
4. 共享核心：`derive.feed(d, filter)` 只认 `'fav'`，SC05 传的是 `'favs'`，其「只看收藏」实际未过滤（本方案已用 `'fav'`）。
