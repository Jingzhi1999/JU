# 「设置」十套 · 参考映射（每套 5–8 例，跨 ≥3 类，写出具体转译）

编号：REFnn = 上一轮继承案例（`research/ledger.md`，证据 `research/evidence/`）；SUnn / SEnn / SDnn / SMnn = 本轮新增（`settings/research/ledger.md`）。类别：ui / motion / editorial / designer / award。「转译」写的是该案例的哪一个可见事实被用在本套的哪个组件上；不是形容词。动效类案例以「已看动效」为准。SM（设置相关动效新增）到位后补入对应套。
