# SC03 文件袋 · 规格与核心动作（当前代码值 · 实际观察 · 建议值分开）

源文件：`settings/concepts/src/SC03.dc.html`。证据：`settings/evidence/SC03/`（命名状态 PNG；`motion-1/2/3/`、`motion-drag/`、`motion-seam-swipe/`、`coverage/` 为抽帧 JPEG）。验证环境：容器内无头 Chromium（SwiftShader，无 GPU），390×844，Playwright 抽帧；三个核心动作用评审面板的关键帧（`inst.scrubTo(n)`）定格采样，另有 0.5× 实时帧；未做真机。360 / 430 宽用 `widths.cjs` 核对（整个场景放在 `.wall` 390×844 内，由 mixin `fitWidth(390)` 写 `--wk` 等比缩放，横向溢出为空）。

## 构图与视觉参数（当前代码值）
- 桌面 `.desk`：三种背景（棉糖 / 光晕 / 落日）各一层 `.sk`，用 `opacity` 650ms `cubic-bezier(.22,1,.36,1)` 交叉淡入（R3 的时长）；外观预览时只换视图态，不写数据。袋子是半透明的，所以换肤 = 整叠袋子下面的桌面换色，所有袋面都跟着变。
- 一叠五个文件袋 `.fold`：宽 310（x 20–330），高 456；首页按 62px 带状错开（`GEO.slot0 70, pitch 62`）：帮助 70 / 记录 132 / 偏好 194 / 收藏 256 / 资料 318（最前，底 774，托盘 780）。每个袋子露出的 62px 带 `.strip` = 分组名 12px/500（字距 .08em）+ 当前值两行 12.5px（line-height 1.3）；收藏带右侧 DM Mono 28px 计数；需要处理的值用红 `#c8362c`，记录标签加 8px 红点。
- 材质：`.fback` 白 .40 + `backdrop-filter: blur(14px) saturate(1.12)` + 内侧 1px 白高光 + 外侧 1px 深线 + 投影；`.ffront` 前片 = 白雾渐变（静止 .34 / 退后 .62 / 抽出 .12）+ `::after` 用内联 SVG `feTurbulence(.85, 2 oct)` 去饱和作塑料纹（multiply, .5）；袋口 `.fback::before` 12px 暗边。内容层 `.fbody` 退后时 `blur(1.3px)`，抽出时 0。袋子内背面印一个超大浅字（`.wm`，92px/700，竖排，opacity .045）作为分组水印。
- 索引标签 `.tabx`：46×48，贴在右缘外 40px（`right:-40px`，叠在袋边 6px），哑光色：帮助 `#b3a6c6` / 记录 `#8dbb98` / 偏好 `#e8c158` / 收藏 `#f08868` / 资料 `#86a0e8`；左侧 9px 暗边表示贴纸包过袋边；字 12px/500 竖排（`writing-mode: vertical-rl`，字距 .14em）黑字。首页标签各在自己袋带的顶部（+6px）；抽出后：抽出袋在顶部 70，其余四袋按原顺序退到 132 / 194 / 256 / 318（只露标签）。
- 纸：`.ppr`（袋内纸片，`#fffdf7`，2px 圆角，细投影，`--r` ±.4° 颤动）、`.slip`（列表条，同材质，可折叠离场）、`.pbig`（抽出的大纸 12,40,366×736）。
- 控件：按扣 `.snap` 34px（环 + 圆顶；扣上 = 环着色 + 圆顶压下 `translateY(1px) scale(.84)` + 内阴影；弹开 = 灰环 + 圆顶抬起 `translateY(-2px)` + 投影）用于开关 / 单选（城市、背景）/ 多选（通知类别）/ 收藏标记（我的局、举报对象）。贴纸按钮 `.stk`（墨黑 / 白塑料 / 红 / 标签色）用于动作与导航。输入 = 纸上的印刷线（`.fld` 底线 1.5px，聚焦 2px 蓝）；长文本 `textarea` 带横格纸底纹（28px 行距）。
- 字体：Noto Sans SC（400/500/700）+ DM Mono（400/500）；称呼 28px/700（>7 字 21–22px 两行）；标签 12px；正文 13–14px；说明 11.5–12px。色板：墨 `#1f1d1b`、次 `#6b665d`、纸 `#fffdf7`、红 `#c8362c`、绿 `#3f7f4f`、蓝 `#4b63c0`；投影 `rgba(40,30,18,α)`。
- 层级：桌面 0 → 袋子 z 1–5（抽出 9）→ 托盘 8 → 大纸 11/12 → 系统弹窗 / 确认 20–21 → 撤销 30 → toast 40。

## 核心动作 ①：抽袋（点或拖索引标签）
- 触发：点标签（`tabClick`）、点袋带（`.strip`）、或拖标签过阈值；再点抽出袋自己的标签 = 放回。
- 起始：`setState({pull:{key, phase:'pulling'}})`；该袋的静态几何立即写成抽出位（top 70 / height 710 / z 9），其余四袋 `top` 过渡到新槽（420ms `cubic-bezier(.2,.8,.2,1)`）并 `scale(.97)`、前片雾 .34→.62、内容 blur 0→1.3px。
- 受力 / 关键变化：`@keyframes sc03-pull` 560ms `cubic-bezier(.4,.05,.2,1)`（`animation-fill-mode both`，`.fold.pulling{transition:none}` 防止 top 过渡叠加）：0–26%：以左下角为支点（`transform-origin: 0 100%`）`rotate(-6deg) translateX(10px)`，高度保持 456，z 仍为原层级（REF43 扇开）；26→30%：z 跳到 9；30–100%：`translateY(var(--dy0)) → 0`、高度 456→710、旋转回 0（REF17：其余袋退后 3% 加雾）。
- 内容接替：`.fbody` 同步 `sc03-focus`（0–45% blur 1.4px → 100% 0），`.ffront` `sc03-clear`（.34 → .12）：内容随袋子到前而对焦。
- 落定：560ms 后 `phase:'pulled'`（静态几何，无 transform），`.fbody` 改为可滚动；标签带内出现「‹ 放回」贴纸。
- 返回（插回）：`phase:'out'`：静态几何直接写回首页槽位，`sc03-insert` 420ms 从 `translateY(-dy0)`、高 710 回到 0 / 456，z 在 68→72% 时从 9 回到原层级（滑入叠中被前袋遮住）；其余四袋同时过渡回原槽（REF40 后袋顶上）。420ms 后 `pull:null`。
- 中断 / 重复：抽出中再点别的标签 → 先插回（300ms 后）再抽；`afterKey('pull')` 保证只有一个落定定时器；减少动态下所有 1ms + `after` 归零，直接呈现抽出态；重播（`motion('pull')`）前 `beforeReplay` 先把 `pull` 清空。
- 实际观察（`motion-1/`，关键帧 0/10/20/30/42/56/72/90% + 插回 0–80%）：f01–f03 袋子以左下角为轴向右上扇出、标签抬起；f04–f07 向上滑到最前、变高、文字由糊到清；插回时整袋向下滑入槽位，其余带回位。
- 建议值：扇开阶段可再加 2px 的 `translateY(-2px)` 抬起感；插回时可让下一袋先抬 4px 再落（当前只有槽位过渡）。

## 拖动预览（SM02）
- `tabDown/Move/Up`：死区 6px；进度 `p = clamp(max(dx, -dy) / 80, 0, 1)`；拖动中袋子 `translate(10p px, -24p px) rotate(-6·min(1,1.4p)°)`，z 9，`transition:none`；袋口上方 `.peek`（第一张纸的标题：称呼 / 第一条收藏 / 通知摘要 / 第一条记录 / 常见问题）按 `min(1, p/.6)` 淡入并从 34px 下方升起 —— 这是「下一状态才有的内容」的预览。
- 阈值 p ≥ .6（48px）：松手 → `pullFolder(key, fast, pose)` 用 `sc03-pull-fast` 200ms 从当前姿态（`--dxd/--dyd/--rot`）直接到前；取消：`tabDrag:null`，袋子 220ms `cubic-bezier(.2,.7,.2,1)` 回位、peek 200ms 淡出，无回弹。
- 实际观察（`motion-drag/`）：拖 36px 时袋子微扇、纸角从袋口探出（第一行标题可读）、松手回位；拖 (70,−30) 过阈值后 200ms 内到前。

## 核心动作 ②：按扣开关（通知类别 / 减少动态 / 城市单选 / 背景单选 / 收藏标记）
- 触发：点 `.snap`（`data-act="toggle"`，`data-rid=类别`）；`act('setNotifyPref')` 即时写入；失败（面板武装）时数据不变、toast 报错、按扣停在原态。
- 变化：环色先变（160ms），圆顶 180ms `cubic-bezier(.2,.9,.3,1.25)` 压下 / 抬起（只在抬起方向过冲），同时整枚按扣播 `sc03-press` 260ms（`scale(1.1,.86) → (.95,1.04) → 1`，塑料形变）；旁边 11px 状态字「开 / 关」同步；上方摘要行「已开启 N 类：…」逐项增减（SM06）；首页偏好带的「提醒 N/6 类开启」同步。
- 实际观察（`motion-2/`，关键帧 15/38/68%）：扣上 → 弹开时圆顶变白抬起、环变灰、文字「关」出现、摘要从 6 类变 5 类；形变幅度在 300px 缩略下肉眼不明显。
- 建议值：形变可加到 `scale(1.14,.82)`；扣合瞬间可加 1px 的整行下沉表示「咔哒」。

## 核心动作 ③：抽纸编辑（个人资料；同一机制用于隐私 / 账户 / 收藏详情 / 记录 / 举报 / 反馈 / 规则 / 接缝详情与举报）
- 触发：点袋内纸片（`.ppr` / `.slip`）；`openPaper(name, id, ev)` 用 `rectOf(el.closest('.ppr,.slip,.mrow'))` 取起点矩形（已除以 `--wk`），源纸片加 `ghost`（opacity 0）。
- 起始 → 关键变化：`.pbig.lifting` `sc03-lift` 440ms `cubic-bezier(.42,.05,.2,1)`：`left/top/width/height` 从起点矩形（含 `--r0` 颤动角）到 12,40,366×736，投影由细到深；`.carry` 层从第一帧起就显示该纸片的内容（称呼大字 + 微信 / 邮箱一行；详情类为标题 + 时间地点）。抽出的纸在前片之外，不再受雾化。
- 内容接替：440ms 后 `phase:'in'`：`.carry` 60ms 后 160ms 淡出；页头 200ms 后 240ms 淡入；正文 240ms 后 260ms 淡入。袋子后退：`.app.paperon .fold.pulled .ffront` 雾 .30、内容 blur .6px；遮罩 `rgba(30,22,12,.2)`。
- 编辑：「编辑资料」→ 同一张纸进入编辑态（顶栏「取消 ｜ 编辑资料 ｜ 保存」，SU08），三行印刷线输入 + 逐字段校验；邮箱改动 → 发送验证码（本机测试码，59s 重发倒计时 `holdKey('resend')`，5 分钟过期）→ 验证通过才可保存；保存 420ms「保存中…」→ 引擎写入 → 回到查看态并印「✓ 已保存 · 刚刚 · 新资料只用于之后的报名」；失败 `.alert` 抖动 360ms + 重试，输入保留；未保存返回 → 纸条确认层（继续编辑 / 放弃修改）。
- 返回（插回）：`.pbig.dropping` `sc03-drop` 420ms 回到起点矩形；`.pbody/.phead` 100ms 淡出、`.carry` 立即显示新值；420ms 后卸载，源纸片取消 `ghost`，袋面透出新称呼（「阿禾二」）。无起点（索引跳转打开的纸）用 `DEFAULT_FROM` 落进袋内。
- 实际观察（`motion-3/`，关键帧 0/15/30/50/75% + 插回 15/40/65/88%）：纸从袋内槽位升起放大、带着「阿禾」大字，落定后表单淡入；保存后查看态出现「已保存」；放回时纸带着「阿禾二」缩回槽位，袋面随即显示新值。
- 建议值：纸抽出时可在前 80ms 加一次 −2° 的微旋（手指拉纸的随机感）；插回后可让下一张纸（隐私）上抬 3px 再落。

## 接缝手势（入局 01）—— V27 参数逐字（`JUS.FAV`）
- 死区 6px；`|dx| > |dy|×1.25` 判横向；右滑 > 82px 且未收藏 → 收进收藏；左滑 < −82px 且已收藏 → 拿出收藏；错误方向位移 ×0.26 + 灰洗层 + 「已经收着了 / 还没收藏」；正确方向夹 ±190px；纸片旋转 `dx×0.012°`；洗层不透明度 `min(1,|dx|/96)`（错误方向 ×0.5）；★ / ☆ 随之旋转 ±13°；释放回弹 `transform .5s cubic-bezier(.2,.9,.3,1.04)`；收藏贴纸（标签同色圆）`scale(.35→1)` 520ms `cubic-bezier(.18,1.5,.36,1)`。
- 实际观察（`motion-seam-swipe/`）：收进 / 已收着 / 拿出 / 未过阈值回弹四种情形与预期一致；toast 与「收藏 N」同步；设置首页收藏带、收藏袋列表、我的局按扣三处一致（`seam-consistency.png` 序列）。

## 其他运动
- 收藏拿出：`.slip.leaving` 360ms 向上滑出袋口（`translateY(-54px) rotate(-3deg)`）+ `max-height` 收到 0 让相邻让位；360ms 后引擎写入；底部纸条「放回」10s；最后一张 → 空态（标题 / 一句 / 去找局）。
- 系统权限：`requestPermission` → 系统弹窗样式的纸条 1300ms → `resolvePermission`（面板预设）→ toast。
- 外观：点小窗立即换桌面色（650ms），「取消预览 / 扣上」只在有未应用更改时出现；应用后「已扣上」2.6s。
- 封口贴（账户）：`.seal.peeling` 420ms `cubic-bezier(.4,0,.8,.4)` 向右上撕起并淡出，红钮才可按；确认纸条 300ms 上滑；结束态 → 重新开始后封口贴复原。
- 关键帧 / 暂停：`.scrub` 下 `sc03-pull / sc03-insert / sc03-lift / sc03-drop / sc03-press` 暂停在 `--frame`；减少动态（评审 `.rm` 与用户 `.rm-user`）全部 1ms。

## 已知问题（主负责人自检）
1. 抽出状态下内容较少的袋（收藏 3 条、帮助）下半是空的磨砂区，只靠水印填充；建议值：抽出高度可按内容收到 ≥ 430px。
2. 其余袋在退后时 `top` 过渡与抽出袋的关键帧同时开始，关键帧定格采样时它们已先到位；实时观看无此问题。
3. 按扣形变幅度小；落日背景下袋面偏橙，雾化文字对比降低但仍可读。
4. 无真机触控验证；`touch-action:none/pan-y` 仅按规范设置。
