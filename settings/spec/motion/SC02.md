# SC02 面板 · 动效与视觉参数记录

源文件 `settings/concepts/src/SC02.dc.html`；证据 `settings/evidence/SC02/`（`motion-1/ motion-2/ motion-3/` 各含 `sheet.png` + `log.json`）。「当前代码值」= 源码里的数；「实际观察」= 看截图帧序列得到的；「建议值」= 复看后认为更好的数（未改代码）。时长全部乘 `--k`（0.5× 时 ×2；评审减少动态 `.rm` 与用户偏好 `.rm-user` 下一律 1ms，并把 transition-delay 归零）。

## 0. 构造一句话

奶白搪瓷面板：黑色铭牌（身份）在最上，下面是模块化的凹槽，每个凹槽里放一件真实硬件——拨杆（偏好）、旋钮（城市 / 外观）、LED（系统权限 / 提醒服务 / 需要处理）、LCD 读数（当前值）、卡槽（收藏）、透明保护盖下的红钮（账户）。点一个模块，它从凹槽里抬起来变成全屏面板；面板内部的二级用 iOS 推入；返回时落回凹槽。

## 1. 核心动作 ① 拨杆开关（motion-1）

| 阶段 | 运动对象 | 当前代码值 | 实际观察（0.5×，70ms/帧） | 建议值 |
|---|---|---|---|---|
| 触发 | `button.sc02-lever`（data-act=toggle），整行可点 | 点击即 `engine.setNotifyPref`；失败则不动杆、toast「…拨杆已回到原位」 | 失败武装后：LED 不亮、杆不动、LCD toast 出现 | — |
| 颜色先走 | `.sc02-led`（杆左侧 8px） | `background / box-shadow 90ms` 无延迟；开 = 橙 `#ff5a1f` + 7px 晕 | 第 1 帧 LED 已亮，杆仍在底 | — |
| 杆后到 | `.sc02-head`（14×18 橙色杆头，slot 16×40） | 开：`sc02-lever-on 280ms cubic-bezier(.3,.6,.3,1)`，关键帧 0%→18px，38% 11px + scaleY(.9)（受压），55% 5px + scaleY(1.04)（过中点弹出），78% −2px（**只在开态落点过冲**），100% 0；关：`sc02-lever-off 240ms`，0→7px(scaleY .9)→14px→18px，无过冲 | 0.5× 下杆头在第 2–4 帧（140–280ms）运动，第 3 帧压扁、第 4 帧到顶 | 过冲 −2px 在 390 宽上刚好可见；若 1× 看不出可增到 −3px |
| 刻字最后 | `.sc02-marks b`（开 / 关，9px 刻字） | `color 120ms` 延迟 190ms（开）/ 150ms（关） | 「开」在杆到位后一帧才变黑 | — |
| 落定 | 整体 | 杆头 `translateY(0)`（开）/ `18px`（关）；LED 稳态；首页 NOTIFY 模块的六个 mini 拨杆同步 | 返回首页时 mini 杆状态一致 | — |
| 重复点击 | — | 每次点击都写引擎；动画类在 `to-on / to-off` 间切换，天然重触发；处理中无锁（引擎幂等） | 连点正常 | — |
| 重播 / 关键帧 | `this.motion('lever')` + `beforeReplay` 把偏好翻回 | `.scrub .sc02-head` 按 `--frame` 暂停在 280ms 内的任意位置 | 面板「重播」先翻回再播 | — |

外观页「减少动态」是同一件拨杆（`flipLever('reduceMotion')`）。

## 2. 核心动作 ② 旋钮选城市（motion-2）

| 阶段 | 运动对象 | 当前代码值 | 实际观察 | 建议值 |
|---|---|---|---|---|
| 触发 | `.sc02-knob`（76px，`touch-action:none`，pointer capture） | 按下记圆心与起始角；六个刻度在 −120°…+120°（步进 48°）；外观是三档 −60°…+60° | 按在圆内任意位置都能起拖 | — |
| 受力 / 阻感 | 旋钮 `--sc02-a` | 原始角 = 基角 + 指针角差（夹到 ±120°）；最近刻度 `k = round((raw+120)/48)`；**显示角 = 刻度角 + (raw − 刻度角) × 0.32**（被刻度拉住），`.drag` 时无过渡、阴影加深 | 拖动中指示线明显跟手，过中点时「跳」到下一刻度 | 0.32 的拉力偏强，建议 0.4 让行程更连续 |
| 读数接替 | `.sc02-lcd-roll .cur/.prev` | 越过刻度中点即换读数：旧值 `sc02-roll-out 180ms`（0→−100%）、新值 `sc02-roll-in 180ms`（100%→0），容器 `overflow:hidden`，两套 keyframes 交替保证重触发；LCD 第二行 EN 名 + 时区同帧换 | 修正前两字重叠成「缀绌顿」（已改成 ±100% + 裁切） | — |
| 归位 | 旋钮 | 松手：`sc02-settle 380ms cubic-bezier(.3,1.45,.5,1)`（from = 松手时显示角，to = 刻度角，过冲约 1–2°）；`.scrub` 可暂停 | 松手帧到落定帧之间能看到指示线回弹 | — |
| 落定 / 写入 | 数据 | 松手时才 `engine.setCity`（拖动中不写）；点下方城市行 = `pickDetent` → `turnTo`（同一 settle 关键帧从旧刻度扫到新刻度）；外观旋钮松手只写预览（`skinPreview`），「应用」才写 | 失败武装时 toast、旋钮不动 | — |
| 返回 | — | 返回首页时 CITY 模块的 mini 旋钮指向同一刻度，LCD 同值 | 一致 | — |

## 3. 核心动作 ③ 保护盖红钮（motion-3）

| 阶段 | 运动对象 | 当前代码值 | 实际观察 | 建议值 |
|---|---|---|---|---|
| 翻盖 | `.sc02-cover`（透明 PC 盖，上沿铰链 `transform-origin:50% 0`） | `perspective(360px) rotateX(0→−116deg) 340ms cubic-bezier(.3,.8,.3,1)`，同时也写成 `sc02-flip` 关键帧供 `.scrub`；红钮 `disabled` 直到盖开；LCD 读数「保护盖已翻开 · 按下红钮结束会话」 | 盖翻起后只剩一条薄边在井口上方 | 翻起后的盖可再加 2px 反光边让它更像竖着的塑料 |
| 按下 | `.sc02-redbtn`（56px，`0 6px 0 #6f170c` 立体边） | `sc02-press 360ms`：0→5px（30%）保持到 70% 再回 0 | 按下帧红钮明显下沉、底边消失 | — |
| 读数闪 | 模块 LCD（`.sc02-lcd.flash`） | `sc02-flash 420ms steps(1)`：15%/55% 反相两次 | 帧序列里有两帧反相 | — |
| 确认从模块里长出 | `.sc02-grow`（`grid-template-rows 0fr→1fr 340ms`）+ 内容 `opacity/translateY` 延迟 120ms | 按下 380ms 后 `confirm=true`：模块下方原地长出「确定结束本机演示会话？」+ 反相 LCD 后果句「只结束本机演示会话，已提交记录不删除；资料、收藏、举报都还在本机。」+ 取消 / 确认结束；无脱离的弹层 | 面板其余内容被向下推，不遮挡 | 高度过渡在 `.scrub` 下不能暂停（grid-rows 是 transition），若需关键帧可改为 max-height 关键帧 |
| 执行 / 结果 | 数据 + LCD | 「确认结束」→ `engine.endDemoSession` → 结果态：SESSION 读数「会话已结束」+ 反相 LCD「演示会话已结束 · 已提交的记录、举报与资料都还在本机」+「重新开始演示」；toast 同步 | 记录 / 举报 / 资料确实都在（首页读数不变） | — |
| 取消 | — | 确认区收回 240ms 后盖合上 | — | — |
| 重播 | `motion('danger')` | `beforeReplay` 合盖、清确认 | — | — |

## 4. 空间过渡（模块抬起成全屏 / 面板内推入）

- 抬起：点模块时 `JU.fx.rectIn` 取凹槽矩形 → `.sc02-lift` 从该矩形（`left/top/width/height` 过渡 400ms `cubic-bezier(.2,.8,.2,1)`，圆角 12→0）长到 390×844；阴影从凹槽内阴影变为 `0 30px 60px -16px rgba(30,20,5,.6)`（抬到前面）；面板标题从模块标签位置出现（内层 start 时 `translateY(-36px)`）；正文 `opacity` 延迟 140ms 淡入；其余模块 `.sc02-home.recede`：`scale(.955) translateX(-6px) brightness(.8)` + 一层 `rgba(30,22,8,.2)` 压暗（≈20%）。
- 落回：`out` 340ms，先量当前凹槽矩形再缩回去（首页滚动过也能落到原位），正文 120ms 淡出；`go()` 定时收尾，减少动态下即时。
- 面板内二级：`.sc02-layer` 右入（`translateX(100%)→0` 320ms），父层 `translateX(-33%) brightness(.82)`，覆盖完成后 `visibility:hidden`（延迟 360ms，避免被当作溢出内容）；返回反向，父层立即可见。
- 接缝：找局 / 我的局整页替换首页（底部轨道 LED 指示当前键）；入局详情与举报表单是接缝内的推入层；从接缝回执打开设置里的举报详情时，面板抬在接缝之上，关闭落回。

## 5. 关键视觉参数

- 字体：Noto Sans SC 500（刻字、正文）、Space Grotesk 600 大写（模块英文标签，字距 .14em；中文标签 .08em）、DM Mono 500（LCD 读数、输入、时间）。
- 字号阶：铭牌称呼 26px（长称呼 21px，首页铭牌一行、资料页可折行）；面板标题 18px；正文 13.5px/1.7；行标题 14px；LCD 12–13px，LCD 大字 17–18px；模块标签 9px 英文 + 12px 中文；说明 12px。
- 色板：搪瓷 `#efe8da`（高光 `#f9f5ec`、低处 `#e2dac8`）；凹槽 `#e8e1d1→#ddd5c2`；墨 `#1f1b16` / 次级 `#5c5547`；铭牌黑 `#17150f`、刻字 `#ece3cc`；LCD `#cfd6c0`（反相 `#1b221a` / `#d9e2ca`）；橙 `#ff5a1f`（只用于拨杆头、旋钮指示线、LED）；绿 LED `#38c46a`（系统 / 服务 / 已验证）；红 `#d7301d`（只有红钮）。
- 材质规则：光源左上——所有凹槽 `inset 1.5px 1.5px 3px rgba(60,45,20,.24)` + 右下 `inset -1px -1px 2px rgba(255,255,255,.75)`；键帽是凸的（`0 2px 0` 边 + `0 3px 4px` 投影，按下位移 2px）；LCD 是凹的（`inset 0 2px 3px`）；铭牌有 115° 斜向弱反光；整块面板四边有厚度（`.sc02-bevel`）。禁用 = 局部透明（`.sc02-disabled` .42 / LED `opacity:.45`），不整块变灰。三种背景（棉糖 / 光晕 / 落日）= 搪瓷底色上的低饱和洗色层，650ms `opacity+blur` 交叉。
- 圆角 / 边：模块 12px、LCD 5–6px、键帽 8px、卡片 8px；只有 1px 刻线分隔，不用卡片阴影堆叠。
- 布局：首页 = 顶栏（设置 / SETTINGS / 序号）+ 铭牌 + 2 列模块网格（收藏｜城市，通知通栏，外观｜记录，举报｜帮助，隐私｜账户｜关于三小格）+ 底部轨道四键；全部在 844 内不滚动（360 / 430 也成立，见 `.build/SC02-widths/sheet.png`）。
- 长文本：首页铭牌是固定尺寸的板——微信号 >26 字、邮箱 >30 字用**显式中段省略**（`sc02Mid`），资料页与编辑器显示全文并允许折行；长称呼降到 21px；长标题两行截断（`-webkit-line-clamp:2`）。
