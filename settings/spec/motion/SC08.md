# SC08 门厅 · 规格与核心动作（当前代码值 · 实际观察 · 建议值分开）

源文件：`settings/concepts/src/SC08.dc.html`。证据：`settings/evidence/SC08/`（命名状态 PNG；`motion-1/2/3/`、`motion-drawer/`、`motion-seam-swipe/`、`coverage/` 为 JPEG 抽帧）。验证环境：容器内无头 Chromium（SwiftShader，无 GPU），390×844，Playwright 抽帧，0.5× 速度；另用 `widths.cjs` 核过 360 / 390 / 430 三档（overflow 为空）。未做真机。

## 构图与视觉参数（当前代码值）

- 导览板 `.board` 362×306 @ (14,40)：黑漆面 + 2px 黄铜边框（上左亮 `#c09c48` / 下右氧化 `#5e4a22`）；板头 30px「住户导览 / DIRECTORY」+ 一枚指示灯（有待处理项时常亮）。7 条轨道 `.track` 各 38px：上缘 1px 白 5%、下缘 1px 黑、内阴影做凹槽；左端 9px 黄铜槽口 `.slot`（z 3）压住滑入的字牌。

## 核心动作 ①：字牌滑入（首次到达导览板）
- 触发：挂载后 160ms（`componentDidMount`，`idle` 预览与状态索引跳转直接呈现落定态 `arrived:'still'`）；`motion('tiles')` 登记，面板「重播」可重放（`beforeReplay` 先清空再滑入）。
- 起始：每行 `.tiles` 处于 `translateX(-104%)`，整条字牌（序号牌 + 分区名 + 点线 + 当前值）藏在轨道左端槽口之后。
- 关键变化：`@keyframes sc08-slide` 460ms `cubic-bezier(.3,.85,.25,1)`：0% −104% → 78% +1.2%（轻微过冲，像牌卡进槽底）→ 100% 0；逐行延迟 `--i × 70ms`（第 7 行 420ms 起步，总长 ≈ 880ms）。槽口 `.slot` 在字牌之上（z 3），字牌从被遮挡到完整露出（REF44 出纸槽的遮挡层级）。
- 落定：1000ms 后状态切到 `'still'`（类 `in`，纯静态），之后切回设置页不再重放（一次性，不循环）。关键帧：`.scrub` 下 `animation-delay = i×70ms − frame×900ms`，暂停播放。
- 中断 / 减少动态：`.rm` / `.rm-user` 下 1ms 直接落定；跳转状态索引时跳过入场。
- 实际观察（`motion-1/`，0.5×）：f01 板面全空只剩灯，f02–f05 逐行从槽口推出，先见行尾的当前值，再见分区名与序号牌，f08 后全部落定，文字无糊。
- 建议值：可给每行末尾加 40ms 的「卡入」音效位（视觉上已有 1.2% 过冲）；长值（`long` 变体）当前以省略号截断在 178px，不做跑马灯（禁止常驻动画）；若要完整显示可在抽屉名牌上看。

## 核心动作 ②：信箱门（通知偏好开关）
- 触发：点格（首页 2×3 阵列或通知页大阵列同一组对象）；`act('setNotifyPref')` 立即写入，失败则门不动 + 提示「本机保存失败，请重试 · 格门没动」。
- 变化：写入成功后给该格加 `anim-open` / `anim-close`：开 `sc08-dooropen` 520ms `cubic-bezier(.3,.8,.25,1)` 0 → −67°（70%）→ −62°；关 `sc08-doorclose` 460ms `cubic-bezier(.4,.1,.3,1)` −62° → +2.5°（85%）→ 0。铰链左缘，`perspective 520px`，门右缘向观者打开并投 12px 影；门面 `::after` 同时压暗 22%；空腔小字在开门 160ms 后淡入（200ms）。540ms 后移除动画类，稳态由 `.mbox.on .door{rotateY(-62deg)}` 接住（同值，无跳变）。名牌刻字「开 / 关」与导览板「04 通知 ·· n/6 类」同步更新。
- 重播：`beforeReplay('door')` 先把该类偏好写回原值，再重放同向开合；关键帧：`.scrub` 下 `animation-delay = −frame×520ms`。
- 实际观察（`motion-2/`，0.5×）：关门 f01–f03 可见门由 −62° 转到平、玻璃窗与把手始终清晰；开门 f09–f12 可见门边从空腔里转出、阴影落进去；首页与通知页两处格门同步。
- 建议值：同一时刻只允许一扇门动（`afterKey('door')`），连点第二扇会让前一扇直接落定；若要并行可改成按 key 的计时器。

## 核心动作 ③：门铃灯（谁能联系你）
- 触发：按门铃按钮 `.bell`（抽屉打开时不响应）。
- 按下：按钮帽 `sc08-press` 320ms（下压 2px、缩 .94）；同时圆顶灯 `.lamp.dome.lit` 播 `sc08-lampon` 420ms（亮度 .35 → 1.3 → 1，光晕 0 → 20px → 14px），显示窗文字由「… · 按铃看规则」换成「N 个局里有人现在能看到你的资料」并变亮（300ms）。
- 发展：320ms 后以门铃面板矩形为起点拉出抽屉（见「抽屉」），页面 = 对讲面板：规则四行 + 每个进行中的局一盏灯（亮 = 对方现在能看到你的资料，`derive.privacy` 只读事实，无开关）。
- 返回：抽屉收回到门铃面板，灯在收回后再亮 300ms 才熄灭（SM02 的附属控件错开消失），显示窗回到提示文案。
- 重播：`beforeReplay('bell')` 关抽屉、熄灯，再完整重放；减少动态下灯直接亮、抽屉直接出现。
- 实际观察（`motion-3/`，0.5×）：f01 帽下压、灯亮、显示窗变亮；f04–f05 抽屉从面板位置展开（展开中可见「IC 门铃」字牌随抽屉走）；返回 f12–f14 抽屉缩回面板，f15–f17 灯仍亮然后熄灭。
- 建议值：灯亮与抽屉拉出之间 320ms 可视设备性能缩到 240ms；显示窗文字可做 1 行滚动（当前为省略号）。

## 过渡：导览板抽屉（二级进入 / 返回）
- 触发：点板上任一行（也用于信箱横条、门铃、侧牌、公告、登记簿行）。起点矩形用 `rectIn(.track[data-rid])`，被拉出的行 `.ghost`（字牌隐去，只剩空轨道与槽口）。
- 发展：`.drawer` 从行矩形（内联 left/top/width/height）到落定几何，`left/top/width/height` 各 250ms `cubic-bezier(.2,.8,.2,1)`（REF29：一出现就排好版、约 250ms 停住，背景只压暗 52%，不缩放）；`.carry` 层在起点显示该行字牌，40ms 后 120ms 淡出；页头 200ms 后 200ms 淡入；正文 160ms 后 220ms 淡入。
- 返回：几何回到行矩形；页头 / 正文 110ms 淡出（无延迟），`.carry` 90ms 后淡入；270ms 后卸载，字牌回到轨道；该行指示灯 300ms 后熄灭；若当前值在抽屉里被改过（改名、换城市、换灯光、关格门），该行字牌用 `retile` 再滑入一次（460ms，无延迟）。
- 抽屉内多级（收藏 → 明信片、登记簿 → 条目 → 写）：`.pg-a / .pg-b` 交替类触发 260ms 推入（28px）/ 弹回（−22px）。
- 实际观察（`motion-drawer/`、`SC08-save`）：拉出 f01–f03 抽屉从第 6 行长到全幅、登记簿在展开中显形；返回 f09–f12 缩回第 6 行、灯延后熄灭；改名后返回可见第 1 行字牌重新滑入「阿禾二」。

## 其他运动
- 收藏取下：`.pc-cell.leaving` 380ms 下坠 46px + 旋 7° + 淡出；随后引擎删除，相邻明信片用 FLIP（`measureCards / flipCards`，320ms）沿挂杆让位；底部「挂回去」撤销条 10s；最后一张取下 → 空挂杆 + `COPY.favEmpty`。
- 公告栏滑动：V27 参数逐字（死区 6、轴比 1.25、±82px、夹 ±190、阻尼 .26、旋 0.012°/px、回弹 `.5s cubic-bezier(.2,.9,.3,1.04)`）；正确方向在告示下方露出黄铜动作区（宽 = |dx|，图标 44px 后、文字 64px 后出现，骑在告示边缘），过阈值整区换琥珀色 + 图标一次涟漪（SM05）；错误方向阻尼 + 灰洗层「已经收着了 / 还没收藏」；执行后告示右下角 ★ 徽记 520ms 弹出、pill 计数与设置 / 我的局同步。
- 保存：刻字按钮 420ms「刻字中…」→ 引擎写入 → 弹回名牌页 → toast 2600ms；失败 `.alert` 抖动 360ms + 重试，输入保留。权限申请：请求中出现磨砂玻璃「系统弹窗（示意）」，1300ms 后按面板预设回答，钥匙牌换色。换锁：确认牌 → 锁芯转 90°（600ms）→ 结果态「钥匙已收回」→ 重新开始。外观：灯光层 650ms 交叉淡入，预览不写数据。

## 已知问题（主负责人自检）
1. 长称呼在导览板上只以省略号截断（178px），完整名在名牌抽屉；未做跑马灯（避免常驻动画）。
2. 我的局登记簿行的局名列在 390 宽下约 130px，长标题截断较多（日期与钩标占去右侧）；可考虑两行局名。
3. 接缝「我的局 · 举报填写（桌游夜）」索引状态因桌游夜已有一条需补充的举报，直接显示回执 + 查看进度（与 SC05 一致），不是空表单。
4. 无真机触控验证；`touch-action:pan-y` 仅按规范设置；无头环境无 GPU，透视门的抗锯齿以真机为准。
