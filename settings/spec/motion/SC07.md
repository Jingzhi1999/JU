# SC07 墨水屏 · 规格与核心动作（当前代码值 · 实际观察 · 建议值分开）

源文件：`settings/concepts/src/SC07.dc.html`。证据：`settings/evidence/SC07/`（命名状态 PNG；`motion-1/2/3/`、`coverage/` 为 JPEG 抽帧）。验证环境：容器内无头 Chromium（SwiftShader，无 GPU），390×844，Playwright 抽帧；0.5× 速度下抽帧；未做真机与真实墨水屏。

## 构图与视觉参数（当前代码值）
- 设备：`.e-bezel` 哑光深灰 `#262523` 整块铺底，顶部一条 34×2 的听筒线；屏幕 `.e-screen` 内缩 10 / 12 / 10 / 10px（370×822），`box-shadow: inset 0 0 0 1px rgba(0,0,0,.28)` 作玻璃边；屏内三层：状态条 `.e-strip`（26px）、内容区 `.e-body`（26px→底部 44px，可滚动，就是「局部刷新」的区域）、底栏 `.e-nav`（44px 四段）。纸纹 `.e-grain` 是一枚内联 SVG（feTurbulence 0.9 / 2 octaves，alpha 0–.16）盖在最上层，`mix-blend-mode:multiply; opacity:.5`，静态、不影响文字清晰。
- 版心：`.e-pg{padding:8px 26px 28px}` → 内容宽 318px ≈ 屏宽 86%（Helmut Lang SS98 的窄版心）；首页只有一条黑 hairline `.e-hr`（1px `#111110`）把称呼区与分组区分开，其余横线都是浅灰 `--g4`。
- 色板（四级灰 + 一枚指示灯色）：底 `--paper #e9e8e4`（棉糖）/ `#ece5e5`（光晕）/ `#ebe3d1`（落日）；墨 `--ink #111110`；灰 1 `#3b3b39`（说明、引导点）；灰 2 `#87867f`（禁用、脚注）；灰 3 `#c3c2bb`（错误方向洗层）；灰 4 `#dcdbd4`（行分隔线、按压态）；指示灯 `--led #cf4f1a` 只用于屏角 LED、「需要处理」小方块、校验错误前的小方块。没有阴影、渐变、圆角容器。
- 字体：Noto Serif SC 600（称呼 34px/1.15，>8 字时 25px；页题 19px；详情标题 22–26px；关于页「JU」30px；「已核实」章 10.5px/700）+ Noto Sans SC 400/500（正文 14px、说明 12px、组头 11.5px 字距 .14em、状态条 11px）。没有第三个字族，数字也用 Noto Sans。
- 首页：称呼大字 → 一行「微信 / 邮箱 / 城市」12px → 黑 hairline → 五个分组。组头 `.e-gh` 黑底白字 20px 高，右端小字（邮箱状态 / 收藏数 / 开关数 / 需要处理数 / 本地演示）；组尾 2px 黑粗线；行 `.e-row` 34px，「项目 ……… 当前值」用 `.e-ld` 引导点对齐（`radial-gradient` 0.9px 点、5px 间距、贴基线，`currentColor`）；需要解释的行在下面加一行「※ …」12px；需要处理的值前加 7px 橙方块。减少动态在首页就是一个方块开关行。
- 控件形态：开关 = 18px 实心 / 空心方块 `.e-sq`（1.5px 边，`background-color 80ms linear`，无回弹）+ 「开 / 关」字；选择 = 黑底反白分段 `.e-seg`（1.5px 边框，`background/color 120ms linear`，文字不动）和外观页三格色样 `.e-tint`；文本编辑 = 下划线输入 `.e-fld`（1px 底线，聚焦 2px，原生光标 `caret-color:#111`），多行用 1px 方框；记录 / 举报 / 收藏 / 接缝 = 清单条目 `.e-ent`（左 40px 日期列 11.5px，中间标题 14px/500 + 说明 12px，右侧状态词），记录页状态词只有三个：已记录 / 待核实 / 已提出（V27 原文 `statusLabel` 放在条目第三行逐字保留）；「已核实」用旋转 −3° 的黑边章 `.e-stamp`（REF94）；危险操作 = 整屏反相的确认页 `.e-fs`（黑底白字，两枚白边硬按钮）；按钮 `.e-btn` 1.5px 黑边直角，主按钮黑底白字，按压即反相（无过渡）。
- 二级页：页头「‹ 返回」硬边小按钮 + 衬线页题 + 右端计数，下接 1px 黑线；长文（帮助问答）用 `-webkit-line-clamp:1` 截到一行，「展开全文」按钮放在段末（SE04）；规则全文页三组用黑组头 + 组引语（衬线 13px）+ 「编号 / 标题 / 正文」行；关于页是版权页式的十行小字（Emigre #64）。

## 核心动作 ①：刷新翻页（进入任何二级页 / 切换底栏 / 返回）
- 触发：点首页任一行、底栏任一段、页头「‹ 返回」、表单保存成功后的回退。`go() / root() / pop()` 都走 `refresh(fn)`。
- 起始 → 反相（0–120ms）：`.e-body.flash{filter:invert(1)}`——内容区整块反相（底色变成近黑 `#16171b`，黑字变白，橙方块变蓝），状态条与底栏不动（只刷新内容区）。时长 `after(120)`，随 0.5× 变 240ms。
- 内容接替（120ms）：定时器到点后一次性换页（`setState({view})`），同时反相撤销，新页以 `.e-pg.settle` 出现。不做位移、不做缩放（SM03 的 fade-through 只取「不共享位移方向」这一点）。
- 残影清除（120–~420ms）：`.e-pg.settle>*` 每个直接子元素跑 `sc07-settle`（160ms linear，`opacity .32` 保持到 70% 再到 1），延迟按行错峰 0 / 60 / 120 / 180 / 240 / ≥300ms（REF16 的按列错峰）；灰色半透明的新内容就是「残影」，逐行变黑即「清除」。
- 落定：`afterKey('settle', 520)` 去掉 `.settle`；首页返回时 `after(20)` 恢复离开前的 `scrollTop`，二级页回到顶部。
- 返回：与进入完全相同的一次局部刷新（没有「反向」动画，墨水屏只有刷新）。
- 中断 / 重复：刷新进行中再触发导航，`refresh()` 直接套用新状态、不叠加第二次反相；`.rm`（评审）下 `after` 为 0ms、动画 1ms → 直接结果；用户偏好「减少动态」下 `refresh()` 跳过反相与 settle（一帧完成，`flashRow` 也跳过）。关键帧：`.scrub .e-pg.settle>*` 用 `animation-delay: calc(-1 * var(--frame) * 460ms)` 冻结。重播：`beforeReplay('refresh')` 把 view / stack / tab 放回起点再执行同一次导航。
- 实际观察（`motion-1/`，0.5×）：f01–f02 两帧整块反相（约 240ms），f03 起我的记录页以灰字出现，f03→f05 组头与条目逐行变黑，f06 稳定；返回 f12–f13 反相、f14–f16 首页从灰到黑、滚动位置不变。无白块、无文字错位。
- 建议值：真机墨水屏的反相常在 80–100ms，这里为可见性取 120ms；若用于真实产品，残影阶段可改成「旧页灰化 + 新页叠印」（需要保留旧页快照），当前实现只对新内容做灰→黑，是一种可被接受的简化。

## 核心动作 ②：方块开关（通知六类、减少动态）
- 触发：点 `.e-trow`（整行可点，`data-act="toggle"`），`act('setNotifyPref')` 立即写入；失败（面板武装）则数据不变、状态行写「本机保存失败，请重试 · 开关保持原状」，方块停在原态。
- 变化：`.e-sq` 的 `background-color 80ms linear`（SM01 ≤100ms，无过冲）；「开 / 关」字即时换；同一帧给该行加 `.flash`（`filter:invert(1)`，行底色是纸色所以反相为黑行白字），`afterKey('rowflash', 110)` 撤销 —— 这就是「伴随局部刷新」。
- 中断 / 重复：连点同一行时 `afterKey` 保证只有一个撤销计时器；重播：`beforeReplay('toggle')` 先把该项写回点击前的值，再重做一次同向切换。减少动态：行不反相，方块 1ms 变色。
- 实际观察（`motion-2/`，0.5×）：f02 该行整行反相一帧（约 220ms）且方块已变空心，f03 恢复、字变「关」；再点 f09–f10 同样反相后填实。其他行不动，文字不糊。
- 建议值：可在反相撤销后让「开 / 关」字多留 40ms 的灰态作为微残影；当前为干脆起见未做。

## 核心动作 ③：反相落定（资料保存、补充 / 异议 / 申诉保存、举报补充、反馈提交）
- 触发：资料编辑页「保存」→ 按钮变「保存中…」并禁用（`after(360)` 可见的处理中）→ 引擎写入。
- 发展：写入成功后走一次 ① 的局部刷新回到查看页（`doNav`，mode `pop`），刷新结束后 `after(150)` → `commit(changed)`：被改动的行（`.e-kv.print` / `.e-row.print`）跑 `sc07-print`（520ms，`steps(1,end)`：0–62% 黑底白字「印出」新值，62% 后瞬间回到纸色黑字）；标签、引导点在反相期间都跟随 `currentColor` 变白。
- 落定：`afterKey('print', 640)` 清掉 `print`，页面静止；查看页顶部留一只薄框「已保存 · 新资料只用于之后的报名」。失败：编辑页出现黑底白字的「没有保存」框 + 「重试」，输入保留；校验失败：各字段下一行错误文字（前置橙方块），不写入。
- 同一动作的其他落点：记录详情「已保存说明 ……… N 条」行印出 + 「保存结果」框（文案 V27 逐字）；举报详情状态框印出「处理中」；反馈页「已提交 · 本地保存 F-MMDD-NN」框印出；举报回执框印出。
- 中断 / 重复 / 重播：`commit()` 先清空再 16ms 后置位，保证重播能重新触发动画；`.scrub .e-kv.print` 以 `--frame` 冻结；减少动态 1ms。
- 实际观察（`motion-3/`，0.5×）：f03–f06「保存中…」禁用态约 700ms；f07–f08 内容区反相；f09–f12 个人资料页灰→黑，称呼行黑底白字印出「阿禾二」；f13 起恢复、薄框「已保存」在位；返回首页后称呼、组内「称呼」行都是新值。
- 建议值：印出时长可随改动字段数递增（1 行 520ms，3 行可错峰 60ms），当前三行同时印。

## 接缝手势（入局 01）—— V27 参数逐字
- 死区 6px；`|dx| > |dy|×1.25` 判横向；右滑 > 82px 且未收藏 → 收进收藏；左滑 < −82px 且已收藏 → 拿出收藏；错误方向位移 ×0.26 + 灰洗层（`--g3` 底、黑字）+ 「已经收着了 / 还没收藏」；正确方向夹 ±190px；行旋转 `dx×0.012°`；洗层不透明度 `min(1,|dx|/96)`（错误方向 ×0.5），过阈值时文字加下划线；★ / ☆ 随 fp 旋转 ±13°；释放回弹 `transform .5s cubic-bezier(.2,.9,.3,1.04)`；写入成功后该行反相一次（`flashRow`）并在状态行写「收进收藏 · 标题 · 共 N 个」。
- 实际观察（`.build/SC07-seam`、`.build/SC07-fav`）：收进 / 已收着 / 拿出 / 未过阈值回弹四种情形与预期一致；找局 ★、设置收藏列表、我的局 ★ 三处同步；已报名的「周末速写」拿出收藏后阶段「等局主审核」不变；最后一个拿出后收藏页是完整空态「还没有收藏 / 遇到想去的，留在这里。/ 去找局」。

## 其他运动
- 收藏拿出：`.e-fent.leaving` `max-height→0 + opacity→0`（260ms ease-in），相邻条目随之上移；280ms 后写入，底部状态行「已拿出收藏 · 标题 [放回]」10s；放回写入后回到列表首位。
- 外观预览：点色样 → 一次局部刷新后整屏换底色（`data-skin` 切 `--paper`，状态条与底栏同色）；应用 / 取消预览各再刷新一次；返回时预览作废。
- 权限申请：`requestPermission` → 卡内出现黑底「系统弹窗 · 示意」→ 1300ms 后 `resolvePermission`（面板预设）→ 卡片文字换为允许 / 拒绝，状态行提示。
- 未保存返回：页顶插入 2px 黑框确认块（继续编辑 / 放弃修改），不弹层；危险操作：整屏反相确认页 → 「退出中…」300ms → 刷新回账户页的结束态 → 重新开始。
- 状态行 `.e-msg`：底栏上方一条 1.5px 黑线的横条，出现即到位（无滑入），2.6s 后消失。

## 已知问题（主负责人自检）
1. 残影是「新内容灰→黑」的简化，不是旧内容真正的叠印残影（需要保留旧页快照才能做）。
2. 文本编辑的光标用原生 caret（系统闪烁频率），没有做方向卡里的「慢闪方块光标」——为避免常驻循环动画。
3. 长微信号在首页行内用省略号截断（资料页完整显示并可换行）；HIG 的中段省略未做。
4. 纸纹层压在最上层（multiply），在深色确认页上无效果，属预期；无真机 / 真实电子纸验证。
