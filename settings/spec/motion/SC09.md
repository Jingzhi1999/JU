# SC09 软体 · 规格与核心动作（当前代码值 · 实际观察 · 建议值分开）

源文件：`settings/concepts/src/SC09.dc.html`。证据：`settings/evidence/SC09/`（命名状态 PNG；`motion-1/2/3/`、`motion-seam-swipe/`、`coverage/` 为抽帧）。验证环境：容器内无头 Chromium（SwiftShader，无 GPU），390×844，Playwright 抽帧（每张截图约 150ms，所以动效帧用 0.5× 抽取）；`widths.cjs` 360 / 390 / 430 三档 overflow 为空；未做真机。

## 构图与视觉参数（当前代码值）
- 底：浅暖平涂 `--ground #f4eee7`（棉糖 `#f4eee7` / 光晕 `#f7f0df` / 落日 `#f8e9d9`），无渐变背景；膨胀后的页面底 `--page #f8f3ec`（光晕 `#faf5e8` / 落日 `#fbf0e3`）。
- 软体材质 `.sb`：哑光平涂 `--clay #e9e0d4`（光晕 `#ece0c6` / 落日 `#f0d9c2`），一道内阴影 `inset 0 -10px 16px -8px rgba(70,50,25,.17)` + 一条顶边高光 `inset 0 2px 0 rgba(255,255,255,.55)` + 左上一枚径向高光（`::before`，白 40% 到 58% 处消失）+ 接触投影 `0 14px 22px -16px rgba(70,50,25,.45)`；无玻璃、无噪点、无滤镜。
- 色板：墨 `#2b2622`、次级 `#786e64`；鼠尾草 `#9eb48f`（开关开态、收藏标记、保存脉冲环）/ 浅鼠尾草 `#d3dec8`（已保存字段、成功体）；杏 `#f1c6a2`（只给需要处理的软体：待核实记录、需补充举报、系统拒绝）/ 浅杏 `#f7dfc9`（校验错误、验证码体）；灰蓝 `#a7b8ca` / 灰蓝墨 `#3f5469`（分段胶囊选中段、城市选中、分段 thumb）；珊瑚 `#d8705a`（危险操作体）/ 浅珊瑚 `#f3c6ba`（失败提示体）。
- 字体：Noto Sans SC 600（标题、值、按钮）/ 400（说明）；Manrope 500–700 只用于数字与账号（收藏数 40px、通知 30px、微信号、验证码 24px、举报编号）。每个软体内只有两档字号：标签 13px + 值（首页：我 34px / 中体 22px / 数字 40 · 30px；小体 15px + 12px）。页面标题 22px/600，正文 14px，说明 13px，标签 12px。
- 首页构图（flex 列，间距 12px，左右 16px，顶部 48px）：`.brand` 行（「设置」15px + 「本地演示 · 不连接真实账户」12px）→ 「我」190px 高的不规则大团（圆角 `46/50/44/54px` 两轴不等，深一档 `--clay2 #dccfbf`：称呼 34px、微信 Manrope、邮箱 + 已验证标签）→ 收藏 : 通知 = 3 : 2（132px）→ 城市 : 外观 = 1 : 1（100px）→ 记录 : 举报 = 3 : 2（96px，有待核实 / 需补充时整团变杏色）→ 帮助 / 隐私 / 账户 / 关于四个小体（62px，圆角 22px）。底部托盘 `.tray` 62px 胶囊，指示球 `.tb` 用 `--i` 定位、`360ms cubic-bezier(.3,1.3,.5,1)` 滚到当前 tab。
- 长变体：称呼 >7 字时 24px 两行（`text-wrap:balance`）；邮箱 >26 字时 11.5px，`overflow-wrap:anywhere`。
- 控件形态：开关 = 胶囊内滚动的软球 `.tg`（轨道 56×32，关态球 18px、开态 24px 带勾）；单选 = 分段胶囊 `.seg`（thumb 为灰蓝墨的充气段，白字层 `.inv` 用 `clip-path: inset(… round 999px)` 按覆盖像素反白）；城市 = 竖排软体，选中项长高到 68px 并变灰蓝墨；文本编辑 = 字段软体 `.fld` 原地长出输入井（`grid-template-rows 0fr→1fr`，320ms）；记录 / 举报 = 叠压软体 `.stackcol`（每个下一团被上一团压住 14px，z-index 递减）；帮助 = 问答软体点一下长出答案；危险 = `.dz` 珊瑚体，按住压缩 900ms 后长成确认卡。

## 核心动作 ①：膨胀进入 / 收缩返回（点任一软体 → 全屏页）
- 触发：点首页任一软体（或接缝列表行）。`open()` 用 `JU.fx.rectIn(el.closest('.sb'))` 取起点矩形、`getComputedStyle` 取起点圆角与底色、标签字号 / 颜色，写入 `.page` 的内联变量 `--sc09-x0/y0/w0/h0/r0/c0/t0/tc0`；同时为首页其余 `[data-rid]` 软体计算远离起点中心的单位向量 × 54px，写成内联 `transform: translate(dx,dy) scale(.86)`。
- 起始：被点的软体加 `ghost`（opacity 0），`.page` 以关键帧 `sc09-inflate` 从起点矩形 / 起点色开始（`from{left:var(--sc09-x0)…}`），`.carry` 层在同一位置显示该软体的内容（我：称呼 / 微信 / 邮箱；其余：值 + 副文；列表行：标题 + 时间地点）。
- 受力 / 关键变化：页面 `480ms cubic-bezier(.3,.75,.3,1)` 膨胀到 `0,0,100%,100%`，圆角到 0，底色从软体色过渡到页面底色；页头 `.phead` 内边距 `16/20px → 54/18px`、标题字号从软体标签 `--sc09-t0`（13px 灰）长到 22px 墨，返回按钮宽度 `0 → 40px`（头部始终钉在膨胀体的顶边，REF69）；其余软体用 `520ms cubic-bezier(.3,1.45,.5,1)` 的弹簧被挤开并缩到 .86。
- 内容接替：`.carry` 延迟 40ms、220ms 淡出；`.pbody` 延迟 200ms、260ms 淡入；页副标题延迟 260ms 淡入。列表行来源（`rowlift`）时页标题改为延迟 200ms 淡入，避免与行标题重叠。
- 落定：`animation-fill-mode: both` 保持全屏；`.scrub` 下 `animation-play-state: paused` + `animation-delay: -frame × 480ms`，关键帧可拖。
- 返回：`close()` → `deflating`：独立关键帧 `sc09-deflate`（400ms `cubic-bezier(.45,.05,.35,1)`，从全屏到起点矩形；不用 `animation-direction: reverse`，因同名动画不会重启）；`.pbody` 140ms 淡出，`.carry` 延迟 160ms 淡入；400ms 后卸载，首页挤开的软体弹回，被点的软体播 `sc09-settle`（`scale 1.04 → .985 → 1`，460ms）。
- 外观页为半高：`sc09-inflate-half` 到 `top:300px; height:calc(100% - 300px)`，上方挤小的软体直接显示预览色。
- 中断 / 重复：`lift.phase==='out'` 期间再点软体会直接以 `in` 打开；页内多级（收藏 → 详情）用 `.pg.push`（36px 滑入 320ms）/ `.pg.pop`（−24px）。重播：`beforeReplay('inflate')` 先无动画关页，再重放保存的起点与挤压向量。减少动态下全部 1ms（`.rm` / `.rm-user`）。
- 实际观察（`motion-1/`，0.5×）：f01–f04 页面从「我」的矩形长到全屏，称呼 / 微信 / 邮箱随页面一起放大后淡出，其余软体向外被挤小；f12–f17 收缩回「我」的位置，挤开的软体弹回，无白块、无残影；0.5× 下 920ms 的膨胀被约 150ms 一张的截图抽成 6 帧。
- 建议值：膨胀曲线可再慢 40ms 的首段让起点更可读（480 → 520ms）；返回时可在最后 60ms 加 2px 的「落座」位移（当前只有 settle 缩放）。

## 核心动作 ②：软球开关（SM01 三层节奏）
- 触发：点 `.tg`；`act('setNotifyPref')` 立即写入，`tgMoved[key]=true` 后才挂关键帧（避免页面打开时自动演一遍）。
- 分段（当前代码值，总长 100ms）：① 轨道颜色 `--clay2 → --sage`，`40ms linear`（先于位移，≥33ms 可感知）；② 球 `sc09-roll-on` 100ms linear：0% `x0 scale(.75)` → 30% `x3 scale(.9)` → 62% `x16 scale(1.2,.84)`（挤压胶囊）→ 86% `x25.5`（1.5px 过冲）→ 100% `x24 scale(1)`；轨道同步 `sc09-trk`（55% 处 `scale(1.04,.93)`）；③ 勾 `.ck` 延迟 60ms、40ms 淡入。关态 `sc09-roll-off` 镜像但不过冲（42% 处挤压，终点 `scale(.75)` 小球、无勾）。
- 失败（面板武装）：引擎不写入，球不动，toast「本机保存失败，请重试」。
- 实际观察（`motion-2/`，0.5×）：f01 轨道已褪色而球未动（颜色先走）；f02 球在中段呈扁椭圆、勾已淡；f03 球到左端缩小；反向 f09–f12 轨道先变鼠尾草、球滚到右端放大、勾最后浮出。
- 建议值：真机 60fps 下可把轨道色阶段提到 50ms；过冲 1.5px 在 2× 屏上约 3 物理像素，符合 SM01「1–2px」。

## 核心动作 ③：保存脉冲（显式保存：资料 / 补充 / 异议 / 申诉 / 举报补充 / 反馈）
- 触发：点「保存」→ 按钮进入「保存中…」（≥300ms 可见）→ `motion('pulse')`。
- 吸气：`.page.pulse-in .pskin` 220ms `cubic-bezier(.3,0,.6,1)`：`scale(1 → 1.035)` + 内环 `inset 0 0 0 16px rgba(158,180,143,.8)`（页面 overflow hidden，放大的边缘顶住框、鼠尾草环从四周涌入）。
- 吸气顶点（220ms）：引擎写入 `act('saveProfile')`；成功 → 视图切回查看态（同一组字段软体，输入井 `grid-template-rows 1fr → 0fr` 320ms 收回，井内容立即隐藏），三个字段软体变浅鼠尾草 `fresh` 2.6s，toast「已保存 · 新资料只用于之后的报名」；校验失败 / 保存失败 → 不切视图，逐字段错误或珊瑚失败体 + 重试，输入保留。
- 呼气：`pulse-out` 360ms `cubic-bezier(.3,1.4,.5,1)` 回到 `scale(1)`、环消失；380ms 后清除 `pulse`。
- 返回：点返回 → 页面收缩回「我」，首页称呼已是新值。
- 实际观察（`motion-3/`，0.5×）：f03–f09 保存中；f10 页面整体微放大、四边出现鼠尾草环；f11 查看态出现、字段变浅绿；f12–f16 环消失、toast；f17 返回首页显示「阿禾二」。
- 建议值：吸气顶点与写入时机已一致；若真机上 1.035 放大导致文字重采样发糊，可改为只做内环不缩放。

## 接缝手势（入局 01）—— V27 参数逐字
- 死区 6px；`|dx| > |dy|×1.25` 判横向；右滑 > 82px 且未收藏 → 收进收藏；左滑 < −82px 且已收藏 → 拿出收藏；错误方向位移 ×0.26 + 灰洗层 + 「已经收着了 / 还没收藏」；正确方向夹 ±190px；软体旋转 `dx×0.012°`；洗层不透明度 `min(1,|dx|/96)`（错误方向 ×0.55）；洗层里的球图标在 44px 后 `scale .75 → 1`（SM07 第一级），>82px `ready`；释放 `transform .5s cubic-bezier(.2,.9,.3,1.04)`（2–3px 过冲）；收藏标记球 `scale(.3 → 1)` `520ms cubic-bezier(.18,1.5,.36,1)`。
- 实际观察（`motion-seam-swipe/`）：收进（鼠尾草洗层）/ 已收着（灰洗层、阻尼）/ 拿出（灰蓝墨洗层）/ 未过阈值回弹 四种情形与 toast、「收藏 N」分段计数同步；我的局与设置的收藏标记同步。

## 其他运动
- 计数跳字（REF08）：离开首页时快照收藏 / 通知 / 举报计数，回到首页时若变化则数字播 `sc09-jump-a/b`（`translateY 0 → −12px → 0`，460ms，交替关键帧名以便重触发）。
- 分段胶囊：thumb `left 180ms cubic-bezier(.3,1.15,.4,1)`，选中段 `sc09-segpop`（`scale(.9,.86) → (1.05,1.06) → 1`，220ms），白字层 clip-path 同步 180ms。
- 危险操作：按下 → `.dz.hold` 变珊瑚并 `scale(1 → .92,.76)` 压缩 900ms（`afterKey('danger')`），`fill` 条同步；松手早于 900ms → 取消恢复；到时 → `.dz.grown` 长高到 206px（420ms 弹簧）显示后果 + 「再想想 / 退出登录」；执行 `endDemoSession` → 会话结束体 + 重新开始。
- 收藏取消：`.favbody.leaving` `max-height 240 → 0` + 淡出缩小 380ms，下方软体随之上移；380ms 后引擎写入；撤销条 10s「放回」。
- 权限申请：`requestPermission` → 权限体内长出蓝灰「系统弹窗（示意）」体 → 1300ms 后 `resolvePermission`（面板预设）→ toast。
- 外观预览：半高页 + 分段胶囊即点即预览（只改视图态 `skinPreview`），`.app` 与所有软体的底色 `650ms cubic-bezier(.22,1,.36,1)` 过渡；应用写入；取消 / 返回恢复。

## 已知问题（主负责人自检）
1. 无头截图约 150ms 一张，100ms 的软球开关在 0.5× 下也只能抽到 3–4 个中间帧；真机需按 60fps 复核过冲是否可见。
2. 首页「我」用更深一档的粘土色而不是鼠尾草，严格遵守「只有需要处理的软体带色」；若主负责人希望主角更跳，可把 `--clay2` 换成 `#cfdac6`（一行变量）。
3. 列表行膨胀（接缝详情）时行标题与页标题「活动」在同一位置先后交替，已做延迟淡入；若仍觉得跳，可让页标题沿用行标题（需改 PAGE 表）。
4. 无真机触控验证；`touch-action:pan-y` 仅按规范设置。
