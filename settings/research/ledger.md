## 四、可复用原则（本轮新增批次提炼）
### draft-ui-settings.md
1. 总览页直接露出当前值：行尾灰色「Detail ›」（HIG）、行尾短词「High」「ON」（Android、Larussa）、或标签下一行摘要「Medium quality, auto-play on, PiP」（Android）；进入子页的入口文字必须与子页标题逐字一致。
2. 分组 = 容器 + 小标题 + 组脚：组头写分组名，组脚承担解释——Signal 用组脚写「这组字段谁能看见」，飞书把说明段落放在卡片外的灰字；只解释不跳转的行用 ⓘ，不用 chevron。
3. 即时生效与需保存分开：开关一律即时生效、不配保存钮（M3）；多选一次确认用复选框 + 保存（M3）；带校验的单字段用「取消 | 字段名 | 完成」模态或底部「关闭／保存」等宽双钮（Signal、Creliq）；邮箱变更走「新增 → 验证码 → 设为主 → 移除旧」而不是直接改字段（Notion）。
4. 通知分三层并各自写状态：应用内偏好（单选 + 开关）→ 系统权限状态卡（标题 + 状态说明 + 「去设置 ›」）→「收不到通知？」诊断入口（飞书）；依赖关系用父开关禁用子项并写明原因（Android Dependency）；开关带来的可见变化用一枚预览小卡示范（飞书横幅预览）。
5. 隐私可见性要给「我看到的 vs 对方看到的」双视图对照（Strava、Notion）：自己视角灰显 + 「仅自己可见」小标签，对方视角直接不渲染；默认值在首次保存后明文写出；单条记录可覆盖全局默认并标「已单独设置」。
6. 资料字段行式：小标签在上、值在下、右端辅助动作（二维码／复制／铅笔）（Telegram iOS、Signal）；头像编辑用头像角上的小徽标（Creliq）或头像下方「Edit Photo」胶囊（Signal）；资料页编辑入口放页头右上角胶囊（Telegram）。
7. 破坏性账号操作：红色文字钮独立于所有分组之外的末尾（Larussa），或确认弹层中最后一枚唯一填色的红钮，弹层给替代方案 + 加粗关键名词与期限的后果说明（Telegram）。
8. 控件选择规则：二值 → 开关；对立二选一 → 分段按钮；>2 互斥 → 单选列表；多选 → 复选框 + 保存；范围 → 滑杆；状态差异不能只靠颜色，开态加勾号或形状差异（HIG Toggles、M3 Switch、Android）。
### draft-motion-settings.md
1. 开关：颜色先于位移、图标最后落定，三层节奏总时长 80–100ms；开态柄放大并带对勾、关态柄小无图标；表现型过冲只给开态且 ≤ 2px（SM01）。
2. 分段控件：新旧两段同时交叉变化，图标在原位变成对勾、文字不动，100–150ms 完成；按压涟漪独立于选中态，可持续到 250ms（SM08）。
3. 底部面板拖拽：拖动中用「下一状态才有的控件淡入」预览结果；过阈值或甩动 ≤ 200ms 直接离场；取消 = 控件淡出 + 面板回位、不弹跳；背景只压暗不缩放；面板与附属控件的消失可错开约 300ms（SM02）。
4. 列表行滑动：动作区按「色条 → 图标 → 文字」渐进露出，或按 44／88px 逐个淡入动作钮（scale 0.75→1）；58px 或行宽约 55% 为提交阈值，到阈值时图标涟漪 + 动作区换色；关闭动量、松手只落在吸附点；未过阈值回弹允许 2–3px 过冲；执行后行高收缩消失 + 目标分组同步更新 + toast 携带撤销（SM05、SM07）。
5. 保存序列：父页内容先更新，编辑面板再用 150–250ms 下滑离场，用内容变化代替成功 toast；主按钮只在存在未应用更改时出现；二级页按同一节奏层层退回（SM04、SM06）。
6. 主题／外观：选择即整页（或页头 + 示例卡）预览，不等应用；应用后在页面内留下可点的确认记录；取消回滚到进入时状态（SM04）。
7. 推入／返回：iOS 新页右入 + 父页左退 1/3 并压暗，返回从 −1/3 亮起滑回；Android 用 fade-through；返回 200–300ms 且不长于推入；父页滚动位置与高亮行保持（SM03）。
8. 撤销窗口：本轮未取得专门动态证据；暂按 SM05 的 toast 停留 ≥ 1.5s 与 M3 snackbar「带动作的 snackbar 应等待用户操作」规则，建议撤销 toast 3–5s 且不自动叠加（下一轮补证）。
### draft-editorial-designer-settings.md
1. 层级靠记号不靠缩进：IDEA 的「Chapter 标签 → 章题 → 条目 → 署名」、字誌的「▌／【】／[ ]」——设置的三级分组用小标签、方头括号、方括号区分，同一列表里不缩进。
2. 元数据写进条目本身，不做时间分组标题：Eye 索引 110 期每格自带「Summer 2026」；记录归档每条自带日期，不加「2026 年」分隔行。
3. 状态只用三个词、只给状态词上色：Eye 的 Buy issue / Low stock / sold out；Helmut Lang 的橙色只出现在闭合件上——设置页只有开态与编辑态用品牌色。
4. 标签 = 固定方式而非文字：Margiela 的空白标与四针白线——「已归档／已固定」用四角钉点表示，识别信息写在旁边；边缘循环小字「产地 ✕ 原料 ✕ 品质」做卡片边缘的元数据。
5. 二级层每层都能独立成立：Yohji SS99 层层脱下仍是完整一件；折叠面板收起时露一条里层的边（1 行预览）。
6. 口袋是外挂箱体：Rick Owens 的箱形袋挂在腰带上、Craig Green 的布袋吊在木框上——可折叠区块做成挂在父级上的独立模块，由一条「带子」（标题行）固定；多个开关用同一种控件形状。
7. 版权页十行 = 「关于」页：Emigre 版权页的编辑／校对／地址／印数／印次行／ISBN 对应版本／构建号／团队／邮箱／备案号；目录「页码左、标题常规、作者斜体缩进」对应设置条目三段式。
