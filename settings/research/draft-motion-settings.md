## 三、可复用动效原则（设置控件）

1. 开关：颜色先于位移、图标最后落定，三层节奏总时长 80–100ms；开态柄放大并带对勾、关态柄小无图标；表现型过冲只给开态且 ≤ 2px（SM01）。
2. 分段控件：新旧两段同时交叉变化，图标在原位变成对勾、文字不动，100–150ms 完成；按压涟漪独立于选中态，可持续到 250ms（SM08）。
3. 底部面板拖拽：拖动中用「下一状态才有的控件淡入」预览结果；过阈值或甩动 ≤ 200ms 直接离场；取消 = 控件淡出 + 面板回位、不弹跳；背景只压暗不缩放；面板与附属控件的消失可错开约 300ms（SM02）。
4. 列表行滑动：动作区按「色条 → 图标 → 文字」渐进露出，或按 44／88px 逐个淡入动作钮（scale 0.75→1）；58px 或行宽约 55% 为提交阈值，到阈值时图标涟漪 + 动作区换色；关闭动量、松手只落在吸附点；未过阈值回弹允许 2–3px 过冲；执行后行高收缩消失 + 目标分组同步更新 + toast 携带撤销（SM05、SM07）。
5. 保存序列：父页内容先更新，编辑面板再用 150–250ms 下滑离场，用内容变化代替成功 toast；主按钮只在存在未应用更改时出现；二级页按同一节奏层层退回（SM04、SM06）。
6. 主题／外观：选择即整页（或页头 + 示例卡）预览，不等应用；应用后在页面内留下可点的确认记录；取消回滚到进入时状态（SM04）。
7. 推入／返回：iOS 新页右入 + 父页左退 1/3 并压暗，返回从 −1/3 亮起滑回；Android 用 fade-through；返回 200–300ms 且不长于推入；父页滚动位置与高亮行保持（SM03）。
8. 撤销窗口：本轮未取得专门动态证据；暂按 SM05 的 toast 停留 ≥ 1.5s 与 M3 snackbar「带动作的 snackbar 应等待用户操作」规则，建议撤销 toast 3–5s 且不自动叠加（下一轮补证）。
