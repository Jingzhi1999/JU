## 视觉判断（单独判，先于功能）

- **首页**三种环境都过关：整高纸栏是主导体量，48px 称呼，26px 值，「2 件事等你回应」色带里有真实局名，右侧露出下一栏的大数字。天色是整片底层，光晕的橙紫光环、落日的蓝到橙都清楚（`homes-3skins.jpg`）。比别的几套安静，但成立。
- **编辑资料**是全套最好的一页：字段栏、栏名骑在栏上，每栏下面实时显示「谁看得到」。通知（三层链）、外观（翻栏即换天色）、确认栏（会保留 / 会丢掉）也都由命题生成。
- **列表页**（记录、举报、收藏、隐私、我的局）靠 64px 数字栏头撑住，算过关。
- **详情页族**（记录详情、举报详情、收藏详情 / 入局详情、关于）：「栏」只停在外框。栏里是一张 78% 白纸，上面一个大日期或状态，下面 4–5 行「时间 / 地点 / 局主 / 机会」键值行，读成通用卡片 UI，明显弱于首页。光晕下天色只剩页头一条和纸后的淡弧：records / notify / help / account 的饱和像素 5–8%，落日下是 23–27%。按「比首页明显弱 → 退回重做那一页」的标准，判 blocker。
- **64px 露边**读成溢出，不像有意设计（见第 2 条）。
- **28px 书脊**可读（竖排 15/600），是深层页唯一的「栏」线索，值得保留。但它点了没反应（见第 9 条）。

## 实际观察通过的项（真实点击 / 拖动 / 输入）

1. **进入与页头**：从根导航 找局 → 设置。滚轮下滚时标题 30 → 27 → 24 → 21 → 18 连续收进中部；回滚恢复 30（`op1-enter-scroll`）。
2. **资料编辑全流程**：
   - 身份块 → 资料（栏展开）→ 编辑（列到达）。
   - 清空称呼保存，提示「请填写称呼」；改称呼，横拖到邮箱栏改邮箱。
   - 发码，错码报错；面板「让验证码过期」后验证报过期；重新发送，正确码通过。
   - 武装失败后保存：保存中… →「本机保存失败，请重试，输入已保留」→ 重试成功。
   - 新值带「刚更新」出现在资料页与首页原位置。改称呼 / 微信号后，报名快照仍是 阿禾 / ahe_ju（`op2-profile`、`op15-consistency`）。
3. **未保存确认**：确认栏从右边到达，写着会丢掉「阿禾三」、保留原来的「阿禾」。继续编辑后输入仍在；放弃修改后回到资料、草稿清掉，离开途中不闪空（`op3-unsaved`、`zoom/unsaved-exit.jpg`）。
4. **通知**：
   - 开启提醒 → 系统弹窗 → 允许。偏好 / 系统权限 / 提醒服务三层分开表达：系统已允许，服务仍未开通。
   - denied / unsupported / connected 三个变体各有自己的结论句和链状态。
   - 类别开关 6/6 → 5/6（`op4-notify`）。
5. **外观**：
   - 点光晕预览，翻到落日，取消预览后数据仍是棉糖；再预览，应用落日，三处标签与 toast 一致。
   - 打开用户减少动态后转场瞬切。
   - 系统减少动态下页面写明「系统已开启…JU 会跟随系统」（`op5b-appearance`、`op5c-rm-system`）。
6. **收藏**：
   - 入局接缝右滑收进 Coffee Chat，计数 3 → 4；首页收藏栏与列表同步。
   - 拿出第 2 条再撤回，回到第 2 位。
   - 全部拿出后显示空态，接缝的星标全部消失（`op6-fav`）。
   - 「只看收藏」在详情往返后保留（`op15-consistency`）。
7. **记录与举报**：
   - 未出席详情 → 补充（文字加本机文件 sick-note.jpg）→ 保存，详情里出现补充与文件名。
   - 提出异议后异议入口撤掉，不能再提第二次。
   - 主动退出 → 补充与申诉。
   - 举报：需补充 → 补充 → 处理中。
   - 我的局历史行 → 举报：空提交时同时提示「请选择举报对象」与字数；选好对象提交后回到我的局，回执显示「已提交」，设置里举报数 2 → 3（`op7a`、`op7b`、`op7c`）。
8. **帮助、隐私、账户、关于**：
   - 反馈失败一次、输入保留，重试成功后「我的反馈 2 条」；规则按组阅读。
   - 隐私两栏（规则 / 你的局）。
   - 账户：退出本机演示 → 结束态 → 重新开始。
   - 关于 → 参加约定全文 → 返回（`op8a`、`op8b`、`op8c`）。
9. **尺寸与变体**：375 / 430 下首页、长称呼、收藏、长局名、较多、资料、新用户、编辑都看过（`size375`、`size430`）。long / many / fresh 用真实点击走过首页、收藏、资料、编辑（`op9-*`）。键盘模拟下 7 个表单的聚焦框与主动作都在键盘上方（`kb/sheet.jpg`）。
10. **暂停与关键帧**，翻栏、栏展开、列到达、环境切换四个动作都核过（`op10-*`）：
    - 进行中按暂停，500ms 后数值不变。
    - 拖关键帧 0 → 1，从这段动作的起点走到终点。栏展开每格对应 p = q = 0.1 … 1.0；翻栏 pos 按曲线 .40 → 1.00；环境 透明度 .25 → 1、模糊 12px → 0。
    - 释放后回到实时。
    - 动作落定后直接拖滑杆，会自动重播最近一次核心动作，并停在对应帧。
    - 「重播上一动效」可用。
11. **其他**：
    - 返回回到原栏与原滚动位置：收藏栏 scrollTop 29，去城市再返回仍是 29，页头收拢度也保留（`op12-return-scroll`）。
    - 城市搜索无结果，选波士顿后首页与找局页头都更新（`op13-city`）。
    - 展开途中按返回，干净地回到首页。点 64px 露边翻到下一栏，点 16px 纸边回到上一栏（`op11-robust`）。
