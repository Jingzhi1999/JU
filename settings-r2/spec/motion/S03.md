# S03 上光下墨 · 动效与视觉参数

命题：一屏两种材料。上面是环境的光场（身份 / 本页的关键陈述浮在光里），下面是一整张哑光墨面（所有内容与操作在墨上）。光源只有一个——上方的光场；墨上「被照亮」的东西就是和你有关的东西：等你回应的、开着的、看得见你的、你选中的、此刻的。所有二级页都是同一构图：光带（256px；资料 150，表单 124，外观为光场 82%）承载本页陈述，墨面承载一个主导物件（票根、亮块、网格、亮度阶梯、章节、书写纸）。首页墨面只有一个亮的焦点：「N 件事等你回应」是一片放在墨上的光（环境三色 64% 混白，深色字），比墨上其他东西都亮；收藏的局是一条亮带（环境第二色），其余（提醒、城市 | 外观、记录 | 举报、索引）是墨上的字，没有盒子。

## 核心动作 1 · 墨面抽起 / 落回（签名转场：`sheet-rise` 进入、`sheet-pull` 资料→编辑、`sheet-settle` 保存后落回）
| 段 | 内容 |
|---|---|
| 驱动 | 一个注册变量 `--s03-w`（0→1）。`@keyframes s03-w-in` 340ms `cubic-bezier(.3,.8,.25,1)`；返回 `s03-w-out` 300ms `cubic-bezier(.32,.72,.24,1)`，从 `--s03-w0` 起落；根导航 320ms、同级换页 280ms。所有几何、交叉淡入、页头、根导航都从 w 取值，所以「暂停」停住整张画面，「关键帧」把每个部件放在同一时刻。 |
| 谁动 | 主语是墨面整张：下层页面那张不透明的墨面带着自己的内容，从它的光带位置平移到新页面的光带位置（`translateY(d·w)`，d = 新墨面上缘 − 旧墨面上缘，含各页滚动量）。光场在墨面后面被压扁（`scaleY` 从 (旧光带+32)/(光场+32) 到 (新光带+32)/(光场+32)）——只压光，不缩字。 |
| 从哪里 | 首页墨面上缘 = 屏高 46%（844 时 388px），陈述页 256，资料 150，表单 124；点哪里都是同一张墨面抽起（被点的块随墨面一起走，不单独飞）。根导航切换同样移动墨面：新页的墨面从旧页墨面所在的高度（含滚动量，`--s03-dr`）出发、不透明，旧页 w 0→.38 淡出，新页内容 w .35→.8 淡入，光场同时伸缩——没有两张半透明墨面叠在一起。 |
| 经过 | 旧内容在 w 0→.33 淡出（1−3w）；新内容骑在移动的旧墨面上，w .40→.80 淡入；新页自己的墨面在 w ≥ .996 才变不透明，所以「换纸」看不见。旧页头 w .33 前淡出；新页头 w .38→.88 淡入并上移 10px。表单页时根导航随 w 滑出（112%），返回时滑回。 |
| 停在 | 新光带下缘。陈述（56/62 数字或 34/42 句子）在光里 sticky，滚动时被墨面盖过，而不是淡掉——与首页身份同一规则。 |
| 文字何时可读 | 新墨面内容在 w≈.6 半透明、.8 完全可读；页头 .88；墨面落定（1×：约 270ms 后）即可点。 |
| 能否打断 | 能。上升中按返回：`onNav('back')` 读出当前 `--s03-w` 写入 `--s03-w0`，下落从当前位置开始（实测 .747 → .546 → 0，无跳变）。控制器先结算未完成的导航。 |
| 返回如何连续 | 每页滚动量存于 `_mem`，页面重新挂载时还原；下层墨面从新页光带落回自己的光带，首页回到原滚动位置（flow-profile：首页滚 40px → 资料 → 编辑 → 保存 → 返回，回到 40px，页头停在半收拢）。 |
| 保存（sheet-settle） | 点「保存」→「保存中…」（控制器 360ms）→ 360ms 时 toast「资料已保存」（≤ 420ms）→ 140ms 后墨面落回资料页（300ms），新值在原位带「刚更新」；合计约 800ms 落定。失败：保留输入，按钮变「重试保存」，红字一行。 |
| 重播 | `beforeReplay`：sheet-rise → 回首页；sheet-pull → 瞬时回到资料；sheet-settle → 瞬时回到「已保存」的编辑页，重播只演墨面落回 + toast + 刚更新，不再写数据（关键帧 0/50/100 = w 1 / .085 / 0，名字不变）。核心 2cbe419 起，从静止开始拖关键帧会自动重播并冻结在绝对帧（实测 50% 帧 w=.931，20% 帧 w=.553）。 |

## 核心动作 2 · 开关点亮（`toggle`：提醒类别、减少动态）
| 段 | 内容 |
|---|---|
| 谁动 | 旋钮：`@keyframes s03-knob-on/off` 160ms `cubic-bezier(.3,.8,.25,1)`，55% 处横向拉长 1.18（被拖过去的手感）；提醒类别是一块块墨面瓷砖，开着 = 被照亮：瓷砖的光（`::before` 的环境色渐变 + 顶缘亮线）用 `s03-lit-on/off` 160ms 同步亮起或熄灭；轨道颜色取瓷砖自己的环境色。 |
| 停在 | `aria-checked` 改变；光带里的「6/6 类提醒开着」同时变成 5/6。 |
| 按压 | 瓷砖 120ms 缩到 .97；行 120ms 底色。 |
| 能否打断 | 连点会再次翻转；两套同样的关键帧（`s03-j2`）交替使用，保证每次都从头播放。 |
| 重播 | `beforeReplay('toggle')` 先把上一次的开关悄悄翻回，再重播，所以重播的方向与原动作一致，数据不被来回改动。 |

## 核心动作 3 · 换光（`skin`：外观页预览 / 应用 / 取消；首页三块小光片直接预览）
| 段 | 内容 |
|---|---|
| 谁动 | 只有光：新环境的光层盖在旧光层上，`@keyframes s03-env` 650ms `cubic-bezier(.22,1,.36,1)`，透明 + 模糊 12px → 清晰；旧光层留在下面到 680ms 才移除。墨面不动；墨上所有亮块、顶缘亮线、数值色用注册颜色变量（`--s03-e1/e2/e3/--s03-val/--s03-on2`）以同一条 650ms 曲线一起换色。 |
| 停在 | 预览时外观页底部升起「取消预览 / 应用「落日」」条（240ms）；应用 → toast「外观已换成「落日」」；取消 → 原来的光再溶回来。 |
| 重播 | `beforeReplay('skin')` 取消预览并把已应用的光记为「屏上的光」，重播时预览之光重新溶入（50% 帧光晕层不透明度 .96）。 |

## 其余运动（同一材料）
- 确认层（未保存 / 退出演示）：暗层 220ms；环境的光以一条光带升起，问题 30/38 深色字在光里；第二张墨面带着两块决定（24/30 亮字：安全的那块被照亮，破坏性的那块是玫瑰色描边）从下方再追上来盖住光带下缘（340ms 整体 + 墨面多走 64px / 420ms）。
- 系统通知提示：同样的两种材料做成一张卡（上光：问题；下墨：「不允许 | 允许」22px），260ms 浮现。
- toast：放在光里——光带工具行正中一块更亮的光（白 90%，深色字，最多 214px 宽、可两行），220ms 从上方落下 8px 淡入，不接收点按，永远不压在按钮上；页头收拢时，工具行里的小标题在 toast 期间让开。撤回条仍是墨上的一片光（环境三色混白），在拇指区；它出现时页面底部多留 96px 让最后一行能滚到它上面。
- 收藏的局 · 拿出 / 撤回：颜色属于局（按局 id 取三色之一），不随位置变；最近的一个局永远是整宽的首卡。拿出：卡片 200ms 收起（缩到 .88 + 淡出），之后网格合上，邻卡从原位置 230ms 滑到新位置（FLIP）；撤回：卡片在原位置淡入放大，邻卡让开。减少动态时直接到结果。
- 城市改变：光里的「纽约」陈述 420ms 上移 8px 重新出现。
- 减少动态（面板 / 系统 prefers-reduced-motion / 用户偏好）：任一生效，`.rm` / `.rm-user` 把所有动画与过渡压到 1ms，控制器计时归零；结果状态完全相同（rm-check：rmSys true，findings []）。外观页「减少动态」行写明「系统已开启「减少动态」，JU 会跟随系统；这里的开关在系统关闭后生效」。
- 一次性动画只用 `backwards` 填充（结束帧 = 自然样式），结束后不再留在 `getAnimations()` 里，所以「从静止拖关键帧」能判断「没有东西在动」并重播核心动作。

## 关键视觉参数
- 字体：Noto Sans SC 400 / 500 / 600 / 700，一个家族；数字用 `font-feature-settings:"tnum"`。
- 滚动容器到根导航上沿为止（`bottom:76px`），静止时没有任何内容压在导航下（375×812 资料页「编辑资料」完整露出）。
- 字号阶：首页称呼 48/54；等你回应 17/24 深色字；光里的陈述数字 56/62 + 单位 20/28，陈述句 34/42；页头 30 → 18；资料称呼 40/48；票根标题 28/36；确认问题 30/38、决定 24/30；章节名 30/36；城市名 24/30；收藏日期 28/32；亮块数字 28–32；正文 15–17；说明 13；最小 13px（widths：minFont 13）。
- 色板：墨 `#14161F`，墨上文字白色 .72–.96；棉糖 e1 `#F6AECD` e2 `#C8BDF3` e3 `#96D6E8` 值色 `#F2BFD6`；光晕 `#FF8D50 #EAC39B #CBB3EC` / `#FFB68A`；落日 `#FF8A47 #FFC53D #69B2FF` / `#FFCD57`；主操作靛蓝渐变 `#5664D2 → #3C49AC`；警示玫瑰 `#FF8C9E / #FFB7C2`。
- 光源 / 表面：唯一光源在上方。墨面哑光，朝上的边接光（1px 顶缘亮线；墨面上缘 2px 高光，位置跟着光场最亮处 `--s03-lx`）。被照亮 = 环境色在墨上的渐变（25% → 10%）+ 顶缘亮线；照亮的强弱有意义：等你回应的（首页亮块）、开着的（提醒瓷砖）、看得见你的（资料亮度阶梯：称呼 32% / 微信号 15% / 邮箱不亮只描边）、你选中的（城市）、此刻的（时间线与记录轨道上的亮点）。「还没有」= 虚线描边的空位（空收藏、无匹配城市）。
- 页头收拢：控制器滚动时写 `--hc`（0→1，72px）；`font-size: calc(30px - 12px * var(--hc))`，标题从左 24px 插值到工具行中部，`top` 60 → 17px，辅助信息 `opacity: 1 - 2.5·hc`。陈述与首页身份 sticky 在光里，被墨面盖过。
- 截断与换行：标题里的「 · 」用不换行空格黏在前一个词后（点永远在行尾）；宽标题按词组换行（`keep-all` + `overflow-wrap:anywhere`），窄卡片按字换行；首页三块收藏签用分词把短标题断在词边界。

## 一个仍可能失败的设计判断
（复核后更新）首页的亮度层级曾是平的（等你回应 55–62、提醒行 60、收藏签 51）。现在：光场 ≈190–217、等你回应 ≈212–219、收藏亮带 ≈60、墨 22（`evidence/S03/twelve/home-3env-gray.jpg` 三环境彩色 + 灰度）。

「亮度表示意义」（资料的可见性阶梯、开着的提醒、选中的城市）依赖读者读出着色强弱。复核发现光晕里用 e2（米色）的「半亮」一档会变成中性灰；现在半亮档改用同一束光（e1）的低强度（15% → 6%），三档在三种环境里都带色，灰度下仍是三档。检查方法：(1) 灰度对照 `evidence/S03/twelve/sheet-gray.jpg` 与 `home-3env-gray.jpg`（称呼是全屏最强的深字）；(2) 三种环境各一张 12 页接触表（`twelve/sheet.jpg`、`sheet-halo.jpg`、`sheet-sunset.jpg`）逐页看阶梯是否仍然由亮到暗；(3) 意义从不只靠颜色：每张卡都有文字标签（同局可见 / 成局后 · 仅局主 / 只显示域名），开关同时有旋钮位置与 `aria-checked`，城市有圆点与 `aria-checked`。
