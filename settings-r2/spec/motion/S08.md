# S08 横向分栏 · 动效与视觉参数

命题：设置是一排横向翻动的纸栏，铺在一整片天色上，天色跟着翻栏慢半拍移动。

- **首页七栏**：你 / 收藏 / 提醒 / 外观 / 记录与举报 / 帮助 / 账户与关于。每栏是一张 .78 的背光纸。
  - 当前栏左缘在 24px。
  - 下一栏露 64px，只露它的名字（骑在栏上方）和一个完整的数字。外观栏露出的是下一种环境的色条。
  - 上一栏留 16px 的纸边。
- **往里走一层，仍是同一套语法**：
  - 一页只有一栏（资料、城市）时，当前栏长成整页（栏展开）。
  - 一页本身是一排栏时，它在原地展开成那一排（展开成一排）。
  - 更深一层是从右边到达的一栏（列到达）；下面那页折成 28px 的书脊，竖排写着自己的名字，点书脊返回。
  - 每一排栏都直接铺在天色上，天色在栏缝之间露出来。
- **详情页**（记录、举报、收藏或找局里的局、关于、账户）同样是一排栏：
  - 第一栏顶部是一条强调色带，放一个和首页同级的主导值：64px 的日期（11.22 / 12.18 / 12.14），或者 64px 的结论（需补充 / 已受理）。
  - 下面是 22px 的值，不再是 13 / 15px 的键值行。
  - 第二、三栏分别是「你的说明」「进度」「补充」或「局主微信」。
- **确认**也是一栏，从右边到达，决定本身就是标题。

三个核心动作都用 `@keyframes` 驱动注册属性，经 `this.motion(name, fn)` 登记，并挂在 `.paused` / `.scrub`（`--frame`）上，所以都能暂停、拖关键帧、重播。

## 核心动作 1 · 翻栏（flip）

| 段 | 内容 |
|---|---|
| 触发 | 以下任一方式：<br>· 点栏名；<br>· 点顶部的七个刻度（鼠标用户可直接跳到任意一栏）；<br>· 点下一栏露出的 64px；<br>· 横向拖动（轴向锁定 1.2×，两端 0.3 阻尼，甩动阈值 ±0.35px/ms）；<br>· 触控板横向滚动。 |
| 谁动 | 只有一个注册数值 `--s08-pos`：<br>· 栏按 `pitch = 100cqw − 88px` 平移；<br>· 栏名按 `pitch + 18px` 平移，略快一点，形成视差；<br>· 天色层按 `−0.5 × pitch` 平移，慢半拍；<br>· 刻度同步变长。 |
| 经过 | 每栏的正文按与当前栏的距离 d 淡出：`1.6 − 2d`，d = .3 时还是满的，d = .8 时为 0。<br>露边上的数字按 `(d − .55) × 3` 淡入。所以翻到一半时两栏正文都还读得到，静止时露边只剩名字和一个完整的数字，不会把字切成半截。<br>栏名字号 20 → 15px，颜色从墨色混到次级色，强调色下划线随 d 消失。 |
| 停在 | 当前栏左缘 24px；下一栏露 64px；上一栏留 16px 的纸边。 |
| 时长 / 曲线 | 300ms，`cubic-bezier(.2,.8,.2,1)`。<br>关键帧 `s08-snap-a / s08-snap-b` 交替命名（`--s08-from → --s08-to`），每次都从头开始。<br>动画类只在播放期间挂着（600ms 后撤掉），静止画面不留已结束的动画。 |
| 打断 / 返回 | 播放中再拖：从当前计算值 `--s08-pos` 接着拖。回翻是同一动作反向。<br>`beforeReplay('flip')` 把栏放回原处，再播一次。 |

## 核心动作 2 · 栏展开 / 展开成一排 / 列到达（expand / arrive）

| 段 | 内容 |
|---|---|
| 触发 | 点栏里的入口：身份块、大数字、行或链接。<br>控制器 `go(surface)` 依次经过 `enter`（1 帧）→ `in` → `idle`。 |
| 栏展开（资料、城市） | 先量出被点的栏（`--s08-fx / fy / fw / fh`、栏内滚动量、页头收拢量）。<br>当前栏的纸（`col-bg`）向四边长到整页（`--s08-q` 0 → 1），两侧邻栏各让开 84px。<br>页的 clip-path 从那张栏的矩形长到整页（`--s08-p` 0 → 1）。<br>称呼一直留在原处，作为共享元素。 |
| 展开成一排（其余一级页） | 根上挂 `.s08-unfold`。被点的栏不长成大纸，它把位置交给这一页的第一栏：<br>· 栏正文在 q < .3 时淡出；<br>· 页的栏在 p .4 → .8 时淡入，后面几栏从第一栏底下向右滑到各自位置（`translateX((j − f) × pitch × p)`）；<br>· 露边上的数字在 p > .7 后才出现；<br>· 首页那张纸在最后三分之一淡掉，天色从栏缝之间露出来。<br>栏名飞到页标题的位置，在 p .25 → .5 淡出；页标题在 p .5 → .83 淡入，两个字不会叠在一起。 |
| 列到达（一级 → 更深） | 新的一栏从右边到达 x = 36px（`translateX((1 − p) × (100cqw − 28px))`）。<br>下面那页向左折成 28px 的书脊（`translateX(u × (28px − 100cqw))`）：内容随 u 淡出，书脊里竖排的页名随 u 出现；页体若是一排栏，书脊有自己的纸。<br>书脊下方有一块 44px 宽的返回命中区（`.s08-spb`），点它和点「‹」效果相同（编辑与表单页走未保存确认）。 |
| 时长 / 曲线 | 进 340ms，退 300ms，曲线 `cubic-bezier(.3,.7,.22,1)`（`s08-p-in / p-out / q-in / q-out / u-in / u-out`）。<br>没有 delay，部件的先后都写在不透明度阈值里，所以同一个 `--frame` 能把所有部件放到同一时刻。 |
| 返回 | `back()` 让同一组关键帧反向播放：<br>· 一排栏收回到第一栏底下，首页那一栏的纸先回来，正文最后淡入；<br>· 单栏页缩回它出来的那一栏，回到原来的滚动量；<br>· 更深页退回右侧，父页从书脊里展开。 |
| 重播 | `beforeReplay('expand')` 先回首页；`beforeReplay('arrive')` 先把导航栈瞬时放回上一层，再重新到达。 |
| 页内分栏 | 同一语法的小尺度：`--s08-f`，300ms，`cubic-bezier(.2,.8,.2,1)`。<br>点名字、点露出的栏、拖动都能翻；键盘焦点进入另一栏时自动翻过去。<br>指针处理挂在根上统一代理；鼠标按下时 `preventDefault` 并清掉已有选区，栏与栏名都是 `user-select:none`，所以连续横拖不会变成拖文字。 |
| 确认栏 | 退出会话、未保存离开时出现：一张从右边到达的高栏（300ms，离开时向右退 260ms）。<br>30px 的决定作标题，中间列出这个决定影响什么，动作放在拇指区。 |

## 核心动作 3 · 环境切换（skin）

| 段 | 内容 |
|---|---|
| 触发 | 外观页的三种环境本身就是一排栏：翻到哪一栏就预览哪种光，不写数据；「应用」才保存，「取消预览」退回并翻回当前那一栏。<br>露边上是下一种环境的色条。 |
| 谁动 | 新天色从透明度 .25、模糊 12px 淡入到清晰（650ms，`cubic-bezier(.22,1,.36,1)`），旧天色同时淡出；底色同样 650ms 过渡。<br>纸不换，光透过 .78 的纸照到每一栏；强调色带随环境换色。 |
| 重播 | `beforeReplay('skin')` 悄悄恢复切换前的预览，再播一次。天色动画只在切换期间挂上（`.s08-go`）。 |

## 保存、提示、根切换

- **保存**：点「保存」后：
  1. 按钮变成「保存中…」（控制器 360ms）；
  2. 提示出现（360ms，≤ 420ms）；
  3. 220ms 后编辑栏向右退，资料页从书脊展开；
  4. 改过的值带「刚更新」，4.5s 后消失（与共享窗口一致）。
- **提示**：只占页标题那一条，宽度铺满，前面有强调色圆点，不透明。底部留给各栏自己的动作，提示从不压在动作上。
  - 收藏页的撤回条出现时，提示收起，同一时刻只有一条消息。
- **根切换**：旧根 140ms 淡出；新根延后 100ms 升起（220ms），中间不会出现两页重影。
- **深层页头**：页头收拢时，「‹ 父页名」的字按 `1 − 3·hc` 淡掉，只剩「‹」。标题向中间移动时，路上已经没有字可以撞。

## 关键帧与减少动态

- **关键帧**：每条 `.scrub` 规则只作用于最后播放的那个动作（根上的 `.s08-m-flip / -expand / -arrive / -skin`），所以拖动滑杆不会把别的动作一起倒回去。
  - 静止画面不留已结束的动画；共享 mixin 在什么都没在动的时候，会先重播最后一个动作再冻结。
- **减少动态三源**：面板开关、系统 `prefers-reduced-motion`、外观页的「减少动态」，任一生效时：
  - 动画与过渡压到 1ms，`after()` 归零；
  - 关键帧都用 `both` 填充，结果画面与正常动态一致；
  - 外观页「动态」栏写明系统设置是否开启、JU 是否跟随系统。

## 关键视觉参数

- **字体**：
  - 正文：Noto Sans SC 400 / 500 / 600；
  - 数字、邮箱、微信号、JU 字标：Archivo 500 / 600。
- **字号阶**：

  | 用途 | 字号（px） |
  |---|---|
  | 主导值（大数字、详情色带里的日期或结论、城市） | 64 |
  | 首页称呼 | 48 / 40 / 34 |
  | 页头 | 30 → 18 |
  | 决定标题、页内主句 | 30 |
  | 局名 | 24 |
  | 详情值 | 22 |
  | 栏名 | 20 / 15 |
  | 规则标题、记录行 | 17 |
  | 正文 | 15 |
  | 说明 | 13 |

  最小 13px。规则全文每行 21.5 字（390 宽），24 字（430 宽）。
- **色板**：
  - 墨 `#14161F`，正文 `#252b3a`，次级 `#535b70`；
  - 纸 `rgba(255,253,250,.78)`；
  - 错误 `#DA3A52`，成功 `#0E9B76`，焦点 `#4A5AD6`；
  - 强调色：棉糖 `#ec6fa6`、光晕 `#ff6a24`、落日 `#ff7a33`；强调色带用强调色 30% 混暖白。
- **天色**：
  - 棉糖：粉 → 紫 → 青的水面；
  - 光晕：暖白上一圈橙到紫的光环；
  - 落日：蓝天到橙黄的黄昏。
- **光源 / 表面**：
  - 一个光源在纸后面（背光纸），没有投影；
  - 每一排栏都直接铺在天色上；
  - 天色层比屏幕宽三个节距，翻栏时以一半速度移动；
  - JU 蓝 CTA 只用于主要确认。
- **页头收拢**：控制器在滚动时写 `--hc`（0 → 1）。
  - 标题从左插值到居中，字号 `30 − 12·hc`；
  - 首页的辅助信息与刻度按 hc 淡出。

## 一个仍可能失败的设计判断

一级页现在「展开成一排」，不再长成一张大纸。风险在于：两种进入方式并存，可能被读成不一致。

- 两种方式的分工：一页只有一栏时，那一栏长成整页；一页本身是一排栏时，就在原地展开成那一排。
- 我的检查：
  1. 用关键帧滑杆逐格看「记录与举报 → 我的记录」，确认两页正文不会叠在一起，标题也不会叠字；
  2. 用 0.5× 看返回，确认第一栏收回后首页那一栏的纸接得上；
  3. 在 12 页接触表里把资料页（单栏）和记录页（一排）并排看。
- 如果主负责人仍觉得两种方式割裂，下一步是让资料页也成为一排栏（「资料 / 谁看得到」两栏），全套只留「展开成一排」一种。
