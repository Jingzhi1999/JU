# S08 横向分栏 · 动效与视觉参数

命题：设置是一排横向翻动的纸栏，铺在一整片会跟着慢半拍移动的天色上。首页七栏（你 / 收藏 / 提醒 / 外观 / 记录与举报 / 帮助 / 账户与关于）每栏是一张 .78 的背光纸，当前栏左缘 24px，下一栏露 64px（带它的名字和大数字），上一栏留 16px 的边；栏名排在各自栏的左缘上方，随栏一起走。二级页不是「返回 + 标题 + 列表」，而是同一套语法往里走一层：当前栏长成整页（栏展开），更深一层是一张从右边到达的栏（列到达），下面那页折成 28px 的书脊并竖排写着自己的名字；页内的分组（可报名 / 已结束、送达 / 类别、出席记录 / 主动退出 / 安排变化、确认 / 信用 / 赴约……）也是一排卡片栏，下一张露 64px，名字骑在各自卡片左缘上方，没有标签栏。确认也是一张从右边到达的栏，决定本身就是标题。三个核心动作都用 `@keyframes` 驱动注册属性，经 `this.motion(name, fn)` 登记，挂在 `.paused` / `.scrub`（`--frame`）上：可暂停、可关键帧、可重播。

## 核心动作 1 · 翻栏（flip）
| 段 | 内容 |
|---|---|
| 触发 | 点栏名、点下一栏露出的 64px、横向拖动（轴向锁定 1.2×，两端 0.3 阻尼，甩动阈值 ±0.35px/ms）、触控板横向滚动。 |
| 谁动 | 一个注册数值 `--s08-pos`：栏按 `pitch = 100cqw − 88px` 平移；栏名按 `pitch + 18px` 走（略快，视差）；天色层按 `−0.5 × pitch` 走（慢半拍）。顶部七个刻度同步变长。 |
| 经过 | 栏的内容从不淡出，纸本身在移动；栏名字号随与当前栏的距离 d 连续变化（20 → 15px），颜色从墨色混到次级色，强调色下划线随 d 消失。 |
| 停在 | 当前栏左缘 24px；下一栏露 64px（名字 + 大数字，读得出「后面还有一张」）；上一栏 16px 的边。 |
| 时长 / 曲线 | 300ms，`cubic-bezier(.2,.8,.2,1)`；关键帧 `s08-snap-a / s08-snap-b` 交替命名（`--s08-from → --s08-to`），新的一次总是重新开始。动画类只在播放期间存在（600ms 后撤掉，终值与静态值相同），静止画面不留已结束的动画。 |
| 打断 / 返回 | 播放中再拖：读当前计算值 `--s08-pos` 接着拖；松手从当前位置吸附。回翻是同一动作反向。`beforeReplay('flip')` 把栏放回原处再播一次。 |

## 核心动作 2 · 栏展开 / 列到达（expand / arrive）
| 段 | 内容 |
|---|---|
| 触发 | 点栏里的入口（身份块、大数字、行、链接）。控制器 `go(surface)`：`enter`（1 帧）→ `in` → `idle`。 |
| 栏展开（首页 → 一级页） | 先量出被点的栏（`--s08-fx / fy / fw / fh`、栏内滚动量、页头收拢量）。当前栏的纸（`col-bg`）向四边长到整页（`--s08-q` 0 → 1），两侧邻栏各让开 84px；一级页的 clip-path 从那张栏的矩形长到整页（`--s08-p` 0 → 1），页体本身透明，纸始终是首页那一张。栏里的内容在 q 的前 1/3 淡出，页内容在 p > .35 后淡入，页标题 p > .4 后淡入；首页页头与栏名在 q 的前半段淡出。 |
| 列到达（一级 → 更深） | 新的一栏从右边到达 x = 36px（`translateX((1 − p) × (100cqw − 28px))`）；下面那页向左折成 28px 的书脊（`translateX(u × (28px − 100cqw))`），内容随 u 淡出，书脊里竖排的页名随 u 出现。 |
| 时长 / 曲线 | 进 340ms，退 300ms，`cubic-bezier(.3,.7,.22,1)`（`s08-p-in / p-out / q-in / q-out / u-in / u-out`），无 delay，部件的先后写在不透明度的阈值里，所以同一个 `--frame` 能把所有部件放到同一时刻。 |
| 停在 | 一级页：纸铺满，页头 30/500 在纸上方；更深页：一张 24px 圆角的栏，左边是父页的书脊。 |
| 返回 | `back()` → 同一组关键帧反向：一级页缩回它出来的那一栏（重新量位置，并回到原来的栏内滚动量）；更深页退回右侧，父页从书脊里展开。 |
| 重播 | `beforeReplay('expand')` 回首页；`beforeReplay('arrive')` 把导航栈瞬时放回上一层，再重新到达。 |
| 页内分栏 | 同一语法的小尺度：`--s08-f` 300ms `cubic-bezier(.2,.8,.2,1)`；点名字、点露出的卡片、拖动都能翻；键盘焦点进入另一张卡片时自动翻过去；名字与卡片同节距。 |
| 确认栏 | 退出会话 / 未保存离开：一张从右边到达的高栏（300ms，离开时向右退 260ms），30px 的决定作标题，中间列出这个决定影响什么（「会保留：资料 / 记录 / 举报 / 收藏」「会丢掉：称呼 阿禾三（划掉）· 保留原来的 阿禾」），动作在拇指区。 |

## 核心动作 3 · 环境切换（skin）
| 段 | 内容 |
|---|---|
| 触发 | 外观页的三张环境卡也是一排栏：翻到哪张就预览哪种光（不写数据）；「应用」保存，「取消预览」退回并翻回当前那张。 |
| 谁动 | 新天色从透明度 .25、模糊 12px 淡入到清晰（650ms，`cubic-bezier(.22,1,.36,1)`），旧天色同时淡出；底色同 650ms 过渡；纸不换，颜色透过 .78 的纸到达每一栏。强调色（栏名下划线、提醒带的底色、标签）随环境切换。 |
| 停在 | 整片天色与纸上的光换成新环境；卡片标签「预览中 / 正在使用」，页头辅助信息「预览「光晕」/ 正在使用「落日」」；应用后 toast。 |
| 重播 | `beforeReplay('skin')` 悄悄恢复切换前的预览，再播一次。天色动画只在切换期间挂上（`.s08-go`，900ms 后撤掉）。 |

## 保存与按压
- 保存：点「保存」→ 按钮「保存中…」（控制器 360ms）→ toast「资料已保存」（360ms，≤ 420ms）→ 220ms 后编辑栏向右退、资料页从书脊展开（300ms）→ 改过的值带「刚更新」（6s）→ 返回首页时落回「你」栏原位、原滚动量。失败：保留输入，红字一行 +「重试保存」。
- 按压：`.s08-press` 140ms 缩到 .985；按钮 120ms。

## 关键帧与减少动态
- 关键帧：每条 `.scrub` 规则只作用于最后播放的那个动作（根上的 `.s08-m-flip / -expand / -arrive / -skin`），所以拖动滑杆不会把别的动作一起倒回去；静止画面不留已结束的动画，共享 mixin 才能在「什么都没在动」时重播最后一个动作再冻结。
- 减少动态三源：面板开关、系统 `prefers-reduced-motion`（`rm-sys`）、用户偏好（外观页「减少动态」，`rm-user`）任一生效：动画与过渡压到 1ms，`after()` 归零；关键帧都是 `both` 填充，结果画面与正常动态一致。外观页「动态」栏写明「系统设置：减少动态已开启 · JU 跟随系统」或「未开启」。

## 关键视觉参数
- 字体：Noto Sans SC 400 / 500 / 600；数字、邮箱、微信号与 JU 字标 Archivo 500 / 600。
- 字号阶：首页称呼 48（6 字以上 40，10 字以上 34）；大数字 64（「3 个收藏」「2 条出席记录」「纽约」）、日期 48；页头 30 → 18；决定标题 / 页面主句 30；栏名 20 / 15，页内分栏名 17 / 15；当前值 26（长值 22 / 19）；局名 20 / 17；正文 15–17；说明 13–14。最小 13px。
- 色板：墨 `#14161F`，正文 `#252b3a`，次级 `#535b70`；纸 `rgba(255,253,250,.78)`，卡片 `#fffdf9`；错误 `#DA3A52`（字 `#bf2a43`），成功 `#0E9B76`（字 `#0a7559`），焦点 `#4A5AD6`。环境强调色：棉糖 `#ec6fa6`、光晕 `#ff6a24`、落日 `#ff7a33`；底色 `#f2c9df / #fff1e2 / #ffc98a`。天色：棉糖 粉 → 紫 → 青的水面；光晕 暖白上一圈橙到紫的光环；落日 蓝天到橙黄的黄昏。
- 光源 / 表面：一个光源在纸后面（背光纸），没有投影；页内卡片只有 1px 的 7% 墨色边。天色层比屏幕宽三个节距，翻栏时以一半速度移动。JU 蓝 CTA 只用于主要确认（保存、提交、开启提醒、应用外观、重新开始）。
- 页头收拢：控制器在滚动时写 `--hc`（0 → 1）；标题 `calc(30px − 12px × hc)`，从左 24px 插值到居中，首页辅助信息与刻度按 hc 淡出；首页栏与栏名一起上移 40px。

## 一个仍可能失败的设计判断
二级页里下一张卡片只露 64px，露出的是被截断的大数字或标题（「6/」「1 条主动退」），可能被读成「内容溢出 / 没排好」，而不是「后面还有一栏」。我做的检查：(1) 截断处上方永远有那张卡片自己的名字（「主动退出」骑在它的左缘上），首页同一语法已经教过一次；(2) 露出部分只放大数字或标题，不放半截正文；(3) 点露出部分或拖动都能翻过去，键盘焦点进入时自动翻；(4) 在 375 / 390 / 430 三个宽度（widths）和 12 页接触表里逐张看过，露出宽度不随屏宽变化。若主负责人仍读成溢出，下一步是把露出部分改成与折叠页相同的竖排书脊（只写名字和数字）。
