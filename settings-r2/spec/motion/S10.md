# S10 叠层 · 动效与视觉参数

命题：设置是一叠整宽的纸层，光从上方的天色来。白色身份层在最后（230px），四层偏好各露 72px 的边，最前面的「帮助 · 隐私 · 账户 · 关于」一直铺到底；每一层都比它后面那层更深一档（相对亮度 .79 → .37），所以每个 28px 圆角里露出的都是更浅的那一层，彩色和灰度下都读得出叠放。三个核心动作都用 `@keyframes` 写，挂在面板的 `.paused` / `.scrub`（`--frame`）上，可暂停、可关键帧、可重播（`this.motion`）。

## 核心动作 1 · 抽起一层（lift / drop / swap）
| 段 | 内容 |
|---|---|
| 触发 | 点一条边（或身份层上的「我的记录 / 我的举报」，前层上的「隐私 / 账户 / 关于」）。控制器 `go(surface)`：`enter`（1 帧）→ `in`（320ms）→ `idle`。 |
| 谁动 | 被点的那一层（主语）：从它在叠层里的位置沿 y 轴升到 `--top`（44px），高度长到「屏幕 − 44 − 堆」；其余五层同时压成 24px 的边，按原叠放顺序堆到屏幕底部（`--pile` 120px，圆角 28 → 16）。页头的「设置」与根导航同时退场（页头 0–35% 淡出，根导航下滑出屏）。 |
| 经过 | 被抽起的层在整个过程中位于最上（z 29），其余层从它后面滑下；它的上缘一路带着投影，经过的地方能看到天色。`enter` 帧里它的高度先收成「只露出的那一段」，所以变成最上层的那一刻不会盖住下一层的边。 |
| 停在 | 层 = 页面：顶部 44px 露天色，页面页头（30/500 + 14）在层内，底部是五条 24px 的边（13/600 标签）。整堆是一个 120px 的「放回」控件（≥ 44px 触控区）。 |
| 文字何时可读 | 边上的字 0–35% 淡出；堆上的标签 45–100% 淡入；页面页头 45–100% 淡入并随内容一起从 `--pg-off` 位移到位；页面正文 45–100% 淡入。资料页的称呼从边上的称呼原位接过来（`--pg-off: -102px`），全程不消失。 |
| 时长 / 曲线 | 320ms，`cubic-bezier(.22,.8,.24,1)`；所有分段都跑满 320ms、无 delay（错落写在关键帧百分比里），所以面板关键帧能把每个部件放到同一时刻。 |
| 返回 | `back()` → `exit`：同一组关键帧反向（另一个动画名 `s10-sheet-b`，保证打断后重新开始），层落回原位，五层从堆里展开；称呼落在边上称呼原来的位置（页面滚动量 `--psc` 补偿）；页头「设置」45% 后淡回。出栈后静态状态与动画终点一致。 |
| 换层（swap） | 在帮助页点「我的举报」：前层落入堆，身份层同时升起（升起者 z 29，落下者 z 28）；返回时反向。 |
| 打断 | 控制器先结算当前转场再执行新动作（`_navSettle`）；动画中返回 = 从抽起状态反向播放。 |
| 更深一页 | 详情 / 表单 / 约定是在已抽起的层里再升起一张纸（300ms，返回 260ms），比父层低 16px（第二张低 32px），父层的边一直可见。 |

## 核心动作 2 · 层内保存（编辑 → 保存 → 落回原位）
| 段 | 内容 |
|---|---|
| 触发 | 编辑资料：身份层里升起第二叠小纸层（称呼 / 微信号 / 邮箱 / 白色动作层，颜色与首页叠层同色），从堆的上缘升起，320ms。 |
| 保存 | 点「保存」：按钮变「保存中…」（控制器 360ms，可见 ≥ 300ms）→ 成功：toast「资料已保存」→ 220ms 后返回。失败：保留输入，红字一行 + 「重试保存」，重试成功走同一条路径。 |
| 落定 | 字段叠层沉回堆的上缘（320ms 关键帧），资料页的页头 45% 后回来；改过的值用 `s10-land`（240ms，上移 10px + 淡入）落在原来的位置，并带「刚更新」（toast 显示期间）。返回首页时，称呼落进身份层原位，「刚更新」随之可见。 |
| 合计 | 点保存 → 结果落定：360ms 处理 + 220ms + 320ms ≈ 900ms，其中「已保存」在 360ms 时就以 toast 出现（≤ 420ms）。 |
| 重播 | `beforeReplay('save')` 把编辑态瞬时放回，再播一次「沉回 + 落定」。 |

## 核心动作 3 · 环境切换（预览 → 应用 / 取消）
| 段 | 内容 |
|---|---|
| 触发 | 外观页点一种环境：整个画面先预览（不写数据）；「应用」才保存，「取消预览」恢复。 |
| 谁动 | 天色：新环境的天空在旧天空之上从模糊 12px + 透明淡入到清晰（650ms，`cubic-bezier(.22,1,.36,1)`）；每一层纸从旧环境的颜色过渡到新环境的颜色（同 650ms 关键帧 `s10-tint`，起点是 `--p1…--p5`）。 |
| 停在 | 整叠纸、页面、天色都换成新环境；外观页里三种环境本身就是三张纸，「预览中 / 使用中」标签。 |
| 重播 | `beforeReplay('skin')` 悄悄恢复切换前的预览，再播一次。 |

## 减少动态（面板 / 系统 / 用户偏好三源）
任一生效：`.rm` / `.rm-user` 把动画与过渡压到 1ms，`after()` 归零；所有关键帧都是 `both` 填充，所以结果状态与正常动态完全一致（层的位置、堆、页面、toast、确认层）。外观页写明是否跟随系统。

## 关键视觉参数
- 字体：Noto Sans SC 400 / 500 / 600；数字与 JU 字标 Archivo 600 / 700。
- 字号阶：称呼 52（长称呼 40 / 30）；页面主导数字 64（「3 个局」「7 条事实」「纽约」）、日期 56；页头 30 → 18；层边 20/600；结论句 24/600；正文 15–17；说明 13–14；堆上标签 13。最小 13px。
- 色板（c1 → c5，相对亮度 .79 / .67 / .57 / .47 / .37）：棉糖 `#FBDDE9 #F2CAEE #D5BDF0 #A3B6E9 #55AFCF`；光晕 `#FFE1C3 #FFCBB1 #F6B5B1 #E0A3C2 #BB96D4`；落日 `#FFE587 #FFCE7A #FFB672 #FF9C6D #F7836B`。身份层白色。文字：墨 `#14161F`，正文 `#252b3a`，浅底次级 `#3a4152`，深层（c4 / c5）上的次级用正文色；错误字 `#8E1A2C`（线用 `#DA3A52`），成功字 `#045541`。
- 光源 / 表面：一个光源在上方。每层：`0 -10px 30px rgba(20,22,31,.10)`，越靠近你越重（c3 .11、c4 .13、c5 .15 + 贴边细影）；每层上缘 1px 亮边。纸层里的列表也是纸层（22px 圆角、自己的上缘投影），最后一张「底纸」铺到底；没有纹理、玻璃、发光、颗粒。JU 蓝 CTA 只在主要确认（保存、提交、开启提醒、应用外观、重新开始）。
- 页头收拢：控制器在滚动时写 `--hc`（0 → 1，96px）；`font-size: calc(30px - 12px * var(--hc))`，标题从左 24px 插值到工具行中部，辅助信息 `opacity: 1 - 2.2·hc`；首页页头带一份与底层天色像素对齐的天空副本，纸层从它下面滑过。
- 确认层：一小叠纸从底部升起（两条环境色的边 + 确认纸），不是通用白色底板。

## 一个仍可能失败的设计判断
首页四条 72px 的边在灰度并排里仍可能被读成「圆角的列表行」。我做了三件事并用 `lead-sheet.cjs --gray` 逐次检查：(1) 每层比后面那层深一档，圆角里永远露出更浅的那层；(2) 每条边下层露出自己内容的一角（收藏的局名标签、城市大字、六个提醒开关的小标记、三种环境色样），读成「更完整的一张纸的上缘」；(3) 最前面的深色层铺到底，给整叠一个「最近的那张」。如果主负责人仍读成行，下一步是把四条边减成三条（城市并入收藏层的边）以加大最前层的面积。
