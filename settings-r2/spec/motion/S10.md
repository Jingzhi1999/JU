# S10 叠层 · 动效与视觉参数

命题：设置是一叠整宽的纸层，光从上方的天色来。白色身份层在最后（230px），四层偏好各露 72px 的边，最前面的「帮助 · 隐私 · 账户 · 关于」一直铺到底；每一层都比它后面那层更深一档（相对亮度 .79 → .37），所以每个 28px 圆角里露出的都是更浅的那一层，彩色和灰度下都读得出叠放。三个核心动作都用 `@keyframes` 写，挂在面板的 `.paused` / `.scrub`（`--frame`）上，可暂停、可关键帧、可重播（`this.motion`）。

**纸带着自己的内容走**（修订轮）：任何一帧都不是一张空纸。每张纸在升降过程中一直带着它的内容；只有纸的「头部」在交接——条名与当前值沿 FLIP 路线走进页头标题与页面主值，其余文字在重叠的窗口里交叉淡化（离场 0–30%，入场 6–38%）。所有部件都跑满 320ms、从 0 开始，关键帧拖到 0 / 25 / 50 / 75 / 100 都落在同一时刻。

## 核心动作 1 · 抽起一层（lift / drop / swap）
| 段 | 内容 |
|---|---|
| 触发 | 点一条边（或身份层上的「我的记录 / 我的举报」，前层上的「隐私 / 账户 / 关于」）。控制器 `go(surface)`：`enter`（1 帧）→ `in`（320ms）→ `idle`。 |
| 谁动 | 被点的那一层（主语）：从它在叠层里的位置沿 y 轴升到 `--top`（44px），高度长到「屏幕 − 44 − 堆」；其余五层同时压成 12px 的边，按原叠放顺序堆到屏幕底部（`--pile` 60px，圆角 28 → 12）。页头「设置」0–30% 淡出，根导航下滑出屏。 |
| 交接（FLIP） | `enter` 帧里组件量出条与页面的文字框（左缘对齐、首行中线对齐、缩放 = 字号比），写成 `--cx / --cy / --cs`：页面标题从条名的位置、条名的字号（20 → 30）长到页头；页面主值从条上的值长到位（城市「纽约」34 → 64 两份重合；「3 个局」「7 条事实」「18 条约定」只走主值，条上的值原地淡出，避免单位被放大成虚影）。从身份层抽起「我的记录 / 我的举报」时，标题从栏名「我的记录」接过；从前层抽起「隐私 / 账户 / 关于」时，标题从那条链接接过。个人资料：称呼从身份层称呼原位接过（`--pg-off` 按实际位置量出，称呼在白纸里居中），全程不消失。 |
| 文字何时可读 | 条 / 身份层其余内容 0–30% 淡出；页头返回键与说明 6–38% 淡入；页面主值 0–28% 出现并移到位；页面正文 6–38% 淡入（层在 25% 时已走完约 73%，正文约 60% 可见）。交接期间页头是透明的（新页面还没有滚动，页头下没有内容），条在它下面露出来。 |
| 时长 / 曲线 | 320ms，`cubic-bezier(.22,.8,.24,1)`；淡化是线性分段，错落写在关键帧百分比里，无 delay。 |
| 返回（drop） | `back()` → `exit`：层落回原位，五层从堆里展开；页头标题沿同一路线缩回条名（14–56% 淡出），条 18–60% 淡入，页头「设置」6–38% 回来。正文跟着纸走：一般页 55–90% 才淡出（纸先把它收短）；身份层 / 前层与页面已滚动时 0–40% 先清掉，避免和回来的条重影；已滚动的页面在页头线以下裁切。称呼落在身份层称呼原来的位置（滚动量量进 `--pg-off`）。 |
| 换层（swap） | 帮助页点「我的举报」：前层带着帮助页落入堆（内容保持到 55%，90% 前清掉），身份层带着「我的举报」从堆里升起（16% 内就可读）；升起者从它自己那条 12px 边开始、落下者在自己那条边结束，所以首末帧与静止时的堆一模一样。返回时反向。 |
| 打断 | 控制器先结算当前转场再执行新动作（`_navSettle`）；动画中返回 = 从抽起状态反向播放。 |
| 更深一页 | 详情 / 表单 / 约定是在已抽起的层里再升起一张纸（300ms，返回 260ms），比父层低 16px（第二张低 32px），父层的边一直可见。从个人资料打开「我的记录 / 我的举报」也是这样一张纸（再往下的详情、表单各低 16px）。 |
| 待处理 | 首页身份层两栏下各有一句 JU 蓝 15px「● 1 条待核实 ›」「● 1 条需补充 ›」：先抽起到列表，再在上面升起那一条记录 / 举报（只有一条时；多条时停在列表）。 |

## 核心动作 2 · 层内保存（编辑 → 保存 → 值飞回原位）
| 段 | 内容 |
|---|---|
| 进入编辑 | 身份层里第二叠小纸层（称呼 / 微信号 / 邮箱 / 白色动作纸，与首页叠层同色）从堆线下面升起，盖过原地不动的个人资料；两个页头交叉（新页头 6–40% 从下 10px 进来，旧页头留在下面）。 |
| 保存 | 「保存」→「保存中…」（控制器 360ms）→ 成功：toast「资料已保存」（≤ 420ms），40ms 后开始落回。失败：保留输入，红字一行 + 「重试保存」，重试成功走同一条路径。 |
| 落回（320ms） | 字段叠层整个沉到堆线以下（不再在堆上露一截）；个人资料从第一帧就在它下面。每个改过的值在保存那一刻量出「输入框 → 资料页原位」，画成一份 FLIP 副本：称呼 20px → 52px 长回名字的位置，微信号 / 邮箱 20px 平移到各自的纸上；输入框里的字同时变透明，资料页上的原值在副本下面等着，退场结束时无缝换成真值。「刚更新」在 72–100% 出现（控制器 4.5s 后清掉）。没有残留的落定类，落定后直接拖关键帧会重播整段保存。 |
| 合计 | 点保存 → 落定：360ms 处理 + 40ms + 320ms ≈ 720ms。 |
| 重播 | `beforeReplay('save')` 把编辑态瞬时放回，用上一次保存的字段再播一次「下沉 + 值飞回」。 |

## 核心动作 3 · 环境切换（预览 → 应用 / 取消）
| 段 | 内容 |
|---|---|
| 触发 | 外观页点一种环境：整个画面先预览（不写数据）；「应用」才保存，「取消预览」恢复。 |
| 谁动 | 天色：新环境的天空在旧天空之上从模糊 12px + 透明淡入到清晰（650ms，`cubic-bezier(.22,1,.36,1)`）；每一层纸从旧环境的颜色过渡到新环境的颜色（同 650ms 关键帧 `s10-tint`，起点是 `--p1…--p5`）。 |
| 停在 | 整叠纸、页面、天色都换成新环境；外观页里三种环境本身就是三张纸，「预览中 / 使用中」标签。 |
| 重播 | `beforeReplay('skin')` 悄悄恢复切换前的预览，再播一次。 |

## 根导航切换（设置 ↔ 找局 / 我的局）
穿过天色：离场页 0–34%（约 110ms）淡完并下移 8px，新页 34% 起从下 24px 升起淡入；两页文字不会同时出现。「开局」与其它未选中项同色同字重，点它仍是 toast「开局不在本次演示范围」。

## 减少动态（面板 / 系统 / 用户偏好三源）
任一生效：`.rm` / `.rm-user` 把动画与过渡压到 1ms，`after()` 归零，FLIP 不测量；所有关键帧都是 `both` 填充，所以结果状态与正常动态完全一致（层的位置、堆、页面、toast、确认层）。外观页写明是否跟随系统。

## 关键视觉参数
- 字体：Noto Sans SC 400 / 500 / 600；数字与 JU 字标 Archivo 600 / 700。
- 字号阶：称呼 52（长称呼 40 / 30，`text-wrap: balance`）；页面主导数字 64（「3 个局」「7 条事实」「纽约」）、日期 56；页头 30 → 18；层边 20/600；结论句 24/600；正文 15–17；说明 13–14。最小 13px。
- 色板（c1 → c5，相对亮度 .79 / .67 / .57 / .47 / .37）：棉糖 `#FBDDE9 #F2CAEE #D5BDF0 #A3B6E9 #55AFCF`；光晕 `#FFE1C3 #FFCBB1 #F6B5B1 #E0A3C2 #BB96D4`；落日 `#FFE587 #FFCE7A #FFB672 #FF9C6D #F7836B`。身份层白色。文字：墨 `#14161F`，正文 `#252b3a`，浅底次级 `#3a4152`，深层（c4 / c5）上的次级用正文色；错误字 `#8E1A2C`（线用 `#DA3A52`），成功字 `#045541`；c3 纸上的链接用墨色加下划线（JU 蓝在 c3 上不到 4.5:1）。
- 光源 / 表面：一个光源在上方。每层：`0 -10px 30px rgba(20,22,31,.10)`，越靠近你越重（c3 .11、c4 .13、c5 .15 + 贴边细影）；每层上缘 1px 亮边。纸层里的列表也是纸层（22px 圆角、自己的上缘投影），最后一张「底纸」铺到底；没有纹理、玻璃、发光、颗粒。JU 蓝 CTA 只在主要确认，动作纸里它停在纸的底部。
- 堆：五条 12px 的边，没有标签（深度提示；「< 设置」负责说明怎么回去），整堆 60px 是一个「放回」控件；toast 与撤回条在抽起时就落在堆上，不盖页面自己的按钮。
- 个人资料：称呼在白纸里居中，下面一小叠纸贴着堆：微信号（c2）/ 邮箱（c3）/ 我的记录 | 我的举报（c4，两半各自可点）/ 白色底纸（快照说明 + 编辑资料，按内容定高）。多出来的高度只出现在称呼上下，不在按钮下面留白。空值写「未填写」（16/400 次级色）+「去填写」（打开编辑并聚焦该栏）。
- 页头收拢：控制器在滚动时写 `--hc`（0 → 1，96px）；`font-size: calc(30px - 12px * var(--hc))`，标题用 `translate` 插值到工具行中部（`transform` 留给交接），辅助信息 `opacity: 1 - 2.2·hc`；首页页头带一份与底层天色像素对齐的天空副本，纸层从它下面滑过。
- 确认层：一小叠纸从底部升起（两条环境色的边 + 确认纸），不是通用白色底板。

## 一个仍可能失败的设计判断
堆去掉了标签、压到 60px 之后，「点堆 = 放回」更难被发现；我把它当作次要手势（主路径是每页左上的「< 设置」），换来列表页多出一到两行。另一个是首页最前层（帮助 · 隐私 · 账户 · 关于）仍是最饱和的一块：它是叠层的深度锚（越近越深），我保留了色板；如果主负责人在缩略图里仍觉得视线落在法务区，下一步是只降最前层的彩度、保持亮度不变，灰度下的叠放顺序不受影响。
