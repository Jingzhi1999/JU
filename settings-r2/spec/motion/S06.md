# S06 一段话 · 关键视觉参数与三个核心动作

## 命题与构图
设置首页是**一段关于你的话**：四组句子（身份 / 城市与收藏 / 提醒与外观 / 记录与举报）各起一行，组间多 10px 行距，末尾一行 15px 文字索引（帮助与反馈 · 隐私 · 账户 · 关于 · 约定）。上半屏是纸，环境色光从底部升起（下 ≈45% 是真实色场）。每个值都是一个短语：墨色 600 + 一条 2px 环境色下划线（基线下 6px）；只有两条「要你回应」的短语用 JU 蓝 + 淡蓝底。点一个短语：它所在的那组句子升到标题下，前面的组退出、后面的组退到 35%，光沉下去，纸在这组句子下面裂开一道**同样的光**——这一页的内容（列表、详情、表单、确认）全部写在这道光带里，用同一种声音：句子、一行一个局、带下划线的动词、短语开关、写在光带里的问句。没有卡片、没有行列表、没有底部弹层（唯一例外是系统自己的权限提示，那是系统的声音）。

## 关键视觉参数
- **字体**：Noto Serif SC 400 / 500 / 600（段落、光带句子、标题、动词）；Noto Sans SC 400 / 500 / 700（页头辅助、说明、根导航、CTA 字）。
- **字号阶（px）**：页头 30 → 18（衬线 500，`--hc` 连续）· 段落 22 / 1.8（值 600）· 光带主句 22 / 1.7 与 20 / 1.75 · 一行一项 20 / 1.65 · 陈述 17 / 1.75 · 约定标题 18 · 约定正文 16 / 1.75 · 注释 15 / 1.7（衬线）· 文字索引 15 · 页头辅助 14（无衬线）· 说明 / 根导航 13（最小字号 13；`widths.cjs` minFont 13）。
- **色板**：墨 `#14161F`（值、动词）· 叙述 `#3a4050`（段落里的连接词）· 正文 `#252b3a` · 次级 `#535b70` · JU 蓝 `#4553BE`（只用于主确认与「要你回应」）· 焦点 `#4A5AD6` · 错误 `#DA3A52` · 成功 `#0E9B76`。每种环境一个下划线色：棉糖 `#A45CC6` · 光晕 `#B43C0B` · 落日 `#DD5F1B`；纸色：`#FBF8F8` / `#FFF9F0` / `#FFF9F1`。
- **光源 / 表面**：唯一的光源是底部升起的环境光（`.s06-sky`，三层叠放：棉糖 = 粉 / 薰衣草 / 青的水面；光晕 = 暖白上一圈像日出的橙紫光环；落日 = 蓝 → 桃 → 橙 → 黄的天色），上三分之一用遮罩渐隐进纸。光带 = 纸上的一道缝：底色是同一环境的光（`--band`），上下 1px 环境色边 + 纸边内侧 7px 柔和压暗（纸是一张盖在光上的纸）。**光只升到文字结束的地方**：若段落最后一组落到屏幕 72% 以下（long / many 在 375 / 390），光整体下沉相应距离——63 组（5 变体 × 3 宽 × 3 环境 × 滚动）实测：叙述字对比 ≥ 5.3、值 ≥ 9.3、蓝色要处理短语 ≥ 3.2、根导航 ≥ 5.1。不用玻璃、颗粒、持续发光、纹理；文字从不放在滤镜里。
- **页头收拢**：`.s06-t{font-size:calc(30px - 12px * var(--hc))}`，并 `translate: calc(var(--hc) * (50cqw - 24px - 50%)) calc(var(--hc) * -40px)` 移入工具行中部（页头是 inline-size 容器）；辅助信息 `opacity: 1 - 3 × hc`；纸色页头底 134 → 68px。`--hc` 由控制器 `c.nav.onScroll` 在 96px 内写入。
- **主确认**：JU 蓝 280 × 48 胶囊（顶部高光 + 底部压暗，按压 scale .958 / 120ms）只用于 保存 / 提交 / 应用外观 / 开启提醒；首页没有 CTA。其余动作都是句子里带下划线的动词（取消、拿出、复制、再想想、放弃修改；危险动作红色）。
- **确认层**：不是白色底部卡片——问句写进它影响的那道光带（「确定要结束这台设备上的本机演示吗？已提交的记录、举报与资料都会保留。」/「有没保存的修改——离开会丢掉刚才的输入。」），两个回答是两条带下划线的动词，问句出现时光带随之长高、自动带入视野。

## 三个核心动作（均为 `@keyframes`，用 `this.motion(name, fn)` 登记；暂停 / 关键帧 / 重播 / 0.5× / 减少动态都可用）

### 1 · 聚焦（签名转场）
- **触发**：在首页点任何短语（或整句身份）。
- **谁动、从哪里、经过什么**：一个注册属性 `--s06-p`（0 → 1）在 `.app` 上用 `s06-open` 320ms `cubic-bezier(.2,.8,.2,1)` 驱动全部：被点的那组句子整体上移到标题下（`margin-top: −lift × p`，只平移不缩放）；纸在这组最后一行下面裂开，光带高度 `gap × p`；后面的组下移光带高度并淡到 35%；前面的组淡出；底部的光下沉 9% 并减到 42%。光带内容在 p > .35 后出现（`(p − .35) × 2.6`），同时 18px 横向滑入（260ms）。
- **文字何时可读**：被点的那组句子全程可读（只平移）；光带文字约 150ms 起可读，320ms 落定。
- **深入**（列表 → 详情 → 表单）：光带不重开，内容横向换页 260ms（返回时反向滑入）；进入更深一层时滚动回到光带顶部。
- **打断 / 返回**：点任何退后的句子或页头返回 = 整条下钻一次收起（`s06-shut` 280ms `cubic-bezier(.3,0,.25,1)`）；滚动位置按控制器记忆平滑回到原处；连点时控制器先结算当前转场。
- **关键帧**：`.app.scrub` 切到孪生 keyframes `s06-openx / s06-shutx`，`animation-delay: −frame × 320ms`，任意帧可停。

### 2 · 写回
- **触发**：段落里的任何值变化——保存资料、选城市、开关某类提醒、申请权限的结果、应用外观、减少动态、收藏增减、记录 / 举报的计数。
- **谁动**：只有变化的那个短语：新字已经在原位，下划线从 0 → 100% 宽重画，同时一层环境色淡底褪去（`s06-wa / s06-wb` 420ms `cubic-bezier(.2,.8,.2,1)`）。字形从不位移。
- **资料保存的完整一拍**：保存中 380ms（按钮「保存中…」，输入变灰）→ 输入框收回成短语、toast「资料已保存」→ 240ms 后光带回到资料说明 → 改过的值重画下划线（≤ 420ms 落定）。失败：输入原样保留、按钮变「重试保存」，重试成功后同样写回，不产生第二条。
- **在接缝页时**：段落等着——收藏从「找局」右滑后回到设置，变化在被看见时才写回。
- **关键帧**：孪生 keyframes `s06-wx`，`animation-delay: −frame × 420ms`。

### 3 · 换光
- **触发**：外观预览 / 应用 / 取消预览（也包括面板换环境）。
- **谁动**：新环境的光层叠在旧光层之上，从 opacity .25 + blur 12px 到 1 + 0（650ms `cubic-bezier(.22,1,.36,1)`，R3 规格）；纸色与下划线色同时 650ms 过渡；文字不动。预览即整屏（光、光带、下划线都换），取消预览同样换回。
- **关键帧**：孪生 keyframes `s06-lx`，`animation-delay: −frame × 650ms`。

## 其余运动
根导航切换（`dir-root`）：离开的页 150ms 上移淡出，进入的页延后 80ms 再用 240ms 上升 16px 淡入（不重叠）。按压 80–160ms（短语淡底 120ms；CTA scale .958）。toast 240ms 升起。系统权限提示（系统的声音）260ms 从底部升起。普通保存不做仪式；没有整页弹跳、交错入场、脉冲、扫光或漂移。

## 减少动态（三源：面板 / 系统 `prefers-reduced-motion` / 用户偏好）
`.app.rm` 与 `.app.rm-user` 把所有 transition / animation 压到 1ms，`this.after()` 归零；结果完全相同：光带直接打开、写回直接显示完整下划线、换光直接换。外观光带写明当前是「正常 / 已减少 / 跟随系统减少」；系统开启时首页句子写「动态跟随系统减少」。

## 一个仍可能失败的设计判断，以及我怎么检查的
**列表写成句子**（一行一个局 / 一条事实，局名是带下划线的短语，动作是句末的动词）。三四项时读起来最像「一段话」，但 `many` 变体（13 个收藏）里光带会变成一长列两三行的句子，想「找到周五那个局」时，扫日期没有表格快。检查：`many` 与 `long` 变体在 375 / 390 / 430 下逐页看——每个局名都在行首、句子 ≤ 3 行、「拿出」从不单独换行（排版换行检查：26145 个字形里 0 处标点行首）；开头一句先给结论（「收藏了 13 个局，1 个已经报名，2 个在别的城市」），已结束的局单独成组。如果主负责人在并排对比里觉得扫读慢，退路是把日期提到句首（「周五 12.18 · 深夜救急火锅局……」），而不是回到行列表。
