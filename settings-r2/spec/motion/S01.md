# S01 字即内容 · 关键视觉参数与三个核心动作

## 命题与构图
当前值就是版面：每页只有一个主角值，站在与首页称呼相同的高度（y≈168），上面是环境色光场，下面是纸。没有卡片、没有框、没有投影；结构只来自字级、1px 规线和留白。点哪个值，哪个值就移动到下一页的主角位置；其余文字只淡入淡出，从不滑动整页。

## 关键视觉参数
- **字体**：Noto Serif SC 600（所有展示值、局名、问题句）；Archivo 500/600/700（数字、日期、微信号与邮箱）；Noto Sans SC 400/500/600（注释与正文）。
- **字号阶（px）**：称呼 56/1.12 · 主角值 48/1.12（计数数字 1.35em≈65，Archivo）· 首页值 34（数字 46）· 详情标题 31 · 状态句 34 · 结论句 21 · 列表局名 22（衬线）· 日期数字 21 / 大时间 50（Archivo）· 阅读正文 17/1.85 · 说明 15 · 标签 13（最小字号 13，无 12 以下）。
- **色板**：纸 `#FBFAF7` · 墨 `#14161F` · 正文 `#252b3a` · 次级 `#535b70` · 色光上的注释 `#2c3243` · JU 蓝 `#4553BE`（只用于主确认与文字链接）· 焦点 `#4A5AD6` · 错误 `#DA3A52` · 成功 `#0E9B76`。
- **光源 / 表面**：唯一的光源是页顶的环境色场（棉糖 = 粉 / 薰衣草 / 青的多段径向水面；光晕 = 暖白底上一圈由橙转紫的柔和光环（conic 渐变 + 环形遮罩，内缘更软），光环按页面换尺度与位置：首页在称呼右侧，整屏页（资料 / 编辑 / 表单 / 外观）放大 1.3–1.45 倍并移到主角值后面，外圈再有一层更淡的暖环把暖色带到纸线；光环换位与色场幕同一个导航时钟（`s01-hA/hB` 关键帧，从当前位置到目的页位置，返回时在退出相位里就走向下层页），所以暂停 / 关键帧能停住它；落日 = 蓝 → 橙 → 黄的天色）。色场高度按页面定义（首页 50%、资料 / 编辑 / 表单 / 外观整屏、列表 40–44%、详情 56–58%、规则 34%），向下用一层 200px 渐隐的纸色幕（`.s01-veil`）过渡成纸。滚动时幕跟随页面上移（光被读者向下推开）。不用玻璃、颗粒、发光或纹理；唯一的实心面是 JU 蓝 CTA。
- **列表语法**（收藏 / 记录 / 举报 / 找局 / 我的局 / 时间线）：顶部一条墨色规线开始，像目录页；左栏 84px 是 30px Archivo 日期数字（`12.27` + 周几），它是页面的字脊；右栏是衬线局名作标题（整栏宽度，标记 / 动作放在元信息下面，局名不再被挤成窄栏），15px 元信息一行；行高 ≥ 76px；分组用「大数字 + 衬线组名」（如「2 出席记录」）。开关是排版开关：一行就是开关，「开 / 关」两个字交换下划线。
- **首页收藏预览**：每个局名一行；第一个「 · 」之后的副题只在整段放得下时出现（放不下就整段折到被裁掉的第二行），所以不会出现截在分隔点上的「·…」，375 宽 long 变体首屏仍能看到 4 组值。
- **主条目**：收藏页的第一条（最近收藏）、举报页最需要回应的一条（需补充优先）排成缩小的详情页：31px 衬线标题 + 50px Archivo 时间（或更新日期）+ 地点 / 局主（或对象 / 本地编号）两组值；举报把状态写成 28px 衬线句（需补充时用 JU 蓝）。条目少于 4 条时色场下沉到 66%，由色场和主条目撑住页面。账户页把「留在这台设备上的」写成 2×2 的大数字（收藏 / 记录 / 举报 / 反馈）；关于页的主角是「18 条约定」，三组约定各一个大数字，编号只作注释。
- **确认层 / 系统提示 / 反馈**：不是白色底部卡片。页面自己的文字退场（170ms），问题句以 34px 衬线站进主角位置，影响的值写成「称呼：~~阿禾~~ → 阿禾 Ahe」，决定是 28px 衬线大字、用规线分开；危险项用错误色。toast / 撤销是根导航上方一条带 2px 墨线的脚注条（✓ / ! 标记 + 17px 衬线句）。
- **页头收拢**：控制器把滚动进度写成 `--hc`（0→1，96px）；标题 `font-size: calc(30px - 12px * var(--hc))`，并以 `translate(calc(var(--hc) * (50cqw - 50%)), calc(var(--hc) * -33px))` 连续移入工具行中部（`.s01-hd` 是 `container-type:inline-size`）；14px 状态行 `opacity: 1 - 1.8·hc`；滚动区顶部遮罩边缘随 `--hc` 上移 60px。首页状态行是真实状态（「资料已验证 · 纽约」），演示边界只在账户 / 关于页说一句。

## 三个核心动作（全部是 @keyframes，接 `.app.paused` 与 `.app.scrub`；`this.motion()` 登记，可重播）
所有延迟都写在已注册的 `--s01-dl` 上，`.app.s01.scrub *` 统一改写成 `calc((--s01-dl − frame × 420ms) × k)`；色场幕与环境的跨度按各自时长。归零 / 恢复走共享 mixin（它按 `.scrub` 规则找到这些动画）。载入时就登记了签名动作（`lastMotion`），所以一打开就能「重播」，静止时拖「关键帧」会自动重播并停在该帧。已结束的动画不常驻：落定态等于静止样式的动画用 `backwards` 填充，色场幕与光环的关键帧只在导航相位（enter / in / exit）存在，根导航的显隐过渡也只在导航相位里有——静止时页面上没有「仍在运行」的动画。
按下后的第一帧就已经在动：主角值的 FLIP、被覆盖页的注释淡出和色场幕都从 24ms 处开始（`--s01-dl:-24ms`），总长不变。

### 1. 签名转场「身份展开成资料页 → 值原位变成编辑 → 保存原位落定 → 回到原位」
| 段 | 谁动 | 从哪里 → 到哪里 | 时长 / 曲线 | 文字何时可读 |
|---|---|---|---|---|
| 触发 | 称呼按压变蓝（:active 90ms） | — | 80–90ms | 始终 |
| 发展 | 称呼、ahe_ju、邮箱三段字（`[data-m]`） | 从首页的 56 / 15 / 15px 位置，量测 FLIP（位移 + 等比缩放，不做非等比）到资料页的 56 / 34 / 30px 位置 | 380ms `cubic-bezier(.3,.4,.2,1)` | 字本身全程可读（不淡出） |
| 发展 | 首页其它注释（值栅格、索引、待处理句） | 原位下沉 22px 并淡出 | 150ms ease-out | 先走，避免叠影 |
| 发展 | 色场 | 纸色幕从首页 50% 处降到整屏以下（`translateY`） | 380ms 同曲线 | — |
| 落定 | 资料页注释（标签、复制、已报名的局） | 淡入并上移 14px | 220ms，延迟 125ms | ≈ 345ms |
| 编辑 | 同一套字原位不动；下划线从左画出、字数与「可空」淡入、CTA 从底部升起 | — | 下划线 300ms；CTA 320ms；「个人资料 → 编辑资料」先出后入（110ms / 190ms 延迟 120ms），不交叉 | 始终 |
| 保存 | CTA「保存中…」（≥ 300ms 可见，320ms）→ 结果原位：CTA「已保存」、被改的字段标签旁出现绿色「已保存」 | — | 320ms 落定 | 320ms |
| 回到资料 | 下划线收回、CTA 下沉、编辑词先出后入 | — | 210 / 230ms | — |
| 返回首页 | 三段字从资料页位置 FLIP 回首页的身份行（新称呼「阿禾二」+「刚更新」），色场升回 50% | 资料页 → 首页原位，滚动位置由控制器恢复 | 340ms 同曲线；首页注释 210ms，延迟 110ms 回来 | 字全程可读 |
可打断：控制器在新动作前先结算当前转场；FLIP 每次在相位开始时重新量测（扣除祖先与源元素正在进行的变换），所以中途返回也落在正确位置。返回的终态等于栈顶 idle 态（无跳动）。失败：CTA「重试保存」+ 一行错误字在 CTA 上方，输入保留。

### 2. 「值展开成页」（首页的收藏 / 提醒 / 记录 / 城市 / 外观 / 举报，及列表 → 详情）
- 触发：值按压变蓝 90ms。
- 发展：被点的值（如「3 个局」34px）量测 FLIP 到下一页的主角位置（48px，Archivo 数字），380ms `cubic-bezier(.3,.4,.2,1)`；首页其余文字 150ms 下沉淡出；色场幕移到目标页高度（380ms）。列表行 → 详情同理：局名从 22px 行标题变成 31px 详情标题。
- 落定：目标页注释与列表 220ms 淡入（延迟 125ms）；页头 30px 标题淡入（200ms，延迟 135ms）。
- 返回：主角值反向 FLIP 回到原值的位置（340ms），原页注释 210ms 回来；滚动位置恢复。
- 页内的值更新（城市、提醒开关计数、外观名、账户状态）：主角值 260ms 由 20% 透明度回到 100%（原位，不移动）。

### 3. 「环境切换」（外观页点名字 → 整页即预览；应用 / 取消）
- 触发：衬线名字（棉糖 / 光晕 / 落日，44px）点击；被选中的名字从 30% 墨变成全墨、下方 3px 墨线 200ms 画出。
- 发展：新环境色场从 14px 模糊 + 透明淡入，旧色场同时模糊淡出；650ms `cubic-bezier(.22,1,.36,1)`（R3 参数）。文字不动。
- 落定：主角值换成新名字（260ms 原位淡入），句子换成该环境的描述；预览中出现 JU 蓝「应用「落日」」与「取消预览，回到「棉糖」」。
- 返回：取消 = 同一 650ms 反向交叉；应用 = 写数据 + 脚注条「外观已换成「落日」」。

### 附：列表让位（收藏「拿出 / 撤回」）
拿出：该行先淡（0–40%）并把行高从 1fr 收到 0fr（270ms `cubic-bezier(.4,0,.7,.2)`），下面的行跟着上移；收完才写数据，「N 个局」随之用 260ms 值更新动作换数。拿出的是主条目时，主条目内容先淡出（260ms，渐入曲线，正好在换数据时到 0），下一条在列表里的那一行同时收起，数据更新后主条目换成它并淡入（240ms）；主条目位低于 30% 不透明的时间约 75ms（1× 实测）。撤回：反向——行从 0fr 展开（280ms），主条目内容交换回来；色场高度跨过 4 条时 420ms 缓动到新位置。
### 附：断行不同的值
同一个值在两页的行数不同（例如举报表单里的一行标题回到「我的局」的两行标题）时，FLIP 不硬跳：前进时移动的值在 15–45% 淡入，返回时在 35–65% 淡出、目标处的真值在 45–85% 淡入；目标行的 ☆ / 举报 / 拿出等控件在值落定前保持隐藏，落定后 180ms 淡入。

## 减少动态（三源）
面板开关（`.rm`）、系统 `prefers-reduced-motion`（`.rm .rm-sys`）、产品内偏好（`.rm-user`）：不运行任何关键帧（`animation:none`，伪元素也包括：下划线与光环），过渡压到 1ms，控制器计时器归零；状态与结果完全相同（瞬切即结果）。被覆盖的页在减少动态下保持光栅化（透明、不可点），所以一帧之内返回的页面是完整的（复核里「返回后数字缺失」的问题就是这一帧里页面还没画出来）。外观页写明「跟随系统」状态。
## 页头静止态
滚动停在收拢区间内（0 < hc < 1）180ms 后自动滑到完全展开或完全收拢；页面返回后也做一次；完全收拢时工具行下出现一条 1px 规线。

## 一个仍可能失败的设计判断
复核确认过的风险（收藏、举报读成「大数字 + 列表」）已经按备用方案改成「主条目 + 日期字脊」。仍可能失败的是条目多的时候：收藏 13 条（many）时色场回到 44%，主条目之下仍是一长列目录行，第二屏以后仍可能读成整齐的列表。检查方法：`lead-sheet.cjs <dir> s-fav-many --codes S01 --gray` 与 `s-fav / s-reports / s-account / s-about` 的灰度缩略图（`evidence/S01/stage2/gray-sparse.png`）；若失败，下一步是按日期分组（「本周」「下周」），每组一个大日期数字作组头。
