# S07 预览在上 · 三个核心动作与关键视觉参数

命题：手机上面 40% 是环境光里的「预览」（舞台），下面 60% 是一张白纸（设置）。白纸上的每个控件都是它驱动的那个预览元素的小一号（同材质、同大字），或带着卡上那一处的颜色；任何改动先在上面的卡上发生，再落到下面的控件里。舞台上只有五种对象：资料卡轮播（三位观看者）、墨色事实卡 G（记录 / 举报 / 约定 / 收藏的局 / 会话 / 草稿）、提醒横幅、找局头、环境头。对象之间的切换都由同一个变形引擎完成：变更前 `morphCapture()` 记下舞台里每个 `[data-m]` 的计算 transform / opacity，渲染后 `morphRun()` 把旧值写进 `--mt / --mo`，用 `@keyframes s07-ma | s07-mb`（交替命名以便重启）从旧值回到新值。三个核心动作都用 `this.motion(name, fn)` 登记，可重播、可暂停（`.app.paused`）、可关键帧（`.app.scrub` + `--frame`）；面板 / 系统 / 用户三种「减少动态」任一开启时，所有时长压到 1ms，状态与结果不变（rm-check：rmSys true，findings []）。

变形引擎的统一节奏（`S07_MS = 300`）：只移动的元素 300ms `cubic-bezier(.2,.8,.2,1)`；变淡离开的元素 150ms `cubic-bezier(.4,0,1,1)`；新出现的元素延迟 114ms、用 186ms `cubic-bezier(0,0,.2,1)` 进来。离开与进入错开，所以同一位置的两段字永远不会以同等强度叠在一起。每一帧都保留到整个动作落定（`animation-fill-mode: both`，最后一次变形 700ms 后才撤掉动画名），所以暂停在离场段之后再拖关键帧，帧 0 仍是动作的起点（例：换光暂停在 200ms，帧 0 显示「棉糖」，不是空白）。

## 1. preview-push · 预览变形 + 纸页推入（签名转场）

| 段 | 谁动 | 从哪里 → 经过什么 → 停在哪里 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 首页任一块（资料、隐私、收藏、城市、提醒、外观、记录、举报、帮助、账户、关于）；纸页里打开子页的块、行与按钮 | 块按下 `scale(.97)`、行按下底色 rgba(20,22,31,.035)；变更前记录舞台每个 `[data-m]` 的当前值 | 120ms ease |
| 发展 · 舞台 | 预览对象 | 首页 → 资料：申请人卡从居中（`50cqw − 卡宽/2`）左移到 20px，「局主 · 成局后」「同局成员」两张卡从 `translateX(64px)`、透明进入；卡顶一行从「活动 · 等局主审核」换成「局主 · 审核时」（旧行上抬 7px 淡出，新行从下 7px 升起）。对象类型变化时（卡 → 墨色卡 / 横幅 / 找局头 / 环境头）整组按同一错位节奏交叉；墨色卡内容用两个槽位交接 | 移动 300ms (.2,.8,.2,1)；离开 150ms；进入 114ms 后 186ms |
| 发展 · 纸页 | 新页 / 下层页 | 新页 `translateX(100%) → 0`，左缘 1px 细线；下层页 → `translateX(-26%)` 并淡出。舞台不属于页面，只有它的内容在变形；顶部 JU + 一行说明用两个槽位交叉 | 320ms `cubic-bezier(.2,.8,.2,1)` |
| 落定 | — | 纸页上沿停在 `--stage`（手机高 40%；键盘弹出时 132px），上圆角 28px | — |
| 文字何时可读 | — | 页标题一开始就按最终字号排好，只平移不缩放，约 120ms 起可读；舞台新字约 200ms 起可读 | — |
| 打断 | — | 可以。每次变形都从「当前计算值」出发，半途再点会从半途继续；导航栈的结算由控制器负责 | — |
| 返回 | 顶页 / 下层页 / 舞台 | 顶页 → `translateX(100%)`；下层页从 −26%、透明回到原位；舞台反向变形（轮播 → 居中的申请人卡）；首页的滚动位置保留，滚动联动的预览按当前位置重新推导 | 280ms `cubic-bezier(.32,.72,.3,1)` |

根导航（找局 / 我的局 / 设置）：离场的纸 120ms `cubic-bezier(.4,0,1,1)` 先淡完，新纸延迟 100ms 再用 180ms `cubic-bezier(0,0,.2,1)` 淡入，两页正文不会同时以可读的强度叠在一起；舞台用同一个变形引擎从找局头变回申请人卡。纸页的层次按角色定：顶页 z 3、下层页 z 2、离场页 z 1（不再取决于 DOM 顺序），所以文本表单与「帮助 → 我的举报」的进出也是新页在上；新页滑入的 320ms 里内容区不接点击（返回仍可点），双击不会落到正在滑入的页上。
登记：`openProfile` 里的 `this.motion('preview-push')`；重播时 `beforeReplay` 先回到首页、清空观看者与焦点，再从首页重新推入。

## 其他动作（不登记）

- 保存资料：按钮「保存中…」360ms（`saveMs`，≤ 420）→「已保存」；舞台卡顶一行换成「已保存 · 之后的报名用新资料」，改过的字段铺环境色，保持 2600ms；120ms 后自动返回（280ms），资料页对应的块右上角带「刚更新」角标（共享核心 4.5 秒后撤去）。
- 保存失败：卡顶一行「没保存成功 · 卡上的改动还在」（#FF8FA0），改过的字段下划同色线；输入保留，按钮「重试保存」。
- 确认层（未保存 / 退出演示）：先让舞台显示后果——会话卡变成「已结束 · 数据保留」（胶囊「已结束」）；申请人卡顶一行「改动还没保存」并标出没保存的字段；文本表单的草稿在墨色卡上划掉，标「离开就丢掉」。决定本身是纸页的一页（上沿与纸页同高，30px 标题、带标记的行列出会变 / 不变的东西），从下方升起 320ms `cubic-bezier(.2,.8,.2,1)`，离开时落下 240ms `cubic-bezier(.4,0,1,1)`。
- 按压：块 `scale(.97)` 120ms ease；行底色即时；主按钮 / 次按钮 `scale(.958)` 120ms ease；开关 160ms。详情页「经过」里带色点的一步、收藏块、局主微信块：点一下，上面卡里对应的那一行铺 40% 环境色 + 2px 下划线（胶囊则加一圈描边），1.8 秒后撤去——联系不靠悬停。
- 减少动态（面板、系统、用户开关任一）：纸页、确认页、环境层、系统弹窗、提示条都 `animation: none; transition: none`，离场页直接 `visibility: hidden`，返回时第一帧就是首页的终态，没有空白帧。
- 提示条：环境的胶囊色底 + 墨字 + 3px 纸色外圈，落在墨色块上也分得开；不接点击。
- 系统权限弹窗：系统样式，260ms 从 .94 放大，遮罩 200ms。
- 找局右滑收藏：卡跟手（拖动时无过渡），松手回弹 500ms `cubic-bezier(.2,.9,.3,1.04)`。

## 关键视觉参数

- 字体：界面 Noto Sans SC（400 / 500 / 600）；数字与标志 Archivo 700（JU 标 20px、墨色卡大数字 44px、日期块 20px、约定编号 15px）。
- 字号阶：44（卡上大数字）· 34（首页块与本机数据块的数字）· 30（页标题、确认标题，收拢到 18；详情页标题用对象名，名字长时按自身长度降到 24 / 20，不随屏宽变）· 26（外观块的环境名）· 22（称呼块、城市块、首页块的称呼 / 城市）· 20（日期数字）· 17（行名、事实格的值、卡上称呼）· 15（行值、导语、正文、横幅标题）· 14（说明、注释）· 13（标签、胶囊、最小字号）。
- 色板：墨 #14161F（卡、标记、开关开）；正文 #252B3A；次要 #535B70；细线 rgba(20,22,31,.08)；纸 #FFFFFF；JU 蓝主按钮 #5462CF → #4553BE → #3C49AE（只给主动作）；危险 #B8243A / #FCEBEE；墨上的错误 #FF6B81 / #FF8FA0。环境色：棉糖 高光 #F49BC4、点 #D9659A；光晕 #FF8A3D、#EE6420；落日 #FFC53D、#F2672A。归属色（称呼 / 邮箱 / 微信，取自各环境自己的三种光）：棉糖 #E57FB2 / #9A86E6 / #4FAED8；光晕 #FF7A2E / #A98BE6 / #E2A04E；落日 #FF7A33 / #3E8BEF / #E9A713。
- 光源与表面：只有一个光源——顶部的环境（棉糖 / 光晕 / 落日的渐变场）。墨色卡坐在光里：纯色 #14161F，只有顶边 1px 内描边用环境的 `--erim`（光照到卡沿），全页没有投影。纸页是平的白纸，上圆角 28px；纸上的颜色只有三种来源：墨色小卡（与舞台的卡同材质）、环境光（外观块、选中的城市、「等你处理」的洗色）、归属色淡底（资料 / 编辑里每块控件属于卡上的哪一处）；其余是白纸加 1px 细线。行内标记仍是预览元素的缩影（墨色方块 = 卡上的元素；白底描边 = 纸上的对象；环境色 = 环境 / 横幅）。灰度下环境场仍是围住墨色卡的中灰体量（lead-sheet --gray 已看）。
- 下半的控件（比预览小一号的同一种东西）：首页每个入口是它所驱动的预览的缩影——资料、记录、举报是墨色小卡（大号 Archivo 数字 / 头像 + 称呼，称呼长时两行 17px），隐私是「三种人 × 三处资料」的点阵，收藏与城市用找局头的大字，提醒是一条小通知，外观直接铺上环境光；当前驱动舞台的那一组描 2px 环境色。资料 / 编辑 / 隐私用「归属」：卡上的称呼、邮箱验证行、微信区各有一种颜色与一种线形——称呼实线 3px、邮箱点线 2px、微信虚线 2px，并铺 16% 同色底；下面改它的那一块控件是同色淡底（16%，聚焦 26% + 2px 描边），块名下有同样线形的下划线，「谁在看」的点阵也分圆 / 方 / 菱形，灰度下靠线形与形状仍对得上；聚焦时卡上那一处铺 34% 同色。资料块的值不省略：长邮箱 / 微信让两块变通栏，「刚更新」是右上角的角标。详情页（记录、举报、收藏的局、找局里的局）：纸面不再复述卡上的格子，只放卡上没有的东西——可做的动作（描边块，带 › ）、「经过」时间线（左列日期 Archivo 20px + 月，同一天只写一次；带环境色点的一步就是卡上的某一行，点一下卡上标出；最后一步「现在」铺洗色底）、材料（墨色小胶囊，和卡上「材料」行一样）、原文。帮助入口是三块缩影（带虚线草稿框的写反馈、墨色举报卡、墨色约定卡），常见问题一题一块，选中的那题变成墨色，上面的卡就是它的答案。账户页是「留在这台设备上的」四个数字块，关于页是一块墨色约定卡 + 两块事实。文本表单的字段就是卡上的草稿框：环境色虚线框 + 12% 淡底，框头是卡上同一个墨色草稿标签（补充 / 异议 / 说明 / 反馈 / 原文），已选文件是墨色小胶囊。首页滚动联动：越过阈值（滚动区顶 + min(170px, 36% 高)）的那一组决定舞台显示什么。
- 页头收拢：控制器在滚动区与页头写 `--hc`（0 → 1，对应 96px 滚动，`headerRange`）；标题字号 `calc(30px − 12px × hc)`，左边从 20px 移到 50% 并上移到 44px 工具行的中线；说明行以 2 倍速度淡出并上移 20px；底部细线不透明度 = hc。连续、不吸附；键盘弹出时强制 `--hk: 1`。返回标签长（4 个字以上）时，标题从左滑向中线的那一段（hc 约 .3–.7）标签文字先让开、只留「‹」，收拢完成后再回来，标题不会擦过它。

## 一个仍可能失败的设计判断

详情页「纸面只放卡上没有的东西」。卡与纸的联系现在靠两件事：「经过」里带环境色点的一步（点一下，卡上那一行被标出 1.8 秒），以及动作块直接写着它改的是卡上的哪部分。风险有二：(1) 色点可点这件事不一定被发现——触屏上没有悬停提示；(2) 步骤少的对象（只收藏、还没报名的局）时间线只有两三步，纸面可能显得空。我这样检查：每页「经过」的小标题直接写「带色点的一步就在上面的卡上，点一下会标出来」；用真实指针点击记录详情的「活动」一步，截到卡上「周日 11.22 · 07:30 · 熊山 · 局主 Leon」被铺亮（灰度下是下划线 + 底色的明暗差）；在 375 / 390 / 430 三种宽度下看记录、举报、收藏详情与帮助页的首屏（widths 无溢出、最小 13px），并把四个详情页和帮助页单独拼成一张接触表逐页看「卡上说了什么、纸上说了什么」有没有重复。若评审仍觉得联系不够明显，退路是进入详情页时自动把「现在」那一步对应的卡上胶囊标亮一次（复用同一个 `lightLine`），结构不变。
