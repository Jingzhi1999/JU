# S07 预览在上 · 三个核心动作与关键视觉参数

命题：手机上面 40% 是环境光里的「预览」（舞台），下面 60% 是一张白纸（设置）。下面的每一行都带一个标记，标记是它驱动的那个预览元素的缩影；任何改动先在上面的卡上发生，再落到下面的行里。舞台上只有五种对象：资料卡轮播（三位观看者）、墨色事实卡 G（记录 / 举报 / 约定 / 收藏的局 / 会话 / 草稿）、提醒横幅、找局头、环境头。对象之间的切换都由同一个变形引擎完成：变更前 `morphCapture()` 记下舞台里每个 `[data-m]` 的计算 transform / opacity，渲染后 `morphRun()` 把旧值写进 `--mt / --mo`，用 `@keyframes s07-ma | s07-mb`（交替命名以便重启）从旧值回到新值。三个核心动作都用 `this.motion(name, fn)` 登记，可重播、可暂停（`.app.paused`）、可关键帧（`.app.scrub` + `--frame`）；面板 / 系统 / 用户三种「减少动态」任一开启时，所有时长压到 1ms，状态与结果不变（rm-check：rmSys true，findings []）。

变形引擎的统一节奏（`S07_MS = 300`）：只移动的元素 300ms `cubic-bezier(.2,.8,.2,1)`；变淡离开的元素 150ms `cubic-bezier(.4,0,1,1)`；新出现的元素延迟 114ms、用 186ms `cubic-bezier(0,0,.2,1)` 进来。离开与进入错开，所以同一位置的两段字永远不会以同等强度叠在一起。

## 1. preview-push · 预览变形 + 纸页推入（签名转场）

| 段 | 谁动 | 从哪里 → 经过什么 → 停在哪里 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 首页任一行（资料、隐私、收藏、城市、提醒、外观、记录、举报、帮助、账户、关于）；纸页里打开子页的行与按钮 | 行按下：底色 rgba(20,22,31,.035)；变更前记录舞台每个 `[data-m]` 的当前值 | 即时 |
| 发展 · 舞台 | 预览对象 | 首页 → 资料：申请人卡从居中（`50cqw − 卡宽/2`）左移到 20px，「局主 · 成局后」「同局成员」两张卡从 `translateX(64px)`、透明进入；卡顶一行从「活动 · 等局主审核」换成「局主 · 审核时」（旧行上抬 7px 淡出，新行从下 7px 升起）。对象类型变化时（卡 → 墨色卡 / 横幅 / 找局头 / 环境头）整组按同一错位节奏交叉；墨色卡内容用两个槽位交接 | 移动 300ms (.2,.8,.2,1)；离开 150ms；进入 114ms 后 186ms |
| 发展 · 纸页 | 新页 / 下层页 | 新页 `translateX(100%) → 0`，左缘 1px 细线；下层页 → `translateX(-26%)` 并淡出。舞台不属于页面，只有它的内容在变形；顶部 JU + 一行说明用两个槽位交叉 | 320ms `cubic-bezier(.2,.8,.2,1)` |
| 落定 | — | 纸页上沿停在 `--stage`（手机高 40%；键盘弹出时 132px），上圆角 28px | — |
| 文字何时可读 | — | 页标题一开始就按最终字号排好，只平移不缩放，约 120ms 起可读；舞台新字约 200ms 起可读 | — |
| 打断 | — | 可以。每次变形都从「当前计算值」出发，半途再点会从半途继续；导航栈的结算由控制器负责 | — |
| 返回 | 顶页 / 下层页 / 舞台 | 顶页 → `translateX(100%)`；下层页从 −26%、透明回到原位；舞台反向变形（轮播 → 居中的申请人卡）；首页的滚动位置保留，滚动联动的预览按当前位置重新推导 | 280ms `cubic-bezier(.32,.72,.3,1)` |

根导航（找局 / 我的局 / 设置）：页面 280ms 交叉淡入淡出（`dir-root`），舞台用同一个变形引擎从找局头变回申请人卡。
登记：`openProfile` 里的 `this.motion('preview-push')`；重播时 `beforeReplay` 先回到首页、清空观看者与焦点，再从首页重新推入。

## 2. switch-preview · 开关一类提醒 → 上面的横幅换成那一类

| 段 | 谁动 | 说明 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 「提醒哪些事」里的一行 | 开关圆钮 `translateX(18px)`，底色墨 ↔ 灰；变更前记录舞台 | 160ms `cubic-bezier(.3,.7,.3,1)` |
| 发展 | 横幅两个槽位（以「类别 + 开 / 关」为键，所以开关正在显示的那一类也会换槽）、横幅上方的结论行 | 旧通知上抬 14px 淡出；新通知从上方 14px 落下淡入（像一条新通知到达）。关掉的那一类落下来时是半透明的灰横幅（图标变灰、字变次要色），右上角「现在」↔「这类已关闭」（红色胶囊）随槽位一起换；结论行（「这类已关闭：这条不会提醒」/「这条提醒可以送达」/ 权限各状态）同步交叉。当前类别的行标记加 2px 环境色描边 | 离开 150ms；进入 114ms 后 186ms；描边 160ms |
| 落定 | — | 点按后 300ms：横幅显示这一类的示例通知（标题取自这一类的示例活动） | — |
| 文字何时可读 | — | 旧字 150ms 内退净；新字约 210ms 过半、300ms 完全 | — |
| 打断 | — | 快速连点：每次都从当前值重新捕获，槽位只有两层，第三次点按复用正在离开的那一层，不闪 | — |
| 返回 | — | 再点一次就是反向的同一动作 | — |

登记：`toggleCat` 里的 `this.motion('switch-preview')`；重播时 `beforeReplay` 先不带动画地撤回上一次开关，再以同一方向重跑一次。

## 3. skin · 环境换光（外观预览）

| 段 | 谁动 | 说明 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 「外观与动态」里的一个环境（棉糖 / 光晕 / 落日） | 只预览、不保存；变更前记录舞台 | 即时 |
| 发展 | 环境层（舞台 40% + 纸页圆角下 56px） | 新的 `.s07-env[data-ek=a|b]` 从 `opacity .25 + blur(12px)` 显影到清晰，下面垫着 `.s07-env-old[data-skin=旧环境]`——新光像照片显影一样盖在旧光上，中间没有白闪。环境头（「现在的外观」→「预览 · 还没应用」，名字 棉糖 → 光晕）与右侧的小手机按变形节奏交接。纸页里所有环境色（标记描边、勾、标签「预览中」、头像、提醒洗色）同一帧切换 | 650ms `cubic-bezier(.22,1,.36,1)` |
| 落定 | — | 650ms；舞台说明「预览中 · 还没应用」；纸页出现「应用「光晕」」与「取消预览」 | — |
| 文字何时可读 | — | 环境头名字约 200ms 起可读；背景约 300ms 已到 85% | — |
| 打断 | — | 半途再选另一个：垫底层取点按那一刻正在显示的环境（`_lastSkin / _envOld`），不会跳回两步前 | — |
| 返回 | — | 「取消预览」用同一显影回到已应用的环境；「应用」不再换光，只换说明并出提示 | 650ms |

登记：`pickSkin` 里的 `this.motion('skin')`；重播时 `beforeReplay` 先取消预览，再重选同一个环境。

关键帧核对（共享核心 2cbe419 之后，动作落定后再拖关键帧，由面板重播并冻结）：preview-push 在 0 / 30 / 60 / 100 时新页 `translateX` 为 390 / 67 / 11 / 0px，第二张卡在 30 时仍未出发（延迟 114ms）、60 时 18px / 不透明度 .71；switch-preview 在 0 / 50 / 100 时新横幅 −14 / −7 / 0px、不透明度 0 / .48 / 1；skin 在 0 / 40 / 100 时环境层不透明度 .25 / .94 / 1、模糊 12 / 1 / 0px。释放后都回到落定状态。

## 其他动作（不登记）

- 保存资料：按钮「保存中…」360ms（`saveMs`，≤ 420）→「已保存」；舞台卡顶一行换成「已保存 · 之后的报名用新资料」，改过的字段下划环境色线，保持 2600ms；240ms 后自动返回（280ms），资料页的行带「刚更新」。
- 保存失败：卡顶一行「没保存成功 · 卡上的改动还在」（#FF8FA0），改过的字段下划同色线；输入保留，按钮「重试保存」。
- 确认层（未保存 / 退出演示）：先让舞台显示后果——会话卡变成「已结束 · 数据保留」（胶囊「已结束」）；申请人卡顶一行「改动还没保存」并标出没保存的字段；文本表单的草稿在墨色卡上划掉，标「离开就丢掉」。决定本身是纸页的一页（上沿与纸页同高，30px 标题、带标记的行列出会变 / 不变的东西），从下方升起 320ms `cubic-bezier(.2,.8,.2,1)`，离开时落下 240ms `cubic-bezier(.4,0,1,1)`。
- 按压：行底色即时；主按钮 / 次按钮 `scale(.958)` 120ms ease；开关 160ms。
- 系统权限弹窗：系统样式，260ms 从 .94 放大，遮罩 200ms。
- 找局右滑收藏：卡跟手（拖动时无过渡），松手回弹 500ms `cubic-bezier(.2,.9,.3,1.04)`。

## 关键视觉参数

- 字体：界面 Noto Sans SC（400 / 500 / 600）；数字与标志 Archivo 700（JU 标 20px、墨色卡大数字 44px、日期块 20px、约定编号 15px）。
- 字号阶：44（卡上大数字）· 30（页标题、确认标题，收拢到 18）· 22（编辑栏里的值）· 20（日期数字）· 17（行名、事实格的值、卡上称呼）· 15（行值、导语、正文、横幅标题）· 14（说明、注释）· 13（标签、胶囊、最小字号）。
- 色板：墨 #14161F（卡、标记、开关开）；正文 #252B3A；次要 #535B70；细线 rgba(20,22,31,.08)；纸 #FFFFFF；JU 蓝主按钮 #5462CF → #4553BE → #3C49AE（只给主动作）；危险 #B8243A / #FCEBEE；墨上的错误 #FF6B81 / #FF8FA0。环境色：棉糖 高光 #F49BC4、点 #D9659A；光晕 #FF8A3D、#EE6420；落日 #FFC53D、#F2672A。
- 光源与表面：只有一个光源——顶部的环境（棉糖 / 光晕 / 落日的渐变场）。墨色卡坐在光里：纯色 #14161F，只有顶边 1px 内描边用环境的 `--erim`（光照到卡沿），全页没有投影。纸页是平的白纸，上圆角 28px；纸上除了「等你处理」的环境洗色和按下态外没有底色块；标记是纸上唯一带颜色的东西，它们是预览元素的缩影（墨色方块 = 卡上的元素；白底描边方块 = 纸上的对象；环境色方块 = 环境 / 横幅），当前驱动舞台的那一组标记加 2px 环境色描边。灰度下环境场仍是围住墨色卡的中灰体量（lead-sheet --gray 已看）。
- 下半的标记：首页每行 → 它打开的预览对象；事实格 → 一张小墨色卡，卡上被这一格占用的那一行点亮（1 眉题、2 标题、3 信息行、4 底栏、0 不在卡上），指针悬停时上方卡的对应行出现下划线；隐私说明 → 称呼 / 微信锁 / 验证勾；确认层的行 → 它影响的对象。首页滚动联动：越过阈值（顶部 + min(170px, 36% 高)）的那一组决定舞台显示什么。
- 页头收拢：控制器在滚动区与页头写 `--hc`（0 → 1，对应 96px 滚动，`headerRange`）；标题字号 `calc(30px − 12px × hc)`，左边从 20px 移到 50% 并上移到 44px 工具行的中线；说明行以 2 倍速度淡出并上移 20px；底部细线不透明度 = hc。连续、不吸附；键盘弹出时强制 `--hk: 1`。

## 一个仍可能失败的设计判断

「上面 40% 永远留给预览」。对长页（约定 18 条、收藏 13 个、记录 7 条）这意味着内容只有 60% 的屏幕，而且内容页上的预览可能被看成装饰而不是信息。我这样检查：(1) 在 widths（窄屏）和 12 页接触表（390）里看每页首屏至少有标题 + 两行内容（收藏、记录在窄屏首屏 3 行；约定页在 390 首屏 2.5 条）；(2) 每个预览都必须给出该页独有、页面里没有重复的信息——约定页的卡跟着滚动显示正在读的那一条，记录页给总数与待核实，收藏页给「在找局里的样子」——在 12 页接触表里逐页对照「上面的卡说了什么下面没说」；(3) 键盘弹出时预览让到 132px，kb-check 无遮挡。若评审觉得长页挤，退路是滚过一屏后把 `--stage` 收到 132px（复用键盘的同一机制），结构不变。
