# S02 大字目录 · 关键视觉参数与三个核心动作

## 命题与构图
设置就是一张目录：九个 40px 的词按四组（资料 收藏 城市 / 提醒 外观 / 记录 举报 / 帮助 账户）排在整屏的环境色光上，每个词右边 15px 是它此刻的值。点一个词，所有词的第一个字缩成 20px 留在左边 64px 的竖栏里，竖栏右侧推进一块白纸面板。40px 的词只留给「词本身就是内容」的地方：首页目录、城市、环境、规则组、列表组名、确认层的两个选择。资料 / 编辑 / 详情页上，字段名降为 15px 次级色标签，用户自己的数据和局名才是最大的字（称呼 40、局名 38、值 26）。列表页先写结论（「1 条待核实」「1 条需补充」，可直接点开），空页仍是一张小目录（如「找局 / 城市」两个入口词、三类记录各写 0 条）。确认层也是目录：页面向下让开，问题和两个选择用首页同样的 40px 大字写在色光上。

## 关键视觉参数
- **字体**：Noto Sans SC 400 / 500 / 600（全部中文）；Archivo 600（日期 `12.27`、数字、验证码），JU 字标 Archivo 700 19px。不用衬线、不用斜体。
- **字号阶（px）**：首页目录词 40/60（竖栏字 = 40 × 0.5 = 20）· 环境名 64 · 城市 / 环境 / 规则组 / 列表组名 40 · 称呼值 40 · 详情局名 38 + 副题 22（详情页没有泛化的「活动详情」标题，局名接管页头，滚动后以 18px 出现在工具行）· 列表结论 38 · 通知「送达」结论 38（长句 32）· 收藏局名 30（长名 24）· 页标题 30 → 收拢 18 · 值 26（次要值 22）· 确认层问题 26、选择 40 · 段内小节 20/600 · 原文 18 · 列表局名 18/600 + 副题 400 · 正文 16/1.65 · 字段标签 15/500 次级色 · 首页值 15 · toast 14/600 · 注释 14 · 说明 / 标签 13。最小字号 13（「系统提示」小签 12，属于签而非正文）。
- **色板**：墨 `#14161F` · 正文 `#252b3a` · 次级 `#535b70` · 色光上的次级随环境（棉糖 `#40475b` / 光晕 `#4c3f49` / 落日 `#1f1b27`）· 面板白 `#fff` · JU 蓝 `#4553BE` 只用于主要确认（保存 / 提交 / 应用 / 开启提醒 / 重新开始）· 焦点 `#4A5AD6` · 错误 `#DA3A52` · 成功 `#0E9B76` · 规线 `rgba(20,22,31,.12)`。
- **光源 / 表面**：唯一的颜色是整屏环境色光（棉糖 = 粉 / 薰衣草 / 青的多段径向水面；光晕 = 暖白上的橙紫光环；落日 = 蓝 → 橙 → 黄天色），全部是 CSS 渐变；面板是纯白纸，左上 28px 圆角，没有投影、玻璃、颗粒或发光。光晕在二级页另有一张场（`--g-halo-deep`）：光环中心移到竖栏左外侧，竖栏自上而下是橙 → 杏 → 丁香，顶带左橙右弧，随签名转场 380ms 交叉淡入；首页与外观预览仍用标准光晕。竖栏平均饱和度 0.26、白舌片对竖栏 1.7–2.3:1，光晕下舌片另有 1px 次级色内缘。首页页头收拢时和根导航背后用同一张色光的切片（`background-size:100% var(--ph)`，页头取顶、根导航取底）。当前词的白色舌片（两个凹圆角用径向渐变伪元素画出）把竖栏上的字和面板连成一体。
- **列表语法**：记录 / 举报 / 已报名 / 我的局 / 找局卡片 = 左栏 Archivo 日期（18px + 周几 13px）、右栏 18/600 局名 + 400 副题（「名 · 副题」拆成两个字重，换行只落在词之间，不留悬空的「·」）+ 14px 一行状态。收藏是逐条「条目」：日期行、30px 局名、18px 副题、地点，★ 在日期行右端可直接拿出。城市 / 环境 / 规则组 = 40px 词行。开关是 46×28 的墨色开关。
- **断行**：中文一律 `word-break: keep-all`，只在词与标点处换行；「 · 」与后一段绑在一起（行首可以是「· 副题」，行尾不留悬空的点）；称呼按 `Intl.Segmenter` 的词断开，单字随前一个词（「十一点」不拆），「·」两侧不断；微信号与邮箱只在 `. _ -` 之后和 `@` 之前断（仅显示，复制用原值）。
- **确认层 / 系统提示（未保存、退出会话、通知权限）**：不是白色底部卡片。面板整体向下让开（`translate` 量到问题块底部 + 30px，360ms `--e-push`），露出它「下面」的色光；问题 26px、说明 15px、两个选择是首页同款 40px 大字，危险项后面跟一个错误色圆点（像首页的提醒圆点），「退出登录（本地演示）」写成「退出登录」+ 15px 注释「本地演示」；系统提示多一枚「系统提示」小签。竖栏一直可见；让开的面板蒙 5% 墨，点它等于安全项，Esc 同样；背景 `inert`，焦点先落在安全项。
- **toast / 撤销**：一条从左缘长出来的墨色舌片（右端圆角），14/600 白字，成功前有薄荷色勾，错误为酒红 `#5b1a2b`。它写在页面上方 44px 的色光带里（外观页写在让开的面板上方、从竖栏边缘长出），从不压在刚变化的内容上；`pointer-events:none`，不吃任何点击。toast 属于说出它的那一页：离开即移除；保存 / 提交后控制器紧接着返回上一页的那一次，跟到返回的页上。撤销条留在收藏页底部，只有「撤回」按钮接收点击。
- **页头收拢**：控制器写 `--hc`（0→1，`headerRange` 72px）。详情页的工具行标题就是局名，静止时透明、随 `hc` 显出。面板页 `.s02-pt`：`font-size: calc(30px - 12px*hc)`，`left: calc(20px + (50% - 20px)*hc)` 加 `translate(calc(-50%*hc), calc(-45px*hc))` 连续移进 52px 工具行正中；14px 状态行 `opacity: 1 - 2.4hc`；工具行底部一条 `rgba(20,22,31,.1*hc)` 细线。首页 `.s02-ht` 同样 30 → 18 移到正中，状态行与身份块按 2.4 倍淡出，背后的色光切片随 `hc` 显出并以遮罩柔化下沿。首页状态行是真实状态（「2 项需要处理 · 纽约」），二级页的辅助行也写真实状态（「nyu.edu 已验证 · 已报名 7 个局」「6/6 类开启 · 未申请系统权限」），演示边界只在账户 / 关于页各一句。

## 三个核心动作（全部是 @keyframes，`this.motion(name, fn)` 登记：目录 → 竖栏 / 竖栏换页 / 值更新）
暂停 = 面板的 `.app.paused`（ju-fx 的 `animation-play-state: paused`），在飞行中停住；关键帧 = 重新渲染后把三个核心动作的动画（`s02-panel-* / c1-* / c2-* / fo / vo / fi / vi / dot-* / tg-* / sw-* / va / vb`，不含 toast、确认块等一次性动画）的 `currentTime` 设为「帧 × 自身时长」（WAAPI seek，不调 play() / pause()，动画仍属于 CSS）；若开始拖动时没有任何动画在跑，共享 mixin 先重播上一个核心动作，我的 seek 等它进入运动相位后再落到所拖的帧，所以动作跑完之后也能拖回任意中间帧（已用 2cbe419 的新核心验证：10 / 50 / 90% 三帧落点正确，释放后回到落定态，飞行中暂停保持住）。重播通过 `beforeReplay` 先把导航栈放回动作开始前的状态。减少动态三源（面板 `.rm`、系统 `.rm-sys`、用户偏好 `.rm-user`）把所有动画 / 过渡改成 1ms，结果状态完全相同；外观页「动态」一行写明「跟随系统」与否。

### 1. 签名转场「目录 → 竖栏」（首页点词进入那一页；返回是它的反向）
| 段 | 谁动 | 从哪里 → 到哪里 | 时长 / 曲线 | 文字何时可读 |
|---|---|---|---|---|
| 触发 | 被按的词右移 3px | — | 110ms ease | 始终 |
| 发展 | 每个词的第一个字 `.s02-c1` | 原位 40px → 同一行的竖栏位置 `translate(-12px, var(--st)) scale(.5)`（`--st` = 首页滚动量，字落在未滚动的槽位上） | 380ms `cubic-bezier(.32,.62,.2,1)` | 全程可读，从不淡出 |
| 发展 | 第二个字 `.s02-c2` | 折进第一个字：`translate(-52px) scale(.5)`，40% 前消失 | 同上 | 前 40% |
| 发展 | 15px 值、页头、隐私 / 关于两行、根导航 | 左移 24px（值）/ 16px 并淡出，20–22% 前走完 | 380ms linear 段 | 先走，避免叠影 |
| 发展 | 提醒圆点 | 跟着字进竖栏 `translate(-66px, st+4px) scale(.75)` | 380ms 同字的曲线 | — |
| 发展 | 白纸面板 | 从屏幕右外 `translateX(100% + 40px)` 推到 `left: 64px` | 380ms `cubic-bezier(.2,.86,.2,1)` | 面板标题约 260ms 可读 |
| 落定 | 白色舌片 | 50% 起从 `scaleX(.15)` 长到 1，把当前字接进面板 | 后 50% | — |
| 返回 | 全部反向（`s02-exp`）：面板滑出，字从竖栏放大回原位，第二个字 36% 后展开，值与页头 40–44% 后回来，舌片 32% 前收回 | 竖栏 → 目录原位；首页滚动位置不变 | 340ms `cubic-bezier(.38,0,.22,1)` | 第一个字全程可读 |
可打断：收拢途中按「目录」时，S02 先读面板 `s02-panel-in` 的当前进度 p，用两条曲线的反函数求出反向动作的起点 q（`e_exp(q) = 1 − e_col(p)`），以 `--xq` 负延迟让反向从面板当前位置开始，不再先跳到竖栏终态（实测：面板 40px 处按返回，下一帧仍在 40px）；字的缩放因两条曲线不同仍有约 0.05 的差。保存后返回首页时，首页的称呼与对应值用动作 3 原位落定。

### 2. 「竖栏换页」（在面板里点竖栏上的另一个字）
- 触发：竖栏字的 64×60 命中区；有未保存修改时先出确认层（同一个守卫）。
- 发展：白色舌片从旧字滑到新字（`translateY(var(--tyf)) → translateY(var(--ty))`，300ms `cubic-bezier(.22,.82,.24,1)`）；页面按竖栏方向换：往下换时旧页上移 40px 并在 35% 前淡完、新页从下方 40px 在 30% 后升入（两页不叠印）；往上换方向相反（`s02-sw-fwd / bwd` 由新旧字的上下关系决定）。面板本身不动，所以只有内容在换。
- 落定：300ms；新页标题从 30% 起可读。同组更深的页（例如记录详情）点自己的字等于返回上一层（push / pop 是横向：新页从右推入 360ms，下层左移 26% 并变淡；返回 300ms）。
- 返回：用面板里的「‹ 目录」回首页时就是动作 1 的反向；舌片落在哪个字，返回标签就写哪个页名。

### 3. 「值更新」（保存后的称呼、默认城市、外观、通知「送达」结论）
- 触发：资料保存成功（220ms 后返回资料页）、点选城市、应用环境、回答系统权限提示。
- 发展：被改的那一个值原位从 `translateY(10px)`、透明度 0、JU 蓝升到位（55% 时已不透明，仍为蓝），再在后 45% 变回墨色；其它字一动不动。两套同名关键帧 `s02-va / s02-vb` 交替，重播一定重新开始。
- 落定：260ms `cubic-bezier(.22,.82,.24,1)`。保存的时间线（复核实测）：「保存中…」约 370ms、「资料已保存」约 400ms 出现（≤ 420ms），新称呼在资料页原位落定约 890ms（共享处理 360 + 共享返回等待 220 + 返回 + 值更新 260）。「刚更新」小签由控制器在保存 4.5s 后撤下；值更新类在 420ms 后撤掉，一次性动画都用 `backwards` 填充，结束后不挂着。
- 可打断：值动画只作用于一个元素，任何导航都不会被它阻塞。

### 其它（非核心）动作
确认层：面板下让 360ms，问题块作为一个整体从左 20px 进入（28% 后可见，不做逐项交错）；回答后问题块在面板下面 280ms 淡出，面板升回盖住它。toast 舌片：底色 300ms 从 `scaleX(.12)` 长出，文字 34% 后进入。竖栏换页的两页不再叠印：旧页 0–35% 走完，新页 30% 起进入。根导航切换 320ms：设置 ↔ 接缝时，接缝的整张白纸从底部升起盖住目录 / 下沉露出色光与目录（目录本身不动、不淡）；两个接缝之间旧页 36% 前淡完、新页 30% 后进入。外观预览：面板下移 30% 屏高（360ms），环境层 650ms 交叉模糊淡入。

## 一个仍可能失败的设计判断与我如何检查
**判断：面板里唯一的导航是 20px 的「首字竖栏」（资 收 城 提 外 记 举 帮 账），没有标签栏。** 风险是单字脱离原词后不够明确（「提」= 提醒、「外」= 外观）。检查：① 竖栏字就是用户刚刚看到的那一行词缩成的，签名转场让每个字沿自己的那一行落进竖栏（flow-enter 第 13 帧、stage1/flow-core 逐帧核对：字的 y 不变）；② 每个竖栏按钮有完整词的 `aria-label` 与 `aria-current`，白色舌片标出当前词，面板返回标签写「目录」；③ 375 宽与长内容下命中区 64×60、kb-check 无发现、widths 三宽无溢出；④ 直接跳到深层状态（没看到目录就进来）时竖栏的含义最弱——这一点只能靠后续真人测试确认，目前没有做。
