# S09 夜灯 · 三个核心动作与关键视觉参数

命题：一间夜里的屋子。整屏是墨色，只有三盏环境灯（`mix-blend-mode: screen` 的径向光池，340–460px，峰值 α .32–.45）照着它；灯平时不动、不漂、不呼吸，只在焦点改变时移动。三个房间（设置首页 / 找局 / 我的局）是灯下的陈述：13px 标签压 30px 的值，值被它头顶那盏灯染色。其余每一页都是一块墨板（左右下各内缩 16px、顶 48px、四角 28px），从下方升起，三盏灯聚到它背后，光从四边漏出来；墨板里只有一汪读书灯，跟着焦点走。确认层、系统提示、toast 是同一种材料的小块：小墨板在暗处升起，三盏灯聚在它背后。

三个核心动作都用 `@keyframes` 写，并通过 `this.motion(name, fn)` 登记（`rise`、`follow`、`skin`；另有 `edit` = 进入编辑态的 rise 变体）。暂停：`.app.paused` 冻结全部动画（面板通用规则 + 本方案的 `.s09-lamp / .s09-lamps / .s09-slab / .s09-pg / .s09-flamp / .s09-fpool` 规则）；关键帧：`.app.scrub` 把这些动画停住并用 `animation-delay: calc(-1 × var(--frame) × 时长 × var(--k))` 定位（灯用各自的 `--dur`，读书灯用 `--pdur`，墨板 510 / 300ms，层内推入 315ms（上下两层都定位）、层内返回 340ms，换灯 650ms）。减少动态三源（面板 `.rm`、系统 `prefers-reduced-motion`、用户在外观页的开关 `.rm-user`）任一开启：所有 animation / transition 压到 1ms、延迟 0；状态、落点、颜色与全动态完全一致。

## 1. rise · 灯先找到被点的那句，再聚到墨板背后，墨板升起（签名转场）

| 段 | 谁动 | 从哪里 → 经过什么 → 停在哪里 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 首页的陈述（称呼、收藏、城市、通知、外观、记录、举报、四个小项）、提醒句里的事件名；找局 / 我的局的行（控制器驱动的推入走同一路径） | 按压：值 `opacity .7`；胶囊 `scale(.96)` | 120ms |
| 发展 ① 找 | 三盏灯 | 从此刻的真实位置（读计算后的矩阵，任何中途状态都能接）移到 focus：主灯落在被点陈述的中心，另两盏在它右下 / 左下；其余陈述降到 .64 | 480ms `cubic-bezier(.22,1,.36,1)` |
| 发展 ② 聚 | 三盏灯 + 墨板 | 170ms 后灯转向 gather：主灯到墨板顶边中间（y = 48 + 30），两盏贴左右两侧（58% / 88% 高，让漏光沿墨板两侧一直流到下沿）；墨板 `translateY(100% + 60px) → 0`；房间降到 .14 | 灯 560ms 同曲线；墨板 420ms `cubic-bezier(.32,.72,0,1)`，延迟 90ms；控制器 fwd 520 |
| 落定 | 墨板 inset 16 / 顶 48 / 圆角 28；读书灯落在新页第一个 `data-lamp` 的右下（+64, +26），让标签与值坐在光的肩上而不是光心；第二盏较暗的低灯（`.s09-llamp`）按页面类型落在下半屏：列表在日期列后（左下，l2）、详情在事实后（右侧中下，l1）、长文是一条贴下沿的地光（l2）、表单在主动作旁（l1）、设置类在左下（l1）、资料在右下（l2），所以每一页的下半屏都有一处亮 | | 读书灯 460ms；低灯 620ms `cubic-bezier(.22,1,.36,1)`（transition） |
| 文字何时可读 | 新页内容随墨板一起升起，不缩放、不淡入；约 300ms 时墨板上半部已到位可读 | | |
| 打断 | 任何时刻返回 / 再点：控制器先结算当前转场，灯从当前读到的矩阵出发，不跳回起点 | | |
| 返回 | 墨板下沉；三盏灯回到来时那句陈述停 760ms（眼睛找到刚才的位置），再散回 rest；改过的值在原位，旁边「刚更新」4.5 秒（控制器清除） | | 下沉 300ms `cubic-bezier(.45,0,.8,.45)`；灯 focus 420ms → rest 620ms |

重播：`beforeReplay('rise')` 瞬时回到首页、灯 rest，再从同一陈述重来。

## 2. follow · 墨板里的读书灯跟着焦点走

| 段 | 谁动 | 说明 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 墨板里点行（收藏 → 详情、记录 → 记录详情、举报 → 举报详情、帮助入口、补充 / 异议 / 申诉）；表单里聚焦一个字段 | | |
| 发展 | 读书灯（460×420 的 l0 光心 + l1 肩光）从当前位置（读矩阵）滑到被点的行；随后层内推入：下层页 110ms 淡出，新页从 +16px 升起淡入（延迟 35ms；旧页 ease-in 先慢后快地退，新页 ease-out 先快后慢地进：交接只有一帧，两层都在 .2–.4 之间，没有空板也没有明显重影）；推入后 170ms 读书灯去新页的锚点 | 表单：读书灯落到聚焦字段，两侧的灯降到该字段高度（field 模式），顶灯降到 .42，聚焦字段成为墨板上最亮的地方 | 读书灯 300ms → 460ms `cubic-bezier(.22,1,.36,1)`；推入 280ms `cubic-bezier(.2,.8,.2,1)`；field 520ms |
| 落定 | 读书灯停在锚点右下，文字在光肩上（51 个状态 × 3 环境实测全部 ≥ 4.5:1，见文末） | | |
| 滚动 | 长页滚动停下 140ms 后，读书灯滑到最靠近阅读线（墨板 36% 高）的那一行；回到顶部时回到本页锚点。光跟着视线往下走，不留一整片暗的下半屏 | | 520ms 同曲线 |
| 返回 | 上层页 100ms 淡出；下层页从 −10px 回来（260ms，延迟 80ms：上层 ease-in 退到 .3 左右时下层才开始，交接只有一帧，不重影也不留空板）；读书灯先回到来时那一行停 700ms，再回到本页锚点 | | 320ms |

重播：`beforeReplay('follow')` 把父页放回栈顶、灯瞬时 gather，再从同一行重来。

## 3. skin · 换灯

| 段 | 谁动 | 说明 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 外观页点一种环境（预览）、应用、取消预览 | | |
| 发展 | 灯层 `.s09-lamps` 与墨板里读书灯的外层 `.s09-fpool` 一起从 `opacity .25 + blur 12px` 回到 `1 + 0`（奇偶两个同义动画名 `fx-a / fx-b`，连续切换每次都重新开始）；同时三盏灯从当前位置移到新环境的 rest 位置；`data-skin` 换掉全部灯色（`--l0..2` 光心、`--r0..2` 光缘）与值的染色（`--t0..2`），所以首页的值在原位换色 | 唯一用到模糊的地方，只作用在灯层，不碰文字 | 650ms `cubic-bezier(.22,1,.36,1)` |
| 落定 | 新环境的灯位；每个值被它头顶那盏灯染色（每种环境一张 TINT 表） | | |
| 返回 | 取消预览 = 同一动作换回已应用的环境 | | 650ms |

重播：`beforeReplay('skin')` 安静地取消预览（不播放），再预览同一环境。

## 其余动作

- 根导航切换（`dir-root`）：三盏灯、JU 字标和根导航都不动也不淡（离场房间的字标隐藏，进场房间的字标在同一位置从第一帧起就是满不透明度）。只有两个房间的文字交叉淡化：标题和辅助信息在 `.s09-hdt`，内容在滚动层；两边在同一帧开始，各 220ms linear，每一帧两者不透明度之和都是 1，所以没有空屏（实测交叠约 110ms，例如 .53 / .47）；进场内容另外升起 8px（320ms ease-out）。系统、面板或用户减少动态时是第一帧直接切换；灯回 rest 520ms。层内替换（`dir-swap`）同样先出后入（120ms / 220ms 延迟 100ms）。
- 确认层（未保存、退出演示）：幕 220ms 变暗到 .8；三盏灯从屏外聚到小墨板背后（`translate + scale 1.3 → 1`，420ms `cubic-bezier(.22,1,.36,1)`），左上 l0、右上 l1、下沿 l2，光从板的上沿和两侧漏出；小墨板 `translateY(100% + 28px) → 0`，340ms `cubic-bezier(.32,.72,0,1)`，延迟 40ms。决定的话（标题、留下的选择）被灯染亮；破坏性的选择是 72% 白的文字，没有胶囊。系统权限提示：同一块小墨板居中、灯聚在四周，两个选择等权（系统提示不替用户选）。toast：小墨板胶囊从页头亮带里下落 8px（280ms），两端各一盏小灯；房间和墨板都在页头亮带里出现（房间里收拢后的标题在 toast 显示时让开），墨板页上一行放不下的长 toast 落到墨板下沿、可换行。
- 保存：CTA「保存中…」→ 360ms 落定（值写入、toast「资料已保存」）→ 40ms 后墨板开始返回（与 toast 同时）；按压 120ms；开关 160ms（transition）。

## 关键视觉参数

- **字体**：Noto Sans SC 400 / 500 / 700；JU 字标 16px / 700，字距 .14em；数字 `font-feature-settings: "tnum"`。
- **字号阶**：称呼 52（长称呼换行并 `text-wrap: balance`，不缩字）/ 页面主值 52（`.s09-hero`：3 个局、待核实、18 条约定…）/ 首页陈述值与二级大句 30 / 页头 30 → 18 / 确认层标题、事件名、日期数字 24 / 外观环境名 22 / 行标题 18 / 正文、行说明 15 / 提醒句 16 / 辅助信息、导航、toast 14 / 标签、注释 13。全方案最小 13px（widths：minFont 13）。中文标题与值 `word-break: keep-all` + `overflow-wrap: anywhere`，「 · 」用 NBSP 绑在前一个词上；首页窄栏的局名按整段排行，分隔点不会出现在行首。
- **色板**：地 `#0E1016`、墨板 `#14161F`、小墨板 `#151823`；文字白 93 / 82 / 72%，墨板上的标签 84%；JU 蓝 `#4553BE → #5866D6`（只用于主确认 CTA 与「N 件事等你回应」的蓝线，蓝线是屏上唯一的发光）、焦点环 `#7685FF`；错误 `#FF8FA2`、成功 `#55DBB0`。
- **三种环境（灯色 → 值的染色）**：棉糖 = 粉 255 112 174 / 紫 156 132 255 / 青 70 204 236 → `#FFB7D8 / #D0C6FF / #A2E7F6`；光晕 = 光心橙 255 168 56 渐到紫缘 176 104 255、珊瑚 255 118 78 → 品红缘、紫 178 122 255 → 橙缘 → `#FFBE7E / #FFAED0 / #D6C2FF`；落日 = 琥珀 255 176 48 / 橙 255 104 34 / 蓝 48 146 255 → `#FFD67A / #FFAE82 / #96CFFF`。
- **光源与表面**：唯一的光源是三盏灯（墨板里的读书灯、确认层背后的灯是同三盏灯的颜色）；灯在一切内容之下，从不压在字上发光；只淡出空的光，不淡文字。值被头顶的灯染色：房间里 86% 灯色 + 白，墨板上 70% 灯色 + 白（为对比度），标签 84% 白。墨板不透明，1px 顶边高光；没有玻璃、颗粒、纹理、投影；模糊只出现在换灯时的灯层上。
- **页头收拢**：控制器写 `--hc`（0 → 1，滚动 96px）。标题 `font-size: calc(30px − 12px·hc)`，左边距从 24 / 20px 线性移到 50% 并 `translateX(−50%·hc)`，`top` 从 58 / 56px 移到 19px，与返回键同一行居中；辅助信息 `opacity: 1 − 2.2·hc` 并上移 10px；墨板页的工具条底（60px，墨板的上圆角）`opacity: hc`，滚上去的内容在 50–102px 之间淡入墨色（只在滚动时发生，静止的首屏不被遮）。

## 一个仍可能失败的设计判断，以及我怎么检查

**判断**：值的颜色来自它头顶那盏灯，而且值直接坐在灯光上（房间）或读书灯的光肩上（墨板）。这是方向的核心，也是最容易失败的地方：光晕和落日的灯更亮、更饱和，灯心一旦正好落在一个染色的值下面，对比度就会掉到 4.5:1 以下；反过来为了安全把灯调暗，又会回到阶段 1 被指出的「浑浊的棕色」。

**检查**：写了一个专门的对比度审计（`.build/S09-work/contrast.cjs` + `contrast.py`）：51 个状态（52 个减去键盘遮挡的 s-kb）× 三种环境，在 390×844 下把所有文字（含 placeholder、伪元素）设为透明后截图，对每个可见文字取它字形范围（Range 矩形；输入框取内容框与 placeholder 色）内最亮的背景像素，按 WCAG 公式算与文字颜色的对比度；有确认层时只量确认层里的字（幕下的内容不可读是设计意图）。结果：1929 个文字元素，0 个低于 4.5:1，最低 4.62（落日 · 我的举报的「2 条举报」）；摘要在 `settings-r2/evidence/S09/contrast/summary.txt`。修正过程：读书灯中心偏到锚点右下（+64, +26）、墨板上的值 70% 灯色 + 白、标签 84%、辅助信息 / 注释 / 导航 82%、房间的值 86% 灯色 + 白、placeholder 60% 白。灰度下另看 lead-sheet 缩略图，确认三种环境在灰度里仍是「暗屋 + 三团光」而不是一片灰。已知限制：审计取的是最亮像素（偏保守），但它只覆盖 390 宽；375 / 430 宽只用 widths 检查了排版，没有逐个量对比度。

**复核后的第二轮**：判断扩展到「光有没有到达深处」。复核指出墨板页下半屏只有 2–5% 是有色光，读成通用的深色列表。改法是在墨板里加一盏按页面类型摆放的低灯，读书灯跟着滚动走，墨板内缩改为 16px，两侧的灯放到 58% / 88% 高。用同一去字测量复查（max−min > 28 记为有色光，51 个状态 + 6 个滚到下半屏的状态 × 三种环境）：墨板页整体从 22–27% 升到 29–46%，下半屏从 2–5% 升到 19–55%，首页仍是 45–47%。对比度 2259 段文字仍全部 ≥ 4.5:1，最低 4.62。下半屏最弱的是光晕（19–31%），所以光晕的低灯乘 1.28。表在 `settings-r2/evidence/S09/contrast/lit-area.txt`。
