# S04 海报拼块 · 关键视觉参数与三个核心动作

## 命题与构图
设置是一张满版拼贴海报：每个设置是一块平涂色块，块与块之间只有 3px 纸缝，没有圆角、阴影、卡片或线框。块的面积等于内容的分量（身份 100% × 34cqh、收藏 60%、城市 40%、提醒 100% × 108、外观 / 记录对半、举报一条墨带、四个 25% 小块）。点一块，这块**原位长成整页**（块色成为页面底色，块标题移到页头），其余块被推出屏幕；返回时页面缩回那一块，其余块推回原位。每个二级页仍是海报：顶部是页的主导元素（88px 数字、64px 城市名、52px 称呼、事实日期、规则大数字），下面一律是块——收藏是一局一块（日期 + 局名大字）、记录是一类一块（计数 + 条目在块内）、提醒是 2 × 3 开关块（权限块在上）、隐私是 2 × 2「称呼 / 微信 / 邮箱 / 票根」关键词块、我的局里「我发起的」是 2 × 2 墨块、历史是裸纸块；确认层、toast、系统回答也都是块。

## 关键视觉参数
- **字体**：Noto Sans SC 400 / 500 / 700（正文、块标题、称呼）；Archivo 600–800，宽度 88%（所有大数字、日期、计数、字标 JU、微信号 / 邮箱 / 验证码输入，`tnum`）。系统权限弹窗用系统字体与灰面，表示「这不是 JU 的材质」。
- **字号阶（px）**：称呼 52/700（超过 6 字 40）· 海报数字 88（Archivo 700，行高 .84）· 城市大字 64 · 块内计数 56 / 40 · 页头 30/500 → 收拢 18 · 页内主句 34 / 22 · 块标题 24 / 20 / 17 · 隐私关键词 36 · 规则号 40 · 正文 15–17 · 辅助行 14 · 标签与块内说明 13（最小 13，无 12 以下；`widths.cjs` minFont 13）。
- **色板**（每个环境 = 整张拼贴的四色：主块 c1 · c2 · c3 · 墨）：棉糖 粉 `#F4B6CF` / 薰衣草 `#A99AE6`（比规范色加深一档，让三块在灰度里仍分得开：L* ≈ 80 / 67 / 85）/ 青 `#A9DEEA`；光晕 橙 `#FF6A1A` / 丁香 `#CDB9E8` / 杏 `#F3C79B`；落日 黄 `#FFC53D`（主块用黄，避免与光晕的橙主块重复）/ 橙 `#FF7A33` / 蓝 `#3D8FF0`。共用：墨 `#14161F`、纸 `#FBF8F2`、JU 蓝 `#4553BE`（只用于主确认 CTA 与「开启提醒」）、焦点 `#4A5AD6`、错误 `#DA3A52`、成功 `#0E9B76`。块上的次级字按块色取 `--s1/--s2/--s3`（墨 80% 或全墨，≥ 4.5:1）；墨块上是 76% 白。
- **光源 / 表面**：没有光源、没有渐变——色块平涂，环境 = 整屏的配色本身（首屏 100% 面积）。唯一的渐变是「外观」块与外观页页头：它们直接显示该环境的色光（三段柔和水面 / 一圈橙到紫 / 蓝橙黄天色）。按压 = 块上叠 8% 墨（120ms）；CTA 按压 `scale(.958)`（120ms）。巨大的首字（称呼首字）在身份块里用 c1 混 12% 墨，永远在称呼之后、比称呼浅。
- **页头收拢**：控制器把滚动写成 `--hc`（0→1，`headerRange = 56px`）。标题 `top: calc(58px − 39.25px·hc)`、`left: calc(20px + (50% − 20px)·hc)`、`translateX(−50%·hc)`、`font-size: calc(30px − 12px·hc)`——30px 标题连续移入 52px 工具行正中并缩到 18px；14px 辅助行 `opacity: 1 − 1.7·hc`；工具行底部 3px 纸缝随 `hc` 出现。首页辅助行是真实状态（「2 件事等你回应 · 纽约」）；演示边界只在账户 / 关于各说一句。

## 三个核心动作（全部 @keyframes，`this.motion()` 登记可重播；接 `.app.paused` / `.app.scrub`）
几何不用 transition：页面的开合用一个已注册的数 `--s04-o`（页面开度 0 = 那一块，1 = 整页），下层拼块的推开用 `--s04-p`（0 → 1），两者在同一帧里由主线程驱动 clip 边、被推开的块与移动中的标题，所以三者永远对齐。`scrub` 时 `animation-delay = −frame × 320ms × k`（环境切换 −frame × 650ms）。

### 1. 签名转场「块长成页 / 页缩回块」（首页 11 个块、收藏块 → 详情、记录条目 → 详情、详情的动作块 → 表单、举报块 → 详情、我的局历史 → 举报表单）
| 段 | 谁动 | 从哪里 → 经过什么 → 停在哪里 | 时长 / 曲线 | 文字何时可读 |
|---|---|---|---|---|
| 触发 | 被按的块 | 叠 8% 墨 | 120ms | 始终 |
| 测量 | — | 记下块的矩形 → 页面 clip 的四个起点；块标题（`[data-ttl]`）到页头标题的位移与等比缩放；推开图 | 一帧 | — |
| 发展 | 新页（块色底） | `clip-path: inset(起点 × (1 − o))` 从块的四边同时开到全屏 | 320ms `cubic-bezier(.2,.75,.15,1)` | — |
| 发展 | 块标题 | 从块里的位置**平移 + 等比缩放**到页头（30px） | 同上（同一个 `--s04-o`） | 全程可读 |
| 发展 | 其余块 | 全宽块：上方的块向上、下方的块向下推出屏幕；半宽块：只有同排的块被横向推开，新页盖住其它块 | 同上（`--s04-p`） | — |
| 发展 | 起点块自己的字 | 浮在长大的页面之上（z 30）并淡出，把位置交给新页 | 130ms | 交接 |
| 落定 | 新页的字（`.s04-fade`） | 上移 12px 淡入 | 210ms，延迟 110ms | ≈ 320ms |
| 返回 | 新页的字先走（130ms），页面 clip 缩回原块，标题回到块里，被推开的块推回，起点块的字在最后 130ms 淡回 | 原块 | 300ms `cubic-bezier(.45,0,.2,1)` | 标题全程可读 |
可打断：返回时读当前 `--s04-o / --s04-p`，从停住的开度反向缩回，时长按剩余开度等比缩短（中途返回不跳到全开再缩）；新的前进先让控制器结算上一个转场。返回的终态就是下层页 idle 态，滚动位置由控制器在揭开前恢复（`s04RestoreUnder`）。根导航切换用同一套几何：被点的标签块向上长成新的根页（300ms），旧根页在下层淡出。

### 2. 保存落定「保存 → 结果回到原位」（资料编辑；五个文字表单同语法）
- 触发：JU 蓝 CTA 按压 `scale(.958)` 120ms → 「保存中…」（`this.saveMs = 300`，契约要求的最短可见时长）。
- 发展：成功后一块墨色 toast 从底部升起（「资料已保存」，120ms）——点按后 420ms 结果落定；再过 240ms 编辑页**缩回「编辑资料」块**（签名转场的返回段，300ms）。
- 落定：资料页上被改的字段旁出现「刚更新」墨签（220ms 淡入），被改的块在揭开后压暗一次（`brightness(.86)`，380ms）；回到首页时身份块同样压暗一次。
- 失败：CTA 变「重试保存」，上方一行红点错误字，输入保留；重试成功走同一落定。

### 3. 环境切换「整张拼贴换色」（外观页点环境块 → 整屏即预览；应用 / 取消）
- 触发：环境块按压；被选块加 4px 墨框。
- 发展：六个已注册颜色（`--s04-c1..c3`、`--s04-e1..e3`）从上一个环境的值走到新值，**所有块原位同时换色**，文字与几何不动；650ms `cubic-bezier(.22,1,.36,1)`（R3 参数）。两组同名关键帧（`s04-sk0 / s04-sk1`）交替，保证连续切换每次都从当前环境出发。
- 落定：页头大字换成环境名（棉糖 / 光晕 / 落日）；底部升起「应用「落日」 | 取消预览」条。
- 返回：取消 = 同一 650ms 换回；应用 = 写数据 + toast 块（预览条出现时 toast 停在它上方）。

（其余运动：按压 120ms；页内的字 210ms 进 / 130ms 出；确认块从底部升起 280ms、停在 `var(--kb)` 之上，安全选项是大墨块、破坏性选项是更窄的裸纸块；系统权限弹窗 220ms 由 1.06 缩到 1。）

## 减少动态（三源）
面板开关（`.rm`）、系统 `prefers-reduced-motion`（控制器 `rmSys` → `.rm`）、产品内偏好（`.rm-user`）：所有 animation / transition 时长压到 1ms、延迟归零，控制器动画计时器归零；状态与结果完全相同（瞬切即结果），toast / 撤销 / 验证码倒计时这类真实时间窗不压缩。外观页的「减少动态」块写明来源：系统开启时显示「开 · 跟随系统」，系统未开启时多一行「跟随系统：系统现在没有开启「减少动态」；开启后 JU 自动跟随」。

## 一个仍可能失败的设计判断
「其余块被推出屏幕」依赖用户把被推开的块读成「同一张海报被挤开」，而不是「整页在乱跑」。全宽块的竖向推开在 320ms 里移动距离可达 500px 以上；若曲线的前段太猛，眼睛会先看到满屏位移、而不是那一块在长大。我用三件事约束它：推开和 clip 共用一个数（永不脱节）；半宽块只推同排、其余被新页盖住（位移最少）；起点块的字在 130ms 内交接。检查方法：`capture.cjs` 以 0.5× 拍首页 → 提醒（全宽）、首页 → 收藏（半宽）、收藏 → 半宽详情三段（`evidence/S04/motion-core-0.5x`、`flow-fav`、`flow-record`），逐帧确认：任何一帧里「长大的块」都是画面中面积变化最大的元素，被推开的块不越过它的边、不与它重叠出纸色空洞；若失败，下一步是把推开距离限制为一屏高的 40%（其余靠新页覆盖）。
