# S05 居中仪式 · 三个核心动作与关键视觉参数

命题：一条中轴。标题、值、控件、确认层落在竖直中线上；节奏由留白与 32px 短线给出。首页的主导体量是称呼背后 360px 的环境光。二级页从被点的那一段的中心长出，长成后是一张左右满宽的底页（上方只露出 44px 的下层页面），同一团光按页面类型变形：一个值的页面（资料、详情、状态、预览）是整盘光；列表页是被底页上沿裁掉的半圆「穹顶」，数字站在穹顶下沿，列表从首屏开始；以词为主的列表页（城市、通知、举报、帮助）是词上方一枚 72px 的小光章；表单没有头部光，光落在正在书写的那一格后面。三个核心动作全部用 `@keyframes` 写，接面板的 `.paused` / `.scrub`（`--frame`），并用 `this.motion(name, fn)` 登记，可重播、可暂停、可关键帧；减少动态（面板 / 系统 / 用户偏好任一）时时长压到 1ms，状态与结果不变。

## 1. sheet · 从被点的段中心长出、收回原处（签名转场）

| 段 | 谁动 | 从哪里 → 经过什么 → 停在哪里 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 被点的段（称呼、收藏、城市、通知、外观、记录、举报、四个索引；页里的行与按钮；接缝的局卡 / 举报） | 按压：段的值 `scale(.97)`，胶囊 `scale(.958)` | 120ms ease |
| 发展 | 新页：外层 `.s05-shw`（scale .92→1、不透明度 0→1，45% 处已到 1）+ 裁切层 `.s05-sheet`（`clip-path: inset(段的盒子 round 20px)` → `inset(0 round 26px 26px 0 0)`）。裁切从段的盒子打开到满宽，长成时左右边缘被推出屏幕 | 起点矩形由控制器记录（`data-origin`），`componentDidUpdate` 在 enter 相位读一次页未变换的盒子，写 `--s5-ox/oy`（transform-origin = 段的中心）与 `--s5-ct/cr/cb/cl`（裁切起点）。其下：纸色幕 0→1；再下一层的页后退 `translateY(-10px) scale(.965)`，在上沿露出一条 | 裁切 260ms、缩放 240ms，`cubic-bezier(.2,.8,.2,1)`；幕 240ms ease |
| 落定 | 满宽底页：上沿距屏顶 44px，下沿贴屏底（键盘时贴键盘上沿），上两角 26px 圆角，只向上投一层软影；根导航被底页盖住；下层页面的页头（含 JU 字标）在底页立起时隐去 | | — |
| 文字何时可读 | 内容一开始就在终点排版，不缩放文字，只做整体 .92→1；约 110ms 起可读 | | |
| 打断 | 可以：新导航前控制器先结算当前转场。长出途中只有已露出的部分接收点按（`.s05-shw` 不接收、`.s05-sheet` 接收），点在裁切之外（例如返回键将出现的位置）落到幕上 = 返回 | | |
| 返回 | 主角周围的字先退（110ms，`@keyframes`，可关键帧）；头部——光与主角——留在页上，随页一起沿反向裁切缩回原来那一段（scale 1→.92，最后 60% 淡出），主角回到它来的那一段里；下层页回到全尺寸。回到首页 / 接缝根页时重新量一次原段位置（值可能已变） | | 240ms `cubic-bezier(.4,0,.6,.6)`；控制器 back 260 |

确认层（未保存、退出演示）、系统权限弹窗、「N 件事等你」卡片用同一个 `s05-grow`（240ms），transform-origin 取最后一次点击的控件中心，其下是 66% 的纸色幕。根导航切换（找局 / 我的局 / 设置）：任何一帧都不空——JU 字标、整屏环境色与根导航全程留在屏上；进场页挂上后离场页才开始退（170ms，先慢后快），进场页的内容在 60ms 起上升 10px 淡入（260ms），两者在 60–170ms 交叠，交叉点两页各约一半、字标始终实心（共 340ms）。减少动态时直接换成结果。1× / 0.5× 真实点击逐帧与系统减少动态的检查见 `evidence/S05/root-switch-frames.png`。
登记：`this.motion('sheet')`；重播时 `beforeReplay` 先把导航栈恢复到点击前，再从同一段重新长出。关键帧：`.scrub` 规则把滑块换成负的 animation-delay（裁切按 260ms、缩放 / 返回的字 / 确认层按 240ms 取帧），0 → 100 从段的盒子走到整页；转场结束后直接拖，面板自动重播最近一次核心动作并停在该帧。一次性的进场（确认层、幕、toast）用 `fill-mode: backwards`。

## 2. value · 值在原位交叉淡入

| 段 | 谁动 | 说明 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 保存资料成功；选城市；开关提醒类别；预览 / 取消外观；拿出收藏 | | |
| 发展 | 同一位置叠两层（CSS grid 同格）：旧值淡出、新值淡入；页头部的值立即开始，资料页与首页称呼延迟 150ms（等上层页收回后才换）；选城市时，城市两栏里被选中的那格背后的光从旧格淡出、在新格升起（260ms） | 首页称呼在资料页收回到称呼时换；资料页在编辑页收回到「编辑资料」时换 | 180ms ease |
| 落定 | 新值留在原位；资料页标题下一行「资料已保存」、称呼下「刚更新」（共享控制器 4.5 秒后撤去）；值下的 32px 短线 120ms 内变为 JU 蓝、600ms 内回到墨色 | | 600ms |
| 返回 | 无反向；保存 CTA 依次显示「保存中…」（≥ 320ms 可见）→「已保存」（140ms）→ 页收回（240ms） | 普通保存在处理结束后约 380ms 落定 | — |

登记：`this.motion('value')`；重播 = 清掉该值的过渡状态后再跑一次同一组旧值 → 新值。

## 3. skin · 环境换光

| 段 | 谁动 | 说明 | 时长 / 曲线 |
|---|---|---|---|
| 触发 | 外观页点一种环境（预览）、应用、取消预览；重置 / 跳转换数据时也会发生 | | |
| 发展 | 全部光层是伪元素：`::before` = 现在的环境，`::after` = 离开的环境（`data-sf`）。整屏底色 `.s05-env` 只做不透明度；脚光 `.s05-pool` 与所有光（首页 360px、整盘 296px、穹顶 440px、光章 72px）做「新光从模糊里升起、旧光沉入模糊」（不透明度 .25→1 + blur 12→0；旧层 1→0 + blur 0→12） | 预览即整屏本身：页头底、底页纸（纸色渐变 + 两侧边光 + 底部脚光）、幕的颜色都随 `data-skin` 换 | 650ms `cubic-bezier(.22,1,.36,1)`（R3） |
| 落定 | 只剩 `::before`；连续切换用两组同义动画名（奇偶）保证每次都重新开始 | | |
| 返回 | 取消预览 = 反向换回已应用的环境 | | 650ms |

登记：`this.motion('skin')`；重播先安静地恢复到预览之前（不播放），再重新预览同一环境。

## 关键视觉参数

- **字体**：Noto Sans SC 400 / 500 / 700；JU 字标 15px/700，字距 .16em。
- **字号阶**：光里的数字 96（单位 22）/ 城市 56 / 称呼 48（长称呼 40）/ 页主角 44（事件与记录标题 30，「A · B」式标题在光里拆成两行）/ 页头 30 → 18 / 规则章名 30、编号 30 / 段值 26 / 列表段标题 22 / 规则标题 20 / 引文 18 / 正文 15 / 说明 14 / 标签 13（字距 .2em，`text-indent` 补偿居中）。编辑框按长度降字号：称呼 40 → 32（9–10 字）→ 26；微信号 26 → 21 → 17 → 13；邮箱 20 → 17 → 15 → 13，任何合法值都能整个看见。标题只在词间（「·」之后）换行。全页最小 13px。
- **中轴与长文**：中轴只留给标题、值和一两行的短说明；三行以上的阅读文字（说明段、规则正文、引文、书写框）是一条居中的栏、字从左起（`width: fit-content; max-width: 300px; margin: auto; text-align: left`），规则正文两端对齐、末行左齐。
- **色板**：墨 `#14161F`、正文 `#252b3a`、次级 `#535b70`、标签 `#3d4458`、JU 蓝 `#4553BE`（只用于主确认 CTA 与「N 件事等你」描边胶囊及其蓝点）、焦点 `#4A5AD6`、错误 `#DA3A52`、成功 `#0E9B76`。
- **环境（三种光的形状）**：棉糖 = 粉 / 紫 / 青三团叠成的水面圆；光晕 = 暖白圆心外一圈橙（首页 `#ff5a10`，底页与接缝页降为 `#ff9a62`，十几页不再是同一圈烈火）到紫的环；落日 = 上蓝中橙下黄的天色圆盘。底页纸不是白纸：每种环境一条纸色渐变，两侧边缘各有一团固定的环境边光，底部一汪脚光。
- **光源与表面**：唯一光源是环境光；页底一汪同色脚光。只有底页与确认层有投影（底页只向上投软影），没有玻璃、颗粒、持续发光。底页之下内容经 38% 纸色幕降暗，小确认层之下 66%。
- **页头收拢**：控制器写 `--hc`（0→1，96px 滚动）。首页 / 根页：JU 字标先让位（左移 29px，在 hc ≈ .45 时到位），标题晚一点上移（hc .2 起，上移 29.5px，30 → 18 连续，右移 21px），两者在中轴两侧并排、终态基线对齐；辅助信息 `opacity: 1 − 2.2·hc`；页头底色是环境顶色，`opacity: hc`。底页：标题同样 30 → 18，收进返回按钮所在的工具行中部，纸色底条随 hc 出现，右上角出现一枚 26px 的光章。
- **开关**：一枚从中轴分开的胶囊「开着 | 关了」，两半各是一个按钮（`aria-pressed`）：点哪一半就设成哪一值，已经是该值则不动。
- **二级页的构图件**：列表条目 = 「段」（13px 日期标签 → 22px 标题 → 14px 一行，条目之间 32px 短线）；三联（三个事实被两条发丝线分开：提醒的三层、记录的三类）；城市两栏（被选中的城市背后亮起一团 92px 的光）；引文（人写下的话 18px，上方一枚环境色渐变的大引号，附的材料在下面一行）；进度（横向中轴上的节点，当前节点是一枚亮的小光）；规则章节（26px 小光 + 30px 章名，编号 30px）。帮助页的主角是「我的反馈」，不与规则页共用「18 条约定」。
- **接缝根页**（找局 / 我的局）：与首页同一个页框；一团被屏幕上沿裁掉的穹顶光，站着该页的数（「21 个局」「7 个进行中」），其下是筛选与局卡 / 段。
- **动作条**：主确认 / 「编辑资料」/ 详情的收藏胶囊站在底页脚光上，位于滚动区之外，滚动内容在它上方 24px 内淡出。资料页的快照说明钉在「编辑资料」上方，静止态最后一行总是完整的。邮箱验证时「发送验证码 / 验证 / 重发」也在动作条里，键盘弹起时贴在键盘上沿之上；过期提示保留到重新发送。
- **toast**：宽度随字（`max-content`，最多屏宽 − 32px）；根页上在根导航之上，底页立起时在底页上方那条 44px 的空里，不压 JU 字标与标题。

## 一个仍可能失败的设计判断，以及我怎么检查

**判断**：「同一团光」既要让每页一眼认得出是 S05，又不能让十几页读成同一个模板。我把光按页面类型变成四种形（整盘、穹顶、光章、书写框后的小光），并让底页满宽；风险是四种形仍不够分开（尤其光晕环境下整盘页仍是一圈环），或穹顶页的标题压在光上显得糊。
**检查**：每次改动后在 390 宽、三种环境各拼一张 12 页接触表（首页、资料、编辑、收藏、收藏详情、城市、通知、外观预览、记录、记录详情、举报详情、规则），逐页确认光的形不同、列表从首屏开始、光晕环境里不是一排同样的烈橙色环；再在 375 / 390 看资料页静止态的最后一行是否完整。已知限制：在 390 宽的手机上，16px 规则正文每行约 20 字，达不到 28–32 字；我保留 16px 与 1.85 行距而不缩字。
