十套并排的共同点（实际观察）：
1. 每套都用一个物件/场景做「母版」，道具（框线、外壳、袋体、书脊、门封、拉链、设备框、信箱、挂杆）占据首屏，设置内容退为道具上的小字。
2. 9–12px 的标签、英文、编号大量出现；30px 称呼之外没有第二个有分量的层级。
3. 三种外观环境被解释成纸色/布色/壳色的染色，没有一套真的呈现 Cotton Candy / Halo / Sunset 的色光面积。
4. JU 蓝的主 CTA 在十套首屏都不存在；页头 30/14 → 18 的连续收拢没有实现（页头多为固定一行）。
5. 过渡都是「物件动作」（抽袋、翻页、拉牌、拉链、抬起），不是页面空间关系的展开；多套的常规保存/返回在 500–1500ms。

## 2. 旧源码问题 · 源码检查（本会话从解包页面核实）

| 问题 | 核实结果 | 新一轮的处理 |
|---|---|---|
| 固定时钟 | `var NOW = t('2026-12-17T15:00')` 出现在十套每页的共享核心；`requestEmailCode` 用 `NOW + 5*M` 写 `expiresAt`，`verifyEmailCode` 用同一个 `NOW` 判断过期 → 过期永远不会发生 | 新核心：`JUS2.now()` = 加载时刻的真实时钟 + 可控偏移（评审面板「时间前进 5 分钟」），数据集的相对时间按加载时刻生成 |
| `prefers-reduced-motion` | 十页 JS 与 CSS 中 0 次出现；只有面板 `.rm` 与用户偏好 `.rm-user` | 新核心：`matchMedia('(prefers-reduced-motion: reduce)')` 监听 → 与用户偏好、面板开关三者任一生效；CSS 同时写 `@media` 规则 |
| 整页缩放 | 旧 mixin `fitWidth(base)` 把固定 390px 场景按 `--wk` 整体 `scale()`（SC05 等使用） | 新契约禁止 `scale()` 适配；375/390/430 三个宽度用真实回流（百分比/`minmax`/`clamp`），并用检查脚本核实字号与点击区不随宽度缩小 |
| SC09 布局插值 | 同时过渡 `left/top/width/height/font-size` | 新契约：几何过渡用 `transform`/`clip-path`，文字不随容器缩放（反向缩放或淡入换层） |
| 导出导航 | 索引页含 10 个指向 `SC01.dc.html…` 的相对链接（打包后失效）；本会话解包的页面之间也无法互相跳转 | 新交付：单文件内的方案切换由 shell 自己实现（无相对链接）；交付前在最终文件上逐套打开 |
| 添加截图 size=0 占位 | 举报补充的「添加材料」只记录文件名（`materials[]` / `shots[{name,size}]`） | 新设计：材料=本机选择的文件名 + 大小（真实 `File` 对象的 name/size），界面写明「本机演示 · 不会上传」 |
