# 限制与未验证项（设置 R2）

- **基准文件缺失**：任务书要求实看的 `JU-V27-review-canvas(2).html` 与 `JU-MY-R8-Visual-Motion-Refined.html` 未上传到本会话；共有语言按任务书 §4 的数值与旧分支的三份提取文件执行（`spec/extracts/`）。「与 V27 / R8 真实画面并排衔接」属于**尚未验证**。
- **验证环境**：云容器无头 Chromium（Playwright，SwiftShader 软件渲染，无 GPU，无真机）；截图与抽帧来自 `tools/capture.cjs / coverage.cjs / widths.cjs / kb-check.cjs / rm-check.cjs / lead-sheet.cjs`。触控手感、帧率、真机字体渲染未验证；不声称 60fps。
- **录屏**：不支持视频；核心动作以 1× 与 0.5× 抽帧（每帧约 60–220ms）记录，评审面板的「暂停 / 关键帧」可在交付文件里逐帧查看。
- **字体**：交付文件内嵌字体子集（Noto Sans SC 400–900、Noto Serif SC 400–600、Archivo 可变字重 500–800 与宽度 62–125%、DM Mono）。子集 = 十套源码、共享数据与外壳里出现的全部字符 + GB2312 一级常用字 3,755 个（共 3,924 个字符，约 4.8 MB woff2），所以你输入的常见称呼、反馈文字也用同一字体显示；只有少数生僻字回落到系统字体。离线打开时十套画面的字形与设计一致（已在阻断全部网络请求的浏览器里核对）。附录长文用系统中文字体（PingFang / 微软雅黑等）排版，避免同一段里混用两种字体。
- **真实能力**：全部本地演示——无账户、登录、验证邮件（验证码为本机测试码）、通知服务、举报审核或后端；材料「添加」只记录本机文件名与大小。产品内各有一句准确说明。
- **持久化**：每套一个 `localStorage` 命名空间 `jus2:<SNN>:v1`；Playwright 每次新上下文，截图不受持久化影响。
- **状态索引**：`jumpTo` 按索引条目重建数据；跨模块一致性用方案自己的导航串联验证。
- **系统减少动态**：用 Playwright `reducedMotion: 'reduce'` 模拟核对（`rm-check.cjs`），不是真机系统设置。
- **键盘**：用面板的 300px 模拟内缩核对（`kb-check.cjs`），不是真实软键盘；真实键盘高度与 `visualViewport` 行为未验证。
- **Design 画布**：本轮主要交付是离线 HTML；画板版本（`settings-r2/concepts/project/`）按 `.dc.html` 规范生成，官方画布渲染未核对。
- **代理产出**：各方案由构建代理实现并自报；主负责人逐套复看证据并在记录中区分「实际观察 / 源码检查 / 尚未验证」；**用户尚未审阅任何一套**。
- **文件选择的测试限制**：自动化（Playwright）在本环境里选不了中文文件名的本机文件（会静默不加入）；产品本身的「添加材料」用中文文件名正常（复核者以 ASCII 文件名与带中文名的内存文件分别核对）。
- **真实输入法**：S06 的句中编辑是可编辑短语（contenteditable），未在真实中文输入法与手机上试过；备选方案（每个字段一个文本框）写在 `spec/motion/S06.md`。
- **体积**：交付文件约 9.5 MB（十套源码 + 共享核心 + 外壳 + 内嵌字体 + 附录），单文件、双击即可离线打开。

## 各套仍保留的已知限制（修复轮之后，构建者说明理由、主负责人认可保留）
- S01：编辑态里很长的微信号 / 邮箱在输入框内会在词中断行（原生输入框无法自定断点；阅读态只在 @ . _ - 处断）。
- S02：在收拢过程中按返回，会从当前位置反向，但首字字号在那一刻约有 0.05 的差。
- S05：规则正文 16px 在 390 宽下每行约 20 字（再宽就要缩字，选择保留字号与行距）；光晕下整盘光仍是一圈环（该环境的形状）。
- S06：375 宽「长内容」首页的光仍下沉约 94px（字号与对比度已到余量边界）。
- S07：编辑页的输入框是原生单行框，极长的邮箱在框内横向滚动（资料页与舞台卡显示全文）。
- S08：规则全文 15px 在 390 宽下每行 23 字（要到 24 字需 14px）；「找局」的筛选保留两个切换按钮（横滑留给 V27 的卡片滑动）。
- S09：墨板页上一行放不下的长 toast 会落在墨板下沿，表单页少数情况下压在主按钮上方。
- S10：最前一层（帮助 · 隐私 · 账户 · 关于）保持最深的颜色，作为叠放的深度线索。
- 各套的旧原型规则（微信必填、免费邮箱限制、每年四次主动退出）保持现状并标为未验收，见附录「规则核对（未验收）」。
- **较矮的屏幕**：手机画面标准尺寸是 390×844；浏览器窗口高度不足 950px 时（例如 13 寸笔记本），方案页第一次打开会自动切到「适应窗口高度」——手机宽度不变、高度跟随窗口（最低 667px），是真实重排、不是缩放；面板里一键切回 375×812 / 390×844 / 430×932。十套在 390×693 下的首页、编辑、记录、收藏、提醒已核对（`settings-r2/evidence/lead/short-693/`）。
