## S01 字即内容

1. **命题**：当前值本身是版面主角。一页里「阿禾 / 纽约 / 棉糖 / 6 类提醒 / 3 个局 / 7 条事实」以大号中文直接排出来，字段名只是 13px 的注释；页面秩序来自大小字的节奏，不来自线框或卡片。
2. **构图与视觉中心**：页头（JU · 设置 30px）之下是称呼 40px/600，紧随 ahe_ju · nyu.edu 已验证 14px；接着每组一段：组名 13px 次级 → 值 28px/500（计数类值用 34px 数字 + 14px 单位）。视觉中心 = 称呼与它下面第一个大值的落差。
3. **空间**：左边距 24px；组与组之间 36px，组内标签与值 6px；首屏可见 4–5 个大值；下方留白不压缩。
4. **中文排版**：Noto Sans SC；40 / 34 / 28 / 16 / 14 / 13 六阶；600 只给称呼，500 给值，400 给说明；数字与中文同一字族（不用等宽）；长值允许两行，不缩字。
5. **色彩与表面**：纸白底 `#fbfaf7`；顶部 40% 高度是环境色光场（棉糖 = 粉紫青三色柔和水面、光晕 = 暖白上一圈橙紫、落日 = 橙蓝黄）向下渐隐；文字墨色 `#14161F`；表面无卡片、无线框；唯一的面是 CTA 的 JU 蓝。
6. **运动**：主语 = 值字本身。进入编辑：值字保持在原位置，字号从 28 → 22 并左移成输入态（变换 260ms `cubic-bezier(.2,.8,.2,1)`），其下滑出校验行与键盘区；保存：新值在原位 200ms 交叉淡入，右侧出现 12px「已保存」2.6s；返回：编辑区收回。页头收拢 30 → 18 随滚动连续。
7. **为什么属于 JU**：页头与 CTA 规格照旧；环境光场是三种外观的真实面积；语气直接（值就是话），年轻而不幼稚。
8. **区别与失败处**：十套里唯一「无容器、以字级为结构」的一套；最易失败：变成海报——值太大、信息太少、滚动很长。检查：`long` 变体下首屏仍能看到 ≥4 组；28px 值两行不溢出；灰度下层级仍靠字级成立。

## S02 侧栏目录（已改写为「大字目录」，以 `art-direction-v2.md` 为准；下文保留作历史）

1. **命题**：把桌面设置的「目录在左、内容在右」压进手机，目录常驻，内容面只换内容，不弹层、不推页。
2. **构图与视觉中心**：左 72px 墨色目录栏，六个组名竖排（资料 / 收藏 / 偏好 / 记录 / 帮助 / 账户），当前组用环境色指示条；右侧内容面顶部 30px 组标题 + 14px 当前状态，下面是该组的行。视觉中心 = 内容面标题与目录指示条的对位。
3. **空间**：内容面左右各 20px；行高 56px；组标题上方 24px、下方 16px；目录栏字与字间距 18px。
4. **中文排版**：竖排组名 15px/500（`writing-mode: vertical-rl`，2 字一组）；内容行标签 16px/500 左、值 15px/400 右对齐；说明 13px。
5. **色彩与表面**：目录栏 `#14161F`；内容面以环境色光做整底（低强度，≈ 环境色 25% 叠白）；行之间 1px 墨色 10% 分隔；详情是同一个面，不加卡片。
6. **运动**：主语 = 内容面。换组：内容沿 y 轴滑 24px + 淡入 280ms，目录指示条 220ms 滑到新位置；进入详情：内容面内沿 y 推换（旧内容上移 40px 淡出、新内容从下 40px 进入）300ms，目录栏不动；返回反向，并恢复滚动位置。
7. **为什么属于 JU**：根导航放在目录栏底部（JU 字标在栏顶）；页头规格在内容面；环境做整底；CTA 蓝。
8. **区别与失败处**：唯一的两栏结构；最易失败：内容面太窄（318px）导致长局名折行多、右对齐值挤压。检查：`long` 变体收藏列表；430 宽时内容面按比例变宽而不是目录栏变宽。

## S03 上光下墨

1. **命题**：一屏两种材料。上 42% 是环境光场，身份浮在光里；下 58% 是墨色操作面，所有控件在墨上以亮字出现。
2. **构图与视觉中心**：上区：JU · 设置（30/14）在光场顶部，称呼 34px/600 墨色（落日环境用白）、账号与验证 14px；下区：墨面 `#14161F` 顶部圆角 28px，内容行 16px/500 亮字 + 值 14px/400 70% 白；待处理项用环境色做小面。视觉中心 = 光与墨的分界线上的称呼。
3. **空间**：上区内边距 24px；墨面内边距 20px；行高 60px；墨面首屏露出 3–4 行，向上滚动时墨面上推、光场压缩到 96px 顶带（身份缩到 18px 进工具行）。
4. **中文排版**：上区称呼 34/600；墨面标签 16/500、值 14/400、组名 13/500 50% 白；没有小于 13px 的文字。
5. **色彩与表面**：光场 = 环境本身（大面积）；墨面哑光，无渐变；按压态 = 行底 8% 白 120ms；CTA 蓝在墨上有顶部高光。
6. **运动**：主语 = 墨面整张。进入详情：墨面作为整张向上抽起到顶带之下 320ms `cubic-bezier(.2,.9,.3,1)`，光场压缩（高度变化，不缩放文字）；详情内容在抽起后 120ms 淡入；返回：墨面落回原高度，光场复原。
7. **为什么属于 JU**：环境光场是三种外观最直接、最大面积的呈现；页头在光场内按规格；CTA 蓝在墨面上。
8. **区别与失败处**：唯一的硬分割两材料构图；最易失败：下半屏「暗色列表」显得冷。检查：墨面上必须有环境色的小面（待处理、当前值强调）；灰度下分割仍成立。

## S04 海报块

1. **命题**：每个分组是一整幅通栏平涂色块，标题压在块上，块既是入口也是展开后的页面。
2. **构图与视觉中心**：页头后依次：身份块（最高 200px：称呼 32/700 + 账号 + 验证）、收藏块、提醒块、外观块、记录与举报块、帮助 / 隐私 / 账户三小块一行、关于块。每块 26px/700 标题左上 + 值 16px/500 左下。视觉中心 = 身份块的大标题。
3. **空间**：块间 8px；块内边距 20px；块高按内容 120–200px；三小块等分一行高 96px。
4. **中文排版**：标题 26/700，值 16/500，说明 13/400；块内文字颜色按块色自动取墨或白（对比 ≥ 4.5）。
5. **色彩与表面**：块色从当前环境取：棉糖 → 粉 / 淡紫 / 青 + 纸白；光晕 → 橙 / 杏 / 淡紫 + 暖白；落日 → 橙 / 蓝 / 黄 + 米白；平涂、无阴影、无渐变；块角 20px。
6. **运动**：主语 = 色块。点块：块以共享元素长成整页（300ms），块色成为页面底色，标题移到页头位置（30px）；内容在 120ms 后淡入；返回：页面缩回块位 260ms。开关 120ms。
7. **为什么属于 JU**：页头与 CTA 规格；三种环境决定整页配色（环境的真实面积 = 整页）；明亮、有生活感。
8. **区别与失败处**：唯一以平涂色块为结构、颜色面积最大的一套；最易失败：变成「九宫格仪表盘」或色块过多显得吵。检查：块数 ≤ 7，同屏不超过 4 种色相；灰度下块的明度层级仍能分组。

## S05 居中仪式

1. **命题**：一条中轴。所有文字、控件、弹层沿中线对称，节奏由留白给出；安静但不冷。
2. **构图与视觉中心**：JU 字标居中；称呼 36/500 居中，账号 14 居中；下方每组：13px 组名居中 → 20/500 值居中 → 一条 24px 短中线；开关是居中的一对胶囊。视觉中心 = 称呼与其后的光晕。
3. **空间**：组间 40px；首屏 3–4 组；弹层宽 318px 居中；留白是主要材料。
4. **中文排版**：36 / 20 / 16 / 14 / 13；全部居中；中文不加字距；长局名居中两行。
5. **色彩与表面**：纸白底；称呼背后 260px 直径的环境色光晕（棉糖 / 光晕 / 落日）；页底 12% 环境色微染；弹层白面 + 1px 墨 8% 边 + 柔和阴影（唯一有阴影的面）。
6. **运动**：主语 = 弹层。从被点的行中心长出：scale .92 → 1 + 淡入 240ms，其余内容 0.6 不透明；关闭反向；值更新 180ms 中心交叉淡入；页头收拢同规格。
7. **为什么属于 JU**：页头 / CTA / 环境光晕；语气像一张好看的邀请，但控件是现代胶囊。
8. **区别与失败处**：唯一全对称中轴；最易失败：像请柬 / 像登录页。检查：`many` 变体收藏列表的居中多行仍可扫读；开关对不会被误读为两个按钮。

## S06 对话流（已改写为「一段话」，以 `art-direction-v2.md` 为准；下文保留作历史）

1. **命题**：设置写成 JU 对你说的话与你的回答：「你的邮箱 ahe@nyu.edu 已验证」「想收到哪些提醒？」，控件嵌在句子里；待处理的事排在最前。
2. **构图与视觉中心**：顶部页头（30/14）；下面是消息流：左侧 36px JU 头像轨，右侧气泡（JU 的话 = 白底墨字；你的回答 = 墨底白字或环境色底）；每条消息末尾是该话题的控件（胶囊、开关、迷你输入）。视觉中心 = 第一条「待处理」消息的亮色气泡。
3. **空间**：气泡最大宽 300px；气泡间 12px，话题间 24px；行高 1.6。
4. **中文排版**：消息 16/400；你的回答 16/500；时间 12/400（只在话题头）；没有标签—值的表格感。
5. **色彩与表面**：流的整底是环境光（棉糖 / 光晕 / 落日，中强度）；气泡白 / 墨 / 环境色三种；无阴影，气泡角 18px。
6. **运动**：主语 = 气泡。新气泡从下 12px 淡入 220ms；点一个话题进入聚焦：其他气泡折成 40px 一行 300ms，该话题展开成编辑态；回答后出现确认气泡；返回：折叠展开反向。
7. **为什么属于 JU**：JU 的语气（直接、年轻）在句子里；页头 / CTA / 环境规格照旧；根导航在底。
8. **区别与失败处**：唯一以「句子 + 嵌入控件」组织的一套；最易失败：开关要翻好几屏、像客服机器人。检查：六个提醒开关在一条消息内一屏可见；任何设置 ≤ 2 次点击可改。

## S07 预览在上

1. **命题**：上面固定一块实时预览——「别人看到的你」「找局默认显示的城市」「提醒会怎么出现」「这个外观长什么样」——下面才是控件；改什么，上面立刻变。
2. **构图与视觉中心**：上 38% 预览区（圆角 24px 的一块真实界面：首页时是你的局卡 + 环境；资料时是别人看到的资料卡；通知时是一条提醒横幅样例；外观时是环境本身）；下区滚动：组标题 14/500 次级 + 行 16/500。视觉中心 = 预览区。
3. **空间**：预览区内边距 20px；控制区行高 56px；预览与控制之间 16px 的缝隙露出环境色。
4. **中文排版**：预览区内文字按被预览的界面规格（局卡 17/500、横幅 15/500）；控制区 16/500 标签、15/400 值。
5. **色彩与表面**：预览区是「真实界面」所以可以有它自己的材质；控制区纸白 + 环境 15% 染；整页底色 = 环境色光。
6. **运动**：主语 = 预览区内容。改一个开关：预览立即（120ms）变化；换组：预览内容 300ms 交叉变形（布局用 transform，不缩放文字），控制区内容沿 x 推换 280ms；进入编辑：控制区推换，预览保持。
7. **为什么属于 JU**：预览里就是 JU 的局卡 / 横幅 / 环境——身份延续最直接；页头 / CTA 规格照旧。
8. **区别与失败处**：唯一「所见即所得」结构；最易失败：预览区抢掉控制区的空间（430 宽时更严重）。检查：三个尺寸下控制区首屏 ≥ 4 行；键盘弹出时预览区让位（高度压到 120px）。

## S08 横向分栏

1. **命题**：分组是并排的整高纵栏，横向翻阅；栏名排在顶部一条轨上对位，像翻一本横向的册子但没有纸。
2. **构图与视觉中心**：页头（30/14）下是栏名轨（资料 · 收藏 · 偏好 · 记录 · 帮助 · 账户，当前 18/600，其余 15/400 次级）；下面是当前栏（宽 100% − 28px，右侧露出下一栏 28px 边）；栏内顶部是该组 30px 标题与状态，下面是行。视觉中心 = 当前栏的标题与左侧色带。
3. **空间**：栏内边距 20px；栏间 12px；行高 56px。
4. **中文排版**：栏标题 30/500；行 17/500 + 值 17/400；说明 13。
5. **色彩与表面**：每栏底 = 环境光（整底）；栏左缘 6px 本栏色带（从环境取色）；栏面无阴影；露出的邻栏边 60% 不透明。
6. **运动**：主语 = 栏。横向滑动 snap，300ms `cubic-bezier(.2,.8,.2,1)`；栏名轨同步滑动；进入详情：当前栏展开占满（邻栏边滑出）320ms，栏标题进页头；返回：再折回露边。
7. **为什么属于 JU**：页头 / CTA / 环境整底；根导航在底；栏名轨是中文优先的目录。
8. **区别与失败处**：唯一横向主轴；最易失败：找不到分组、误触滑动。检查：栏名轨可点；纵向滚动不被横向手势吞（`touch-action: pan-y` 在行上、横向只在栏空白处）。

## S09 夜灯

1. **命题**：墨底上几团会移动的彩色光；光跟着你看的地方聚拢，文字亮而大，夜里也明亮。
2. **构图与视觉中心**：墨底 `#0f1117`；居中单列（宽 342px）；称呼 32/500 白；每组：组名 13/500 50% 白 → 行 16/400 92% 白 + 值 16/500 环境色；三团光（环境三色）直径 260–360px 以 12–18% 不透明度浮在墨上。视觉中心 = 称呼与它背后最亮的一团光。
3. **空间**：组间 32px；行高 56px；列左右 24px。
4. **中文排版**：32 / 16 / 13；白字在墨上用 400 为主；值 500 带环境色。
5. **色彩与表面**：光团用径向渐变（不用模糊滤镜），文字在光上保持清晰（光在最底层）；行无边框，分隔用 1px 8% 白；CTA 蓝有外发光（唯一发光的元素，只在主确认）。
6. **运动**：主语 = 光团。滚动时光团以 0.3 倍速视差；点一行，离它最近的光团 400ms 移到该行背后并增亮到 24%；进入详情：详情面从下升起 300ms，光团聚到面后；返回：光团散回。
7. **为什么属于 JU**：三种环境就是三组光（棉糖粉紫青 / 光晕橙紫 / 落日橙蓝黄）；页头 / CTA 规格；深色但明亮有生活感，不是黑白。
8. **区别与失败处**：唯一墨底 + 动态光；最易失败：冷、像深色模式模板。检查：灰度下光团仍能区分组；减少动态下光团固定但仍存在。

## S10 叠层

1. **命题**：界面层沿 z 轴叠起：顶层是身份，下面每层露出 56px 的边，边上写着分组名与当前值；抽起一层，它来到最上面，其他层压成边。
2. **构图与视觉中心**：页头（30/14）；下面是叠层：顶层身份层（高 220px：称呼 30/600、账号、验证、待处理）；其下六层各露 56px 边（边上左 18/600 分组名、右 15/400 当前值）；最底层贴底。视觉中心 = 顶层与第一条边。
3. **空间**：层左右边距 16px；层角 24px；边的露出高度固定 56px（不随内容变）。
4. **中文排版**：层边 18/600 + 15/400；顶层内 16/500；没有小字。
5. **色彩与表面**：每层一个浅色面（从环境取三色的浅版 + 纸白轮换）；层与层之间 8px 的缝隙里露出环境光（整底）；层有 1px 墨 6% 边与 0 12px 24px −16px 的柔影（唯一的深度表现）。
6. **运动**：主语 = 层。抽起：被点层 320ms 沿 y 轴上到页头之下，并从 scale .97 到 1；其余层压成 40px 的边堆到底部；层内内容在 100ms 后淡入；返回：该层落回原位、其余层展开。页头收拢规格照旧。
7. **为什么属于 JU**：页头 / CTA / 环境在缝隙与底层；明亮的分层色面有生活感。
8. **区别与失败处**：唯一 z 轴叠层；最易失败：像卡片堆 / 像钱包。检查：层面无纹理、无圆角过大的「卡片感」，边上的文字对齐成一个目录；430 宽下层高不变、宽度随之变。
