# R2 艺术指导 v2（主负责人 · 读过七份半成品首屏之后）

七份被配额中断的半成品（S02 / S03 / S04 / S05 / S08 / S09 / S10，见 `.build/lead-partial/sheet.png`）有一个共同问题：**缩略图里都读成「页头 + 身份 + 一列等高行」**，只是底色、圆角和行的颜色不同——这正是用户否决的「十种配色的通用设置列表」。差异不能停在背景上，必须落在首屏的**主导体量、信息的组织方式和字级关系**上。以下规则对十套都有效，逐套配方在后面。

> 用户 2026-10-22 重申：**视觉呈现是最高优先级**——视觉不好看，功能再完美也没有意义。

## 通用规则（每套首屏与二级页都要过）
1. **缩略图测试**：50% 缩略图（`settings-r2/tools/lead-sheet.cjs`）里，首屏必须有**一个主导体量**（占可见画面 ≥ 30%：一片色光、一组巨字、一个预览物、一块色块、一层叠层……），其余内容围绕它组织。读成「身份 + 一列等高行」= 不通过。
2. **列表只给真正是列表的内容**（提醒类别、记录、规则、城市），而且页面上方必须有该页的主导元素（结论句、大数字、预览），行的节奏 ≥ 56px，不叠两行小字。
3. **字级**：首屏至少三级、相邻 ≥ 1.5 倍（如 48–64 / 24–34 / 15–17），说明 13px，任何文字 ≥ 12px（根导航标签允许 12px）。浅底次级文字不浅于 `#535b70`，深底不低于 70% 白。不要灰色小字遍布。
4. **生活感落在人、活动与收藏内容上**：首屏出现真实的局名（收藏 / 即将见面），不只是「3 个局」这样的计数。
5. **环境是大面积真实色光**：棉糖 / 光晕 / 落日切换时，整屏情绪要像换了一天里的时间；不是纸色微染。
6. **表面**：每套一个光源与深度逻辑；只有「深度就是命题」的套（S05 弹层、S10 叠层）用投影；禁止玻璃卡、新拟态、颗粒、持续发光。
7. **JU 蓝 CTA** 只在编辑 / 确认场景、每屏最多一个；首页不放主 CTA。
8. **二级页**用同一个构图命题生成（每套配方里写了资料页 / 编辑页的样子），不能回到「返回 + 标题 + 三个输入框」。
9. **签名转场**：首页 → 资料 → 编辑 → 保存 → 回到原位，是每套的核心交互，按配方实现；常规 240–420ms，按压 80–160ms。

## 逐套配方

### S01 字即内容（无半成品）
纸 `#FBFAF7`；顶部 ≈ 45% 是环境色光场（多段渐变，向下淡入纸色）。页头 JU · 设置 30 / 辅助 14。身份 = 展示级：称呼 **56px/600**，下一行 15px「ahe_ju · ahe@nyu.edu 已验证」。下面是**不对称两栏的「值」排版**：每个值块 = 13px 标签在上 + 值在下，值用 **Noto Serif SC 600 34–44px**（数字用 Archivo 600），如「3 个局」+ 其下三条收藏局名 14px、「纽约」、「6 类提醒」+「还没申请系统权限 ›」（JU 蓝 15px）、「棉糖」、「7 条事实 · 1 待核实」。需要处理的事 = 一句 JU 蓝 17px 句子「● 2 件事等你回应 ›」。底部是 15px 文字索引（帮助与反馈 · 隐私 · 账户 · 关于），细线分隔。资料页 = 身份块放大成整页；编辑 = **同一套大字原位变成可编辑**（只有下划线），校验字 13px 在值下方，CTA 在底部。签名转场：值字原位变形（位置与字号连续，不换页）。

### S02 大字目录 → 侧栏（方向改写；旧半成品为窄黑栏 + 列表，不再采用）
首页 = **整屏环境渐变** + 页头 + 紧凑身份（44px 首字圆 + 称呼 20px + 账号 14px）+ **大字目录**：资料 / 收藏 / 城市 / 提醒 / 外观 / 记录 / 举报 / 帮助 / 账户（9 项，40px/600 墨色，行高 60px，左对齐），每项同基线右侧 14px 当前值；需要处理的项后面一枚 JU 蓝点。点一项：**目录收缩成左侧 64px 竖栏**（每项只剩首字 20px，竖向排列，当前项是一块与内容面相连的白色舌片），白色内容面（左上 28px 圆角）从右滑入，内容面自带 30px 页头；竖栏在所有二级页常驻，点别的首字 = 内容面纵向换页；返回 = 内容面滑出、竖栏重新展开成大字目录。签名转场：目录 → 竖栏 + 内容面。

### S03 上光下墨（半成品结构可用，内容要重排）
光场占上 **46%**，两层渐变 + 一处柔和高光，身份 **48px/600**；墨面（`#14161F`，顶部 28px 圆角，顶缘 1px 12% 白高光）上：先是 **2 块待处理亮块**（并排，环境色字 15px + 13px 说明），再是**收藏横带**（3 个小局签：局名 15px、日期 13px，顶部一条环境色细线），然后才是分组行（17/15px，行高 64px，值用环境色调）。资料页：墨面整张上抽、光场压成顶带，墨面上是大号资料（称呼 34px 白）；编辑在墨面上进行（白色下划线输入，JU 蓝 CTA 在墨上带顶部高光）。签名转场：墨面整张抽起 / 落回。

### S04 海报拼块（半成品是带间距的粉彩圆角卡，不采用）
**满版拼块**：块与块之间 3px 纸色缝，**无圆角**（除手机外框），环境决定高饱和配色（棉糖：粉 `#F4B6CF` / 薰衣草 `#CFC6F2` / 青 `#A9DEEA` / 墨；光晕：橙 `#FF6A1A` / 杏 `#F3C79B` / 丁香 `#CDB9E8` / 墨；落日：橙 `#FF7A33` / 蓝 `#3D8FF0` / 黄 `#FFC53D` / 墨）。块的构图各不相同：身份块 100%×200（称呼 52px/700）；收藏块 60%×180（「3」88px Archivo + 三条局名 13px）；城市块 40%×180（「纽约」34px/700）；提醒块 100%×120（「6/6」64px + 「未申请系统权限 ›」）；外观块 50%（块面就是当前环境渐变）；记录块 50%（「7」+「1 待核实」）；底部四小块 25%×72（帮助 / 隐私 / 账户 / 关于 15px）。字色按对比自动取墨或白。签名转场：块**原位长成整页**（块色成为页面底色，块标题移到页头位置）。

### S05 居中仪式（半成品方向对，但尺度与仪式感不够、灰色小字太多）
中轴对称；称呼背后 **360px 环境光晕**；称呼 **48px/500**，其下 15px 账号行居中；然后是居中的「段」：13px 字距 .2em 的标签 + **26px/500 值** + 14px 说明，段与段之间 40px，中间一条 32px 短线；需要处理 = 居中 JU 蓝描边胶囊「2 件事等你」。二级页内容同样居中成列；弹层从被点的段的中心长出（scale .92→1 + 淡入 240ms），其余变 0.6。资料编辑：居中的大字输入（下划线居中），CTA 居中。签名转场：中心长出的弹层。

### S06 一段话（方向改写：不再是聊天气泡）
纸色上半屏，**环境色光从底部升起（下 45%）**。首屏是**一整段关于你的话**：Noto Serif SC 400 **22px / 行高 1.8**，例如「我是 **阿禾**，微信 **ahe_ju**，邮箱 **ahe@nyu.edu**（已验证）。平时在 **纽约** 找局，收藏了 **深夜救急火锅局**、**周末看展搭子局** 和 **周末速写**。**6 类提醒**都开着，但还**没有向系统申请通知权限**。界面用 **棉糖**，动态**正常**。我有 **7 条记录**，其中 **1 条待核实**；**2 条举报**在处理，**1 条需要补充**。」——加粗处是可点的值（600 字重 + 3px 环境色下划线）。段落下方是 15px 文字索引（帮助与反馈 · 隐私 · 账户 · 关于 · 约定）。点一个值：整段其它部分降到 35% 透明度，被点的短语**原位变成编辑器**（同字号输入）或在该行下方展开一块面板（提醒类别、城市列表、外观三环境）；资料编辑 = 把「我是 ___，微信 ___，邮箱 ___」这一句变成三个内联输入。签名转场：段落聚焦一个短语、其余退后。

### S07 预览在上（无半成品）
上 **40%** 是环境上的**实时预览**：首页时预览「局主审核你时看到的样子」——一张 JU 申请人卡（首字头像、称呼 22px、「nyu.edu 邮箱已验证」、「成局后才交换微信」、留言占位）；下 60% 是白色控制面（分组行 17/15px、行高 60px）。进入通知 → 预览区变成一条提醒横幅样例（「收到邀请 · 周六早午餐 · 6 小时内确认」）；外观 → 预览区就是环境本身 + 首页缩略；城市 → 预览「纽约 · 本周 N 个局」的找局页头；资料编辑 → 预览卡随输入实时变化。签名转场：预览内容变形（布局用 transform，不缩放文字），控制面横向推换。

### S08 横向分栏（半成品读成「标签页 + 列表」，要重做）
首页**就是横向的栏**：每栏是整高纸面（宽 = 100% − 44px，24px 圆角），右侧露出下一栏 28px，横向 snap；顶部栏名轨（当前 17px/600 + 环境色下划线，其余 15px）。每栏自己的主导构图：「你」栏（称呼 48px + 账号 + 两件待处理事）；「收藏」栏（3 张竖向叠放的局卡，局名 20px）；「提醒」栏（「6/6」64px + 六个开关）；「外观」栏（三块整宽环境色样，各 120px 高）；「记录与举报」栏；「帮助」栏；「账户与关于」栏。环境作为横贯所有栏的连续背景，在栏缝与轨道上露出。签名转场：当前栏展开占满（邻栏边滑出）、栏标题进页头；返回再折回露边。

### S09 夜灯（半成品是深色列表 + 光团，要改组织方式）
底 `#0E1016`；三团大光（环境三色径向渐变，直径 340–460px，透明度 30–45%），位置静止，**只在焦点变化时 400–600ms 移动**（不做持续漂移）。称呼 **52px/500** 白；分组**不用分隔行**，而是「光下的陈述」：13px 60% 白标签 + **30px/500 环境色值**（「3 个局」「纽约」「6 类提醒」「棉糖」「7 条事实」），两栏网格、36px 间距；需要处理 = 一道 JU 蓝亮线 + 句子。二级页从下升起的墨面板，光团聚到面板后面。签名转场：光团跟随焦点 + 面板升起。

### S10 叠层（半成品读成粉彩胶囊列表，要真正叠起来）
**真正重叠的层**：顶层身份层（白，230px 高，顶部 28px 圆角，投影）；其后每层整宽、顶部 28px 圆角、**压在前一层上只露出 72px 的边**，每层一个环境派生的实色（棉糖：粉 `#F6C9DA` / 薰衣草 `#DCD5F5` / 青 `#C5E8F0` / 奶油 `#FFF3E3`…），边上是 20px/600 分组名 + 15px 当前值；每层顶缘投影 `0 -10px 30px rgba(20,22,31,.10)` 读出叠放；最后一层延伸到底。点一条边：该层沿 y 轴上升到顶部并展开（320ms），其余层压成 24px 的边堆到底部；返回反向。资料编辑在身份层内展开。

## 交付门槛（阶段 1）
首屏三种环境 ×（390 宽）+ 资料页 + 编辑页（接控制器的真实校验 / 验证码 / 保存）+ 签名转场接触表（1×），并且自己跑一遍 `lead-sheet.cjs` 的缩略图与灰度，确认第 1 条规则成立。主负责人会把十套隐名并排看；读成「一列等高行」的会被要求推翻。
