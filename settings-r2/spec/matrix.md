# 「设置」R2 · 十套差异矩阵（S01–S10）

本表写十套**已经建成**的样子。依据是各套 `spec/motion/SNN.md`（构建者写的视觉与动效规格）、`spec/verification.md` §2.2 的独立复核与修复轮，以及每套 390 宽的 12 页接触表。八个字段对应任务书 §5，px 都指 390×844 画面。

十套共用同一套 JU 语言（`spec/concept-contract.md` §1）：JU 字标；根导航「找局 / 开局 / 我的局 / 设置」；页头 30px 主标题 + 14px 辅助信息，滚动时连续收拢到 18px 并进入工具行；约 280×48 的 JU 蓝主按钮只用于主要确认（保存、提交、应用外观、开启提醒）；棉糖 Cotton Candy、光晕 Halo、落日 Sunset 是大面积真实色光（≥ 首屏 35% 或整个底层），切换都是 650ms。

语义也一致：没有公开信用分，收藏 ≠ 报名，举报 ≠ 处罚，记录是私有事实，本机演示不冒充真实服务。

差异只落在整屏构图、空间组织、中文字级、色彩面积、表面纵深和运动上，不靠换配色、圆角或动画参数。

## 仍可能失败的设计判断

每套至少一条（任务书 §12）。路径相对于 `settings-r2/`；「通过」只指所列检查通过，视觉是否通过由用户判断。

|---|---|---|---|
| S01 字即内容 | 收藏多到 13 条（many）时，主条目下面仍是一长列目录行，第二屏起可能读回「大数字 + 普通列表」 | `lead-sheet.cjs <dir> s-fav-many --codes S01 --gray`；收藏 / 举报 / 账户 / 关于的灰度缩略图 `evidence/S01/stage2/gray-sparse.png` | 交付前核对：修复轮进行中，列表页已改为「主条目 + 日期字脊」；many 情形是构建者自列的风险，备用方案为按「本周 / 下周」分组 |

## 十套之间的关系

- **S03 与 S09** 都以墨色为大面积：S03 用一条水平接缝分出上 46% 的环境光场和下方墨面，称呼是光上的深色字，详情是把屏上那张墨面抽起；S09 整屏是墨，光是三盏会移动的灯，称呼是白字、值被灯染色，详情是一块从下方升起、左右下内缩 16px 的墨板。
- **S01 与 S06** 都是衬线排版 + 纸 + 环境光：S01 的光在顶部，值是分开的 34–56px 展示字、按两栏排，转场让值字移位；S06 的光从底部升起，值嵌在 22px 连续句子里，转场只平移整组句子，值的字形从不移动。
- **S04 与 S10** 都把环境色铺成大面积色面：S04 平铺、零圆角、3px 纸缝、无投影，块在原位长成页；S10 沿 z 轴叠放、28px 圆角、带上投影、亮度 .79→.37 递进，一层抽起、其余压成底部 60px 的堆。
- **S02 与 S08** 的二级页左侧都有一条竖条：S02 是 64px 首字竖栏，常驻全部九个入口（全局导航）；S08 是 28px 竖排书脊，只写父页名（返回路径）。首页上 S02 是纵向的 40px 目录词，S08 是横向的纸栏。
- **S03 与 S07** 都在 40–46% 处横向分屏：S03 上方是放陈述的光、下方是墨面；S07 上方舞台放墨色预览卡、下方是白纸控件，改动先在卡上发生。
- **S05 与 S09** 的称呼都站在一团光前：S05 是纸上一枚居中光盘、全对称，详情从段的中心长出；S09 是墨地上三盏灯、左对齐两栏，灯随焦点移动。
