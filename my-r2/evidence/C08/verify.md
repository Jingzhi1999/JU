## §1 视觉结论：**需修改后复核**

整体构图成立、方向可辨，但有四处会被用户一眼看到的画面问题必须先改（深层页把环境完全盖住、成局结果页与待赴约票根页大半空白、短页页头停在半收拢的重影态、主 CTA 与首条色带的配色冲突待用户裁定）。不是整体构图问题，所以不是「不通过」。

依据截图（都在 `my-r2/evidence/C08/verify/`）：首屏三环境 `v-home/f001,f003,f004`（参加者 棉糖/光晕/落日）、`v-home/f005,f006,f007`（局主）；详情 `v-deep/f001`（早午餐）`f003–f005`（还在等三种）；票根 `v-deep/f006,f007,f008`；管理 `v-deep/f013,f014,f015`；出席 `v-deep/f016,f017`；历史 `v-deep/f009,f010,f011,f012,f018`；草稿 `v-deep/f019,f020`；弹层 `v-deep/f021,f022`；空态 `v-deep/f023,f024`；环境露出量测 `v-env/ks-env.png`；最近邻 `v-c04/f001,f002,f003`；成局结果 `o2-brunch/f043`。

1. **主体形态与重心**：首页成立——页头在环境色光上，下面三条整宽色带（要你回应 / 就快见面 / 还在等；局主侧 待你处理 / 改期中 / 招募中·已成局），第一条带最重、最高，局名 22px + 倒计时 + CTA 构成明确重心，后两条带依次变轻，面积比例直接说明「要回应多 / 等待多」。留白在带内有组织。问题在**稀疏页**：`h-history`（`v-deep/f018`）、草稿（`f019`）、完全空（`f023/f024`）下半屏 45–55% 只剩环境，没有构图收尾；**成局结果页**（`o2-brunch/f043`）只在带面写一行「已确认 · 已成局 / 全员到齐，票根已出」，下面约 60% 是空白纸，票根要再点「查看票根」才出现——这是本流程最该有分量的一刻；**待赴约票根**（`v-deep/f007` 外百老汇）票下面 45% 空白，没有联系信息、没有「待赴约」状态说明。
2. **中文**：字阶少而清楚（标题 30→18、带内局名 22 / 15、元数据 14 / 13、组名 13、状态 13 粗），行宽用满 346px，第二条起正文不低于 13px；两行局名在带面按「·」断成两行（`v-deep/f006`「公园慢跑 3K · / 跑完喝咖啡」，行尾留「·」，可接受）。没有胶囊泛滥、没有低对比灰字密布（浅紫带上的 13px 次级字 #535b70 可读）。底部导航半透明，下面一行局名与时间清楚透出、和导航文字叠在一起（`v-home/f001` 底部）。手机内出现评审语言「本轮不可点」「账户级记录页不在本次范围」（草稿行、历史、空态按钮，共 8 处），任务书要求范围说明放手机外。
3. **表面与光**：色带不透明、无阴影，深度逻辑统一；没有噪点、堆渐变、玻璃模糊替代关系（落日环境下首条带是三段线性渐变 #A8451F→#9A3F55→#64489A，属于有表现力的颜色，不算堆渐变）。冲突点在**固定物件与带面的关系**：V27 主 CTA 的浅蓝玻璃高光胶囊直接压在 #B8325A 深莓红（棉糖）/ #AE4110 焦橙（光晕）上，红蓝 / 橙蓝互补振动，像贴片（`v-home/f001,f003`）；对照 C04 把同一 CTA 放在浅色凹槽里（`v-c04/f001`）。首条带在棉糖下是 #B8325A 而不是命题写的棉糖粉 #E65C7E（为白字对比加深，可以理解），结果读起来更像「警示红」而不是「期待见面」——是否接受需要用户看图裁定。
4. **深层页是否同一构图**：是。详情 = 该带变成头部面 + 原局卡（V27 中档 212 宽）+ 事实行 + 成员蓝带；票根 = 带面 + 纸上原票根；管理 = 带面 + 申请红带 / 成员蓝带 / 安排灰带；历史 = 墨色 / 灰色带面；弹层 = 带色帽 + 纸面。没有退回默认面板。但见 6、7 两条的环境与半收拢问题。
5. **关掉动画后**：静态构图完全靠色块与字，不依赖动画成立（rm 终态见 §2 / §4）。
6. **与 C04 对照**（`v-c04/f001,f002` vs `v-home/f001,f005`）：不看名字能分辨——C04 是每场一张圆角叠纸、颜色来自局卡、有接触阴影；C08 是每组一条直角整宽色带、颜色来自意图、无阴影、行间白线。
7. **固定物件**：局卡详情中档 212×265、弹层大档 296×370（`v-deep/f001,f021`）；票根面宽 258、副券在（`v-deep/f006`）；出席章约 64px、散场章卡约 250 宽（`v-deep/f010,f016`）；主 CTA 280×48 原构造；页头 30→18 连续收拢（§2 第 1 条实测）。票根下方到页脚 CTA 只有约 70px，原件要求副券坠落区纵向 220px 内无文字 / 按钮（`baseline-rituals.md` §9），见 §2。

**环境「固定并忠实继承」核对**（主负责人点名项）：环境本身是共享原件（`JU.shared.skins.mount`，C08 没有覆盖样式），三环境首页都能看到。但把环境换成纯品红后量露出面积（`v-env/ks-env.png`，`tools/envfrac.py`）：首页参加者 18.4% / 局主 18.7%（只剩页头和 6px 带缝）；**详情、票根（待撕 / 待赴约）、管理、出席 全部 0.0%**——深层页的带缝也被不透明底色填掉（命题写的「带间 6px 缝也透出环境」在深层页不成立）；历史 42% / 局主历史 76% / 空态 74%（内容少、下面空着）。结论：**深层页把三套环境完全盖掉**，切换环境时深层页只剩首条带色相变化。
