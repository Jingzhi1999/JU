## §2 功能与动效发现（按严重度；每条：现象 / 复现 / 截图 / 建议修法）

13 项操作全部用真实点击 / 拖拽 / 滚轮 / 键盘做完（jump 只用于 §1 的静态截图和对照）；1× 段落全部在 1 分钟负载 < 8 时录（各段负载写在对应目录 `log.json` 的 `load` 字段）。`o1b-role-memory`、`o3-run3k-tear` 两次运行时负载 11–14，这两段帧只用于功能判断，运动结论用低负载重录的 `o1c-role-motion`、`o3c-tear-lowload`。**没有发现 blocker**：每条核心流程都能走到终态。

### major

1. **深层页把三套环境完全盖掉。** 现象：详情 / 阅读 / 票根（待撕、待赴约）/ 管理 / 出席的环境露出 0.0%，深层页的 6px 带缝被不透明底色填掉，换环境时深层页只有首条带色相在变；首页也只剩 18%（页头 + 带缝）。复现：任一环境进任意深层页；量法见 `v-env/`（环境换纯品红后数像素，`tools/envfrac.py` 在 scratchpad）。截图：`v-env/ks-env.png`。修法：深层页底层改透明、让带缝和面板四周透出环境（命题本来就写了「带间 6px 缝也透出环境」），或在带面与纸面之间留一段环境光；首页考虑让第一条带以外的带不全宽贴满。
2. **成局结果页大半空白，票根要再点一次才出现。** 现象：阅读到末尾 → 确认入局 → 处理中 → 带面只写「已确认 · 已成局 / 全员到齐，票根已出」，下面约 60% 空白纸，唯一按钮「查看票根」；点了才进入票根面并开始打印。复现：参加者首页 →「阅读并确认」→ 滚到末尾 →「确认入局」。截图：`o2-brunch/f043`、`o2b-print/f001`。修法：确认成功后直接在该页（或自动转入票根面）出票打印；至少让结果页带出局卡 / 票根占位，不要空着。
3. **重新进入「待赴约」票根页时联系信息消失。** 现象：外百老汇（已加微信待赴约）票根页只有一张已撕的票，下面 45% 空白，没有局主微信、没有「已加微信 · 等这次见面」、页脚空；而刚在公园慢跑上点完「已加微信」时同一页是有联系行的（`o3-run3k-tear/f088`）。复现：首页点「外百老汇小剧场」。截图：`v-deep/f007`、`o5-leave/f056`。修法：going 态票根面保留联系行（账号、复制、已加微信状态）与窗口期说明。
4. **短内容深层页停在半收拢页头，标题与元数据重影。** 现象：内容只比屏高一点的页（如「看展搭子」出席页，可滚约 45px），滚到底后页头停在 p≈0.5：标题已上移，三行元数据仍以约 40–50% 透明度留在标题下面，形成重影的稳定态。复现：局主首页 → 看展搭子 → 滚到底。截图：`v-deep/f017`（真实滚轮复测见 `o9b-misc/`）。修法：元数据在 p≤.35 内淡完或整体随面一起收起；或可滚距离小于收拢区间时把页头吸附到 0 / 1。
5. **退出 / 拒绝改期后打开的历史页沿用旧分组的颜色和面包屑。** 现象：外百老汇「已退出」的历史页是蓝色带面、面包屑「就快见面」；Livehouse「拒绝改期」的历史页是红色带面、面包屑「要你回应」（同类的深夜拉面「已取消」是灰色「未成行」）。复现：票根面「去不了了 → 确认退出 → 燃烧 → 查看退出结果」。截图：`o5-leave/f095`、`o4b-decline/f044`、对照 `v-deep/f012`。修法：history 表面一律用 closed 色调（燃烧结果那一刻带面已经抽成灰色，历史页应接着灰色）。
6. **关键帧对 C08 自己的运动不起作用。** 现象：签名路径（「审核申请」→ 带展开进管理）进行中按「暂停」后拖关键帧 0→100，画面完全不变；审核通过落定后直接拖关键帧，控制器确实进入重播（`last: fx:invited`、paused、scrub 100），画面也不变。只有燃烧接了 `seek`（`o12b-burn-scrub` 0→100 正确从完整票烧到灰烬）。源码里没有任何 `.scrub` 规则。复现：见 `o12-scrub/log.json`。截图：`o12-scrub/ks-scrub.png`、`o12b-burn-scrub/ks-burn-scrub.png`。修法：给带展开 / 收回、审核结果行、草稿收起 / 恢复、角色 / 分区切换补 `.scrub` 规则（mixin 已负责把 currentTime 归零）。
7. **「阅读并确认」与「查看票根」的进入穿过一帧完整详情页再叠化。** 现象：点首页 CTA 后第一帧就是整页详情（局卡、事实行、成员带），随后阅读层以约 300ms 叠化盖上，局卡与约定正文双重曝光；「查看票根」进入票根面时同样闪过详情页。复现：参加者首页点「阅读并确认」（0.5× 更清楚）。截图：`o2-brunch/ks-enter-read.png` f002–f006、`o2b-print/ks-05-read.png` f059–f066、`o2b-print/ks-print.png` f003。修法：从首页直推 read 时不要先画出插入的 detail（或让它停在带面收拢态），由带直接展开成阅读层。
