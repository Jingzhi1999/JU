# 限制与未验证项

这一页只写真实存在的限制：哪些地方因为不改原件而受限、哪些数字只在本机无 GPU 环境测过、哪些是演示假设而不是产品政策，以及最后留给你判断的设计决定。

## 1. 原件带来的限制（为保持原件逐字节不改，未加接口）

- **出票**（V27 原件 `JuPrint`，2.3s）用 `performance.now` 计时，没有暂停 / 定位接口。评审面板的「暂停」和关键帧滑杆对出纸不起作用，只能用「重播」重看；出纸也只认系统的「减少动态」，不认面板里的同名开关。
- **燃烧**（`JUNativeBurn`）可以暂停和定位。原件拖到终点只置完成、不回调；落定由我们自己的包装层补上：暂停中拖到终点先不落定，松手后落定。
- **出席章**依赖 WebGL2。没有 WebGL2 时只显示原件的平面图，没有降级的 DOM 盖章动画。
- 燃烧原件在手机高度 < 720 时的布局预飞没有并入复用件；各方案按自己的布局保证原件周围的空间。
- 玻璃包局卡没有照片时，显示原件的条纹占位和 PHOTO_0n 字样；局卡原件里的占位文字对比度为 4.09:1。
- grain 卡包的大字是英文名（如「POKER 101」），中文名只在卡底 8.6px，这是 V27 原卡包版式。
- V27 主按钮白字的对比度是 2.39:1，来自原件构造本身。

## 2. 只在本机测过的数字

所有截图、录帧和计时都在 4 核、无 GPU 的无头 Chromium（软件栅格）里完成；录运动帧时 1 分钟负载都 < 8。

- 点击到出纸开始约 0.4–1.5s，其中页面切换约 0.4s，其余是本机栅格化和 WebGL 准备；散场 08 场景首次挂载约 1–2s，等待期各套只显示票位 / 卡位轮廓。
- 帧率在 12–66fps 之间，散场场景最低。有 GPU 的真机上，等待时长、余烬粒子（多为 5px 左右）和 1× 节奏都需要实机复看。
- 原生日期 / 时间控件跟浏览器语言走：截图时浏览器以中文启动，显示「2026/12/24 · 19:30」；在别的语言环境下，弹出的选择器会不同。

## 3. 评审面板的已知怪处（不影响产品画面）

- 导航类动效的「重播」会先播返回、再播进入。
- 落点高亮还没走完就拖关键帧，冻住的是落点而不是重播。
- 关键帧滑杆只驱动各套自己的转场和燃烧原件；出票见 §1。

## 4. 演示假设（不是产品政策）

预留 6 小时、撕票后 8 小时内联系、散场后 24 小时关闭联系方式、每年 4 次主动退出、容量含局主、全员确认才成局出票，都是演示用的数值，没有确认为产品政策。R9 的不同口径（每位确认即出票、局主年度改期 / 取消额度、拒绝改期与主动退出同为 exited 等）只记录、不采纳，见 `my-r2/spec/baseline-r9.md` §B。演示时钟固定在 2026-12-17 15:00（纽约时间），面板可以推进时间来检查到期、跨日与窗口关闭；演示日期不冒充实时日期。

R3 没有上传，开局侧的共有语言只能从 V27 与 R9 交叉核对。R9 的「我参加的」没有数据写入路径，参加者侧动作（票根、撕票、联系、候补、撤回 / 退出、改期答复）在 R9 没有前例，以 V27 的票根实现为准。

## 5. 字体

内嵌 10 个家族、25 个字面，全部是 SIL Open Font License 1.1（Google Fonts 静态 TTF，经 fontTools 子集化为 WOFF2）。子集包含十套源文件里出现的全部字符，再加 GB2312 一级常用字；家族、字重与大小的逐项记录见附录「字体」。断网打开时，手机内任何字体都不回退到系统字体（离线检查逐项核对）。

## 6. 没有做到或没有实测的

- 没有真机、真实触屏和有 GPU 的设备；手势只用鼠标拖动和键盘等价入口验证。
- 读屏只核对了焦点顺序、按钮标签和弹层的焦点进出，没有用真实读屏软件走完整流程。
- 360 / 375 / 430 宽、115% 文字、软键盘和安全区都用评审面板的模拟检查过，不等于全部机型。

## 7. 留给你判断的设计决定

以下都是主负责人或复核在过程中做出的决定，或复核明确留给用户的观感问题，没有替你拍板。

| 方案 | 需要你看的地方 |
|---|---|
| 全部 | 每套最终的整体视觉与 1× 动效观感；三套环境在真机上的色光 |
| C01 左轴 | 「参 · 发」角色钮的可发现性；grain 卡以英文名为主名 |
| C02 人先 | 取消这局的分量够不够；进详情、票根与管理时点中的人物簇放大飞入名单、下一页以簇为圆心揭开，这个读感是否成立；「较多」变体滚到深处会不会读成通讯录；确认后阅读层滑回顶部让状态行说出结果 |
| C03 双窗 | 窗底「硬边」切过半行字，读作纸压纸是否可以；白窗深层页 .82 半透在真机上的色感；取消作废的分量 |
| C04 叠层 | 首页局卡只露约 42px；凹陷 CTA 托盘与黑色「发出邀请」；返回改成两拍淡出淡入后，原来「纸收回纸带」的签名返回动作没有了，签名只留在打开时纸从纸带长出 |
| C05 大面 | 色面改成透出活环境的纱之后，「大面」的分量比初稿轻（棉花糖环境下最轻）；面上字阶定为时间 34 / 局名 26 |
| C06 字排 | CTA 下的全宽色光带；「局名不动」改为「放得下时不动，否则只移到需要的距离」 |
| C07 下盘 | 盘内块交接改为同一帧换手后，盘的升降仍在、块之间没有了「空盘」那一拍；进详情时局卡在盘升起之后约 0.45s 才画出（本机），之前只有卡位轮廓 |
| C08 色带 | 带内 CTA 的白承托环与首条带的配色（光晕环境下蓝 / 橙最冲）；页头收拢后点标题回顶才能切角色 |
| C09 地点 | 出纸口用原件矮屏值 24px（主线 84px）；阅读层页题保持「参加约定」、局名作首行 |
| C10 中轴 | 余烬粒子 5px；深层页 toast 的位置 |
