# C07「下盘」· 动效与视觉实现记录（阶段 2）

构图一句话：底部一块深墨「盘」（#14161F，一整张刚性的全高纸板，停靠时只露出顶部 `--th`）放**这一刻该做的那一件**；列表在盘上方的环境色光里流动。进入详情 / 票根 / 历史 / 阅读层时盘整张升满屏，返回时整张落回；进入「管理这局」时盘不升，**盘就是动作区**，上方列表换成名单。停靠高度随内容（`--thc` = 盘内当前块的实测高度 + 56px 导航，最小 160），盘内永远没有空档。

时长一律 `calc(Nms * var(--k))`（`--k` 1 = 正常，2 = 0.5× 评审速度，减少动态时 `.app.rm *` 全部 1ms）；JS 计时走控制器 `after / afterKey / holdKey`。原件仪式（打印 / 撕 / 联系 / 燃烧 / 盖章 / stampFace）的时长、曲线、尺寸不改。证据：`my-r2/evidence/C07/stage2/motion-*`（CDP 截屏流，正常速度；环境引擎渲染后暂停；只在 1 分钟负载 < 8 时录，开始 / 结束负载写在各目录的 `load.txt`）。

## 命题与数据的差异（记录，不改数据）
命题把「成局出票」写成之后就「就快见面」。数据（`ju-data.js` derive.joined）里出票后的 `tear` 仍属 **act（要你回应 · 待撕票）**，`contact` 也是 act（待联系）；只有撕票并自报加微信之后的 `going` 才进入 **soon（就快见面）**。C07 按数据画：成局出票 → 盘内的「先处理这一件」变成该局的「待撕票」，就快见面只在撕票 + 已加微信之后出现。

- **字体角色与字阶**（Noto Sans SC，数字 Archivo）：首页标题 30/600 → 收拢 18；升起页标题 30 → 18；盘内 lead 标题 24/600（两行省略 + balance）、表单 / 纸条标题 22/600；列表行标题 15/500；辅助 13–14；盘标签 13；倒计时 Archivo 16/500 等宽数字；CTA 15/500（V27 原件 280×48）；票面 / 局卡沿用票根原件字阶（标题 20/600、时间 Archivo 28/700、品牌 Space Mono 13）；章面标记 Space Mono 12；最小字号 12（widths 实测）。
- **行宽实测**（390 宽）：列表行标题 346px（360 → 316，430 → 386）；盘内标题 346px；CTA 280×48；纸条 346×96（姓名区 249 + 打孔副券 96，章面 64px 圈径）；局卡 / 票根纸 258px；草稿 / 历史局卡 258px 居中。

- **局卡**：凡是「这局本身」出现的地方（完整局卡、局主取消、没有票的历史：审核未通过 / 撤回 / 预留到期 / 放弃预留 / 退出候补 / 没留住）都是 V27 局卡原件：`JuFilm.paintCard`（ju-paper-film.js，720×900，与盖章场景用的同一张卡）画在 V27 正面壳里（ju-card.css：圆角 13、1px 内描边、上下打孔），V27 中档 212×265（directions §0.3 只用 V27 档；详情、历史、盘内局卡层、取消燃烧一致，复核 M4）；没有票的历史在卡上压一枚事实章（「这次没留住」「预留已到期」…）。字体由 C07 自己按卡面文字加载已声明的字族（含主负责人 10-29 补进内嵌字体的 Zhi Mang Xing 400，手写字是真字体；上限 1.5s），不走 `JuFilm.loadFonts`（它等全部字族声明）。草稿不是局卡：用票纸画，缺的字段留空位。
- **光源 / 表面**：环境光（skins 引擎）只在盘上方；盘是不透明墨面，只有顶边 1px 内高光 + 向上的软影；纸（票根、局卡、出席纸条）是盘里唯一的浅色物件，`mix-blend-mode:multiply` 的章只落在纸上或浅色列表上；第二层弹层是更浅一档的墨（#1D2130），不用白纸。
- **页头收拢**：控制器写 `--hc`，概念只用 `calc()` 插值（无 JS 改样式），收拢不改变滚动容器高度；列表底部留白 = 盘高 + 28px，最后一行总能滚到盘顶之上。

## 一个仍可能失败的设计判断与检查
**判断：盘高跟着内容走。** 盘内永远没有空档（阶段 1 的 50–60px 空带消失了），代价是盘和列表的分界线会随内容移动：回执、表单、局卡燃烧、角色切换都会让整张墨板滑动 320ms。可能失败在：连续操作（逐人记出席、连续审核、时钟连跳）时分界线来回动，读列表底部的人会觉得盘在「呼吸」，或者行被盖住又露出。
**我如何检查**：① 回执改为**替换标签行**（同一行高），连续审核 / 记出席 / 时钟回执不改盘高（`flow-enter-operate-return`、`motion-m9-attendance`、`clock/` 帧里分界线不动）；② 盘高只在块类型变化时变（lead ↔ 表单 ↔ 出席台 ↔ 结果），每次都用同一条 320ms 曲线，录屏逐帧看没有跳变、没有黑帧（M6 曾有一帧整屏变黑：根节点与表单块重名 `c07-form`，根节点吃到了表单的入场动画——已改名 `c07-formon`，`probe` 实测首帧亮度恢复）；③ `reveal` 改写成按盘顶判断，返回原行 / 跳到下一位都落在盘顶之上；④ 列表底部留白 = `--th` + 28px，`widths` 在 360/115% 下最后一行仍可滚出。若用户验收仍觉得「呼吸」太多，退路是把表单类（改时间 / 取消 / 散场）改成固定的「半盘」高度。

## 复核第 1 轮（10-29）改了什么

- **M1 成局**：阅读层停在结果与「查看票根」，不自动跳；交换（阅读层 → 票根）改为新页带墨底在旧页之上淡入 220ms，旧页留到被盖住（`motion-m8-print`）。
- **M2 交接不空盘**：所有块的进入都从可读的透明度开始（换块 .25、表单关闭 .35、离场 110ms 与进场交叉），角色 / 分区切换时列表窗格从 .3 接手（不再一帧替换）；被点的那一行在盘升起、盖住它之前一直亮着，返回时落点直接从「亮着」开始淡出（`.is-going` → `.is-landing.from-going`）。
- **M3 参加者详情**：从盘的构图长出来——V27 局卡原件（212×265）在上，时间地点一行，和盘里一样的座位点 + 计数，参加约定一行摘要（要确认时点了进阅读层，其余就地展开三组），不再是成员表 / 约定表。
- **M4 局卡档**：全套只用 V27 中档 212×265；取消燃烧把原件纸裁到 212（燃烧按纸自身尺寸取样）。
- **M5 暂停 / 关键帧**：盘的升起 / 下落、列表后退、遮罩、页面换入、首页 ⇄ 管理、盘内交接全部改成 keyframes（静态规则给终态），`.app.paused` 冻结、`.scrub` 规则按各族时长（升 340 / 降 320 / 管理 260 / 页 320 / 交换 220 / 交接 300ms）拖帧；盘的高度变化用 WAAPI 从「此刻位置」到新位置（320ms），暂停 / 关键帧由 `_syncTrayClock` 接管；燃烧（退出、历史、局卡）在暂停时 pause、继续时 resume、关键帧 seek。**出票原件（print.js）没有 pause / seek 接口，暂停对出纸不起作用——共享层的缺口，已报。**
- **小项**：状态列的时效不再截断（放不下就换到第二行），盘内 meta / 座位计数 / 提示最多两行（m1）；标题按词断行（keep-all + 「·」后断，m2）；手机里不再有「本轮不可点 / 不在本次范围」，入口文字留在原位、不可点（m3，见下）；短列表在滚到底时页头能完整收到 18（尾部补足 96px 收拢距离，m6）；「要你回应」改用自己的紫色（--st-due），错误红只给失败（m7）；撕票失败行预留高度，票根不动（m9）；回执不再以「 · 」开头、结果不重复页头、草稿删空是「草稿都清空了」（m10）；盘里局名可点，进它自己的详情（m11）；改时间后新时间在页头与盘里「到达」（560ms，m12）；时钟对别的局的变化用 toast 说，盘的标签行只说这一件（m13）；页底动作上方留足空间（m14）；散场印记起步前，卡位上已是同一张卡面（m16）；盘升起后首页 inert、焦点到返回键，回来落到原行（m17）；历史 / 草稿只有一两条时，列表的收尾说明落在盘上方，盘里是分组计数（m18）；取消先抽色再燃烧（m19）。
- **补充**：盘升起时首页 inert、`role="button"` 的行对 Enter / Space 像按钮一样响应（键盘可以打开行）；分区 / 角色切回时恢复的滚动位置不再被旧盘高钳住（原因在 C07：列表底部留白跟着盘高，盘高在切换后才量，现改为量到就写 `--thc` 并补回位置，m20，不是共享层）；局主侧候补补位时，补进来的那一行「到达」（900ms 由 .3 淡入并带一层亮底，附录）；页头副标题随收拢更早淡出（hc × 2.6）。
- **范围外接缝（画面外说明）**：查看我的记录 / 我的举报与记录（账户级页面）、继续编辑草稿 / 再开一局（开局模块）、查看进度、底部「找局」「开局」——这些在手机里只保留文字与位置，不可点，不再写说明。

## 复核第 2 轮（10-29 晚）改了什么

- **交接分两拍，不在原位交叉**：凡是两块内容在同一处换手——盘内 lead ⇄ 升起的页、页 ⇄ 页（详情 → 阅读、阅读 → 票根）、首页 ⇄ 管理（上半区与盘内块）、盘内块 ⇄ 表单——离开的一方 80ms 内退到 0，到来的一方 80ms 起进入（200–220ms）。盘的墨底、导航、环境始终在，所以没有空屏；任何一帧都不会有两段字叠在同一位置。到来一方的淡入放在块内一层 `.c07-hv` 上，块自己的换入动画不会被打断重启。逐帧采样（`review-r2/overprint-*.json`，rAF 里比每段可见文字的位置与实际不透明度，盘按不透明计）1× 与 0.5× 都是 0 处叠印。
- **环境在每一页（directions §0 第 10 条）**：升起的页不再是整页深墨——页头（返回、标题、状态）留在环境上，盘从页头下沿开始（`--upgap` = 安全区 + 150px），列表在盘升起的 80ms 内让开、落下时 80ms 起回来；深层页（详情七态、票根、阅读层、候补门、草稿）直接露出环境 15.9–16.7%、透过半透明面再看到 0.8–1.3%，首页 / 管理 / 历史 / 空态 56–76%（`review-r2/env-probe/count.json`，阅读层与候补门不是跳转状态，由点击进入后同样替换环境测得）。
- **取消燃烧的终态由 state 决定**：三处燃烧（退出 / 拒绝改期的票根、历史的票根、局主取消的局卡）都以原件的回调或句柄的 promise（先到者）落定；共享句柄在拖到终点后自己补上落定（暂停中松手 resume 时、未暂停下一帧），本套不再有自己的保持计时。新构建实测：暂停 → 关键帧 40 / 100 / 30→90→10 → 释放，分别在 5.7s / 5ms / 5.9s 后落到「这局已取消」；退出燃烧 60 → 释放，2.1s 后空舞台 + 「联系方式已关闭」（`review-r2/burn-terminal.json`）。
- **矮屏的票根**：盘从页头下沿开始，矮屏（高 < 839，安全区模拟下 < 903）放不下原件 84px 的出纸口留白和下方的 CTA，副券会滑到「撕开票根」下面——按原件自己的矮屏值（print.js：24px）收出纸口留白，票与副券整张露在 CTA 之上（360×780：票底 577 / CTA 顶 606）。
- **回执 toast 随盘走**：盘停靠时高度变化（WAAPI 320ms）期间，toast 不再先到终位、压在还没收回的盘字上（改时间确认那一帧曾叠在「周五 12.25 · 19:30 · …」上）——toast 叠加同一段位移随盘一起落位，暂停 / 关键帧与盘同钟（`fix-r2/toast-follow.json`：1× 与 0.5× 均 0 帧相交；`fix-r2/motion-m7-reschedule`）。
- **出席更正与证据目录**：更正后焦点留在被更正的那一行（见 M9）；本轮之后的新录制都在 `my-r2/evidence/C07/fix-r2/<名字>/`，已提交的 stage2 证据不再删除或覆盖（`motion-m7-reschedule` 是唯一一份原地重录的）。
- **m18**：历史或草稿只有一条时，用「只有这一件」的构图——列表区一句说明，这一条就是盘里的那一件（标题、时间地点、状态，「查看这局 / 查看记录 / 打开草稿」，草稿还能在盘里删除）；两条以上照旧是列表 + 盘里的分组计数。草稿摘要仍是票面样式 258×226（不是局卡）。
