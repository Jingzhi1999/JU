# C04「叠层」· 动效与视觉实现记录（阶段 2）

构图一句话：首页是一叠**不透明的纸**。每张纸的颜色来自它那张局卡的 pack，在 OKLab 里降饱和到同一族；最上面一张（「这一场」lead）展开约 260px，局卡原件斜插在它背后、露出卡头；其余每张只露 70px 的纸带（局名 · 状态 / 日期 · 时间 · 地点）。点哪张，哪张纸就长成页面（详情 / 票件 / 管理 / 历史），但只长到页头之下：页头（返回、局名、meta、弱操作）和首页的页头一样，留在活的环境上（规则 10）。返回时纸沉回原槽。状态变了的纸（例如 Livehouse 接受改期后进「就快见面」）先停在旧槽，首页停稳后再滑到新槽。

时长一律写成 `calc(Nms * var(--k))`：`--k` 为 1 是正常速度，为 2 是评审用的 0.5×。减少动态时 `.app.rm *` 全部 1ms，`after()` 计时归零。行为全部来自 `this.ctlVals()`：先写数据，再放动画。动画进行中的输入由共享 nav 相位接住（enter / in / exit / idle，非 idle 时不受理第二次 go）。原件（局卡、票根打印 / 撕 / 联系 / 燃烧、出席章、V27 CTA / danger / back pill）只调用，不改它们的表面。

## 关键视觉参数（390 宽实测，fixes/after 日志）

- **字体角色**：Noto Sans SC 用于中文；Archivo 用于数字和拉丁字母；局卡原件用它自己 pack 的字体。最小字号 12px（widths 检查）。
- **字阶与实测行宽**：
  - 首页标题 30/500，收拢后 18。
  - lead 纸局名 24/600，最多两行（balance + keep-all），行宽 249–279px，约 10–12 字；meta 14/400，行宽 277–333px，约 20–24 字。
  - 纸带局名 17/600，单行省略，行宽 203–248px，约 12–15 字；纸带 meta 13/400，行宽 184–220px，约 14–17 字；分组标签 12/500，字距 .05em。
  - 页面标题 30/500，最多两行（收拢后 18），行宽 201–314px，约 7–10 字 / 行；页 meta 14/400，约 17–23 字。
  - 管理说明 13/400，338px，约 26 字；确认层正文 14/400，350px，约 25 字；票根标题（原件）20/600，134–165px，约 7–8 字。
  - 长内容变体（b-long）：纸带局名按 269px 的盒子单行省略，lead 纸两行。
- **色板**：纸色是 pack 主色在 OKLab 里降饱和后的结果。
  - 浅纸：C ≤ min(0.8×, 0.05)，L ≤ 0.90。invite #e6ddca，riso #b8bcd4，acid #d8e4bf。
  - 深纸：C ≤ 0.045，L ≥ 0.30。street #5c5041，grain #272c44，mono #5b3e34。
  - 退色纸（取消 / 散场 / 未成行）：C ≤ 0.012，L 浅 0.86 / 深 0.40。
  - 墨色对纸 7.4–13.8:1；次级墨 5.0–5.9:1，退色纸上 4.9–6.6:1。
  - CTA 凹槽 `--pr` = 纸色加 7% 黑（深纸 9%），只用 inset 1px 2px、8% 的阴影，没有暗圈。
- **前景面积与环境（规则 10）**：首页纸叠从 y≈150 起，占满宽度（左右各露 8px 环境）；环境出现在页头带、两侧细缝和组标签行。深页的纸停在页头之下，页头在环境上；票件页上，局色纸露出约 24px 的一条，压在票灰纸之上。env-probe 实测（直接露出 / 透出 %）：首页 j 25.7 / 3.1、h 31.6 / 4.8，空态 69.6 / 22.0；深页 15.3–19.0 / 1.2–1.7（详情 15.3、票根 18.9、待赴约 19.0、改期 18.9、历史 15.6、已取消 15.4、审核 15.7、出席 15.7、草稿 16.1）；局卡弹层 0 / 16.8（透过遮罩）。收拢页头后纸不上移，比例不变。
- **光源 / 表面**：只有一个顶光。每张纸顶边有 1px 高光（浅纸 .55 白，深纸 .13 白），阴影向上投到上一张纸（`0 −10px 24px −14px`）。纸全部不透明，没有毛玻璃，遮罩是唯一的半透明层。章、票、局卡是原件，保持原有表面。
- **页头收拢**：见 M3。收拢只改字号和位置，所以标题行盒高度不变，纸叠不会重排；收拢终点 88px 在长列表上真实可达。

## 一个仍可能失败的设计判断，以及我怎么检查

**判断**：开页时，局名必须始终落在长大的纸上，返回时每一帧都必须有内容。为此做了三件事：

- 共享元素做成纸的子元素，坐标相对纸本身，所以它和纸在同一个合成层、同一套几何里，栅格再慢也会跟着纸一起慢，不会跑到纸外。
- 开页期间去掉滚动容器的 mask；那时滚动在顶部，mask 本来就看不出来，去掉后软件栅格不必每帧重建离屏表面。
- 返回不再飞局名：纸带着被裁剪的内容收回去，最后溶成下面那条真的纸带。

**仍可能失败**：在比本机（无 GPU，SwiftShader，负载 4–7）更慢的设备上，或者刚返回首页就立刻点下一张纸，新页面的首帧栅格可能被推迟。这时开页会整体晚一些出现，但不会压字。另外，阶段 2 中途确实出现过局名飞出纸面、压在别的纸上的帧，冻结取帧看不出这个问题。

**怎么检查**：每次改 M4 都录 1× 实时 CDP 录屏，并且用真实点击，不走索引跳转：

- `fix-r1/cast-1x`：纸带 / 首张 / 滚动后 / 阅读四种进入，以及对应的返回。
- `fix-r1/open-back-k1`：同一路径的逐帧取样。

需要 A/B 判断时，每个变体都在新页面里首开，避免缓存把差别抹掉（`stage2/fixes/m4-realtime-*.jpg`）。
