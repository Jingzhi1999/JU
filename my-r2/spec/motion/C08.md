# C08「色带」· 动效与视觉实现记录（阶段 2）

构图一句话：页头（V27 外层标题 30→18、角色与分区）直接站在 **live 环境色光**上；其下每个意图组一条满宽、不透明、无阴影的色带，带高 = 内容高，带与带之间 6px 缝透出环境。点一条带里的一段（先做这件 / 一行），**那一段带展开成整页**：带色成为页的头部面，头部面下面仍是带（同色延续带放局卡中档、倒计时、席位、时间地点；成员带 JU 蓝；候补带灰紫；记录带浅灰紫），只有需要阅读面的地方（参加约定正文、票根、出席落章、08 散场场景）才是纸 #F6F4F1。返回时头部面收回到它来的那一段，局名一路被带回原位。

时长一律 `calc(Nms * var(--k))`（`--k` 1 = 正常，2 = 0.5× 评审速度；减少动态 `.app.rm *` 全部 1ms）。导航相位来自共享控制器（`motionSpec` fwd 380 / back 320 / swap 280 / role 300），JS 计时走 `after / holdKey`。原件仪式（打印 2300ms、撕、联系、燃烧 B/C、08 盖章、stampFace、V27 CTA、局卡 JuCardV2）的时长、曲线、尺寸、构造不改。证据：`my-r2/evidence/C08/stage2/motion-*`（CDP 截屏流，正常速度；环境引擎渲染一次后暂停；只在 1 分钟负载 < 8 时录，负载写在各目录 `load.txt`）；`step-*`（冻结 + 逐 40ms 定位的验证帧，与负载无关，只用于核对构图，不代表速度）。

曲线：`--tA` = cubic-bezier(.22,.8,.24,1)（出发快、落定慢，用于展开 / 切换），`--tB` = cubic-bezier(.32,.72,.2,1)（返回、收起）。

## 关键视觉参数

- **字体角色与字阶**：Noto Sans SC（400 / 500 / 600）。外层标题与页标题 30 → 18（500，行高 1.05，两行时 text-wrap:balance）；先做这件局名 22 / 600；空态与结果 20 / 500；行局名 15 / 500（两行省略）；时间地点 13（行）/ 14（先做这件、页面）；组名与口径 13 / 500；状态 13 / 500；动作 15（CTA 原件）/ 14（弱动作，下划线）。数字（倒计时、计数、候补位次 56px）用 Archivo tabular-nums。Space Mono / Libre Caslon / Noto Serif SC 900 只出现在原件里（票根、局卡、出席章）。
- **行宽实测**：390 宽时带内正文宽 346px（左右 22px）；360 → 316px，430 → 386px。行局名 15px 一行约 23 字，长标题两行省略；先做这件 22px 一行约 15 字。
- **色板与前景面积**：要你回应 / 待你处理 = 环境主色调深（棉糖 #B8325A、光晕 #AE4110、落日 100° 渐变 #A8451F→#9A3F55→#64489A，白字 ≥ 4.96:1）；就快见面 / 改期中 = JU 蓝 #4553BE（6.49:1）；还在等 / 招募中 = #E8E6F0 墨字；散场 = #2B2F3C；未成行 = #E1DFE6；草稿 = #EFEDE8。首页默认（参加者）色带约占屏幕 70%，第一条带最高。页头在环境上：标题 #14161F，非当前标签 #353a4b（实测 live 三环境 ≥ 4.5，见 `stage2/contrast/`），当前标签墨色 500 + 下划线。
- **光源 / 表面规则**：带不透明、无阴影、无圆角，彼此不叠压；阴影只属于原件（V27 CTA 的蓝光与外环、局卡外壳投影、票根投影、章）。环境只在页头区与 6px 缝、带以外的区域出现；纸只给阅读 / 票 / 落章；根导航 = 90% 纸 + 18px 模糊。
- **页头收拢实现**：页头无底色；滚动容器 `mask-image: linear-gradient(transparent var(--hdb), #000 calc(var(--hdb) + 16px * var(--hc)))`，`--hdb = --sat + 68px + 86px·tz·(1−hc)`，带从页头下滑过时被裁掉而不是被盖住。

## 一个仍可能失败的设计判断与检查

**全空时让三条带以「零高」留在原位（只剩组头、计数 0），而不是给一块空态面板。** 我的理由是：C08 的意义就是「带高 = 数量」，零就该是最矮的带——结构在，用户知道局会出现在哪；空态文字直接站在环境上。可能失败的方式：三条只有组头的色带在空屏上像三个「坏掉的容器」或占位骨架，而不是「此处为零」；落日环境下最上面那条深色带还会把视线拉走。检查：同一状态在三环境与灰度下并排看（`stage2/variants/empty-*`、`stage2/env/`），确认组头文字与「0」在灰度下仍可读、三条带的明度顺序与有内容时一致；再看 M11 的真实路径（最后一件处理完返回）——面收进零高带的组头、计数从 1 滚到 0，零高带是被动作「做出来」的，而不是凭空出现。如果用户仍把它读成骨架屏，退路是只保留第一条带（要你回应 0）并把另外两条并成一行说明。
